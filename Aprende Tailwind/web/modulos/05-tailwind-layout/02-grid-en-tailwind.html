Grid en Tailwind CSS

Módulo 5 · Tailwind: Layout ⏱ 35 minutos

1 · Introducción

CSS Grid es el sistema de layout bidimensional más potente que existe en la web. Mientras Flexbox trabaja en una dimensión (fila o columna), Grid te permite controlar filas y columnas simultáneamente. Es la herramienta definitiva para layouts de página completos, dashboards, galerías y cualquier diseño donde necesites una cuadrícula precisa.

Tailwind traduce cada propiedad de CSS Grid a clases de utilidad con la misma filosofía que viste en Flex. Si ya estudiaste Grid en el Módulo 3, esta lección te resultará una referencia directa y práctica. Si no, cada tabla te guiará paso a paso.

¿Cuándo usar Grid en lugar de Flex?

Usa Grid cuando necesites controlar filas y columnas a la vez. Un dashboard con sidebar + contenido, una galería de imágenes con número fijo de columnas, o un layout de página con header, main y footer. Usa Flex cuando solo necesites controlar una dirección (navbar horizontal, stack vertical de tarjetas).

2 · Teoría

2.1 Activar Grid y definir columnas

La clase grid activa el contexto de cuadrícula. A diferencia de Flex, necesitas definir explícitamente cuántas columnas quieres y de qué tamaño.

Clase TailwindCSS equivalenteEfecto
griddisplay: grid;Activa grid en el contenedor
inline-griddisplay: inline-grid;Grid en línea
grid-cols-1grid-template-columns: repeat(1, 1fr);1 columna de igual ancho
grid-cols-2grid-template-columns: repeat(2, 1fr);2 columnas
grid-cols-3grid-template-columns: repeat(3, 1fr);3 columnas
grid-cols-4 … grid-cols-12repeat(4, 1fr) … repeat(12, 1fr)De 4 a 12 columnas
grid-cols-nonegrid-template-columns: none;Sin definición explícita de columnas
grid grid-cols-3 gap-4 ┌──────────┬──────────┬──────────┐ │ col 1 │ col 2 │ col 3 │ │ (1fr) │ (1fr) │ (1fr) │ ├──────────┼──────────┼──────────┤ │ col 4 │ col 5 │ col 6 │ │ (1fr) │ (1fr) │ (1fr) │ └──────────┴──────────┴──────────┘

2.2 Columnas de tamaños específicos (grid-cols-* con valores arbitrarios)

A veces necesitas columnas que no sean todas iguales. Tailwind te permite definir cualquier fracción o ancho fijo:

Clase TailwindCSS equivalente
grid-cols-[200px_1fr_1fr]grid-template-columns: 200px 1fr 1fr;
grid-cols-[1fr_2fr]grid-template-columns: 1fr 2fr;
grid-cols-[repeat(4,minmax(0,1fr))]grid-template-columns: repeat(4, minmax(0, 1fr));
grid-cols-subgridgrid-template-columns: subgrid;
🔑 El patrón sidebar + contenido

grid-cols-[260px_1fr] crea un layout de dos columnas: la primera de 260px fijos (sidebar) y la segunda ocupando el resto (contenido). Este es probablemente el patrón grid más usado en aplicaciones web.

2.3 Span: hacer que un elemento ocupe varias columnas

Por defecto, cada hijo ocupa 1 columna. Con col-span-{n} le dices a un elemento que se expanda para ocupar n columnas.

Clase TailwindCSS equivalente
col-span-1 … col-span-12grid-column: span 1 / span 1; … span 12 / span 12;
col-span-fullgrid-column: 1 / -1;
col-autogrid-column: auto;
col-start-{n} / col-end-{n}Posicionamiento explícito en líneas de grid

2.4 Definición de filas (grid-rows-*)

Aunque Grid crea filas automáticamente según el contenido, puedes definir explícitamente cuántas filas y de qué altura:

Clase TailwindCSS equivalente
grid-rows-{n}grid-template-rows: repeat(n, minmax(0, 1fr));
grid-rows-[200px_1fr_auto]Header de 200px, contenido flexible, footer automático
row-span-{n}grid-row: span n / span n;
auto-rows-{size}grid-auto-rows: {size}; — altura de filas implícitas

2.5 Espaciado: gap en Grid

Exactamente igual que en Flex: gap-{n}, gap-x-{n}, gap-y-{n}. La diferencia es que en Grid el gap se aplica entre todas las celdas (filas y columnas).

2.6 Alineación en Grid: place-items-* y place-content-*

Grid ofrece un control de alineación más fino que Flex. Puedes alinear tanto el grid completo como cada celda individual:

Clase TailwindCSS equivalenteEfecto
place-items-centerplace-items: center;Centra el contenido de cada celda (atajo de justify-items + align-items)
place-content-centerplace-content: center;Centra el grid completo dentro del contenedor
place-self-centerplace-self: center;Centra una celda individual respecto a su área
justify-items-start / center / endControl horizontal de cada celda
items-start / center / endControl vertical de cada celda (atajo align-items en grid)
🧠 ¿Confundido con place-*?

place-items-center es un atajo que equivale a justify-items: center; align-items: center;. Significa «el contenido de cada celda se centra dentro de ella». place-content-center equivale a justify-content: center; align-content: center; y centra las filas/columnas del grid entero cuando el contenedor es más grande que la suma de las celdas. Rara vez necesitarás place-content-* si tus celdas ya ocupan todo el espacio con 1fr.

2.7 Grid flow: controlar cómo se rellenan las celdas

Clase TailwindCSS equivalente
grid-flow-rowgrid-auto-flow: row; (por defecto: llena fila por fila)
grid-flow-colgrid-auto-flow: column; (llena columna por columna)
grid-flow-densegrid-auto-flow: dense; (intenta rellenar huecos)

5 · Buenas prácticas

6 · Errores habituales

Error 1 — Olvidar grid en el contenedor

<!-- ❌ MAL: grid-cols-3 sin grid no hace nada -->
<div class="grid-cols-3 gap-4">
  <div>Elemento</div>
</div>

<!-- ✅ BIEN -->
<div class="grid grid-cols-3 gap-4">
  <div>Elemento</div>
</div>

Error 2 — No controlar el número de columnas en responsive

<!-- ❌ MAL: 4 columnas fijas, imposible de leer en móvil -->
<div class="grid grid-cols-4 gap-4">...</div>

<!-- ✅ BIEN: mobile-first, columnas progresivas -->
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4">...</div>

Error 3 — Confundir col-span con grid-cols

grid-cols-* va en el contenedor y define la estructura. col-span-* va en los hijos y determina cuántas columnas ocupa cada uno. Son conceptos distintos que operan a niveles distintos.

Error 4 — Usar gap sin definir grid

Al igual que en Flex, gap solo funciona si el contenedor tiene grid (o flex). En un div normal se ignora completamente.

Error 5 — No declarar filas cuando se necesita un layout preciso

<!-- ❌ MAL: el main puede colapsar si hay poco contenido -->
<div class="grid grid-rows-[auto_1fr_auto] min-h-screen">
  <header>...</header>
  <main>...</main> <!-- 1fr asegura que ocupe el espacio sobrante -->
  <footer>...</footer>
</div>

Si no declaras grid-rows-[auto_1fr_auto], el main solo será tan alto como su contenido. El footer no se pegará al fondo de la pantalla. Con 1fr en la fila del medio, el main se expande para empujar el footer hacia abajo (sticky footer).

8 · Reto

🎯 Layout de portfolio con Grid

Construye un layout de portfolio personal usando solo utilidades Grid de Tailwind con los siguientes requisitos:

  1. Header: Ocupa todo el ancho (col-span-full). Contiene nombre, título profesional y una foto de perfil redonda.
  2. Grid de proyectos: 3 columnas en desktop, 2 en tablet, 1 en móvil. Cada proyecto es una tarjeta con imagen, título, tags y enlace.
  3. Proyecto destacado: El primer proyecto ocupa 2 columnas y tiene una imagen más grande.
  4. Skills section: Una sección debajo del grid con grid-cols-2 sm:grid-cols-4 mostrando iconos con nombres de tecnologías.
  5. Footer: col-span-full con enlaces a redes sociales y copyright.

Pista: Todo el layout usa un solo contenedor grid. No anides grids innecesariamente: puedes dividir el espacio del portfolio con sub-grids si quieres, pero es más simple usar un grid plano con col-span-full para secciones de ancho completo.

9 · Resumen

  • grid activa el contexto de cuadrícula. Sin esto, grid-cols-* no funciona.
  • grid-cols-{n} define cuántas columnas de igual ancho (1fr) tiene el grid. De 1 a 12.
  • grid-cols-[...] permite valores arbitrarios: grid-cols-[260px_1fr] para layout sidebar+contenido.
  • col-span-{n} hace que un hijo ocupe n columnas. col-span-full ocupa todo el ancho.
  • grid-rows-[auto_1fr_auto] define filas con alturas específicas. El patrón auto_1fr_auto crea sticky footer.
  • row-span-{n} hace que un hijo ocupe n filas.
  • place-items-center centra el contenido de todas las celdas de una vez.
  • Responsive: grid-cols-1 md:grid-cols-2 lg:grid-cols-4 adapta el número de columnas según el viewport.
  • Grid vs Flex: Grid para layouts bidimensionales (filas + columnas). Flex para layouts unidimensionales (una fila o una columna).
  • Regla de oro: Si te descubres anidando flex dentro de flex dentro de flex, necesitas grid.

10 · Preguntas frecuentes

¿Cuándo usar grid y cuándo flex?

Grid cuando necesitas control simultáneo de filas y columnas (dashboard, galería, layout de página completo). Flex cuando solo necesitas una dirección (navbar, lista horizontal de botones, stack vertical). Si tu layout tiene una cuadrícula mental de filas × columnas, usa grid.

¿Cómo hago un grid que no tenga un número fijo de columnas?

Usa grid-cols-[repeat(auto-fill,minmax(250px,1fr))]. Esto crea tantas columnas de al menos 250px como quepan, y las que están parcialmente llenas se estiran para ocupar el espacio sobrante. Es el patrón ideal para galerías y listas de tarjetas que no sabes cuántos ítems tendrán.

¿Puedo usar grid y flex juntos?

Absolutamente. De hecho es lo más común. El layout principal de la página es grid (sidebar + contenido), pero dentro del contenido usas flex para navbars, tarjetas y stacks. Grid y flex no compiten: se complementan.

¿Por qué mis columnas no miden lo mismo aunque usé grid-cols-3?

El contenido determina el tamaño mínimo de cada celda. Si una celda tiene una palabra muy larga o una imagen sin max-w-full, forzará su columna a ser más ancha. La solución: añade min-w-0 a los hijos para permitir que se encojan por debajo de su contenido mínimo, o usa overflow-hidden en la celda problemática.

¿Cómo hago un sticky footer con Grid?

En el contenedor: grid grid-rows-[auto_1fr_auto] min-h-screen. Header con auto (altura según contenido), main con 1fr (ocupa todo el espacio sobrante), footer con auto (pegado al fondo). Si el contenido es poco, el main se expande y empuja el footer abajo. Si hay mucho contenido, el main crece y el footer queda al final del scroll.
