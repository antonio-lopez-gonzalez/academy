2. Definición avanzada: fr, minmax, repeat, auto-fit

⏱ 35 minutos 📐 CSS Grid 🎓 Intermedio

1 · Introducción

En la lección anterior aprendiste los fundamentos de Grid. Ahora vamos a subir el nivel: las herramientas que convierten Grid en un sistema de layout verdaderamente responsive sin necesidad de media queries. Hablamos de minmax(), repeat(), auto-fit, auto-fill, grid-auto-rows, grid-auto-flow y subgrid.

💡 ¿Por qué necesitas estas funciones?

Sin minmax(), tus columnas son rígidas: o tienen tamaño fijo o son flexibles, pero no ambas cosas. Sin repeat(), escribir 12 columnas iguales es tedioso y propenso a errores. Sin auto-fit, necesitas media queries para cambiar el número de columnas. Estas funciones son las que hacen que Grid piense por ti.

2 · Teoría

minmax(min, max)

minmax() define un rango de tamaño para un track. El track nunca será más pequeño que min ni más grande que max. Es la pieza clave para layouts responsivos sin media queries.

🧩 Analogía: minmax es un acordeón

Imagina un mueble con estantes ajustables. minmax(200px, 1fr) significa: "cada estante debe medir al menos 200px, pero si sobra espacio, que se estire para ocuparlo todo". El estante nunca colapsa por debajo de 200px, pero tampoco desperdicia espacio.

/* La columna mide mínimo 250px, máximo 1fr (todo el espacio sobrante) */
grid-template-columns: minmax(250px, 1fr);

/* Combinado con valores fijos: sidebar mínimo 200px, máximo 300px */
grid-template-columns: minmax(200px, 300px) 1fr;

/* Mínimo 0 permite que la columna desaparezca si no hay espacio */
grid-template-columns: minmax(0, 1fr) minmax(0, 2fr);
⚠️ Cuidado con minmax(0, ...)

minmax(0, 1fr) es diferente de 1fr. Por defecto, 1fr tiene un mínimo implícito de min-content (el ancho de la palabra más larga). Si necesitas que una columna pueda ser más pequeña que su contenido (para truncar con overflow), usa minmax(0, 1fr) explícitamente.

repeat(n, valor)

repeat() evita tener que escribir el mismo valor decenas de veces. Especialmente útil cuando tienes muchas columnas iguales o cuando usas auto-fit/auto-fill.

/* SIN repeat: tedioso y propenso a errores */
grid-template-columns: 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr;

/* CON repeat: limpio y mantenible */
grid-template-columns: repeat(12, 1fr);

/* También puedes repetir patrones */
grid-template-columns: repeat(3, 100px 1fr);
/* Equivale a: 100px 1fr 100px 1fr 100px 1fr */

/* repeat con auto-fit (lo veremos enseguida) */
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

auto-fit vs auto-fill — La magia del responsive sin @media

Esta es probablemente la característica más potente de Grid y la que menos desarrolladores entienden bien. Ambos crean tantas columnas como quepan, pero se comportan distinto cuando hay columnas vacías.

COMPORTAMIENTO DE auto-fill (con 4 items en espacio para 6 columnas): ┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐ │ Item 1 │ Item 2 │ Item 3 │ Item 4 │ (vacía) │ (vacía) │ └──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘ ↑ Columnas vacías OCUPAN espacio COMPORTAMIENTO DE auto-fit (mismos 4 items, mismo espacio): ┌──────────────┬──────────────┬──────────────┬──────────────┐ │ Item 1 │ Item 2 │ Item 3 │ Item 4 │ └──────────────┴──────────────┴──────────────┴──────────────┘ ↑ Las 4 columnas se ESTIRAN para llenar todo
Palabra claveComportamiento¿Cuándo usarla?
auto-fill Crea tantas columnas como quepan. Las columnas vacías mantienen su tamaño mínimo. Cuando quieres que el espacio vacío sea visible (ej. grid con tamaño de celda fijo).
auto-fit Crea tantas columnas como quepan. Las columnas vacías colapsan a 0, y las columnas con contenido se estiran para llenar el espacio. Cuando quieres que los items llenen TODO el ancho disponible. El caso de uso más común.

La combinación mágica

grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

Esta línea, por sí sola, reemplaza docenas de media queries. Le dice al navegador:

  1. auto-fit: "crea tantas columnas como quepan en el espacio disponible".
  2. minmax(250px, 1fr): "cada columna debe medir al menos 250px, pero si sobra espacio, que las columnas se estiren (1fr) para llenarlo todo".

El resultado: en un monitor ancho tendrás 5-6 columnas, en una tablet 2-3, en un móvil 1. Todo sin escribir un solo @media.

🪄 Esta línea deberías tatuártela

repeat(auto-fit, minmax(250px, 1fr)) es probablemente la declaración CSS más valiosa que aprenderás en todo el curso. Resuelve el 80% de los layouts de tarjetas, galerías y grids de contenido. Memorízala.

grid-auto-rows: altura de filas implícitas

Cuando tienes más items que celdas definidas en grid-template-rows, el navegador crea filas implícitas. Con grid-auto-rows controlas su altura.

/* Filas implícitas de 200px de alto */
grid-auto-rows: 200px;

/* Filas implícitas con altura mínima de 150px que crecen si el contenido lo necesita */
grid-auto-rows: minmax(150px, auto);

/* Alternando alturas (la primera implícita 100px, la segunda 200px, y se repite) */
grid-auto-rows: 100px 200px;

grid-auto-flow: la dirección del flujo automático

Controla cómo se colocan los items cuando no les asignas una posición explícita.

/* Por defecto: llena filas de izquierda a derecha, luego siguiente fila */
grid-auto-flow: row;

/* Llena columnas de arriba a abajo, luego siguiente columna */
grid-auto-flow: column;

/* Como row, pero intenta rellenar huecos (puede desordenar visualmente) */
grid-auto-flow: dense;
grid-auto-flow: row (por defecto) ┌───┬───┬───┐ │ 1 │ 2 │ 3 │ ← Se llena la fila 1 ├───┼───┼───┤ │ 4 │ 5 │ 6 │ ← Luego la fila 2 └───┴───┴───┘ grid-auto-flow: column ┌───┬───┬───┐ │ 1 │ 3 │ 5 │ ← Se llena la columna 1, luego la 2... ├───┼───┼───┤ │ 2 │ 4 │ 6 │ └───┴───┴───┘

Subgrid (CSS Grid Level 2)

subgrid permite que un grid anidado herede las tracks (columnas y/o filas) del grid padre. Así los items nietos se alinean perfectamente con los tracks del grid abuelo.

/* Grid padre: define las columnas */
.padre {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* Grid hijo: hereda las columnas del padre */
.hijo {
  display: grid;
  grid-template-columns: subgrid;  /* ¡Misma cuadrícula que el padre! */
  grid-column: span 3;              /* Ocupa las 3 columnas */
}

/* Los items dentro de .hijo ahora se alinean con las columnas del .padre */
📝 Soporte de subgrid

subgrid es parte de CSS Grid Level 2 y tiene soporte completo en todos los navegadores modernos desde 2023 (Chrome 117+, Firefox 71+, Safari 16+). Puedes usarlo en producción.

📝 auto-fill vs auto-fit en e-commerce

Aquí usamos auto-fill en vez de auto-fit porque en pantallas muy anchas no queremos que 3 productos se estiren a 400px cada uno (se verían raros). Con auto-fill, las columnas vacías mantienen su tamaño mínimo y los productos no se deforman.

5 · Buenas prácticas

✅ Qué hacer

  • Usa minmax(0, 1fr) para contenido que puede desbordarse. Si tienes texto largo o imágenes dentro de un grid item, el mínimo implícito de 1fr puede impedir que la columna se encoja. minmax(0, 1fr) lo fuerza.
  • Prefiere auto-fit para galerías y cards. En el 90% de los casos quieres que los items llenen el ancho disponible. auto-fill es para casos específicos donde el espacio vacío debe ser visible.
  • Define grid-auto-rows siempre que uses auto-fit. Si tus tarjetas necesitan altura consistente, grid-auto-rows: minmax(150px, auto) asegura que todas midan al menos 150px.
  • Usa dense solo si el orden visual no importa. grid-auto-flow: dense reordena items para llenar huecos, lo cual puede confundir a lectores de pantalla y usuarios que esperan orden secuencial.
  • Subgrid para alinear contenido entre tarjetas. Si tienes tarjetas con título, descripción y botón, y quieres que todos los botones estén alineados aunque las descripciones tengan distinta longitud, subgrid en las filas lo resuelve.

❌ Qué evitar

  • No uses minmax() con min > max. minmax(300px, 200px) es inválido y el navegador lo ignorará.
  • No anides repeat() dentro de repeat(). repeat(3, repeat(2, 1fr)) no funciona. Usa repeat(6, 1fr).
  • No abuses de dense. Rearreglar visualmente los items puede crear problemas de accesibilidad porque el orden del DOM ya no coincide con el orden visual.

6 · Errores habituales

Error 1: minmax con valores que no cuadran

❌ Incorrecto

/* min > max: el navegador ignora esta declaración */
grid-template-columns: minmax(500px, 300px);

/* La unidad fr en el mínimo no tiene sentido porque fr ya es flexible */
grid-template-columns: minmax(1fr, 500px);

✅ Correcto

/* El mínimo debe ser ≤ que el máximo */
grid-template-columns: minmax(300px, 500px);

/* fr va en el máximo para permitir crecimiento */
grid-template-columns: minmax(250px, 1fr);

Error 2: Pensar que auto-fill y auto-fit son lo mismo

Este es el error conceptual más frecuente con Grid. La diferencia solo se nota cuando hay menos items que columnas potenciales.

/* Con 3 items en una pantalla que permite 5 columnas de 250px: */

/* auto-fill: crea 5 columnas, las 2 vacías ocupan 250px cada una */
grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
/* Resultado: [Item1][Item2][Item3][_____][_____] */

/* auto-fit: crea 5 columnas, las 2 vacías colapsan, las 3 con items se estiran */
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
/* Resultado: [  Item1  ][  Item2  ][  Item3  ] */

Error 3: Olvidar que grid-auto-rows controla SOLO las filas implícitas

Si definiste grid-template-rows para 3 filas, grid-auto-rows solo afecta a partir de la cuarta fila.

.grid {
  grid-template-rows: 100px 200px;     /* Filas explícitas 1 y 2 */
  grid-auto-rows: 150px;               /* Filas 3, 4, 5... (implícitas) */
}

⚠️ Cuidado con grid-row: span en auto-fit

Cuando usas grid-row: span 2 con auto-fit, el algoritmo de colocación automática puede dejar huecos si la tarjeta alta no cabe en el espacio restante de la fila actual. Prueba siempre con diferentes números de tarjetas.

8 · Reto

🎯 Tu reto: Galería estilo masonry SIN JavaScript

Crea una galería de imágenes tipo "masonry" (Pinterest) donde las imágenes tienen diferentes alturas y se acomodan sin dejar huecos. Las reglas:

  • Usa grid-auto-flow: dense para rellenar huecos.
  • Usa grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)).
  • Algunas imágenes deben ocupar 2 filas (grid-row: span 2) y otras 2 columnas (grid-column: span 2).
  • Todas las imágenes deben usar object-fit: cover.
  • Investiga: ¿cómo afecta dense al orden de las imágenes? ¿Es aceptable en este caso?
  • Extra: haz que las imágenes en móvil se muestren en una sola columna.

El objetivo de este reto es que experimentes con dense y entiendas sus ventajas y desventajas de primera mano.

9 · Resumen

📌 Conceptos clave de esta lección
  • minmax(min, max): define un rango de tamaño para un track. El track nunca será menor que min ni mayor que max.
  • repeat(n, valor): repite un patrón de tracks n veces. Evita repetición manual y errores.
  • auto-fit: crea tantas columnas como quepan. Las vacías colapsan a 0 y las ocupadas se estiran.
  • auto-fill: crea tantas columnas como quepan. Las vacías mantienen su tamaño mínimo.
  • Combinación mágica: repeat(auto-fit, minmax(250px, 1fr)) — responsive sin media queries.
  • grid-auto-rows: altura de las filas creadas automáticamente (implícitas).
  • grid-auto-flow: dirección en la que se colocan los items automáticamente (row, column, dense).
  • subgrid: un grid anidado hereda las tracks del grid padre (CSS Grid Level 2).

10 · FAQ — Preguntas frecuentes

¿Cuál es la diferencia real entre auto-fit y auto-fill?

La diferencia solo se nota cuando hay menos items que columnas potenciales. auto-fill deja las columnas vacías con su tamaño mínimo, creando espacio vacío al final. auto-fit colapsa las columnas vacías y reparte ese espacio entre las columnas ocupadas. En la práctica: usa auto-fit para galerías y tarjetas (quieres que llenen el ancho), y auto-fill para grids de tamaño fijo donde el espacio vacío es intencional.

¿Puedo usar repeat() con auto-fit y también con un número fijo?

Sí. repeat(auto-fit, minmax(250px, 1fr)) usa palabras clave en vez de número. Pero NO puedes mezclar: repeat(3, 1fr) repeat(auto-fit, minmax(250px, 1fr)) no funciona. Cada repeat() debe usar o bien un número fijo o bien auto-fit/auto-fill, no ambos.

¿Qué pasa si el contenido de una celda es más ancho que minmax permite?

Por defecto, el mínimo real de un track con 1fr es min-content (el ancho del contenido más largo que no se puede romper, como una palabra larga o una imagen). Si necesitas que la columna sea más pequeña que su contenido (para truncarlo), usa minmax(0, 1fr). Esto es especialmente importante en layouts con texto largo o tablas.

¿Subgrid funciona con auto-fit?

Sí, pero con matices. Si el padre usa repeat(auto-fit, minmax(250px, 1fr)), el número de columnas es dinámico y depende del viewport. El subgrid heredará exactamente esas columnas, sean las que sean en ese momento. Esto significa que el subgrid también es responsive sin hacer nada adicional.

¿Cómo centro la última fila cuando tiene menos items?

Grid no tiene una propiedad nativa para centrar la última fila. Algunas soluciones: (a) usar Flexbox con flex-wrap: wrap y justify-content: center en lugar de Grid. (b) Añadir items fantasma invisibles para rellenar la última fila. (c) Usar :has() y selectores de cantidad para estilos condicionales (avanzado).

¿grid-auto-flow: dense afecta a la accesibilidad?

Sí. dense cambia el orden visual de los items respecto al orden del DOM. Los lectores de pantalla y la navegación por teclado siguen el orden del DOM, por lo que un usuario podría encontrar un orden visual distinto al que está recorriendo. Usa dense solo cuando el orden de los items no sea significativo (ej. galería de imágenes decorativas, no una lista de pasos numerados).
