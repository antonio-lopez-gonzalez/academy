Colores, Tipografía y Fondos

Módulo 4 · Tailwind: Fundamentos ⏱ 35 minutos

1 · Introducción

Si el layout es el esqueleto de tu interfaz, los colores, la tipografía y los fondos son su piel, voz y personalidad. Tailwind incluye un sistema de color profesional con 22 paletas de 11 tonos cada una, una escala tipográfica completa y utilidades para fondos que cubren desde colores sólidos hasta gradientes.

En esta lección dominarás las tres herramientas visuales esenciales que usarás en cada proyecto.

2 · Teoría

Sistema de colores

Tailwind genera colores con la sintaxis: {propiedad}-{color}-{tono}. La escala va de 50 (más claro) a 950 (más oscuro), con 10 tonos intermedios. Las dos propiedades principales son text-{color}-{tono} para color de texto y bg-{color}-{tono} para color de fondo.

<!-- Color de texto -->
<p class="text-red-500">Texto rojo tono 500</p>
<p class="text-blue-700">Texto azul oscuro</p>
<p class="text-slate-400">Texto gris medio</p>

<!-- Color de fondo -->
<div class="bg-emerald-400">Fondo verde esmeralda</div>
<div class="bg-slate-100">Fondo gris muy claro</div>
<div class="bg-slate-900">Fondo casi negro</div>

<!-- Opacidad con barra (/) — sintaxis moderna de v4 -->
<p class="text-red-500/75">Rojo al 75% de opacidad</p>
<div class="bg-blue-600/30">Fondo azul al 30%</div>
<div class="bg-black/50">Negro semitransparente</div>

¿Por qué tantos grises? Porque el 90% del diseño UI son grises. Cada gris tiene una temperatura distinta: slate es frío (azulado), zinc es cálido, stone es terroso. Elegir el gris correcto define la atmósfera completa de tu interfaz.

Tipografía

Tailwind ofrece control completo sobre cada aspecto tipográfico. La escala de tamaños usa text-{size} y cubre desde text-xs (12px) hasta text-9xl (128px).

Fondos y gradientes

Además de bg-{color}-{tono}, Tailwind soporta gradientes con control de dirección y colores:

<!-- Gradiente lineal básico -->
<div class="bg-gradient-to-r from-blue-500 to-purple-600">
  Gradiente horizontal de azul a púrpura
</div>

<!-- Con punto intermedio (via) -->
<div class="bg-gradient-to-r from-cyan-400 via-blue-500 to-purple-600">
  Gradiente con tres paradas: cyan → azul → púrpura
</div>

<!-- Direcciones disponibles -->
<!-- to-t (top), to-tr, to-r, to-br, to-b, to-bl, to-l, to-tl -->
<div class="bg-gradient-to-br from-pink-500 to-orange-400">
  Gradiente diagonal de rosa a naranja
</div>

<!-- Texto con gradiente (truco popular) -->
<span class="bg-gradient-to-r from-blue-400 to-cyan-400
             bg-clip-text text-transparent">
  Texto con efecto gradiente
</span>

6 · Errores habituales

Error #1 — «Mi texto no se ve bien porque usé text-gray-500 sobre bg-gray-100»
Problema de contraste. La escala funciona así: para texto sobre fondo oscuro, usa tonos bajos (50-300). Para texto sobre fondo claro, usa tonos altos (600-900). Verifica siempre el ratio de contraste WCAG (mínimo 4.5:1 para texto normal).
Error #2 — «Puse bg-gradient-to-r pero no se ve nada»
Te faltan from-{color} y to-{color}. bg-gradient-to-r solo establece la dirección del gradiente. Sin los colores, el gradiente es transparente. Siempre necesitas: dirección + color inicial + color final.
Error #3 — «Usé font-bold pero no se nota la diferencia con font-semibold»
Algunas fuentes del sistema tienen poca variación entre pesos. Carga una fuente web con múltiples pesos (Inter, Plus Jakarta Sans, DM Sans) si necesitas variedad tipográfica real. Tailwind no incluye fuentes — solo las declara.
Error #4 — «¿Dónde está el color X? ¡Tailwind no tiene suficientes colores!»
Tailwind tiene 22 paletas × 11 tonos = 242 valores. Si necesitas más, puedes extender la configuración con @theme. Pero honestamente, si 242 colores no te alcanzan, el problema probablemente no son los colores — es la falta de un sistema de diseño definido.

8 · Reto

🎯 Sección de estadísticas

Crea una sección de estadísticas con 3 tarjetas en fila, cada una con:

  • Un número grande con gradiente de color (ej: bg-gradient-to-r from-blue-400 to-cyan-400 bg-clip-text text-transparent)
  • Una etiqueta descriptiva debajo en mayúsculas, pequeña, con tracking ancho
  • Fondo oscuro (bg-slate-800 o similar) en toda la sección
  • Texto claro sobre el fondo oscuro para buen contraste

Pista: Necesitarás grid grid-cols-3, text-transparent bg-clip-text para texto con gradiente, y text-5xl font-extrabold para los números grandes.

9 · Resumen

  • Colores: sintaxis text-{color}-{tono} y bg-{color}-{tono}. Escala 50-950 (claro a oscuro). Opacidad con barra: /porcentaje.
  • Neutros: slate, gray, zinc, neutral, stone. Elige uno principal y sé consistente en todo el proyecto.
  • Tipografía: Control total con text-* (tamaño), font-* (peso), leading-* (interlineado), tracking-* (espaciado entre letras).
  • Alineación y decoración: text-center, underline, line-through, uppercase, capitalize.
  • Fondos: Sólidos con bg-{color}, gradientes con bg-gradient-to-{dir} + from-* + to-* (+ via-* opcional).
  • Texto con gradiente: bg-gradient-to-r from-* to-* bg-clip-text text-transparent. Las tres clases son obligatorias.
  • Familias tipográficas: font-sans (Inter o sistema), font-serif (Georgia), font-mono (Fira Code o Consolas).

10 · Preguntas frecuentes

¿Cómo elijo entre slate, gray, zinc, neutral y stone?

Slate tiene un ligero tono azulado (el más popular y moderno). Gray es gris puro y completamente neutro. Zinc tiene un matiz ligeramente cálido. Neutral es totalmente neutro sin matices. Stone es cálido con toques marrones. Si no sabes cuál usar: slate. Es la elección por defecto más acertada para UI moderna.

¿Puedo usar colores que no están en la paleta de Tailwind?

Sí, con valores arbitrarios: bg-[#bada55] o text-[#ff6b6b]. Pero hazlo con moderación. Si usas un color arbitrario en más de 2-3 lugares, considera añadirlo a tu @theme de Tailwind para mantener la consistencia y tener todos los tonos disponibles.

¿Cómo cambio la fuente por defecto de todo el proyecto?

No se hace con clases de Tailwind. Configuras las fuentes en tu CSS con @theme o @layer base. Luego Tailwind asigna automáticamente font-sans al <body> a través de Preflight. Si estás usando el CDN, puedes poner font-sans en el <body> una sola vez.

Los gradientes con texto (bg-clip-text) no funcionan. ¿Qué hago mal?

Verifica que tienes las 3 clases juntas y en este orden: bg-gradient-to-r from-blue-400 to-purple-400 bg-clip-text text-transparent. bg-clip-text recorta el fondo a la forma del texto, y text-transparent hace el texto invisible para que se vea el gradiente de fondo. Si falta cualquiera de las tres, no funciona.
