Espaciado, Bordes y Sombras

Módulo 4 · Tailwind: Fundamentos ⏱ 30 minutos

1 · Introducción

El espacio es el elemento más infravalorado del diseño. Una interfaz con buen espaciado se siente profesional incluso antes de añadir colores. Los bordes definen límites y jerarquía visual. Las sombras crean profundidad y elevación. Estos tres sistemas trabajan juntos para dar a tu UI una sensación tridimensional y ordenada.

Tailwind tiene el sistema de espaciado más robusto de cualquier framework CSS — una escala numérica consistente basada en 0.25rem que se aplica a padding, margin, gap, width, height y más.

2 · Teoría

La escala de espaciado

Tailwind usa una escala basada en 0.25rem (4px con el font-size por defecto del navegador). Cada valor numérico multiplica esta base. Esto significa que p-4 = 4 × 0.25rem = 1rem = 16px.

Padding: direccional y abreviado

<!-- Padding uniforme en los 4 lados -->
<div class="p-4">16px en los 4 lados</div>

<!-- Padding por eje (x = horizontal, y = vertical) -->
<div class="px-6 py-3">24px horizontal, 12px vertical</div>

<!-- Padding direccional (t = top, r = right, b = bottom, l = left) -->
<div class="pt-4 pr-6 pb-2 pl-3">
  top 16px, right 24px, bottom 8px, left 12px
</div>

<!-- Margin: misma lógica con m-*            -->
<!-- mx-auto centra horizontalmente cualquier elemento block con ancho definido -->
<div class="mt-8 mb-4 mx-auto max-w-lg">
  margen superior 32px, inferior 16px, centrado horizontal
</div>

Espaciado entre hijos: space-y y space-x

A diferencia de gap (que funciona en flex y grid), space-* añade margen entre hijos usando el selector CSS > * + *. Es decir, aplica margen a todos los hijos excepto el primero. Es ideal para contenedores block con listas de elementos.

<!-- Espacio vertical entre elementos -->
<div class="space-y-4">
  <p>Primer párrafo (sin margen superior)</p>
  <p>Segundo párrafo (mt-4 automático)</p>
  <p>Tercer párrafo (mt-4 automático)</p>
</div>

<!-- Espacio horizontal entre botones -->
<div class="flex space-x-3">
  <button>Cancelar</button>
  <button>Guardar</button>
  <button>Eliminar</button>
</div>

Bordes

El sistema de bordes de Tailwind tiene 4 dimensiones independientes: lado, grosor, color y radio. Puedes combinarlas libremente.

<!-- Borde completo: grosor + color -->
<div class="border border-slate-200">Borde de 1px gris claro</div>

<!-- Borde por lado específico -->
<div class="border-t border-b border-blue-500">
  Solo bordes superior e inferior
</div>

<!-- Grosor de borde: border (1px), border-2, border-4, border-8 -->
<div class="border-2 border-red-400">Borde de 2px</div>
<div class="border-4 border-green-500">Borde de 4px</div>

<!-- Bordes redondeados (radios) -->
<div class="rounded">0.25rem (4px)</div>
<div class="rounded-md">0.375rem (6px)</div>
<div class="rounded-lg">0.5rem (8px)</div>
<div class="rounded-xl">0.75rem (12px)</div>
<div class="rounded-2xl">1rem (16px)</div>
<div class="rounded-3xl">1.5rem (24px)</div>
<div class="rounded-full">9999px (círculo / píldora)</div>

Divide: bordes entre hijos

Similar a space-* en concepto, pero en lugar de márgenes añade líneas divisorias entre elementos hijos. Perfecto para listas, menús y tablas sin usar una sola línea de CSS.

<div class="divide-y divide-slate-200">
  <div class="py-3">Elemento 1</div>
  <div class="py-3">Elemento 2</div>
  <div class="py-3">Elemento 3</div>
</div>

<!-- divide-x para divisores verticales -->
<div class="flex divide-x divide-slate-300">
  <span class="px-4">Col A</span>
  <span class="px-4">Col B</span>
  <span class="px-4">Col C</span>
</div>

Sombras

La escala de sombras va de sutil (sm) a dramática (2xl), más sombras de color e inner shadow. Las sombras con color son más modernas y se integran mejor con el diseño.

<div class="shadow-sm">Sombra muy sutil</div>
<div class="shadow">Sombra estándar</div>
<div class="shadow-md">Sombra media</div>
<div class="shadow-lg">Sombra grande</div>
<div class="shadow-xl">Sombra extra grande</div>
<div class="shadow-2xl">Sombra máxima</div>
<div class="shadow-inner">Sombra interior (efecto hundido)</div>

<!-- Sombras de color (más modernas y profesionales) -->
<div class="shadow-lg shadow-blue-500/40">Sombra grande azul al 40%</div>
<div class="shadow-xl shadow-slate-200/50">Sombra gris sutil</div>

<div class="shadow-none">Sin sombra (para resetear)</div>

Anillos (ring)

Los anillos son como outlines pero más flexibles y estilizables. Se dibujan con box-shadow, por lo que no afectan al layout. Son el estándar moderno para indicar foco en inputs y botones.

<input class="ring-2 ring-blue-500">

<!-- ring-offset crea espacio entre el borde y el anillo -->
<input class="ring-2 ring-offset-2 ring-blue-500">

<!-- Combinación típica para inputs accesibles -->
<input class="outline-none focus:ring-2 focus:ring-blue-500
              focus:ring-offset-2">

6 · Errores habituales

Error #1 — «margin-top: 16px no es igual a mt-4»
Sí lo es. mt-4 = 1rem = 16px (con el font-size por defecto de 16px en el navegador). La escala de Tailwind está en rem, no en px. Si cambias el font-size del <html>, los espaciados escalan proporcionalmente. Es una ventaja de accesibilidad, no un bug.
Error #2 — «Puse border-blue-500 pero no se ve ningún borde»
border-{color} solo establece el color. Necesitas también border (para 1px), border-2, border-4, etc. para establecer el grosor. Sin grosor, el color no tiene dónde aplicarse. Siempre: grosor + color juntos.
Error #3 — «space-y-4 no funciona en mi contenedor flex»
space-y-* solo funciona en contenedores block (display: block, que es el default de un div). No funciona en contenedores flex o grid. Para esos, usa gap-*. Si necesitas espacio vertical en un contenedor flex, probablemente lo que quieres es flex-col gap-*.
Error #4 — «Los bordes redondeados no se ven redondos»
rounded-lg es 0.5rem = 8px. Si tu elemento mide 200×50px, 8px de radio es casi invisible. Para ver bien el efecto necesitas un elemento suficientemente grande o usar rounded-xl / rounded-2xl. Y para un círculo perfecto: rounded-full con width = height.

8 · Reto

🎯 Sección de comentarios

Construye una sección de comentarios con los siguientes requisitos:

  • Contenedor principal con padding, fondo blanco, sombra grande, bordes redondeados
  • Cada comentario separado por una línea divisoria (divide-y)
  • Avatar circular del usuario a la izquierda (con rounded-full)
  • Nombre en negrita y fecha en gris claro, separados por un bullet
  • Texto del comentario con leading-relaxed para lectura cómoda
  • Espacio interno en cada comentario con py-* (no pongas padding en el contenedor exterior si usas divide)

Pistas: divide-y divide-slate-100, gap-* para avatar + contenido, text-xs text-slate-400 para la fecha. El padding interno de cada comentario va con py-4 en cada hijo, no en el contenedor.

9 · Resumen

  • Escala de espaciado: basada en 0.25rem = 4px. p-4 = 16px. Sufijos direccionales: t, r, b, l, x, y.
  • space-y-* y space-x-*: añaden margen entre hijos (excepto el primero). Ideal para listas y colecciones.
  • Bordes: border (1px), border-2, border-4, etc. + border-{color}. Bordes por lado con border-t, border-b, etc.
  • Radios: rounded-sm → rounded-3xl. rounded-full para círculos perfectos y píldoras.
  • divide-*: bordes entre hijos. divide-y para líneas horizontales, divide-x para verticales.
  • Sombras: shadow-sm a shadow-2xl. shadow-{color}/{opacidad} para sombras de color. shadow-inner para efecto hundido.
  • Anillos (ring): ring-{width} ring-{color}. Con ring-offset-* para separación del borde. Úsalos en focus states.

10 · Preguntas frecuentes

¿Cuándo uso space-y-* y cuándo gap-*?

gap-* funciona en contenedores flex y grid. Es la opción moderna y recomendada para layouts. space-y-* funciona en cualquier contenedor (incluso display: block) y es útil para listas de contenido donde no necesitas flex/grid. Regla práctica: si el contenedor es flex o grid, usa gap-*. Si es un div normal con una lista de elementos, usa space-y-*.

¿Por qué mis sombras no se ven en modo oscuro?

Las sombras negras sobre fondo oscuro son casi invisibles. Tienes tres opciones: usar sombras de color (shadow-lg shadow-blue-500/20), usar sombras más claras (shadow-slate-700/50), o cambiar el color de sombra condicionalmente con dark:shadow-slate-900/80. Las sombras claras sobre fondo oscuro crean un efecto de «brillo» muy atractivo.

¿mx-auto centra cualquier elemento?

Sí, siempre que el elemento tenga un ancho definido (max-w-sm, w-96, etc.) y sea display: block. Los elementos inline no se ven afectados por mx-auto. Para centrar contenido inline (como texto o imágenes inline), usa text-center en el elemento padre.

¿Cómo quito el borde azul que Chrome pone en los inputs al hacer foco?

Eso es el outline del navegador. Usa outline-none para quitarlo, pero siempre reemplázalo con focus:ring-2 focus:ring-blue-500 u otro indicador visual accesible. Si quitas el outline sin reemplazo, rompes la accesibilidad para usuarios de teclado. Nunca uses outline-none solo.
