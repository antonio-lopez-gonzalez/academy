Conceptos Fundamentales de Flexbox

Módulo 2 · Flexbox ⏱ 30 minutos

1 · Introducción

Flexbox, o CSS Flexible Box Layout, es un módulo de CSS3 diseñado para distribuir espacio y alinear contenido dentro de un contenedor, incluso cuando el tamaño de los items es desconocido o dinámico. Es, probablemente, la herramienta más transformadora que ha llegado a CSS en toda su historia.

Antes de Flexbox, centrar algo verticalmente era una odisea. Los layouts se construían con float, clearfix, display: table y trucos con position: absolute. Cada uno de esos métodos tenía fugas de diseño, problemas de colapso de altura y un sinfín de hacks.

Flexbox llegó para resolver el problema del layout unidimensional: organizar items en una sola dirección, ya sea una fila o una columna. En esta lección vas a entender qué es, cómo funciona y por qué cambió la forma en que escribimos CSS para siempre.

2 · Teoría

El infierno antes de Flexbox

Durante más de una década, los desarrolladores web pelearon con tres técnicas principales para crear layouts:

  • Float + clearfix: Los elementos flotaban a izquierda o derecha y se usaba un .clearfix::after { content: ""; display: table; clear: both; } para evitar el colapso del contenedor. Funcionaba, pero era frágil y propenso a errores.
  • Display: inline-block: Los elementos se trataban como palabras en una línea. El problema: los espacios en blanco entre etiquetas HTML generaban gaps no deseados que había que eliminar con hacks como font-size: 0 en el padre.
  • Display: table / table-cell: Simulaba el comportamiento de tablas HTML. Permitía centrar verticalmente con vertical-align: middle, pero era semánticamente incorrecto y muy limitado.

Flexbox fue propuesto por primera vez en 2009 por la W3C, pero pasó por tres sintaxis diferentes (display: box, display: flexbox y finalmente display: flex en 2012). La especificación alcanzó Candidate Recommendation en 2016. Desde entonces, todos los navegadores modernos lo soportan de forma nativa, incluido IE11 (con prefijos y algunos bugs).

El modelo de caja flexible

Flexbox funciona con dos tipos de elementos:

  • Contenedor flex (flex container): El elemento padre al que se le aplica display: flex o display: inline-flex.
  • Items flex (flex items): Los hijos directos del contenedor flex. Solo los hijos directos participan en el layout flex; los nietos no.

Eje principal y eje cruzado

Este es el concepto más importante de todo Flexbox. Siempre hay dos ejes:

  • Eje principal (main axis): La dirección en la que se colocan los items. Por defecto es horizontal (de izquierda a derecha).
  • Eje cruzado (cross axis): Perpendicular al eje principal. Por defecto es vertical (de arriba hacia abajo).

Regla de oro: cuando cambias flex-direction de row a column, todas las propiedades que dependen del eje principal (justify-content) ahora actúan en vertical, y las del eje cruzado (align-items) en horizontal.

Imagina Flexbox como una cinta transportadora en una fábrica. La dirección de la cinta (flex-direction) determina hacia dónde se mueven las cajas. Puedes hacer que la cinta vaya de izquierda a derecha (row), de derecha a izquierda (row-reverse), o incluso girar toda la fábrica 90 grados (column). Las reglas de cómo se alinean las cajas no cambian internamente; simplemente se aplican en la nueva orientación.

Flexbox es unidimensional

A diferencia de CSS Grid, que es bidimensional (maneja filas Y columnas simultáneamente), Flexbox está pensado para layouts en una sola dimensión: o una fila, o una columna. Cuando necesitas control sobre ambos ejes al mismo tiempo con precisión de cuadrícula, Grid es la herramienta correcta. Cuando necesitas distribuir items en una línea que puede hacer wrap, Flexbox brilla.

3 · Ejemplo mínimo

El caso más básico: tres cajas dentro de un contenedor con display: flex.

HTML

<div class="contenedor">
  <div class="caja">1</div>
  <div class="caja">2</div>
  <div class="caja">3</div>
</div>

CSS

.contenedor {
  display: flex;           /* ¡Activa Flexbox! */
  gap: 1rem;               /* Espacio entre items */
  border: 2px solid #38bdf8;
  padding: 1rem;
  border-radius: 8px;
}

.caja {
  background: #38bdf8;
  color: #0f172a;
  font-weight: bold;
  padding: 1.5rem 2rem;
  border-radius: 6px;
}

Observa lo que acaba de pasar sin escribir nada más que display: flex:

  • Las tres cajas, que normalmente serían bloques que ocupan todo el ancho, ahora se alinean en fila.
  • Todas tienen la misma altura automáticamente (por align-items: stretch, el valor por defecto).
  • No hay colapso de márgenes ni necesidad de clearfix.

display: inline-flex hace que el contenedor se comporte como un elemento inline (no ocupa todo el ancho disponible), pero por dentro sigue siendo un contenedor flex. Úsalo cuando quieras que el contenedor flex se ajuste al contenido, como un badge o un grupo de botones.

4 · Ejemplo real

Un caso de uso clásico: una barra de acciones con botones alineados, que antes requería floats, inline-block y malabares. Con Flexbox se resuelve en 3 líneas: 

<div class="toolbar">
  <button class="btn">Guardar</button>
  <button class="btn btn--primary">Publicar</button>
  <button class="btn btn--danger">Eliminar</button>
</div>
.toolbar {
  display: flex;
  justify-content: flex-end;  /* Botones a la derecha */
  gap: 0.75rem;
  padding: 1rem;
  background: #1e293b;
  border-radius: 8px;
}

.btn {
  padding: 0.6rem 1.5rem;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  font-weight: 600;
}

.btn--primary { background: #38bdf8; color: #0f172a; }
.btn--danger  { background: #ef4444; color: white; }

Antes de Flexbox, para lograr esto necesitabas text-align: right en el padre y display: inline-block en cada botón. Y si un botón tenía más padding, los demás no se alineaban verticalmente. Flexbox iguala las alturas automáticamente gracias a align-items: stretch.

6 · Errores habituales

Error 1: Creer que Flexbox es Grid

Flexbox no controla filas y columnas simultáneamente con precisión. Si necesitas que un elemento ocupe la posición (2,3) exactamente, necesitas Grid. Flexbox distribuye en una dirección y, si hace wrap, la segunda línea no está alineada con la primera como en una cuadrícula. 

/* ❌ MAL: Intentar emular una cuadrícula con Flexbox */
.contenedor {
  display: flex;
  flex-wrap: wrap;
}
.item { width: calc(33.333% - 1rem); } /* Frágil, problemas de redondeo */

/* ✅ BIEN: Usar Grid para cuadrículas */
.contenedor {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

Error 2: Olvidar que solo los hijos directos son flex items

<!-- ❌ MAL: El <span> NO es un flex item -->
<div style="display: flex">
  <div>
    <span>Este texto no participa en el layout flex</span>
  </div>
</div>

Error 3: Usar flex-direction: column y esperar que justify-content actúe en horizontal

Cuando cambias el eje principal con flex-direction: column, justify-content distribuye los items verticalmente. Para centrar horizontalmente necesitas align-items: center.

Error 4: Confundir align-items con align-content

align-items funciona siempre. align-content SOLO tiene efecto cuando hay flex-wrap: wrap y múltiples líneas. Si tu contenedor tiene una sola línea, align-content no hace nada.

7 · Ejercicio guiado

Objetivo: Construir un contenedor con 4 cajas que cambie de layout al hacer clic en botones que modifican flex-direction. Esto te ayudará a interiorizar cómo cambian los ejes.

  1. Estructura HTML: Crea un contenedor con 4 cajas y 4 botones con atributos data-dir que almacenen los valores row, row-reverse, column y column-reverse.
  2. CSS base: Al contenedor aplícale display: flex; gap: 0.5rem; flex-direction: row; y min-height: 200px para que se note el cambio a columna. A las cajas dales background, padding, border-radius.
  3. JavaScript: Agrega un event listener a cada botón que modifique container.style.flexDirection con el valor del atributo data-dir.
  4. Observa: Alterna entre las cuatro direcciones y responde mentalmente: ¿cuál es el eje principal ahora? ¿dónde está main start y main end? ¿dónde está cross start y cross end?

Haz este ejercicio hasta que puedas responder instantáneamente. Esa intuición sobre los ejes es lo que separa a alguien que "usa Flexbox" de alguien que domina Flexbox.

8 · Reto

🎯 Tarjeta de perfil horizontal

Nivel: Intermedio. Crea un layout de "tarjeta de perfil horizontal" usando exclusivamente Flexbox, con los siguientes requisitos:

  1. Una imagen de avatar a la izquierda (100×100px, redonda).
  2. A la derecha del avatar: nombre, bio corta y un botón de "Seguir".
  3. El nombre y la bio deben estar en columna (usa un contenedor flex anidado con flex-direction: column).
  4. El botón "Seguir" debe estar alineado a la derecha de todo.
  5. En móvil (menos de 500px), la tarjeta debe cambiar a layout vertical: avatar arriba, texto debajo.

Regla: No puedes usar Grid. Solo Flexbox. Y debes cambiar el layout con una sola media query que modifique flex-direction.

9 · Resumen

  • Flexbox es un sistema de layout unidimensional para distribuir items en una fila o columna.
  • Se activa con display: flex en el contenedor padre.
  • El eje principal lo define flex-direction (por defecto row = horizontal).
  • El eje cruzado es siempre perpendicular al principal.
  • flex-direction puede ser row, row-reverse, column o column-reverse.
  • Solo los hijos directos del contenedor flex participan en el layout.
  • Flexbox NO reemplaza a Grid; son complementarios. Flexbox para layouts lineales, Grid para cuadrículas bidimensionales.
  • El valor por defecto de align-items es stretch, lo que iguala las alturas de los items automáticamente.

Regla mnemotécnica: "Justify" va en el eje principal (como justificar texto en un párrafo, que va en horizontal). "Align" va en el eje cruzado (como alinear verticalmente en un renglón). Esto funciona para justify-content / align-items y también para Grid.

10 · Preguntas frecuentes

¿Flexbox o Grid? ¿Cuál uso?

Usa Flexbox cuando tu layout fluye en una dirección (fila de botones, lista de cards que hacen wrap, navbar). Usa Grid cuando necesitas control bidimensional (página completa con header, sidebar, main, footer; galería con celdas alineadas perfectamente).

¿Flexbox reemplaza a los floats?

Para layout, sí completamente. El único caso legítimo de float hoy es para hacer que el texto fluya alrededor de una imagen (float: left dentro de un párrafo). Si estás usando float para posicionar cajas, estás usando una herramienta obsoleta.

¿Puedo usar Flexbox en producción sin preocuparme por navegadores antiguos?

Sí. El soporte global de Flexbox sin prefijos supera el 98% (Can I Use, 2024). IE11 requiere la sintaxis antigua con prefijos y tiene bugs conocidos. Si no necesitas soportar IE11, puedes usar Flexbox sin preocupaciones.

¿Por qué mis items flex no se encogen cuando reduzco la pantalla?

Probablemente tienes flex-shrink: 0 (o flex: none) en los items, o tienes un min-width implícito. Por defecto, los items flex tienen un min-width: auto que impide que se encojan más allá de su contenido.

¿display: flex afecta a los pseudo-elementos ::before y ::after?

Sí. Los pseudo-elementos generados por ::before y ::after se tratan como hijos del contenedor flex y, por tanto, se convierten en flex items. Esto puede ser útil para crear separadores visuales sin añadir HTML extra.
