Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Todo es código

Pipelines, infraestructura y configuración viven en el repositorio y se versionan. Los secretos nunca: van por Secrets/variables de entorno. El mismo artefacto que se prueba es el que se despliega.

Para quién es

Para desarrolladores que ya programan y usan Git (idealmente tras Aprende Docker) y quieren dominar el ciclo de entrega: cómo se prueba, se construye y se despliega de forma reproducible y segura. El hilo conductor es Publicar el Copiloto.

Linux, macOS y Windows

Los runners suelen ser Linux. El shell canónico es bash, con callouts de PowerShell para lo que ejecutes en local; gh y act son multiplataforma.
