Herencia

Módulo 2 · POO en C# 40 minutos

1 · Introducción

Muchas clases comparten estructura y comportamiento: un Perro y un Gato son Animal. En vez de repetir código, la herencia permite crear una clase a partir de otra, reutilizando lo común.

Objetivo

Crear clases derivadas, entender la relación "is-a" y usar protected y base.

2 · Teoría

¿Qué es la herencia?

  • Clase base (o padre): la clase de la que se hereda.
  • Clase derivada (o hija): la que hereda.
class Animal
{
    public string Nombre { get; set; } = "";

    public void Comer()
    {
        Console.WriteLine($"{Nombre} está comiendo");
    }
}

// Perro hereda de Animal (sintaxis ":")
class Perro : Animal
{
    public void Ladrar()
    {
        Console.WriteLine("Guau");
    }
}

var perro = new Perro { Nombre = "Rex" };
perro.Comer();    // heredado de Animal
perro.Ladrar();   // propio de Perro

Relación "is-a"

La herencia expresa una relación "es un": un Perro es un Animal. Úsala solo cuando esa relación tenga sentido. Si es "tiene un", es composición (lo verás más adelante).

protected

private es invisible para las derivadas; protected es visible para la clase y sus derivadas:

class Animal
{
    protected int Energia { get; set; } = 100;   // visible para derivadas

    public void Dormir() => Energia = 100;
}

class Perro : Animal
{
    public void Correr()
    {
        Energia -= 10;   // accede al miembro protected
    }
}

base

base te permite acceder a los miembros de la clase base, incluido su constructor:

class Animal
{
    public string Nombre { get; set; }

    public Animal(string nombre)
    {
        Nombre = nombre;
    }
}

class Perro : Animal
{
    public Perro(string nombre) : base(nombre)   // llama al constructor base
    {
    }
}

var perro = new Perro("Rex");
Console.WriteLine(perro.Nombre);   // Rex

Constructores y herencia

Cuando creas una derivada, siempre se ejecuta un constructor de la base primero. Si la base no tiene constructor sin parámetros, debes llamar explícitamente con base(...).

Miembros heredados y sobrescritura

La derivada hereda los miembros de la base, y puede sobrescribir métodos marcados como virtual usando override (lo verás en la lección de polimorfismo).

3 · Ejemplo mínimo

class Animal
{
    public void Comer() { Console.WriteLine("Comiendo"); }
}

class Perro : Animal
{
}

var perro = new Perro();
perro.Comer();   // heredado

4 · Ejemplo real

Una jerarquía de vehículos con constructor base y miembros heredados:

class Vehiculo
{
    public string Marca { get; set; }
    public int Velocidad { get; private set; }

    public Vehiculo(string marca) => Marca = marca;

    public void Acelerar(int kmh) => Velocidad += kmh;
    public virtual string Describir() => $"{Marca} a {Velocidad} km/h";
}

class Coche : Vehiculo
{
    public int Puertas { get; }

    public Coche(string marca, int puertas) : base(marca)
    {
        Puertas = puertas;
    }

    public override string Describir() => $"{base.Describir()}, {Puertas} puertas";
}

var coche = new Coche("Toyota", 5);
coche.Acelerar(80);
Console.WriteLine(coche.Describir());   // Toyota a 80 km/h, 5 puertas

6 · Errores habituales

Error 1: herencia múltiple

// C# NO permite heredar de dos clases
// class Perro : Animal, Mascota { }   // error

// Solo se hereda de una clase; múltiples interfaces sí son válidas

Error 2: olvidar llamar a base cuando no hay constructor sin parámetros

class Base
{
    public Base(int x) { }
}
class Derivada : Base
{
    // public Derivada() { }   // error: Base no tiene constructor sin parámetros
    public Derivada(int x) : base(x) { }
}

Error 3: usar herencia para "tiene un"

// Un Coche TIENE un Motor (composición), no ES un Motor (herencia)
// class Coche : Motor { }   // incorrecto

9 · Resumen

  • Herencia: una clase deriva de otra con :.
  • Relación "is-a"; reutiliza código común.
  • protected visible para derivadas; base accede a la base.
  • Solo herencia simple de clases en C#.

10 · Preguntas frecuentes

¿Puedo heredar de varias clases?

No. C# permite una sola clase base, pero puedes implementar múltiples interfaces.

¿Se hereda todo?

Los miembros private no son accesibles desde la derivada (aunque existan internamente). Los public y protected sí se heredan y son accesibles.

¿Qué constructor se ejecuta primero?

El de la clase base. La derivada no puede funcionar sin que la base esté inicializada primero.
