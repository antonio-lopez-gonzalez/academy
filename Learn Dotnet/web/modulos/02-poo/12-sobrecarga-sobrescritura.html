Sobrecarga y sobrescritura

Módulo 2 · POO en C# 35 minutos

1 · Introducción

"Sobrecarga" y "sobrescritura" suenan parecido pero son cosas muy distintas. Una crea variantes del mismo método; la otra reemplaza un método heredado. Confundirlas es fuente clásica de bugs.

Objetivo

Distinguir claramente overload de override, y saber usar virtual, abstract y new.

2 · Teoría

Method overloading (sobrecarga)

Varios métodos con el mismo nombre pero distintos parámetros, en la misma clase. Se resuelve en compilación:

class Calculadora
{
    public int Sumar(int a, int b) => a + b;
    public int Sumar(int a, int b, int c) => a + b + c;
    public double Sumar(double a, double b) => a + b;
}

var c = new Calculadora();
c.Sumar(1, 2);        // int, int
c.Sumar(1, 2, 3);     // int, int, int
c.Sumar(1.5, 2.5);    // double, double

También aplica a constructores (visto en la lección de constructores).

Method overriding (sobrescritura)

Reemplazar un método virtual/abstract de la clase base en la derivada, usando override. Se resuelve en tiempo de ejecución:

class Animal
{
    public virtual void HacerSonido() => Console.WriteLine("...");
}

class Perro : Animal
{
    public override void HacerSonido() => Console.WriteLine("Guau");
}

Diferencia entre overload y override

Overload (sobrecarga)Override (sobrescritura)
¿Dónde?Misma claseEntre base y derivada
¿Qué cambia?ParámetrosImplementación
ResoluciónCompilaciónTiempo de ejecución
Palabras(nada)virtual + override

abstract

Un método abstracto obliga a la derivada a sobrescribirlo:

abstract class Animal
{
    public abstract void HacerSonido();
}
class Perro : Animal
{
    public override void HacerSonido() => Console.WriteLine("Guau");
}

new (ocultar)

new oculta un miembro en vez de sobrescribirlo. No es polimorfismo real:

class Animal
{
    public void Comer() => Console.WriteLine("Comiendo");
}
class Perro : Animal
{
    public new void Comer() => Console.WriteLine("Comiendo croquetas");
}

Animal a = new Perro();
a.Comer();        // "Comiendo" (¡la base, no la derivada!)
Perro p = new Perro();
p.Comer();        // "Comiendo croquetas"
Ojo

new crea una versión paralela según el tipo de la variable, lo que genera resultados inconsistentes. Usa override para polimorfismo real.

3 · Ejemplo mínimo

// Overload
static int Sumar(int a, int b) => a + b;
static int Sumar(int a, int b, int c) => a + b + c;

// Override
class Base { public virtual string Texto() => "Base"; }
class Derivada : Base { public override string Texto() => "Derivada"; }

4 · Ejemplo real

class Empleado
{
    public string Nombre { get; set; } = "";
    public virtual decimal Salario() => 20000m;   // salario base
}

class Gerente : Empleado
{
    public override decimal Salario() => base.Salario() + 10000m;   // override + base
}

class Desarrollador : Empleado
{
    public override decimal Salario() => 30000m;
}

// Overload para calcular con o sin bono
class Nomina
{
    public decimal Pagar(Empleado e) => e.Salario();
    public decimal Pagar(Empleado e, decimal bono) => e.Salario() + bono;   // overload
}

6 · Errores habituales

Error 1: confundir overload con override

// Overload: distintos parámetros, misma clase.
// Override: mismo método de la base, sobrescrito.

Error 2: intentar override sin virtual/abstract en la base

class Base { public void M() {} }
class Derivada : Base
{
    // public override void M() {}   // error: no es virtual/abstract
}

Error 3: usar new cuando se quería override

// new oculta en vez de sobrescribir → el polimorfismo no funciona

9 · Resumen

  • Overload: mismo nombre, distintos parámetros (misma clase).
  • Override: sobrescribe un método virtual/abstract (derivada).
  • Overload se resuelve en compilación; override en tiempo de ejecución.
  • new oculta, no sobrescribe.

10 · Preguntas frecuentes

¿Puedo sobrecargar con solo distinto tipo de retorno?

No. La sobrecarga se decide por los parámetros; cambiar solo el tipo de retorno no es válido en C#.

¿Puedo sobrecargar operadores?

Sí, C# permite sobrecargar operadores como + o == con la palabra operator, pero es un tema avanzado.

¿abstract implica override?

Sí: para implementar un método abstracto en una derivada, usas la palabra override.
