Clases abstractas

Módulo 2 · POO en C# 35 minutos

1 · Introducción

A veces una clase representa un concepto tan general que no debería poder instanciarse: no existe un "Animal" concreto, sino perros, gatos y pájaros. Una clase abstracta define la estructura común y deja ciertos detalles sin implementar.

Objetivo

Declarar clases abstractas con métodos abstractos e implementados, y saber cuándo usarlas.

2 · Teoría

¿Qué es una clase abstracta?

Es una clase que no se puede instanciar y que sirve de plantilla para clases derivadas. Puede contener:

  • Métodos abstractos: sin cuerpo, que las derivadas deben implementar.
  • Métodos implementados: con código, que las derivadas heredan.
abstract class Animal
{
    public string Nombre { get; set; } = "";

    // Método abstracto: cada animal suena distinto
    public abstract void HacerSonido();

    // Método implementado: común a todos
    public void Dormir() => Console.WriteLine($"{Nombre} está durmiendo");
}

class Perro : Animal
{
    public override void HacerSonido() => Console.WriteLine("Guau");
}
Dato clave

No puedes hacer new Animal(): es abstracta. Pero sí puedes tener Animal a = new Perro();.

Propiedades abstractas

abstract class Figura
{
    public abstract double Area { get; }   // propiedad abstracta
}

class Circulo : Figura
{
    public double Radio { get; set; }
    public override double Area => Math.PI * Radio * Radio;
}

Constructores en clases abstractas

Una clase abstracta puede tener constructor (aunque no se instancie), para inicializar el estado común:

abstract class Animal
{
    public string Nombre { get; }

    public Animal(string nombre)   // constructor abstracto (lo usan las derivadas)
    {
        Nombre = nombre;
    }

    public abstract void HacerSonido();
}

class Perro : Animal
{
    public Perro(string nombre) : base(nombre) { }
    public override void HacerSonido() => Console.WriteLine("Guau");
}

Abstract vs virtual

Diferencia con una clase normal

La única diferencia estructural: una clase abstracta puede tener métodos abstractos y no se instancia. Por lo demás, es una clase normal con herencia.

4 · Ejemplo real

Una jerarquía de notificaciones con lógica común y variante:

abstract class Notificacion
{
    public string Destinatario { get; set; } = "";

    public void MarcarComoEnviada() => Console.WriteLine($"Enviada a {Destinatario}");

    public abstract void Enviar();   // cada canal envía distinto
}

class NotificacionEmail : Notificacion
{
    public override void Enviar() => Console.WriteLine($"Email a {Destinatario}");
}

class NotificacionSms : Notificacion
{
    public override void Enviar() => Console.WriteLine($"SMS a {Destinatario}");
}

var n = new NotificacionEmail { Destinatario = "ana@mail.com" };
n.Enviar();
n.MarcarComoEnviada();

6 · Errores habituales

Error 1: instanciar una clase abstracta

// var a = new Animal();   // error: no se puede instanciar

Error 2: no implementar todos los métodos abstractos

abstract class Animal
{
    public abstract void A();
    public abstract void B();
}
class Perro : Animal
{
    public override void A() { }
    // falta B() → error de compilación (o Perro debe ser abstracta)
}

Error 3: declarar método abstracto en clase no abstracta

// class Animal { public abstract void A(); }   // error: la clase debe ser abstracta

9 · Resumen

  • Una clase abstracta no se instancia; sirve de plantilla.
  • Métodos abstractos (sin cuerpo) e implementados (con cuerpo).
  • Puede tener propiedades abstractas y constructores.
  • abstract obliga; virtual es opcional.

10 · Preguntas frecuentes

¿Clase abstracta o interfaz?

Abstracta cuando compartes estado y lógica común; interfaz cuando solo defines un contrato. Verás interfaces en la próxima lección.

¿Puede una abstracta heredar de otra abstracta?

Sí. Una abstracta puede derivar de otra, e implementar solo parte de los métodos abstractos, dejando el resto pendiente.

¿Por qué una abstracta tiene constructor si no se instancia?

Porque sus derivadas lo invocan con base(...) para inicializar el estado común.
