Constructores

Módulo 2 · POO en C# 40 minutos

1 · Introducción

Cuando creas un objeto con new, alguien tiene que ponerlo en un estado inicial válido. Ese "alguien" es el constructor: un método especial que se ejecuta automáticamente al crear la instancia.

Objetivo

Crear constructores con parámetros, sobrecargarlos, encadenarlos y usar constructores primarios.

2 · Teoría

¿Qué es un constructor?

Es un método que:

  • Tiene el mismo nombre que la clase.
  • No devuelve nada (ni siquiera void).
  • Se ejecuta automáticamente al hacer new.
class Persona
{
    public string Nombre { get; }

    // Constructor: se ejecuta al crear el objeto
    public Persona(string nombre)
    {
        Nombre = nombre;
    }
}

var p = new Persona("Ana");
Console.WriteLine(p.Nombre);   // Ana

Constructor por defecto

Si no defines ningún constructor, el compilador crea uno implícito sin parámetros:

class Persona
{
    public string Nombre { get; set; } = "";
}

// Usa el constructor por defecto (sin parámetros)
var p = new Persona();
Atención

Si defines cualquier constructor, el constructor por defecto sin parámetros desaparece (a menos que lo declares tú explícitamente).

Sobrecarga de constructores

class Persona
{
    public string Nombre { get; set; }
    public int Edad { get; set; }

    public Persona() { }                          // sin parámetros
    public Persona(string nombre) { Nombre = nombre; }               // solo nombre
    public Persona(string nombre, int edad) { Nombre = nombre; Edad = edad; }
}

var a = new Persona();
var b = new Persona("Ana");
var c = new Persona("Ana", 30);

this y encadenamiento con this(...)

Puedes reutilizar un constructor desde otro con this(...), evitando duplicar lógica:

class Persona
{
    public string Nombre { get; set; }
    public int Edad { get; set; }

    public Persona() : this("Desconocido", 0) { }            // delega al completo
    public Persona(string nombre) : this(nombre, 0) { }      // delega al completo
    public Persona(string nombre, int edad)
    {
        Nombre = nombre;
        Edad = edad;
    }
}

this también se usa para desambiguar entre un parámetro y un campo con el mismo nombre:

class Persona
{
    private string _nombre;

    public Persona(string nombre)
    {
        this._nombre = nombre;   // this distingue el campo del parámetro
    }
}

Inicializadores de objetos

Puedes fijar propiedades al crear el objeto, sin tocar el constructor:

var p = new Persona
{
    Nombre = "Ana",
    Edad = 30
};

Constructores primarios (C# 12)

Para clases sencillas, puedes declarar los parámetros directamente en la línea de la clase:

class Persona(string nombre, int edad)
{
    public string Nombre { get; } = nombre;
    public int Edad { get; } = edad;

    public void Saludar() => Console.WriteLine($"Soy {nombre}");   // acceso directo al parámetro
}

var p = new Persona("Ana", 30);

Los parámetros del constructor primario son accesibles en toda la clase.

3 · Ejemplo mínimo

class Persona
{
    public string Nombre { get; }

    public Persona(string nombre)
    {
        Nombre = nombre;
    }
}

var persona = new Persona("Antonio");
Console.WriteLine(persona.Nombre);

4 · Ejemplo real

Un constructor que valida la entrada y garantiza un estado válido desde el inicio:

class CuentaBancaria
{
    public string Titular { get; }
    public decimal Saldo { get; private set; }

    public CuentaBancaria(string titular, decimal saldoInicial)
    {
        if (string.IsNullOrWhiteSpace(titular))
            throw new ArgumentException("El titular es obligatorio", nameof(titular));
        if (saldoInicial < 0)
            throw new ArgumentException("El saldo no puede ser negativo", nameof(saldoInicial));

        Titular = titular;
        Saldo = saldoInicial;
    }
}

var cuenta = new CuentaBancaria("Ana", 500);
Console.WriteLine($"{cuenta.Titular}: {cuenta.Saldo:C}");

6 · Errores habituales

Error 1: creer que el constructor devuelve algo

// Incorrecto: los constructores no tienen tipo de retorno
// public string Persona() { }

// Correcto
public Persona() { }

Error 2: olvidar que el constructor por defecto desaparece

class Persona
{
    public Persona(string nombre) { }
}

// var p = new Persona();   // Error: ya no hay constructor sin parámetros

Error 3: confundir inicializador de objeto con constructor

// El inicializador { ... } fija propiedades DESPUÉS del constructor
var p = new Persona("Ana") { Edad = 30 };

9 · Resumen

  • El constructor inicializa el objeto y se llama con new.
  • Sin constructores, existe uno por defecto sin parámetros.
  • Sobrecarga y encadenamiento con this(...).
  • Constructores primarios (C# 12) para clases sencillas.

10 · Preguntas frecuentes

¿Puede haber varios constructores?

Sí, mediante sobrecarga: mismo nombre, distintos parámetros. El compilador elige según los argumentos de new.

¿Qué es this(...)?

Llama a otro constructor de la misma clase, reutilizando su lógica. Debe ser la primera instrucción del constructor.

¿Cuándo uso constructor primario?

Para clases simples donde los parámetros se asignan a propiedades y no hay validación compleja. Es azúcar sintáctico de C# 12.
