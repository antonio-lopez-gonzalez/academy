Fechas y horas

Módulo 1 · Fundamentos de C# 35 minutos

1 · Introducción

Fechas y horas parecen simples hasta que te toca calcular plazos, diferencias o gestionar zonas horarias. C# tiene tipos específicos para cada necesidad, y el más importante, DateTime, es inmutable: cada operación devuelve uno nuevo.

Objetivo

Usar DateTime, DateOnly, TimeOnly y TimeSpan, con formateo y operaciones.

2 · Teoría

DateTime: la fecha y hora

DateTime ahora = DateTime.Now;            // hora local actual
DateTime hoy = DateTime.Today;            // solo la fecha (00:00)
DateTime utcAhora = DateTime.UtcNow;      // hora UTC actual

// Crear una fecha concreta
DateTime nacimiento = new DateTime(1990, 5, 15);   // 15/05/1990

DateOnly y TimeOnly (.NET 6+)

Cuando solo necesitas una parte, son más claros que DateTime:

DateOnly fecha = new DateOnly(2024, 1, 31);    // solo fecha
TimeOnly hora = new TimeOnly(14, 30);          // solo hora (14:30)

DateOnly hoy = DateOnly.FromDateTime(DateTime.Today);

TimeSpan: diferencias de tiempo

DateTime inicio = new DateTime(2024, 1, 1);
DateTime fin = new DateTime(2024, 1, 15);

TimeSpan diferencia = fin - inicio;
int dias = diferencia.Days;         // 14
double horas = diferencia.TotalHours;   // 336

// Crear un TimeSpan directamente
TimeSpan dosHoras = TimeSpan.FromHours(2);

Operaciones con fechas

DateTime manana = DateTime.Today.AddDays(1);
DateTime laSemanaPasada = DateTime.Today.AddDays(-7);
DateTime enDosHoras = DateTime.Now.AddHours(2);

Comparación

DateTime a = new(2024, 1, 1);
DateTime b = new(2024, 6, 1);

bool anterior = a < b;    // true
bool igual = a == b;      // false
int cmp = a.CompareTo(b); // -1 (a es anterior a b)

Formateo y parsing

DateTime fecha = new DateTime(2024, 1, 31, 14, 30, 0);

// Formatear con formatos estándar
string s1 = fecha.ToString("yyyy-MM-dd");     // "2024-01-31"
string s2 = fecha.ToString("dd/MM/yyyy HH:mm");// "31/01/2024 14:30"
string s3 = fecha.ToString("D");              // formato largo según cultura

// Interpolación con formato
Console.WriteLine($"Fecha: {fecha:dd-MM-yyyy}");

// Parsear texto a fecha
DateTime parseada = DateTime.Parse("2024-01-31");
if (DateTime.TryParse("31/01/2024", out DateTime d)) { /* válida */ }

UTC vs hora local

Regla de oro

Guarda las fechas en UTC en la base de datos y convierte a la hora local solo al mostrarlas. Esto evita bugs de zonas horarias en aplicaciones globales.

DateTime utc = DateTime.UtcNow;
DateTime local = utc.ToLocalTime();    // convierte a la zona horaria de la máquina

3 · Ejemplo mínimo

DateTime hoy = DateTime.Today;
DateTime manana = hoy.AddDays(1);
TimeSpan diff = manana - hoy;

Console.WriteLine($"Hoy: {hoy:yyyy-MM-dd}");
Console.WriteLine($"Días de diferencia: {diff.Days}");   // 1

4 · Ejemplo real

Calcular la edad de una persona a partir de su fecha de nacimiento:

static int CalcularEdad(DateTime nacimiento)
{
    DateTime hoy = DateTime.Today;
    int edad = hoy.Year - nacimiento.Year;

    // Resta 1 si aún no ha cumplido años este año
    if (nacimiento.Date > hoy.AddYears(-edad))
        edad--;

    return edad;
}

var nacimiento = new DateTime(1990, 5, 15);
Console.WriteLine($"Edad: {CalcularEdad(nacimiento)}");

6 · Errores habituales

Error 1: comparar DateTime con hora incluida

DateTime a = DateTime.Now;       // incluye hora
DateTime b = DateTime.Today;     // 00:00
// a > b casi siempre, aunque sean el "mismo día"

// Correcto: compara solo la fecha
if (a.Date == b.Date) { }

Error 2: Parse con formato inesperado

// "01/02/2024" puede ser 1 de febrero o 2 de enero según cultura.
// Usa ParseExact con formato explícito si conoces el formato.

Error 3: creer que AddDays modifica el original

DateTime d = DateTime.Today;
d.AddDays(5);        // no cambia d (DateTime es inmutable)
// Correcto: d = d.AddDays(5);

9 · Resumen

  • DateTime: fecha y hora; DateOnly/TimeOnly para una parte.
  • TimeSpan: diferencias de tiempo.
  • Operaciones con AddDays/AddHours (inmutable).
  • Formateo con ToString("patrón") y parsing con TryParse.
  • Guarda UTC, muestra local.

10 · Preguntas frecuentes

¿Por qué DateTime es inmutable?

Para que las fechas sean predecibles y seguras de compartir. Cualquier operación devuelve una nueva instancia en lugar de modificar la existente.

¿Qué es UTC?

Coordinated Universal Time: una referencia horaria global sin zonas. Todas las zonas horarias se expresan como desplazamientos respecto a UTC.

¿DateTime o DateTimeOffset?

DateTime no guarda la zona horaria; DateTimeOffset sí (incluye el desplazamiento). Para eventos globales, DateTimeOffset es más seguro.
