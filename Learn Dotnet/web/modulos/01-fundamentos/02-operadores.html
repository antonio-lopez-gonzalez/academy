Operadores

Módulo 1 · Fundamentos de C# 40 minutos

1 · Introducción

Los operadores son los símbolos que combinan valores para producir otros valores: sumar, comparar, decidir lógica. C# comparte la mayoría con otros lenguajes, pero tiene algunos que no existen en JS o Python y conviene dominar desde ya.

Objetivo

Conocer todos los operadores básicos, su precedencia, y los operadores de "null" propios de C#.

2 · Teoría

Aritméticos

int a = 10, b = 3;
int suma = a + b;      // 13
int resta = a - b;     // 7
int mult = a * b;      // 30
int division = a / b;  // 3  (¡división entera! trunca)
int resto = a % b;     // 1  (módulo)
Ojo con la división

En C#, dividir dos enteros produce un entero (10 / 3 = 3). Para obtener decimales, uno de los operandos debe ser decimal: 10 / 3.0 = 3.333....

Comparación e igualdad

bool mayor = 5 > 3;      // true
bool menor = 5 < 3;      // false
bool mayorIgual = 5 >= 5;// true
bool igual = 5 == 5;     // true
bool distinto = 5 != 4;  // true

Lógicos

bool esAdulto = edad >= 18;
bool tienePermiso = false;

bool puedeEntrar = esAdulto && tienePermiso;   // AND: ambos true
bool puedePasar = esAdulto || tienePermiso;     // OR: al menos uno true
bool negado = !esAdulto;                        // NOT: invierte

&& y || son de cortocircuito: si con el primer operando ya se sabe el resultado, el segundo no se evalúa. Esto permite escribir código seguro:

// Si texto es null, el cortocircuito evita evaluar texto.Length
if (texto != null && texto.Length > 0) { /* ... */ }

Asignación, incremento y decremento

int x = 5;
x += 3;   // x = 8  (equivalente a x = x + 3)
x -= 2;   // x = 6
x *= 4;   // x = 24
x /= 2;   // x = 12

int contador = 0;
contador++;  // post-incremento: contador = 1
++contador;  // pre-incremento: contador = 2
contador--;  // contador = 1

La diferencia entre x++ y ++x solo importa cuando el valor se usa en la misma expresión:

int i = 5;
Console.WriteLine(i++);   // imprime 5, luego i pasa a 6
Console.WriteLine(++i);   // i pasa a 7, luego imprime 7

Operador ternario

int edad = 20;
string mensaje = edad >= 18 ? "Mayor" : "Menor";   // "Mayor"

Operadores de null

Tres operadores muy útiles que reducen el código defensivo contra null:

// ??  : si es null, usa el valor de la derecha
string? nombre = null;
string nombreFinal = nombre ?? "Anónimo";   // "Anónimo"

// ??= : asigna solo si es null
nombre ??= "Por defecto";   // nombre pasa a "Por defecto"

// ?.  : acceso condicional (si es null, devuelve null sin explotar)
string? apellido = null;
int? longitud = apellido?.Length;   // null, no lanza excepción

Precedencia

El orden de evaluación sigue las reglas matemáticas. Lo más seguro: usa paréntesis cuando haya duda.

int resultado = 2 + 3 * 4;      // 14  (la multiplicación va antes)
int conParentesis = (2 + 3) * 4; // 20

3 · Ejemplo mínimo

int baseNum = 7;
int exponente = 2;

bool esPar = baseNum % 2 == 0;      // false
Console.WriteLine($"¿{baseNum} es par? {esPar}");

4 · Ejemplo real

Calcular el precio final con descuento y mensajes según el resultado, usando varios operadores:

decimal precio = 100m;
int cantidad = 3;
decimal subtotal = precio * cantidad;

// Descuento del 10% si el subtotal supera 250
decimal descuento = subtotal > 250 ? subtotal * 0.10m : 0m;
decimal total = subtotal - descuento;

Console.WriteLine($"Subtotal: {subtotal:C}");
Console.WriteLine($"Descuento: {descuento:C}");
Console.WriteLine($"Total: {total:C}");

6 · Errores habituales

Error 1: confundir = con ==

int x = 5;
// if (x = 10)   // Error: = asigna, no compara
if (x == 10) { } // Correcto: == compara

Error 2: división entera inesperada

// Incorrecto (para el alumno): esperaba 3.33
double r = 10 / 3;      // r = 3.0

// Correcto
double r2 = 10 / 3.0;   // r2 = 3.333...

Error 3: & en vez de &&

// & no cortocircuita: evalúa ambos lados siempre (más frágil)
// && cortocircuita: más seguro y eficiente
if (a != null && a.Length > 0) { }

9 · Resumen

  • Aritméticos: + - * / %; la división de enteros trunca.
  • Comparación: > < >= <= == !=.
  • Lógicos: &&, ||, !, con cortocircuito.
  • Incremento/decremento: ++ y -- (pre vs post).
  • Null: ??, ??=, ?..

10 · Preguntas frecuentes

¿Cuál es la diferencia entre ++i y i++?

++i incrementa y devuelve el nuevo valor; i++ devuelve el valor actual y luego incrementa. La diferencia solo se nota si usas el valor en la misma línea.

¿Qué es el operador ???

El "null-coalescing": si el valor de la izquierda es null, devuelve el de la derecha. Es un atajo para el típico if (x == null) x = valor;.

¿Por qué 10 / 3 da 3?

Porque ambos operandos son int, y la división entera descarta el resto. Para decimales usa 10 / 3.0 o convierte explícitamente.
