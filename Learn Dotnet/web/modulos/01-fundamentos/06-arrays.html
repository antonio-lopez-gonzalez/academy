Arrays

Módulo 1 · Fundamentos de C# 35 minutos

1 · Introducción

Un array es una colección de tamaño fijo que guarda varios elementos del mismo tipo en posiciones contiguas de memoria. Es la estructura más básica y rápida para agrupar datos.

Objetivo

Crear arrays, recorrerlos, y conocer sus variantes multidimensional y "jagged" (dentada).

2 · Teoría

Crear e inicializar

// Declarar con tamaño fijo
int[] numeros = new int[5];        // 5 ceros por defecto

// Inicializar con valores
int[] otros = { 10, 20, 30, 40 };  // tamaño 4, se deduce

// También con new explícito
string[] frutas = new string[] { "manzana", "pera" };

Índices

Los índices empiezan en 0. El último elemento es longitud - 1:

int[] numeros = { 10, 20, 30, 40 };

int primero = numeros[0];    // 10
int ultimo = numeros[3];     // 40
numeros[1] = 99;             // cambia el valor del índice 1

int longitud = numeros.Length;  // 4

C# 8 introdujo el operador ^ para índices desde el final y .. para rangos:

int[] numeros = { 10, 20, 30, 40 };

int ultimo = numeros[^1];           // 40 (desde el final)
int[] trozo = numeros[1..3];        // { 20, 30 }

Recorrer arrays

int[] numeros = { 10, 20, 30, 40 };

// Con for (controlas el índice)
for (int i = 0; i < numeros.Length; i++)
{
    Console.WriteLine($"índice {i}: {numeros[i]}");
}

// Con foreach (más simple, solo recorres)
foreach (int n in numeros)
{
    Console.WriteLine(n);
}

Arrays multidimensionales

Una "matriz" rectangular con filas y columnas:

int[,] matriz = new int[2, 3];   // 2 filas, 3 columnas

matriz[0, 0] = 1;
matriz[0, 1] = 2;
matriz[1, 2] = 9;

int valor = matriz[1, 2];       // 9

Arrays de arrays (jagged)

Un array cuyos elementos son, a su vez, arrays de tamaños distintos:

int[][] jagged = new int[3][];   // 3 filas de tamaño variable

jagged[0] = new int[] { 1, 2 };
jagged[1] = new int[] { 3, 4, 5, 6 };
jagged[2] = new int[] { 7 };

int valor = jagged[1][2];   // 5

La clase Array

Todo array hereda de System.Array, que ofrece utilidades:

int[] numeros = { 5, 3, 8, 1 };

Array.Sort(numeros);             // { 1, 3, 5, 8 }
Array.Reverse(numeros);          // { 8, 5, 3, 1 }
int indice = Array.IndexOf(numeros, 5);   // posición de 5
Array.Resize(ref numeros, 6);    // redimensiona (crea uno nuevo)
Tamaño fijo

Un array no crece solo. Si necesitas añadir/eliminar elementos dinámicamente, usa List<T> (próxima lección).

3 · Ejemplo mínimo

int[] numeros = { 10, 20, 30, 40 };
int suma = 0;
foreach (int n in numeros)
{
    suma += n;
}
Console.WriteLine($"Suma: {suma}");   // 100

4 · Ejemplo real

Calcular la nota media y la máxima de un grupo de alumnos:

double[] notas = { 5.5, 8.0, 6.5, 9.0, 7.0 };

double suma = 0;
double max = notas[0];

foreach (double nota in notas)
{
    suma += nota;
    if (nota > max) max = nota;
}

double media = suma / notas.Length;
Console.WriteLine($"Media: {media:F2}");   // 7.20
Console.WriteLine($"Nota máxima: {max}");   // 9

6 · Errores habituales

Error 1: índice fuera de rango

int[] n = { 1, 2, 3 };
// Console.WriteLine(n[3]);   // IndexOutOfRangeException: índice válido 0..2

Error 2: olvidar que el array empieza en 0

int[] n = { 10, 20, 30 };
// int primero = n[1];   // 20, no 10
int primero = n[0];      // 10

Error 3: confundir Length con índice del último

int[] n = { 10, 20, 30 };
// n.Length es 3, pero el último índice es 2 (o n[^1])

9 · Resumen

  • Array = colección de tamaño fijo y mismo tipo.
  • Índices desde 0; Length da el tamaño.
  • ^ (desde el final) y .. (rangos).
  • Multidimensional [,] vs jagged [][].
  • Clase Array: Sort, Reverse, IndexOf.

10 · Preguntas frecuentes

¿Array o List?

Array si el tamaño es fijo y conocido. List<T> si necesitas añadir o quitar elementos dinámicamente.

¿Qué es un jagged array?

Un "array de arrays" donde cada fila puede tener distinto tamaño. Útil para estructuras irregulares como una tabla con filas de distinta longitud.

¿Qué hace exactamente n[^1]?

^1 significa "una posición desde el final", es decir, el último elemento. ^2 sería el penúltimo, y así.
