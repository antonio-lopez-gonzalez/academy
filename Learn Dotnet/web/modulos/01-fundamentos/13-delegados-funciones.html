Delegados y funciones

Módulo 1 · Fundamentos de C# 45 minutos

1 · Introducción

¿Qué pasaría si quisieras pasar un método como argumento de otro método? Por ejemplo, decirle a una función "ordena usando esta comparación" o "filtra con esta condición". Los delegados hacen exactamente eso: permiten tratar los métodos como valores.

Es un concepto central en C#: de aquí salen las lambdas y todo LINQ. Si vienes de JavaScript, un delegate es como pasar una función como parámetro (callback).

Objetivo

Declarar delegados, usar Action, Func y Predicate, y escribir lambdas.

2 · Teoría

¿Qué es un delegate?

Un delegate es un tipo que describe la "forma" de un método (qué parámetros recibe y qué devuelve). Puedes asignarle cualquier método que coincida con esa forma.

// Declara un delegate: "método que recibe dos int y devuelve int"
delegate int Operacion(int a, int b);

// Métodos que encajan con esa forma
static int Sumar(int a, int b) => a + b;
static int Restar(int a, int b) => a - b;

// Asignar métodos al delegate
Operacion op = Sumar;
Console.WriteLine(op(5, 3));   // 8

op = Restar;
Console.WriteLine(op(5, 3));   // 2

Delegates como parámetros

static int Aplicar(int a, int b, Operacion operacion)
{
    return operacion(a, b);
}

int resultado = Aplicar(10, 4, Sumar);   // 14
int otro = Aplicar(10, 4, Restar);       // 6

Funciones anónimas y lambdas

En vez de declarar un método aparte, puedes escribir la función "en línea" con una lambda:

Operacion multiplicar = (a, b) => a * b;
Console.WriteLine(multiplicar(3, 4));   // 12

La sintaxis de lambda es (parámetros) => expresión. Para varios pasos, usa llaves:

Operacion maximo = (a, b) =>
{
    if (a > b) return a;
    return b;
};

Los delegados predefinidos

C# incluye tres delegados genéricos que cubren casi todos los casos, así que rara vez declaras los tuyos:

DelegateQué representa
Action / Action<T>Método que no devuelve nada (void)
Func<T> / Func<T, TResult>Método que devuelve un valor (último tipo = retorno)
Predicate<T>Método que recibe T y devuelve bool
 
// Func: recibe dos int y devuelve int
Func<int, int, int> sumar = (a, b) => a + b;

// Action: recibe un string y no devuelve nada
Action<string> imprimir = mensaje => Console.WriteLine(mensaje);

// Predicate: recibe int y devuelve bool
Predicate<int> esPar = n => n % 2 == 0;

Console.WriteLine(sumar(2, 3));    // 5
imprimir("Hola");                  // Hola
Console.WriteLine(esPar(4));       // True
Regla para leer Func

En Func<T1, T2, TResult>, el último tipo es siempre el de retorno; los anteriores son los parámetros. Func<int, int, int> = dos int de entrada, un int de salida.

3 · Ejemplo mínimo

Func<int, int, int> sumar = (a, b) => a + b;
Console.WriteLine(sumar(2, 3));   // 5

4 · Ejemplo real

Filtrar una lista usando un Predicate, como hará LINQ por debajo:

var numeros = new List<int> { 1, 2, 3, 4, 5, 6 };

// Predicate que decide qué elementos se quedan
static List<int> Filtrar(List<int> lista, Predicate<int> condicion)
{
    var resultado = new List<int>();
    foreach (int n in lista)
        if (condicion(n))
            resultado.Add(n);
    return resultado;
}

var pares = Filtrar(numeros, n => n % 2 == 0);
Console.WriteLine(string.Join(", ", pares));   // 2, 4, 6

6 · Errores habituales

Error 1: confundir el orden de los tipos en Func

// Func: recibe string, devuelve int (último = retorno)
Func<string, int> longitud = s => s.Length;

// Incorrecto si lo lees al revés: no es "recibe int, devuelve string"

Error 2: usar Action esperando un retorno

// Action no devuelve nada; si necesitas valor, usa Func
// Action duplicar = n => n * 2;   // error: Action es void
Func<int, int> duplicar = n => n * 2;

Error 3: lambda con muchas líneas sin llaves

// Si el cuerpo tiene varias instrucciones, usa llaves y return explícito
Func<int, int> f = n =>
{
    int r = n * 2;
    return r;
};

8 · Reto

Reto

Escribe un método Transformar<T>(List<T>, Func<T, T>) que aplique una función a cada elemento de la lista y devuelva una lista nueva. Pruébalo duplicando números y poniendo strings en mayúsculas.

9 · Resumen

  • Un delegate trata los métodos como valores.
  • Action (void), Func (retorno) y Predicate (bool).
  • Las lambdas son funciones anónimas: (a, b) => a + b.
  • En Func<T1, T2, TResult>, el último tipo es el retorno.

10 · Preguntas frecuentes

¿Delegate es lo mismo que callback en JS?

Conceptualmente sí: ambos pasan funciones como argumentos. La diferencia es que en C# un delegate es un tipo con una firma fija y segura en compilación.

¿Cuándo declaro mi propio delegate?

Rara vez. Usa Func/Action/Predicate. Los delegates propios tienen sentido en escenarios avanzados como eventos.

¿Una lambda puede no recibir parámetros?

Sí: Func<int> cinco = () => 5;. Los paréntesis vacíos indican que no recibe argumentos.
