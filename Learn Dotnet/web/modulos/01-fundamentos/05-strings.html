Strings

Módulo 1 · Fundamentos de C# 40 minutos

1 · Introducción

Los string son el tipo de dato con el que más vas a trabajar: nombres, mensajes, JSON, rutas, logs. C# tiene una rica colección de herramientas para manipularlos, y entender su inmutabilidad te evitará errores de rendimiento.

Objetivo

Crear y manipular strings con soltura, y entender cuándo usar StringBuilder.

2 · Teoría

Crear strings

string s1 = "Hola";                 // literal normal
string s2 = new string('a', 5);     // "aaaaa"
string s3 = string.Empty;           // cadena vacía ("" mejor que null)

Concatenación e interpolación

string nombre = "Ana";
int edad = 30;

// Concatenación con +
string a = "Hola " + nombre + ", tienes " + edad + " años";

// Interpolación (la forma preferida)
string b = $"Hola {nombre}, tienes {edad} años";

// Interpolación con formato
string c = $"Precio: {125.5m:C2}";   // "Precio: 125,50 €"

La interpolación $"..." es más legible que concatenar y equivale a los template literals de JavaScript (`Hola ${nombre}`) o los f-strings de Python.

Verbatim strings y raw strings

// Verbatim (@): no interpreta caracteres de escape, útil para rutas
string ruta = @"C:\Usuarios\Ana\Documentos";

// Raw string literals (""", C# 11+): para texto multilínea, con comillas y llaves
string html = """
    <div>
        <p>Hola {nombre}</p>
    </div>
    """;
Console.WriteLine(html);

Propiedades y métodos básicos

string texto = "Hola Mundo";

int longitud = texto.Length;            // 10
bool contiene = texto.Contains("Mundo");// true
bool empieza = texto.StartsWith("Ho");  // true
bool termina = texto.EndsWith("do");    // true

Manipulación

string texto = "  Hola,Mundo  ";

string recortado = texto.Trim();        // "Hola,Mundo"
string mayus = texto.ToUpper();         // "  HOLA,MUNDO  "
string minus = texto.ToLower();         // "  hola,mundo  "
string reemplazado = texto.Replace("Mundo", "C#");  // "  Hola,C#  "
string[] partes = texto.Split(',');     // ["  Hola", "Mundo  "]
string sub = texto.Substring(2, 4);     // "Hola" (desde índice 2, 4 caracteres)

Comparación

string x = "casa";
string y = "CASA";

// == compara CONTENIDO (no referencia), a diferencia de Java
bool igual = x == "casa";              // true
bool igualSinMayus = x.Equals(y, StringComparison.OrdinalIgnoreCase); // true

// Para ordenar: CompareTo devuelve 0 si son iguales
int cmp = string.Compare(x, y, StringComparison.OrdinalIgnoreCase);

Inmutabilidad

Un string no puede cambiar. Cada operación crea un string nuevo; el original queda igual:

string s = "hola";
string s2 = s.ToUpper();   // s2 = "HOLA", pero s sigue siendo "hola"
// s = s.ToUpper();        // para "modificar", reasigna

Esto es costoso si concatenas en un bucle, porque cada + crea una cadena nueva.

StringBuilder

Para construir strings en bucles, usa StringBuilder, que modifica un buffer interno sin crear copias:

using System.Text;

var sb = new StringBuilder();
for (int i = 0; i < 5; i++)
{
    sb.Append(i).Append(", ");
}
string resultado = sb.ToString().TrimEnd(',', ' ');  // "0, 1, 2, 3, 4"

3 · Ejemplo mínimo

string nombre = "ana";
string saludo = $"¡Hola, {nombre.ToUpper()}!";
Console.WriteLine(saludo);   // "¡Hola, ANA!"

4 · Ejemplo real

Normalizar la entrada de un usuario (típico en formularios): recortar espacios, capitalizar y validar:

string entrada = "  maría pérez  ";

string normalizado = entrada.Trim();                       // "maría pérez"
bool valido = normalizado.Length >= 3;                     // true
string primeraMayus = char.ToUpper(normalizado[0]) + normalizado[1..];

Console.WriteLine(primeraMayus);   // "María pérez"

6 · Errores habituales

Error 1: concatenar en bucle

// Incorrecto: crea una cadena nueva en cada vuelta
string resultado = "";
for (int i = 0; i < 1000; i++) resultado += i;

// Correcto
var sb = new StringBuilder();
for (int i = 0; i < 1000; i++) sb.Append(i);

Error 2: comparar con == en vez de Equals ignorando mayúsculas

// "casa" == "CASA" es false; si quieres ignorar mayúsculas:
"casa".Equals("CASA", StringComparison.OrdinalIgnoreCase); // true

Error 3: esperar que ToUpper modifique el original

string s = "hola";
s.ToUpper();          // no cambia s
Console.WriteLine(s); // sigue "hola"
// Hay que reasignar: s = s.ToUpper();

9 · Resumen

  • Interpolación $"..." para componer strings.
  • Verbatim @"..." y raw strings """...""".
  • Métodos: Length, Contains, StartsWith, EndsWith, Replace, Split, Substring, Trim, ToUpper/ToLower.
  • string es inmutable; usa StringBuilder para bucles.

10 · Preguntas frecuentes

¿Por qué string es inmutable?

Por seguridad y rendimiento: permite compartir cadenas sin miedo a que otro código las modifique, y habilita el "interning" (reutilizar cadenas idénticas).

¿Cuándo uso @ y cuándo """?

@ para rutas y texto con barras. """ para bloques multilínea que además contienen comillas o llaves (JSON, HTML).

¿== compara contenido o referencia?

En string, == está sobrecargado para comparar contenido. En la mayoría de las clases, == compara referencias; por eso hay que recordarlo.
