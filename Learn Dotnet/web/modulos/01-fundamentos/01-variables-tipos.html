Variables y tipos de datos

Módulo 1 · Fundamentos de C# 45 minutos

1 · Introducción

Un programa manipula datos: nombres, edades, precios, resultados. Para guardar esos datos usamos variables, y cada variable tiene un tipo que define qué puede contener.

Si vienes de JavaScript o Python, aquí está la gran diferencia de partida: C# es un lenguaje de tipado estático. Eso significa que el tipo de una variable se fija al compilar, y el compilador te avisa si intentas mezclar cosas incompatibles, antes de que el programa se ejecute.

Objetivo

Aprender a declarar variables, conocer los tipos básicos y convertir entre ellos sin errores.

2 · Teoría

Declarar e inicializar

// Declarar: reservamos un nombre con su tipo
int edad;

// Inicializar: le asignamos un valor
edad = 30;

// Declarar e inicializar en una línea (lo más común)
int altura = 175;

// var: deja que el compilador deduzca el tipo
var nombre = "Ana";   // nombre es string

Con var, el tipo se deduce del valor que le pones a la derecha. El tipo sigue existiendo y siendo fijo; var solo te ahorra escribirlo. No es lo mismo que el var de JavaScript (que es una variable global mutable de cualquier tipo).

const

Una const es un valor que no puede cambiar jamás. Se debe inicializar al declararla:

const double Iva = 0.21;
// Iva = 0.30;   // Error de compilación: no puedes reasignar una constante

¿Por qué decimal para dinero?

double y float usan representación binaria y pueden introducir errores de redondeo (por ejemplo 0.1 + 0.2 = 0.30000000000000004). decimal usa base 10 y es exacto para cifras monetarias. Regla de oro: dinero = decimal.

Otros tipos

bool esMayor = true;        // true o false
char inicial = 'A';         // UN solo carácter, comillas simples
string texto = "Hola";      // cadena de texto, comillas dobles

Conversión de tipos

Hay dos grandes categorías de conversión:

  • Implícita: ocurre sola cuando no hay riesgo de perder datos (ej. int → long).
  • Explícita (casting): tú la pides, y puede perder datos (ej. double → int trunca decimales).
int a = 10;
long b = a;                 // implícita: seguro

double pi = 3.99;
int entero = (int)pi;       // casting explícito: entero = 3 (trunca)

Para convertir texto a número (muy común al leer del teclado o de una API):

string entrada = "42";

// Convert: lanza excepción si falla
int n1 = Convert.ToInt32(entrada);

// Parse: también lanza excepción si falla
int n2 = int.Parse(entrada);

// TryParse: NO lanza excepción; devuelve true/false (recomendado)
if (int.TryParse(entrada, out int n3))
{
    Console.WriteLine($"Valor válido: {n3}");
}
else
{
    Console.WriteLine("No era un número");
}
Regla práctica

Cuando la entrada viene del usuario (o de fuera), usa TryParse. Parse/Convert solo cuando estás seguro de que el dato es válido.

Value types y reference types

Los tipos se dividen en dos familias fundamentales, y esta distinción es de las más importantes del curso:

Value typesReference types
Ejemplosint, double, bool, char, structstring, class, arrays, object
Dónde vivenEn el stack (o inline)En el heap
Al asignarSe copia el valorSe copia la referencia

El stack es una zona de memoria rápida y pequeña; el heap es más grande y lo gestiona el Garbage Collector. Profundizaremos en la lección de memoria; por ahora quédate con la idea clave:

// Value type: se copia
int x = 5;
int y = x;
y = 10;        // x sigue siendo 5

// Reference type: se comparte la referencia
var lista1 = new List<int> { 1, 2, 3 };
var lista2 = lista1;
lista2.Add(4); // lista1 también ve el 4

4 · Ejemplo real

Un caso real: leer la edad del usuario de forma segura con TryParse, calculando si es mayor de edad:

Console.Write("Introduce tu edad: ");
string? entrada = Console.ReadLine();

if (int.TryParse(entrada, out int edad))
{
    bool esMayor = edad >= 18;
    Console.WriteLine(esMayor ? "Eres mayor de edad" : "Eres menor de edad");
}
else
{
    Console.WriteLine("Eso no parece un número válido.");
}

6 · Errores habituales

Error 1: usar double para dinero

// Incorrecto: el binario pierde precisión
double precio = 0.1;
double total = precio + 0.2;   // 0.30000000000000004

// Correcto
decimal precio2 = 0.1m;
decimal total2 = precio2 + 0.2m;  // 0.3

Error 2: Parse en vez de TryParse

// Incorrecto: si el usuario escribe "abc", explota
int n = int.Parse(Console.ReadLine());

// Correcto
if (int.TryParse(Console.ReadLine(), out int n2)) { /* ... */ }

Error 3: creer que var es "dinámico"

var x = 10;
// x = "hola";   // Error: x ya es int y no puede cambiar de tipo

9 · Resumen

  • C# es de tipado estático: el tipo se fija en compilación.
  • Enteros: int (por defecto), long; decimales: double (por defecto) y decimal (dinero).
  • var deduce el tipo; const fija un valor inmutable.
  • Conversión: casting explícito, Convert, Parse y TryParse (el seguro).
  • Value types se copian; reference types se comparten por referencia.

10 · Preguntas frecuentes

¿Por qué string es reference type si se comporta como valor?

string vive en el heap y es un tipo de referencia, pero es inmutable: cualquier operación crea una cadena nueva. Eso lo hace parecer "de valor" en el uso diario.

¿Cuándo uso long en vez de int?

Cuando el valor puede superar ~2.1 millones de millones. En general int basta; usa long para contadores o identificadores enormes.

¿Por qué decimal lleva sufijo M y no D?

Porque la D ya estaba reservada para double (1.0D). La M viene de "Money" (dinero).
