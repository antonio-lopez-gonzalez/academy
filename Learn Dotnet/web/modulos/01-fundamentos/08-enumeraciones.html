Enumeraciones (enum)

Módulo 1 · Fundamentos de C# 25 minutos

1 · Introducción

Muchas veces una variable solo puede tomar un conjunto cerrado de valores: los días de la semana, el estado de un pedido, los niveles de log. En vez de usar "números mágicos" (1 = lunes, 2 = martes...), usamos un enum, que da nombres claros a cada opción.

Objetivo

Definir enums, convertir entre enum y número/texto, y usar flags para combinar valores.

2 · Teoría

Declarar un enum

enum DiaSemana
{
    Lunes,      // 0
    Martes,     // 1
    Miercoles,  // 2
    Jueves,     // 3
    Viernes,    // 4
    Sabado,     // 5
    Domingo     // 6
}

Por defecto, a cada nombre se le asigna un int empezando en 0 y sumando 1. Puedes asignar valores explícitos:

enum EstadoPedido
{
    Pendiente = 1,
    Pagado = 2,
    Enviado = 3,
    Entregado = 4
}

Usar un enum

DiaSemana hoy = DiaSemana.Miercoles;

// Comparar
if (hoy == DiaSemana.Viernes) { /* ... */ }

Conversiones

// enum → número (int)
DiaSemana d = DiaSemana.Jueves;
int numero = (int)d;                 // 3

// número → enum
DiaSemana otro = (DiaSemana)2;       // Miercoles

// enum → texto
string texto = d.ToString();         // "Jueves"

// texto → enum (ignora mayúsculas)
DiaSemana desdeTexto = Enum.Parse<DiaSemana>("sabado", ignoreCase: true);

Flags: combinar valores

Con el atributo [Flags] y potencias de 2, un enum puede combinar varias opciones a la vez (por ejemplo, permisos):

[Flags]
enum Permisos
{
    Ninguno = 0,
    Leer    = 1,     // 0001
    Escribir = 2,    // 0010
    Borrar  = 4,     // 0100
    Admin   = 8      // 1000
}

// Combinar con | (OR)
Permisos permisos = Permisos.Leer | Permisos.Escribir;

// Comprobar si incluye un flag con HasFlag o &
bool puedeBorrar = permisos.HasFlag(Permisos.Borrar);   // false
bool puedeLeer = (permisos & Permisos.Leer) == Permisos.Leer;  // true

La clase Enum

// ¿Es válido un valor para el enum?
bool valido = Enum.IsDefined(typeof(DiaSemana), 7);   // false (0..6)

// Obtener todos los nombres
string[] nombres = Enum.GetNames<DiaSemana>();
// { "Lunes", "Martes", ... }

3 · Ejemplo mínimo

enum DiaSemana { Lunes, Martes, Miercoles, Jueves, Viernes, Sabado, Domingo }

DiaSemana hoy = DiaSemana.Miercoles;
Console.WriteLine($"Hoy es {hoy}");   // "Hoy es Miercoles"

4 · Ejemplo real

Modelar el estado de un pedido y avanzar por sus fases:

enum EstadoPedido { Pendiente, Pagado, Enviado, Entregado }

EstadoPedido estado = EstadoPedido.Pendiente;

if (estado == EstadoPedido.Pendiente)
{
    estado = EstadoPedido.Pagado;   // avanza
}

// Mostrar el estado de forma legible
Console.WriteLine($"Estado actual: {estado}");   // "Pagado"

6 · Errores habituales

Error 1: flags sin potencias de 2

// Incorrecto: 3 = 1 | 2 se solapan
[Flags] enum Mal { A = 1, B = 2, C = 3 }   // C choca con A|B

// Correcto: potencias de 2
[Flags] enum Bien { A = 1, B = 2, C = 4 }

Error 2: comparar enum con número directamente

// Incorrecto: no compila
// if (estado == 1) { }

// Correcto
if (estado == EstadoPedido.Pagado) { }

Error 3: parsear texto sin control

// Enum.Parse lanza excepción si el texto no existe.
// Más seguro: Enum.TryParse<DiaSemana>(texto, out var d)

9 · Resumen

  • enum define un conjunto cerrado de opciones con nombre.
  • Valores enteros por defecto desde 0 (personalizables).
  • Conversión: casting a int, ToString() y Enum.Parse.
  • [Flags] permite combinar valores con |.

10 · Preguntas frecuentes

¿Un enum solo puede ser int?

Puedes cambiar el tipo subyacente: enum Dia : byte { Lunes, Martes }. Por defecto es int.

¿Qué es un "número mágico"?

Un valor numérico literal cuyo significado no es evidente (if (estado == 3)). El enum lo reemplaza por un nombre legible.

¿Cómo compruebo si un valor numérico es un enum válido?

Con Enum.IsDefined(typeof(TuEnum), valor), que devuelve true o false.
