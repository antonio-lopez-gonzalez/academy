Colecciones

Módulo 1 · Fundamentos de C# 45 minutos

1 · Introducción

Los arrays tienen un límite: tamaño fijo. Las colecciones crecen y decrecen solas, y cada tipo está optimizado para una necesidad distinta. Elegir bien la colección es una de las decisiones más frecuentes del día a día.

Objetivo

Conocer las cinco colecciones principales y saber cuándo usar cada una.

2 · Teoría

List<T>: la más usada

Una lista dinámica de elementos del tipo T. Es la evolución natural del array.

var frutas = new List<string>();

frutas.Add("manzana");       // añadir al final
frutas.Add("pera");
frutas.AddRange(new[] { "uva", "kiwi" });   // añadir varios

frutas.Remove("pera");       // eliminar por valor
frutas.RemoveAt(0);          // eliminar por índice

bool existe = frutas.Contains("uva");   // true
int indice = frutas.IndexOf("uva");     // posición (o -1)
int total = frutas.Count;               // cantidad actual

// Recorrer
foreach (string fruta in frutas)
{
    Console.WriteLine(fruta);
}

Las listas usan genéricos (<T>): el tipo va entre ángulos y te da seguridad en compilación (no puedes meter un int en una List<string>).

Capacidad vs cantidad

Internamente, una List<T> guarda un array. Capacity es cuánto espacio tiene reservado; Count, cuántos elementos tiene de verdad. Cuando Count supera la capacidad, la lista reserva más espacio (doble) y copia. Por eso, si conoces el tamaño aproximado, resérvalo:

var lista = new List<int>(capacity: 1000);  // reserva de una vez
for (int i = 0; i < 1000; i++) lista.Add(i);   // sin redimensionar

Dictionary<TKey, TValue>: pares clave-valor

Para buscar rápidamente por una clave (como un objeto en JS o un dict en Python):

var edades = new Dictionary<string, int>();

edades["Ana"] = 30;          // añadir o actualizar
edades["Luis"] = 25;
edades.Add("María", 40);     // añadir (falla si la clave ya existe)

int edadAna = edades["Ana"]; // 30
bool existe = edades.ContainsKey("Luis");   // true

// Recorrer pares clave-valor
foreach (var par in edades)
{
    Console.WriteLine($"{par.Key}: {par.Value}");
}
Clave ausente

Acceder a una clave que no existe lanza KeyNotFoundException. Para evitarlo: edades.TryGetValue("X", out int v).

HashSet<T>: elementos únicos

var tags = new HashSet<string>();

tags.Add("csharp");   // true
tags.Add("dotnet");   // true
bool duplicado = tags.Add("csharp");   // false: ya estaba

int distintos = tags.Count;   // 2

Queue<T>: cola (FIFO)

Primero en entrar, primero en salir (First-In-First-Out). Ideal para trabajos pendientes:

var cola = new Queue<string>();
cola.Enqueue("primero");
cola.Enqueue("segundo");

string siguiente = cola.Dequeue();   // "primero" (y lo quita)
string frente = cola.Peek();         // "segundo" (sin quitarlo)

Stack<T>: pila (LIFO)

Último en entrar, primero en salir (Last-In-First-Out). Ideal para deshacer acciones:

var pila = new Stack<string>();
pila.Push("acción 1");
pila.Push("acción 2");

string ultima = pila.Pop();   // "acción 2" (y la quita)
string tope = pila.Peek();    // "acción 1" (sin quitarla)

Cuándo usar cada una

ColecciónUsar cuando...
List<T>Lista ordenada y dinámica, acceso por índice
Dictionary<K,V>Búsqueda rápida por clave única
HashSet<T>Conjunto sin duplicados, test de pertenencia
Queue<T>Procesar en orden de llegada (FIFO)
Stack<T>Procesar en orden inverso (LIFO)

3 · Ejemplo mínimo

var numeros = new List<int> { 1, 2, 3 };
numeros.Add(4);
numeros.Remove(2);
Console.WriteLine(string.Join(", ", numeros));   // "1, 3, 4"

4 · Ejemplo real

Agrupar usuarios por ciudad usando un Dictionary:

var usuarios = new Dictionary<string, string>()
{
    ["ana@mail.com"] = "Madrid",
    ["luis@mail.com"] = "Barcelona",
    ["maria@mail.com"] = "Madrid",
};

// Contar usuarios por ciudad
var porCiudad = new Dictionary<string, int>();
foreach (var u in usuarios.Values)
{
    porCiudad.TryGetValue(u, out int contador);
    porCiudad[u] = contador + 1;
}

foreach (var c in porCiudad)
    Console.WriteLine($"{c.Key}: {c.Value}");   // Madrid: 2, Barcelona: 1

6 · Errores habituales

Error 1: modificar una colección mientras se recorre

// Incorrecto: lanza InvalidOperationException
foreach (var n in lista) { if (n == 2) lista.Remove(n); }

// Correcto: recorre una copia o usa RemoveAll
lista.RemoveAll(n => n == 2);

Error 2: acceder a clave inexistente en Dictionary

// Incorrecto: KeyNotFoundException
// int v = edades["NoExiste"];

// Correcto
if (edades.TryGetValue("NoExiste", out int v)) { }

Error 3: confundir Count con Capacity

var lista = new List<int>(100);
// lista.Count == 0  (¡aunque reservó 100 huecos!)
// lista.Capacity == 100

9 · Resumen

  • List<T>: lista dinámica por índice.
  • Dictionary<K,V>: pares clave-valor con búsqueda rápida.
  • HashSet<T>: conjunto sin duplicados.
  • Queue<T> (FIFO) y Stack<T> (LIFO).
  • Las colecciones son genéricas: seguridad de tipos en compilación.

10 · Preguntas frecuentes

¿Por qué falla al modificar una lista dentro de foreach?

El enumerador detecta que la colección cambió y lanza InvalidOperationException para evitar estados inconsistentes. Usa RemoveAll o recorre una copia.

¿Dictionary es ordenado?

No garantiza orden. Si necesitas orden, ordena al recorrer o usa SortedDictionary.

¿Qué significa la T en List<T>?

Es un parámetro de tipo (genérico). Representa "cualquier tipo" que elijas al crearla. Lo verás a fondo en la lección de genéricos.
