IEnumerable y enumeración

Módulo 1 · Fundamentos de C# 35 minutos

1 · Introducción

¿Cómo sabe foreach recorrer un array, una lista o un diccionario? Porque todos implementan la interfaz IEnumerable<T>, que define la capacidad de "enumerar" (recorrer) una secuencia de elementos. Entender esto es la llave de LINQ y de la ejecución diferida.

Objetivo

Comprender qué es IEnumerable, cómo funciona foreach por dentro, y usar yield return.

2 · Teoría

¿Qué es IEnumerable<T>?

Es la interfaz que garantiza: "puedo darte un enumerador que te deja ir elemento a elemento". Todas las colecciones que conoces la implementan:

int[] array = { 1, 2, 3 };
List<int> lista = new() { 1, 2, 3 };

IEnumerable<int> secuencia1 = array;   // un array ES un IEnumerable
IEnumerable<int> secuencia2 = lista;   // una lista también

Cómo funciona foreach por dentro

Cuando escribes foreach, el compilador lo traduce a un patrón con el enumerador:

// Lo que escribes:
foreach (int n in numeros)
{
    Console.WriteLine(n);
}

// Lo que ocurre por debajo (simplificado):
IEnumerator<int> enumerador = numeros.GetEnumerator();
while (enumerador.MoveNext())      // ¿hay siguiente?
{
    int n = enumerador.Current;    // el elemento actual
    Console.WriteLine(n);
}
  • GetEnumerator(): devuelve el enumerador.
  • MoveNext(): avanza al siguiente elemento (devuelve false al terminar).
  • Current: el elemento en la posición actual.

yield return: crear secuencias

Puedes crear tu propio IEnumerable sin construir una lista entera, usando yield return para ir "entregando" elementos:

IEnumerable<int> ObtenerNumeros()
{
    yield return 1;
    yield return 2;
    yield return 3;
}

foreach (int n in ObtenerNumeros())
{
    Console.WriteLine(n);   // 1, 2, 3
}

Enumeración diferida

La clave: con yield, el código no se ejecuta hasta que se recorre. Nada ocurre al llamar a ObtenerNumeros(); todo ocurre al hacer foreach (o ToList()):

IEnumerable<int> Generar()
{
    for (int i = 0; i < 5; i++)
    {
        Console.WriteLine($"Generando {i}");
        yield return i;
    }
}

Console.WriteLine("Antes de recorrer");
var secuencia = Generar();      // aquí NO se genera nada
Console.WriteLine("Después de llamar, antes de foreach");

foreach (int n in secuencia)    // aquí sí se ejecuta
{
    Console.WriteLine($"Recibido {n}");
}
Salida real

El programa imprime "Antes de recorrer", "Después de llamar...", y luego intercala "Generando 0 / Recibido 0", "Generando 1 / Recibido 1"... Todo se genera bajo demanda.

3 · Ejemplo mínimo

IEnumerable<int> ObtenerNumeros()
{
    yield return 1;
    yield return 2;
    yield return 3;
}

foreach (int n in ObtenerNumeros())
    Console.WriteLine(n);

4 · Ejemplo real

Generar una secuencia infinita (o muy grande) sin gastar memoria, leyendo solo lo necesario:

IEnumerable<int> NumerosNaturales()
{
    int i = 0;
    while (true)
    {
        yield return i++;
    }
}

// Tomamos solo los 5 primeros
foreach (int n in NumerosNaturales().Take(5))
{
    Console.WriteLine(n);   // 0, 1, 2, 3, 4
}

Sin yield, tendrías que generar todos los números en memoria. Con yield, solo se producen los que consumes.

6 · Errores habituales

Error 1: creer que la secuencia se ejecuta al llamarla

var secuencia = Generar();   // no se ejecuta aún
// El código de Generar corre al hacer foreach/ToList()

Error 2: recorrer dos veces una secuencia costosa

var s = GenerarCostoso();
Console.WriteLine(s.Count());   // recorre una vez
Console.WriteLine(s.Count());   // recorre OTRA vez

// Correcto: materializar una sola vez
var lista = GenerarCostoso().ToList();

Error 3: olvidar que yield "pausa" y "reanuda"

// yield return no "sale" del método: pausa y vuelve al siguiente MoveNext()

9 · Resumen

  • IEnumerable<T> define la capacidad de enumerar.
  • foreach usa GetEnumerator + MoveNext + Current.
  • yield return crea secuencias con generación perezosa.
  • La enumeración es diferida: no se ejecuta hasta que se recorre.

10 · Preguntas frecuentes

¿IEnumerable guarda los datos?

No necesariamente. Es solo una "promesa" de que puedes recorrer una secuencia. Puede estar respaldada por una lista, o generarse al vuelo con yield.

¿Cuál es la diferencia entre IEnumerable y List?

List<T> guarda los datos en memoria y ofrece acceso por índice. IEnumerable<T> es solo la capacidad de recorrer, sin almacenamiento garantizado.

¿Qué es el Take() del ejemplo?

Es un método de LINQ que devuelve los primeros N elementos de una secuencia. Lo verás en la próxima lección.
