Tu primer programa en C#

Módulo 0 · Preparación 30 minutos

1 · Introducción

Es el momento de escribir y entender tu primer programa. No vamos a copiar "hola mundo" sin más: vamos a desmontar cada línea para que sepas qué hace, porque ese esqueleto será la base de todo lo que viene.

  • Program.cs: el archivo por donde empieza todo.
  • Top-level statements: la sintaxis moderna sin tanto "boilerplate".
  • Console.WriteLine: cómo imprimir por pantalla.
  • Comentarios y convenciones: las reglas de estilo que usarás siempre.
Objetivo

Entender qué significa cada línea del programa mínimo y poder explicarla con tus palabras.

2 · Teoría

El programa mínimo

Cuando creas un proyecto de consola, el archivo Program.cs contiene algo así:

// Imprime un mensaje en la consola
Console.WriteLine("Hola mundo");

Esas dos líneas son un programa completo. En versiones antiguas de C# necesitabas mucho más "andamiaje", pero desde C# 9 existe el concepto de top-level statements: puedes escribir instrucciones directamente en el archivo, sin declarar explícitamente una clase y un método Main.

¿Y dónde está el Main?

El compilador lo genera por ti en segundo plano. Antes escribías algo como class Program { static void Main() { ... } }. Hoy eso es implícito: todo lo que escribas en Program.cs se ejecuta al arrancar. Más adelante, cuando necesites una estructura más formal, podrás declararlo explícitamente.

Desmontando la línea

Console.WriteLine("Hola mundo");
  • Console: una clase de la biblioteca estándar que representa la consola (terminal).
  • WriteLine: un método de esa clase que escribe una línea de texto (y salta a la siguiente).
  • "Hola mundo": el texto que le pasamos como argumento, entre comillas dobles.
  • ;: el punto y coma cierra la instrucción. En C# es obligatorio al final de cada sentencia.

Comentarios

Los comentarios son texto que el compilador ignora. Sirven para explicar el código a humanos:

// Esto es un comentario de una línea.

/*
   Esto es un comentario
   de varias líneas.
*/

Console.WriteLine("Hola mundo"); // también puedes comentar al final de una línea

Sintaxis: mayúsculas y minúsculas importan

C# es sensible a mayúsculas y minúsculas (case-sensitive). Console, console y CONSOLE son tres cosas distintas:

Console.WriteLine("correcto");   // bien
console.WriteLine("error");      // error: "console" no existe
CONSOLE.WRITELINE("error");      // error: tampoco

Importante

Los identificadores (nombres de variables, métodos, clases) van en inglés en el código profesional. Los comentarios y mensajes en este curso van en español. Esa es la convención del curso.

Compilación y ejecución

Cuando haces dotnet run ocurre lo que vimos en la lección 1: el compilador traduce tu C# a IL y el runtime lo ejecuta. Si hay un error de sintaxis, la compilación falla y verás el mensaje de error con la línea exacta.

3 · Ejemplo mínimo

El programa más pequeño posible que imprime varias líneas:

// WriteLine añade un salto de línea al final
Console.WriteLine("Primera línea");
Console.WriteLine("Segunda línea");

// Write NO añade salto de línea
Console.Write("Sin salto ");
Console.Write("en la misma línea");

4 · Ejemplo real

Un programa de consola que se presenta a sí mismo, con comentarios que explican cada bloque:

// Mensaje de bienvenida de una app real
Console.WriteLine("==========================");
Console.WriteLine("  Bienvenido a MiApp v1.0");
Console.WriteLine("==========================");
Console.WriteLine();

// Pregunta al usuario
Console.Write("¿Cómo te llamas? ");
string nombre = Console.ReadLine();

// Responde usando el dato introducido
Console.WriteLine($"Encantado, {nombre}!");

Aquí aparece Console.ReadLine() (leer texto del teclado), una variable string y la interpolación $"...". Todo eso lo veremos con detalle en las próximas lecciones; por ahora observa que el programa interactúa con el usuario.

6 · Errores habituales

Error 1: olvidar el punto y coma

// Incorrecto: falta el ;
Console.WriteLine("hola")

// Correcto
Console.WriteLine("hola");

Error 2: comillas simples para texto

// Incorrecto: las comillas simples son para un solo carácter
Console.WriteLine('Hola mundo');

// Correcto: las comillas dobles son para cadenas de texto
Console.WriteLine("Hola mundo");

Error 3: ignorar mayúsculas/minúsculas

// Incorrecto
console.writeline("hola");

// Correcto
Console.WriteLine("hola");

9 · Resumen

  • Program.cs es el punto de entrada; con top-level statements no hace falta un Main explícito.
  • Console.WriteLine imprime con salto de línea; Console.Write, sin él.
  • C# es case-sensitive y usa ; al final de cada sentencia.
  • Identificadores en inglés: PascalCase (clases/métodos) y camelCase (variables).

10 · Preguntas frecuentes

¿Sigue existiendo el método Main?

Sí. Con top-level statements el compilador lo genera implícitamente. Puedes declararlo de forma explícita si necesitas lógica de arranque más compleja.

¿Por qué mis comentarios van en español y el código en inglés?

Es una convención de este curso (y muy común en equipos hispanohablantes): el código se escribe en inglés para ser profesional y portátil, pero la comunicación y los comentarios en español.

¿Qué pasa si ejecuto sin compilar?

dotnet run compila automáticamente. No existe "ejecutar C# directamente"; siempre hay una compilación a IL de por medio.
