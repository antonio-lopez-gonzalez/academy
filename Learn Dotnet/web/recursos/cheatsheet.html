Cheatsheet de C# 12

Recurso

Cómo usar esta cheatsheet

Este recurso es una referencia rápida de C# 12 y .NET 8. No pretende explicar cada concepto en profundidad, sino ofrecer ejemplos copiables y tablas comparativas para consultar mientras programas. Úsala junto a las lecciones del curso.

Syntax basics

Concepto Ejemplo Notas
Declaración implícita var count = 42; Solo cuando el tipo es obvio a la derecha.
Constantes const int MaxItems = 100; Valor conocido en tiempo de compilación.
Interpolación $"Hola, {name}" Equivalente a template strings de JavaScript.
Null-coalescing var x = input ?? "default"; Si input es null, usa el valor de la derecha.
Null-conditional var len = text?.Length; Devuelve null si text es null.
Switch expression var msg = status switch { 200 => "OK", _ => "Otro" }; Más conciso que switch statement.
Expression-bodied member public int Double(int x) => x * 2; Para métodos de una sola expresión.

Primary constructors (C# 12)

Permiten declarar parámetros directamente en la definición de la clase o struct, evitando campos y constructores manuales. 

// Antes de C# 12
public class OrderService
{
    private readonly ILogger<OrderService> _logger;

    public OrderService(ILogger<OrderService> logger)
    {
        _logger = logger;
    }
}

// Con C# 12
public class OrderService(ILogger<OrderService> logger)
{
    public void Create() => logger.LogInformation("Creating order...");
}

// Si necesitas exponerlo como propiedad
public class ProductService(ILogger<ProductService> logger)
{
    public ILogger<ProductService> Logger { get; } = logger;
}
Cuidado: los primary constructors capturan parámetros como campos privados de solo lectura. En una clase sealed es seguro; en clases heredables, piensa en cómo se comportan los subtipos.

Collection expressions

C# 12 introduce la sintaxis [] para inicializar colecciones de forma unificada. 

// Array
int[] numbers = [1, 2, 3, 4, 5];

// List
List<string> names = ["Ana", "Luis", "Pedro"];

// Span
Span<int> span = [10, 20, 30];

// Combinar con spread operator
int[] first = [1, 2];
int[] second = [3, 4];
int[] combined = [..first, ..second, 5]; // [1,2,3,4,5]

// Inicializar un diccionario con inicializadores clásicos
Dictionary<int, string> map = new()
{
    [1] = "uno",
    [2] = "dos"
};

Async/await quick reference

Tipo / Método Cuándo usarlo
TaskOperación asíncrona sin resultado.
Task<T>Operación asíncrona con resultado.
ValueTask / ValueTask<T>Resultado sincrónico frecuente; hot path.
async voidSolo event handlers; nunca en código productivo.
Task.WhenAllEjecutar varias tareas en paralelo.
Task.WhenAnyEsperar la primera tarea que termine.
IAsyncEnumerable<T>Streaming asíncrono de elementos.
await foreachConsumir IAsyncEnumerable<T>.
 
public async Task<List<Post>> GetPostsAsync(CancellationToken ct = default)
{
    return await dbContext.Posts
        .AsNoTracking()
        .ToListAsync(ct);
}

// Ejecutar varias llamadas en paralelo
var usersTask = GetUsersAsync();
var postsTask = GetPostsAsync();
await Task.WhenAll(usersTask, postsTask);
Nunca: uses .Result ni .Wait() en código asíncrono; provocan deadlocks en contextos con SynchronizationContext.

// using declaration: IDisposable
using var stream = File.OpenRead("data.txt");

// IAsyncEnumerable: streaming
public async IAsyncEnumerable<LogEntry> StreamLogsAsync([EnumeratorCancellation] CancellationToken ct = default)
{
    await foreach (var line in File.ReadLinesAsync("logs.txt", ct))
    {
        yield return new LogEntry(line);
    }
}

ASP.NET Core minimal API snippets

var builder = WebApplication.CreateBuilder(args);

// Servicios
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();
builder.Services.AddSingleton<IEmailService, EmailService>();

var app = builder.Build();

// Middleware
if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.UseHttpsRedirection();

// Endpoint básico
app.MapGet("/", () => "Hola .NET 8");

// Endpoint con parámetros y DTO
app.MapGet("/posts/{id:int}", (int id, IPostService service) =>
{
    var post = service.FindById(id);
    return post is null ? Results.NotFound() : Results.Ok(post);
});

// Endpoint con DI y validación
app.MapPost("/posts", async (CreatePostRequest request, IPostService service) =>
{
    var created = await service.CreateAsync(request);
    return Results.Created($"/posts/{created.Id}", created);
});

// Grupo de rutas
var api = app.MapGroup("/api/v1/posts");
api.MapGet("/", () => Results.Ok([]));
api.MapPost("/", () => Results.Created("/1", new { Id = 1 }));

app.Run();

EF Core snippets

// DbContext
public class CmsDbContext(DbContextOptions<CmsDbContext> options) : DbContext(options)
{
    public DbSet<Post> Posts => Set<Post>();
    public DbSet<Category> Categories => Set<Category>();

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Post>(entity =>
        {
            entity.HasKey(e => e.Id);
            entity.Property(e => e.Title).HasMaxLength(200).IsRequired();
            entity.HasOne(e => e.Category)
                  .WithMany(c => c.Posts)
                  .HasForeignKey(e => e.CategoryId)
                  .OnDelete(DeleteBehavior.Restrict);
        });
    }
}

// Registro en DI
builder.Services.AddDbContext<CmsDbContext>(options =>
    options.UseNpgsql(builder.Configuration.GetConnectionString("Default")));

// Consulta común
var posts = await dbContext.Posts
    .AsNoTracking()
    .Include(p => p.Category)
    .Where(p => p.IsPublished)
    .OrderByDescending(p => p.PublishedAt)
    .Take(20)
    .ToListAsync();

// Inserción
var post = new Post { Title = "Novedades .NET 8" };
dbContext.Posts.Add(post);
await dbContext.SaveChangesAsync();
