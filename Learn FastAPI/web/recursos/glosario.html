Glosario de términos

Referencia 📖 Términos clave de APIs en Python

A

Alembic
Herramienta de migraciones para SQLAlchemy/SQLModel. Versiona los cambios de esquema (crear tabla, añadir columna…), así que la base de datos evoluciona igual en tu máquina, en CI y en producción. Cada cambio es una revisión con upgrade y downgrade (Módulo 4).
Annotated
Tipo de la librería estándar (typing) que permite adjuntar metadatos a una anotación: Annotated[int, Path(ge=1)]. FastAPI lo usa para declarar validación y dependencias sin ambigüedad. Es la forma actual de escribir parámetros; reemplaza al truco de Query(...) como valor por defecto.
API (Application Programming Interface)
Contrato por el que dos programas hablan. En este curso, una API HTTP: recursos identificados por URLs, operaciones con verbos (GET/POST/…), cuerpos JSON y códigos de estado. OpenAPI describe ese contrato de forma legible por máquinas.
APIRouter
Objeto que agrupa rutas de un mismo recurso (con prefix y tags) y se monta en la app con app.include_router(...). Es la forma de partir una API grande en varios archivos sin perder el contrato OpenAPI único.
ASGI (Asynchronous Server Gateway Interface)
Interfaz estándar entre un servidor (uvicorn) y una app de Python asíncrona. Es el «enchufe» que define cómo llega la petición y cómo se devuelve la respuesta. El equivalente async de WSGI, que era sync y bloqueaba una petición por proceso. FastAPI es una app ASGI (Módulo 0).
async/await
Sintaxis de concurrencia cooperativa de Python: una corrutina async def puede await una operación de E/S y ceder el control mientras espera. En FastAPI, los endpoints async def corren en el bucle de eventos; los def normales corren en un threadpool. La regla: nunca bloquees el bucle de eventos.

B

BaseModel
Clase base de Pydantic para definir modelos de datos con anotaciones de tipo. FastAPI la usa tanto para el body de entrada como para el esquema de salida (response_model). Valida al construir y serializa con model_dump().
Body (cuerpo de la petición)
Contenido que viaja en el mensaje HTTP, típicamente JSON. En FastAPI, si un parámetro es un modelo Pydantic o se marca con Body(), se lee de ahí. No lo lleva GET.
bcrypt
Algoritmo de hashing de contraseñas deliberadamente lento y con salt. Se usa vía passlib: guardas el hash, nunca la contraseña. Verificas comparando con pwd_context.verify(), no «desencryptando» (Módulo 5).

C

CLI de FastAPI (fastapi dev)
Comando de la herramienta oficial que arranca el servidor de desarrollo con recarga automática; equivalente cómodo a uvicorn app.main:app --reload. En este curso se usa uv run uvicorn ... para ver el objetivo completo.
Content negotiation / Accept
Mediante la cabecera Accept el cliente pide el formato; las respuestas usan Content-Type (p. ej. application/json o application/problem+json). Elegir bien el media type forma parte del contrato.
CORS (Cross-Origin Resource Sharing)
Mecanismo del navegador que decide si una web de otro origen puede llamar a tu API. Se configura con CORSMiddleware (orígenes, métodos, cabeceras). Sin él, el navegador bloquea la petición aunque el servidor responda (Módulo 5).
Cookie / Set-Cookie
Par de valores que el servidor envía con Set-Cookie y el navegador devuelve en peticiones siguientes. En APIs con JWT suele preferirse la cabecera Authorization para no depender de cookies (ni de CSRF).

D

Dependencia (dependency)
Cualquier función o clase que FastAPI ejecuta antes del endpoint para producir un valor. Separa la construcción de recursos (sesión, config, usuario) de la lógica del endpoint. Se declara con Depends.
Depends
Mecanismo de inyección de dependencias de FastAPI: db: Annotated[Session, Depends(get_session)]. Resuelve el grafo, cachea el resultado dentro de una petición y permite dependencias anidadas. Sustituye al service locator por un parámetro explícito y testeable (Módulo 3).
DI (Dependency Injection)
Patrón por el que un objeto recibe sus colaboradores desde fuera en lugar de crearlos él mismo. Hace el código explícito (se ve qué necesita cada endpoint) y fácil de testear con dobles. En FastAPI es Depends, y también lo usan pydantic-settings y SQLModel.
/docs
Swagger UI autogenerada desde el esquema OpenAPI. Permite ver y probar cada endpoint desde el navegador. /redoc ofrece una vista de documentación alternativa.

E

Endpoint (path operation)
Función asociada a un método HTTP y una ruta. En FastAPI se declara con @app.get("/items/{id}") y sus parámetros tipados definen la validación de la entrada.
Error 422 (Unprocessable Entity)
Respuesta que FastAPI devuelve automáticamente cuando el body o los parámetros no cumplen el esquema (falta un campo, un texto es demasiado corto, un entero está fuera de rango). Incluye la ruta del campo inválido. No lo lanzas tú: lo lanza la validación.
Esquema (schema)
Descripción formal de la forma de los datos: tipos, campos obligatorios y restricciones. Un modelo Pydantic genera un JSON Schema, y el conjunto de todos ellos forma el contrato OpenAPI de la API.

F

FastAPI
Framework para APIs HTTP en Python, construido sobre Starlette (ASGI, routing, middleware) y Pydantic (validación). Su rasgo distintivo: los tipos de Python son la validación y el contrato (OpenAPI), sin generar código.
Field
Función de Pydantic para añadir metadatos y restricciones a un campo: Field(ge=0, max_length=50, default_factory=list). Las descripciones que escribes aquí aparecen en el OpenAPI y documentan también al cliente.
field_validator
Decorador de Pydantic v2 para validar o transformar un campo, antes (mode="before") o después (mode="after") de las comprobaciones de tipo. Va acompañado de @classmethod.
Form / File
Parámetros para peticiones x-www-form-urlencoded / multipart: formularios HTML y subida de ficheros. Una subida se recibe como UploadFile, que es spooled (en memoria y luego a disco) para no cargar todo el fichero en RAM.

G

Gunicorn (y trabajadores)
Gestor de procesos de la era WSGI; con apps ASGI suele usarse con uvicorn.workers.UvicornWorker. En producción se levantan varios procesos detrás de un proxy (Nginx, Caddy o el del proveedor).

H

Header (cabecera HTTP)
Metadatos de la petición o respuesta (Authorization, Content-Type, ETag…). En FastAPI se leen con Annotated[str, Header()] y se devuelven con Response/JSONResponse.
HTTPException
Excepción que lanza el código de la app para cortar la petición con un código y un detail. FastAPI la captura y responde un JSON controlado: es tu forma de producir un 404 o un 403 con sentido.
httpx
Cliente HTTP con soporte async. Es lo que se usa para llamar a otros servicios dentro de un endpoint async def, y también para los tests con AsyncClient. Nunca requests dentro de un endpoint async: bloquea el bucle de eventos (Módulo 6).

I

Idempotencia
Propiedad de una operación que produce el mismo estado aunque se repita. GET, PUT y DELETE son idempotentes; POST normalmente no. Importa para reintentos y para elegir el verbo correcto.
include_router
Método que monta un APIRouter en la app, con prefijo opcional: app.include_router(items.router, prefix="/api/v1"). Es la pieza que da forma a la estructura por capas del proyecto.

J

JWT (JSON Web Token)
Token firmado (no cifrado) con tres partes: cabecera, payload (claims) y firma. El servidor lo verifica con su clave secreta y lee los claims (sub, exp, roles) sin consultar la base de datos. Si se filtra, vale hasta que expira: por eso se combina con expiraciones cortas y, si hace falta, revocación (Módulo 5).

L

lifespan
Contexto asíncrono que envuelve toda la vida de la app: código antes del yield al arrancar y después al apagar. Es el lugar correcto para crear y liberar recursos costosos (motor de base de datos, cliente HTTP, caché) una sola vez, en vez de por petición.
Linter / formateador
Herramientas que garantizan un estilo y detectan errores antes de ejecutar. En el curso: ruff (lint + formato) y mypy (comprobación de tipos estáticos). FastAPI saca ventaja del tipado, así que mypy pasa de extra a útil.

M

Middleware
Capa que envuelve todas las peticiones y respuestas, antes de llegar a la ruta o al salir. Aquí viven CORS, el logging de peticiones, la correlación de trazas y la compresión. El orden de montaje importa.
Migración
Cambio de esquema versionado y reproducible (Alembic). Frente a create_all, que solo crea lo que falta y no altera columnas existentes, una migración deja la base en un estado conocido y reversible en cualquier entorno.
Modelo (schema vs tabla)
Dos modelos distintos: el de tabla (SQLModel/SQLAlchemy, ligado al almacenamiento) y el de esquema (Pydantic, contrato de entrada/salida). Mezclarlos acopla la API al almacenamiento y filtra campos internos. Sepáralos.

O

OAuth2
Marco de autorización estándar. En el curso se usa el password flow para el login: OAuth2PasswordBearer extrae el token de la cabecera Authorization y OAuth2PasswordRequestForm recibe usuario y contraseña. FastAPI lo integra en /docs con el botón Authorize.
OpenAPI
Especificación del contrato de la API (rutas, parámetros, modelos de entrada/salida, códigos). FastAPI lo genera desde tus tipos y lo sirve en /openapi.json. Es la fuente de verdad: cliente y servidor se validan contra él.
ORM (Object-Relational Mapping)
Capa que traduce objetos de Python a tablas SQL y viceversa (SQLAlchemy, SQLModel). No exime de entender el SQL que genera: el problema N+1 (una consulta por elemento) nace justo de usarlo sin mirarlo.

P

Paginación
Devolver un listado en páginas (limit/offset o cursor) en lugar de todo de golpe. Es obligatoria en cualquier colección que pueda crecer; un GET /items sin límite es una bomba de latencia.
Path parameter
Parte variable de la URL declarada entre llaves: /items/{item_id}. FastAPI convierte y valida el tipo (item_id: int) y responde 422 si no encaja.
Pydantic
Biblioteca de validación y serialización basada en tipos de Python. FastAPI la usa para el body, los parámetros, los settings y el response_model. En v2 el núcleo de validación está en Rust, así que validar modelos es barato.
pydantic-settings
Extensión de Pydantic para configuración: lee variables de entorno y .env a un modelo tipado (BaseSettings). Los secretos viven ahí, nunca en el código (Módulo 3).
Problem Details (RFC 9457)
Forma estándar para errores HTTP: type, title, status, detail e instance, con media type application/problem+json. Da a todos los errores la misma forma, así el cliente los interpreta sin adivinar.

Q

Query parameter
Parámetro que viaja tras el ?: /items?limit=10&search=fast. En FastAPI, cualquier parámetro de tipo simple que no esté en el path es de query; se valida con Query(...) y admite alias.

R

Rate limiting
Limitar cuántas peticiones puede hacer un cliente en una ventana de tiempo (por IP, por token, por ruta). Protege de abusos y de picos de coste; se implementa con un contador o un algoritmo de cubo de fichas y suele coordinarse en un almacén compartido como Redis (Módulo 5).
Repositorio (patrón)
Capa que encapsula el acceso a datos detrás de una interfaz (HistoryRepository.add()). El endpoint depende del repositorio, no de SQL concreto: se testea con un doble y se cambia el almacenamiento sin tocar la API (Módulo 4).
response_model
Declara el modelo de la respuesta. FastAPI valida y filtra lo devuelto contra él, de modo que los campos no declarados no salen por la red. Es la defensa principal contra fugas de datos en la salida.
Router
Ver APIRouter.

S

Sesión (session)
Objeto de SQLAlchemy/SQLModel que agrupa operaciones en una transacción y mantiene una identidad por objeto. En FastAPI se abre y cierra por petición con una dependencia de yield: una sesión por petición, nunca una global compartida entre hilos.
SQLAlchemy 2.0
La librería de acceso a datos de referencia en Python. SQLModel se apoya en ella y en Pydantic. Aquí interesa entender las consultas que emite y el patrón select() de la versión 2.
SQLModel
Librería de Tiangolo (autor de FastAPI) que combina SQLAlchemy 2.0 y Pydantic: un mismo modelo puede ser tabla y esquema. Reduce el código al no duplicar clases, a cambio de cierta magia que conviene entender.
Status code
Número de tres cifras que resume el resultado HTTP: 2xx éxito, 3xx redirección, 4xx error del cliente, 5xx error del servidor. En FastAPI se usan las constantes de fastapi.status.
Subdependencia
Una dependencia que a su vez declara Depends(...). FastAPI resuelve el árbol completo y cachea cada resultado dentro de la misma petición, de modo que dos endpoints que comparten una dependencia no la ejecutan dos veces.
Sync vs async
Decision clave de diseño. Un endpoint async def debe no bloquear (usa clientes async). Un endpoint def normal corre en un hilo aparte, así que puede usar librerías bloqueantes (ORM sync) sin congelar el bucle de eventos. Mezclar mal (E/S bloqueante dentro de async def) mata la concurrencia.

T

TestClient
Cliente de Starlette basado en httpx que ejecuta la app en memoria, sin servidor ni red. Permite testear endpoints (status, body, cabeceras) rápido y en aislamiento. Para pruebas async se usa httpx.AsyncClient con ASGITransport.
Token
Credencial opaca o firmada que el cliente presenta para autenticarse. En este curso es un JWT en la cabecera Authorization: Bearer <token>.
Transacción
Unidad atómica de trabajo en la base de datos: se aplica entera o no se aplica (commit / rollback). Delimitar bien la transacción evita estados a medias cuando algo falla a mitad de una petición.

U

uvicorn
Servidor ASGI rápido, basado en uvloop y httptools. Recibe las peticiones HTTP y las entrega a la app por la interfaz ASGI. En desarrollo se arranca con --reload; en producción, con varios trabajadores tras un proxy.
uv
Gestor de proyectos y entornos de Python (muy rápido, en Rust) que sustituye a la combinación pip + venv. Usa pyproject.toml y uv.lock: uv add, uv sync y uv run. Es el estándar del curso.
UploadFile
Tipo que representa un fichero subido, con acceso streaming y métodos read() / write() async. Evita cargar ficheros grandes enteros en memoria (Módulo 2).

V

Validación
Comprobar que los datos cumplen el esquema al entrar, y devolver 422 si no. En FastAPI es declarativa: los tipos y las restricciones de Pydantic hacen el trabajo, y no se escribe un if por campo.
Versionado de API
Estrategia para evolucionar sin romper a los clientes existentes: prefijo (/api/v1), cabecera o media type. Un contrato vivo cambia; la versión es cómo lo cambias sin sorpresas.

Y

yield en dependencias
Forma de que una dependencia haga setup antes del yield y teardown después de la respuesta (p. ej. cerrar la sesión). FastAPI garantiza que el teardown corre aunque el endpoint lance una excepción.
