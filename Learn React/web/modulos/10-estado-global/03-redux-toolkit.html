Redux Toolkit

Módulo 10 · Estado Global ⏱ 50 minutos

1 · Introducción

Redux Toolkit (RTK) es la forma oficial y recomendada de usar Redux en aplicaciones React modernas. Resuelve los problemas de complejidad y boilerplate del Redux tradicional, haciendo que el código sea más simple, mantenible y escalable.

¿Por qué existe Redux Toolkit? Redux original requería mucho código repetitivo: action creators, action types, reducers separados, etc. RTK simplifica todo esto con APIs modernas que reducen el código en un 80%.

¿Cuándo usarlo? Cuando tienes estado global complejo que necesita:

  • Múltiples componentes accediendo a los mismos datos
  • Actualizaciones predecibles y trazables
  • DevTools avanzados (time-travel debugging)
  • Middlewares (thunk para async, logger, etc.)

2 · Teoría

Conceptos clave de Redux Toolkit

RTK se basa en los mismos principios de Redux, pero con APIs simplificadas:

  • Store: Contenedor global del estado (igual que Redux)
  • Slices: Reducers + actions combinados en un solo archivo (novedad de RTK)
  • Dispatch: Función para enviar acciones al store
  • useSelector: Hook para leer datos del store

Flujo de datos en Redux Toolkit

Componente
    │
    ├─► dispatch(action) ──► Slice Reducer ──► Store (estado actualizado)
    │                                              │
    └──────────────── useSelector ◄─────────────────┘

Instalación

pnpm add @reduxjs/toolkit react-redux

¿Por qué dos paquetes?

  • @reduxjs/toolkit: Contiene las APIs modernas (createSlice, configureStore)
  • react-redux: Contiene los hooks para React (useSelector, useDispatch)

Configuración del Store

// src/store/index.js
import { configureStore } from '@reduxjs/toolkit';
import counterReducer from './counterSlice';

export const store = configureStore({
  reducer: {
    counter: counterReducer,
    // Aquí añades más slices
  },
});

¿Qué hace configureStore?

  • Combina todos los reducers en un solo reducer raíz
  • Añade middleware thunk automáticamente (para acciones async)
  • Añade Redux DevTools automáticamente
  • Configura el store con las mejores prácticas

Creación de un Slice

// src/store/counterSlice.js
import { createSlice } from '@reduxjs/toolkit';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => {
      // RTK usa Immer internamente, puedes "mutar" el estado
      state.value += 1;
    },
    decrement: (state) => {
      state.value -= 1;
    },
    incrementByAmount: (state, action) => {
      state.value += action.payload;
    },
  },
});

// Exporta las acciones automáticamente
export const { increment, decrement, incrementByAmount } = counterSlice.actions;

// Exporta el reducer
export default counterSlice.reducer;

¿Qué es createSlice? Es una función que genera automáticamente:

  • El reducer (con lógica de switch/case interna)
  • Los action creators (uno por cada función en reducers)
  • Los action types (basados en el nombre del slice + nombre de la acción)

Uso en componentes

// src/App.jsx
import { Provider } from 'react-redux';
import { store } from './store';
import Counter from './Counter';

function App() {
  return (
    <Provider store={store}>
      <Counter />
    </Provider>
  );
}
// src/Counter.jsx
import { useSelector, useDispatch } from 'react-redux';
import { increment, decrement, incrementByAmount } from './store/counterSlice';

function Counter() {
  // Leer estado del store
  const count = useSelector((state) => state.counter.value);
  
  // Obtener la función dispatch
  const dispatch = useDispatch();

  return (
    <div>
      <h2>Contador: {count}</h2>
      <button onClick={() => dispatch(increment())}>+</button>
      <button onClick={() => dispatch(decrement())}>-</button>
      <button onClick={() => dispatch(incrementByAmount(5))}>+5</button>
    </div>
  );
}

4 · Ejemplo real

Carrito de compras con Redux Toolkit:

src/store/cartSlice.js
import { createSlice } from '@reduxjs/toolkit';

const cartSlice = createSlice({
  name: 'cart',
  initialState: {
    items: [],
    total: 0,
  },
  reducers: {
    // Añadir producto al carrito
    addToCart: (state, action) => {
      const product = action.payload;
      const existingItem = state.items.find(item => item.id === product.id);
      
      if (existingItem) {
        // Si ya existe, incrementar cantidad
        existingItem.quantity += 1;
      } else {
        // Si no existe, añadir nuevo item
        state.items.push({ ...product, quantity: 1 });
      }
      
      // Recalcular total
      state.total = state.items.reduce(
        (sum, item) => sum + item.price * item.quantity,
        0
      );
    },
    
    // Eliminar producto del carrito
    removeFromCart: (state, action) => {
      const productId = action.payload;
      state.items = state.items.filter(item => item.id !== productId);
      
      // Recalcular total
      state.total = state.items.reduce(
        (sum, item) => sum + item.price * item.quantity,
        0
      );
    },
    
    // Actualizar cantidad de un producto
    updateQuantity: (state, action) => {
      const { productId, quantity } = action.payload;
      const item = state.items.find(item => item.id === productId);
      
      if (item) {
        item.quantity = quantity;
        
        // Recalcular total
        state.total = state.items.reduce(
          (sum, item) => sum + item.price * item.quantity,
          0
        );
      }
    },
    
    // Vaciar carrito
    clearCart: (state) => {
      state.items = [];
      state.total = 0;
    },
  },
});

export const { addToCart, removeFromCart, updateQuantity, clearCart } = cartSlice.actions;
export default cartSlice.reducer;

const products = [

src/components/Cart.jsx
import { useSelector, useDispatch } from 'react-redux';
import { removeFromCart, updateQuantity, clearCart } from '../store/cartSlice';

function Cart() {
  const { items, total } = useSelector((state) => state.cart);
  const dispatch = useDispatch();

  if (items.length === 0) {
    return <p>El carrito está vacío</p>;
  }

  return (
    <div>
      <h2>Carrito</h2>
      <ul>
        {items.map(item => (
          <li key={item.id}>
            {item.name} - ${item.price} x 
            <input
              type="number"
              value={item.quantity}
              min="1"
              onChange={(e) => dispatch(updateQuantity({
                productId: item.id,
                quantity: parseInt(e.target.value)
              }))}
            />
            <button onClick={() => dispatch(removeFromCart(item.id))}>
              Eliminar
            </button>
          </li>
        ))}
      </ul>
      <h3>Total: ${total.toFixed(2)}</h3>
      <button onClick={() => dispatch(clearCart())}>
        Vaciar carrito
      </button>
    </div>
  );
}

export default Cart;

6 · Errores habituales

Error 1: Olvidar el Provider

// ✘ MAL: Sin Provider
function App() {
  return <Counter />;
}

// ✔ BIEN: Con Provider
function App() {
  return (
    <Provider store={store}>
      <Counter />
    </Provider>
  );
}

Error 2: Mutar el estado fuera de un reducer

// ✘ MAL: Mutar estado directamente en el componente
function Counter() {
  const count = useSelector((state) => state.counter.value);
  
  const handleClick = () => {
    count += 1; // ✘ Esto no actualiza el store
  };
  
  return <button onClick={handleClick}>{count}</button>;
}

// ✔ BIEN: Usar dispatch
function Counter() {
  const count = useSelector((state) => state.counter.value);
  const dispatch = useDispatch();
  
  return (
    <button onClick={() => dispatch(increment())}>
      {count}
    </button>
  );
}

Error 3: Crear múltiples stores

// ✘ MAL: Múltiples stores
const store1 = configureStore({ reducer: { counter: counterReducer } });
const store2 = configureStore({ reducer: { cart: cartReducer } });

// ✔ BIEN: Un solo store con múltiples slices
const store = configureStore({
  reducer: {
    counter: counterReducer,
    cart: cartReducer,
  },
});

Error 4: No usar selectores para datos computados

// ✘ MAL: Calcular en cada render

7 · Ejercicio guiado

  1. Crea un slice llamado todoSlice con las siguientes acciones:
    • addTodo: Añadir una tarea (payload: texto)
    • toggleTodo: Marcar/desmarcar tarea (payload: id)
    • removeTodo: Eliminar tarea (payload: id)
  2. Configura el store con el todoSlice.
  3. Crea un componente TodoList que:
    • Muestre la lista de tareas
    • Tenga un input para añadir nuevas tareas
    • Permita marcar tareas como completadas
    • Permita eliminar tareas
  4. Añade un contador de tareas pendientes.
Ver solución
src/store/todoSlice.js
import { createSlice } from '@reduxjs/toolkit';

let nextId = 0;

const todoSlice = createSlice({
  name: 'todos',
  initialState: [],
  reducers: {
    addTodo: (state, action) => {
      state.push({
        id: nextId++,
        text: action.payload,
        completed: false,
      });
    },
    toggleTodo: (state, action) => {
      const todo = state.find(todo => todo.id === action.payload);
      if (todo) {
        todo.completed = !todo.completed;
      }
    },
    removeTodo: (state, action) => {
      return state.filter(todo => todo.id !== action.payload);
    },
  },
});

export const { addTodo, toggleTodo, removeTodo } = todoSlice.actions;
export default todoSlice.reducer;
src/TodoList.jsx
import { useState } from 'react';
import { useSelector, useDispatch } from 'react-redux';
import { addTodo, toggleTodo, removeTodo } from './store/todoSlice';

function TodoList() {
  const [text, setText] = useState('');
  const todos = useSelector((state) => state.todos);
  const dispatch = useDispatch();

  const pendingCount = todos.filter(todo => !todo.completed).length;

  const handleSubmit = (e) => {
    e.preventDefault();
    if (text.trim()) {
      dispatch(addTodo(text));
      setText('');
    }
  };

  return (
    <div>
      <h2>Lista de Tareas</h2>
      <form onSubmit={handleSubmit}>
        <input
          value={text}
          onChange={(e) => setText(e.target.value)}
          placeholder="Nueva tarea"
        />
        <button type="submit">Añadir</button>
      </form>

      <ul>
        {todos.map(todo => (
          <li key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              onChange={() => dispatch(toggleTodo(todo.id))}
            />
            <span style={{ 
              textDecoration: todo.completed ? 'line-through' : 'none' 
            }}>
              {todo.text}
            </span>
            <button onClick={() => dispatch(removeTodo(todo.id))}>
              Eliminar
            </button>
          </li>
        ))}
      </ul>

      <p>Tareas pendientes: {pendingCount}</p>
    </div>
  );
}

export default TodoList;

9 · Resumen

  • Redux Toolkit es la forma oficial y recomendada de usar Redux.
  • createSlice combina reducer + actions en un solo archivo, reduciendo boilerplate.
  • configureStore configura el store con las mejores prácticas automáticamente.
  • useSelector lee datos del store, useDispatch envía acciones.
  • Puedes "mutar" el estado en los reducers porque RTK usa Immer internamente.
  • Usa selectores reutilizables para datos computados.
  • Organiza slices por dominio (cart, user, todos, etc.).
  • Usa Redux DevTools para debuggear el estado.

10 · Preguntas frecuentes

¿Redux Toolkit reemplaza a Context API?
No, son herramientas diferentes. Context es para estado simple que cambia poco (tema, usuario). Redux es para estado complejo con muchas actualizaciones (carrito, formularios grandes).
¿Puedo usar Redux sin React?
Sí, Redux es independiente del framework. Pero los hooks (useSelector, useDispatch) son específicos de React.
¿Qué es createAsyncThunk?
Es una función de RTK para manejar operaciones async (fetch, API calls). Genera automáticamente acciones de pending/fulfilled/rejected para manejar estados de carga y error.
¿Redux es lento?
No. Redux es muy eficiente. El problema de rendimiento suele estar en cómo lo usas (selectores mal optimizados, re-renders innecesarios). Usa selectores memoizados si es necesario.
¿Cuándo NO usar Redux?
No uses Redux si:
  • El estado es local de un componente (usa useState)
  • El estado se comparte con pocos componentes (usa Context)
  • La app es pequeña y simple
