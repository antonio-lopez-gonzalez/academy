Proyecto: carrito de compra

Módulo 10 · Estado Global ⏱ 70 minutos

1 · Introducción

En este proyecto construiremos un carrito de compra completo usando Redux Toolkit. Practica: store, slices, dispatch, selectors y persistencia opcional.

2 · Objetivos

  • Listar productos disponibles
  • Añadir y quitar productos del carrito
  • Modificar cantidades
  • Calcular totales
  • Mostrar/ocultar el carrito

4 · Slice del carrito

// src/store/cartSlice.js
import { createSlice } from '@reduxjs/toolkit'

const initialState = {
  items: [],
  isOpen: false
}

const cartSlice = createSlice({
  name: 'cart',
  initialState,
  reducers: {
    addItem: (state, action) => {
      const existing = state.items.find((i) => i.id === action.payload.id)
      if (existing) {
        existing.quantity += 1
      } else {
        state.items.push({ ...action.payload, quantity: 1 })
      }
    },
    removeItem: (state, action) => {
      state.items = state.items.filter((i) => i.id !== action.payload)
    },
    updateQuantity: (state, action) => {
      const item = state.items.find((i) => i.id === action.payload.id)
      if (item) item.quantity = action.payload.quantity
    },
    clearCart: (state) => {
      state.items = []
    },
    toggleCart: (state) => {
      state.isOpen = !state.isOpen
    }
  }
})

export const { addItem, removeItem, updateQuantity, clearCart, toggleCart } = cartSlice.actions
export default cartSlice.reducer

5 · Selectores

// src/store/cartSelectors.js
export const selectCartItems = (state) => state.cart.items
export const selectCartIsOpen = (state) => state.cart.isOpen
export const selectCartCount = (state) =>
  state.cart.items.reduce((total, item) => total + item.quantity, 0)
export const selectCartTotal = (state) =>
  state.cart.items.reduce((total, item) => total + item.price * item.quantity, 0)

6 · Resumen

  • El carrito es un ejemplo clásico de estado global
  • Redux Toolkit maneja la lógica de forma predecible
  • Usa selectores para derivar datos sin duplicar estado
  • El proyecto demuestra add, remove, update y toggle
