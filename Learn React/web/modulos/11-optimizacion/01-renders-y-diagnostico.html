Re-renders y cómo diagnosticarlos

Módulo 11 · Optimización

Introducción

Antes de optimizar, necesitas entender qué está causando el problema. React re-renderiza componentes constantemente, y la mayoría de las veces está bien. Pero cuando los re-renders son excesivos o innecesarios, la aplicación se vuelve lenta.

En esta lección aprenderás a identificar re-renders problemáticos y diagnosticar sus causas antes de aplicar cualquier optimización.

¿Cuándo ocurre un re-render?

React re-renderiza un componente cuando:

  • Cambia su estado (useState, useReducer)
  • Cambian sus props (el padre se re-renderiza)
  • Cambia un contexto que consume (useContext)

Un re-render no es malo por sí mismo. React es muy eficiente re-renderizando gracias al Virtual DOM. El problema surge cuando:

  • Hay demasiados re-renders en componentes pesados
  • Se re-renderizan componentes que no necesitan actualizarse
  • Los re-renders causan cálculos costosos repetidos

Herramientas de diagnóstico

1. React DevTools Profiler

La herramienta más poderosa para diagnosticar problemas de rendimiento. Te permite:

  • Grabar sesiones de interacción
  • Ver qué componentes se re-renderizan
  • Cuánto tiempo tarda cada render
  • Por qué se re-renderizó (cambio de estado, props, etc.)
Pasos para usar el Profiler:
1. Abre React DevTools
2. Ve a la pestaña "Profiler"
3. Haz clic en el botón de grabación (círculo azul)
4. Realiza la interacción que quieres analizar
5. Detén la grabación
6. Analiza los resultados

2. console.log estratégico

La forma más simple de detectar re-renders: añadir logs en el cuerpo del componente. 

function ExpensiveComponent({ data }) {
  console.log('ExpensiveComponent renderizado');
  
  // Cálculo costoso
  const result = expensiveCalculation(data);
  
  return <div>{result}</div>;
}

Si ves el log muchas veces sin que cambien las props, hay un problema.

3. React DevTools "Highlight updates"

Activa esta opción en React DevTools para ver visualmente qué componentes se re-renderizan en tiempo real. 

Pasos:
1. Abre React DevTools
2. Ve a la pestaña "Settings" (engranaje)
3. Activa "Highlight updates when components render"
4. Interactúa con tu aplicación
5. Los componentes que se re-renderizan se iluminan

Causas comunes de re-renders excesivos

1. Estado en el lugar incorrecto

Si el estado está muy arriba en el árbol, muchos componentes se re-renderizan innecesariamente. 

// ❌ Mal: estado muy alto
function App() {
  const [inputValue, setInputValue] = useState('');
  
  return (
    <div>
      <Header />              {/* Se re-renderiza innecesariamente */}
      <Sidebar />             {/* Se re-renderiza innecesariamente */}
      <SearchInput 
        value={inputValue} 
        onChange={setInputValue} 
      />
      <MainContent />         {/* Se re-renderiza innecesariamente */}
    </div>
  );
}

// ✅ Bien: estado cerca de donde se usa
function SearchSection() {
  const [inputValue, setInputValue] = useState('');
  
  return (
    <div>
      <SearchInput 
        value={inputValue} 
        onChange={setInputValue} 
      />
      <SearchResults query={inputValue} />
    </div>
  );
}

2. Objetos/arrays nuevos en cada render

Si pasas objetos o arrays como props, React los recrea en cada render, lo que causa re-renders en los hijos. 

// ❌ Mal: nuevo objeto en cada render
function Parent() {
  const [count, setCount] = useState(0);
  
  // style se recrea en cada render
  const style = { color: 'blue', fontSize: '16px' };
  
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>
        Count: {count}
      </button>
      <ExpensiveChild style={style} />  {/* Se re-renderiza siempre */}
    </div>
  );
}

// ✅ Bien: objeto estable fuera del render
const STYLE = { color: 'blue', fontSize: '16px' };

function Parent() {
  const [count, setCount] = useState(0);
  
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>
        Count: {count}
      </button>
      <ExpensiveChild style={STYLE} />  {/* No se re-renderiza */}
    </div>
  );
}

3. Funciones nuevas en cada render

Similar al problema anterior, las funciones se recrean en cada render. 

// ❌ Mal: nueva función en cada render
function Parent() {
  const [count, setCount] = useState(0);
  
  function handleClick() {
    console.log('Clicked!');
  }
  
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>
        Count: {count}
      </button>
      <Child onClick={handleClick} />  {/* Se re-renderiza siempre */}
    </div>
  );
}

// ✅ Bien: useCallback para estabilizar la función
import { useCallback } from 'react';

function Parent() {
  const [count, setCount] = useState(0);
  
  const handleClick = useCallback(() => {
    console.log('Clicked!');
  }, []);  // Sin dependencias, se crea una sola vez
  
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>
        Count: {count}
      </button>
      <Child onClick={handleClick} />  {/* No se re-renderiza */}
    </div>
  );
}

Ejemplo práctico: identificando el problema

import { useState } from 'react';

function App() {
  const [count, setCount] = useState(0);
  const [text, setText] = useState('');
  
  console.log('App render');
  
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>
        Count: {count}
      </button>
      
      <input 
        value={text} 
        onChange={(e) => setText(e.target.value)} 
      />
      
      <ExpensiveList items={getItems()} />
    </div>
  );
}

function ExpensiveList({ items }) {
  console.log('ExpensiveList render');
  
  return (
    <ul>
      {items.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  );
}

function getItems() {
  console.log('getItems called');
  // Simula cálculo costoso
  return Array.from({ length: 1000 }, (_, i) => ({
    id: i,
    name: `Item ${i}`
  }));
}

Problema: Cada vez que escribes en el input, getItems() se ejecuta de nuevo, creando 1000 objetos.

Solución: Mover getItems() fuera del render o usar useMemo (veremos esto en la siguiente lección).

Regla de oro: mide antes de optimizar

No optimices por intuición. Usa el Profiler para identificar los cuellos de botella reales. A veces el problema no es donde crees que es. 

Flujo de optimización:
1. Identifica el problema (la app es lenta)
2. Mide con el Profiler (qué componentes son lentos)
3. Diagnostica la causa (por qué se re-renderizan)
4. Aplica la optimización adecuada
5. Mide de nuevo (verifica que mejoró)

Ejercicio

  1. Crea una aplicación con un contador y un input de texto
  2. Añade console.log en varios componentes
  3. Observa qué se re-renderiza cuando cambias el contador vs el texto
  4. Usa el Profiler para grabar una sesión y analizar los resultados
  5. Identifica qué componentes se re-renderizan innecesariamente

Resumen

  • Los re-renders ocurren cuando cambia el estado, props o contexto
  • No todos los re-renders son malos, solo los excesivos o innecesarios
  • Usa React DevTools Profiler para diagnosticar problemas
  • Causas comunes: estado mal ubicado, objetos/funciones nuevos en cada render
  • Siempre mide antes de optimizar
