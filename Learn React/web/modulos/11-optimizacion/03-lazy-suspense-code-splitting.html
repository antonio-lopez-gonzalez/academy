lazy, Suspense y code splitting

Módulo 11 · Optimización

Introducción

Cuando tu aplicación crece, el bundle de JavaScript se hace cada vez más grande. Esto significa que el usuario tiene que descargar todo el código antes de poder usar la aplicación, incluso si solo va a usar una pequeña parte.

Code splitting es la técnica de dividir tu código en chunks más pequeños que se cargan bajo demanda. React proporciona lazy y Suspense para implementar esto de forma sencilla.

React.lazy

React.lazy te permite cargar componentes de forma diferida. El componente no se carga hasta que realmente se necesita. 

import { lazy } from 'react';

// Carga normal: el componente se incluye en el bundle principal
import HeavyComponent from './HeavyComponent';

// Carga diferida: el componente se carga solo cuando se usa
const HeavyComponent = lazy(() => import('./HeavyComponent'));

// Uso normal
function App() {
  return <HeavyComponent />;
}

Cuando usas lazy, Webpack/Vite crea un chunk separado para ese componente. El chunk solo se descarga cuando el componente se renderiza por primera vez.

Suspense

Suspense te permite mostrar un fallback mientras el componente lazy se está cargando. 

import { lazy, Suspense } from 'react';

const HeavyComponent = lazy(() => import('./HeavyComponent'));

function App() {
  return (
    <Suspense fallback={<div>Cargando...</div>}>
      <HeavyComponent />
    </Suspense>
  );
}

¿Cómo funciona?

  1. React empieza a renderizar HeavyComponent
  2. Detecta que es lazy y necesita cargarse
  3. Muestra el fallback de Suspense
  4. Descarga el chunk en background
  5. Cuando termina, reemplaza el fallback con el componente real

Ejemplo con React Router

El caso de uso más común es cargar páginas bajo demanda. 

import { lazy, Suspense } from 'react';
import { BrowserRouter, Routes, Route } from 'react-router-dom';

// Carga diferida de páginas
const Home = lazy(() => import('./pages/Home'));
const About = lazy(() => import('./pages/About'));
const Contact = lazy(() => import('./pages/Contact'));
const Dashboard = lazy(() => import('./pages/Dashboard'));

function App() {
  return (
    <BrowserRouter>
      <Suspense fallback={<div className="loading">Cargando página...</div>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
          <Route path="/contact" element={<Contact />} />
          <Route path="/dashboard" element={<Dashboard />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}

Ventaja: Si el usuario solo visita la página de inicio, nunca descarga el código de About, Contact o Dashboard.

Carga condicional

Puedes cargar componentes solo cuando se cumplen ciertas condiciones. 

import { lazy, Suspense, useState } from 'react';

const Chart = lazy(() => import('./Chart'));

function Dashboard() {
  const [showChart, setShowChart] = useState(false);
  
  return (
    <div>
      <button onClick={() => setShowChart(true)}>
        Mostrar gráfico
      </button>
      
      {showChart && (
        <Suspense fallback={<div>Cargando gráfico...</div>}>
          <Chart />
        </Suspense>
      )}
    </div>
  );
}

El chunk de Chart solo se descarga cuando el usuario hace clic en el botón.

Preloading

Puedes precargar chunks antes de que se necesiten para mejorar la experiencia. 

import { lazy, Suspense } from 'react';

const HeavyComponent = lazy(() => import('./HeavyComponent'));

function App() {
  // Precargar cuando el usuario pasa el mouse sobre el botón
  function handleMouseEnter() {
    import('./HeavyComponent');
  }
  
  return (
    <div>
      <button onMouseEnter={handleMouseEnter}>
        Cargar componente pesado
      </button>
      
      <Suspense fallback={<div>Cargando...</div>}>
        <HeavyComponent />
      </Suspense>
    </div>
  );
}

Manejo de errores

Si la carga falla (error de red, chunk eliminado, etc.), necesitas manejar el error. 

import { lazy, Suspense, Component } from 'react';

const HeavyComponent = lazy(() => import('./HeavyComponent'));

// Error Boundary para capturar errores de carga
class ErrorBoundary extends Component {
  state = { hasError: false };
  
  static getDerivedStateFromError(error) {
    return { hasError: true };
  }
  
  render() {
    if (this.state.hasError) {
      return <div>Error al cargar el componente. Intenta de nuevo.</div>;
    }
    return this.props.children;
  }
}

function App() {
  return (
    <ErrorBoundary>
      <Suspense fallback={<div>Cargando...</div>}>
        <HeavyComponent />
      </Suspense>
    </ErrorBoundary>
  );
}

Estrategias de code splitting

  • Por ruta: cada página es un chunk separado (más común)
  • Por componente pesado: componentes grandes o poco usados
  • Por feature: agrupa componentes de una funcionalidad
  • Por vendor: librerías externas en chunks separados

¿Cuándo usar code splitting?

Úsalo cuando:

  • Tu bundle es grande (> 200KB gzipped)
  • Tienes rutas que no todos los usuarios visitan
  • Tienes componentes pesados (gráficos, editores, etc.)
  • La carga inicial es lenta

No lo uses cuando:

  • Tu aplicación es pequeña
  • Todos los usuarios visitan todas las páginas
  • El overhead de múltiples requests es mayor que el beneficio

Resumen

  • React.lazy carga componentes bajo demanda
  • Suspense muestra un fallback mientras se carga
  • Code splitting divide el bundle en chunks más pequeños
  • Ideal para rutas y componentes pesados
  • Usa Error Boundaries para manejar errores de carga
  • Mide el impacto antes y después de implementar
