React Compiler

Módulo 11 · Optimización

Introducción

React Compiler (anteriormente conocido como "React Forget") es una herramienta experimental que automatiza la memorización de componentes y valores. Su objetivo es eliminar la necesidad de usar manualmente useMemo, useCallback y React.memo.

¿Qué hace? Analiza tu código en tiempo de compilación y añade automáticamente la memorización donde sea necesario.

El problema que resuelve

Hasta ahora, hemos tenido que optimizar manualmente: 

// Sin React Compiler: optimización manual
import { memo, useMemo, useCallback } from 'react';

const ExpensiveComponent = memo(function ExpensiveComponent({ data, onClick }) {
  const processed = useMemo(() => {
    return expensiveProcessing(data);
  }, [data]);
  
  const handleClick = useCallback(() => {
    onClick(processed);
  }, [processed, onClick]);
  
  return <div onClick={handleClick}>{processed}</div>;
});

Esto es tedioso, propenso a errores y fácil de olvidar.

Con React Compiler

// Con React Compiler: sin optimización manual
function ExpensiveComponent({ data, onClick }) {
  const processed = expensiveProcessing(data);
  
  function handleClick() {
    onClick(processed);
  }
  
  return <div onClick={handleClick}>{processed}</div>;
}

// El compiler añade automáticamente:
// - useMemo para 'processed'
// - useCallback para 'handleClick'
// - React.memo para el componente

Ventaja: Escribes código simple y el compiler se encarga de la optimización.

Estado actual

Importante: React Compiler está en fase experimental (a 2024). No está listo para producción todavía, pero es el futuro de React.

Características:

  • Automatiza la memorización
  • Reduce el boilerplate de optimización
  • Mantiene el código más limpio y legible
  • Compatible con código existente

Cómo funciona

El compiler analiza tu código en tiempo de compilación y:

  1. Identifica valores que podrían memorizarse
  2. Determina sus dependencias
  3. Inserta llamadas a useMemo, useCallback automáticamente
  4. Añade React.memo a componentes cuando es seguro
Tu código:
function Component({ a, b }) {
  const result = expensiveCalc(a, b);
  return <div>{result}</div>;
}

Código compilado:
function Component({ a, b }) {
  const result = useMemo(() => expensiveCalc(a, b), [a, b]);
  return <div>{result}</div>;
}

export default memo(Component);

Reglas del compiler

Para que el compiler funcione correctamente, tu código debe seguir las reglas de React:

  • Pure functions: los componentes deben ser funciones puras
  • Inmutabilidad: no mutar props o estado directamente
  • Hooks en el nivel superior: no llamar hooks condicionalmente
  • Sin efectos secundarios en el render: solo en useEffect
// ❌ Mal: efecto secundario en el render
function Component({ data }) {
  console.log('Render');  // Efecto secundario
  return <div>{data}</div>;
}

// ✅ Bien: sin efectos secundarios
function Component({ data }) {
  return <div>{data}</div>;
}

Configuración

Para usar React Compiler (cuando esté listo), necesitas: 

# Instalar el plugin
npm install babel-plugin-react-compiler

# Configurar en babel.config.js
module.exports = {
  plugins: [
    ['babel-plugin-react-compiler', {
      // Opciones de configuración
    }]
  ]
};

Nota: La configuración exacta puede cambiar a medida que el compiler evoluciona.

Ventajas

  • Menos código: no necesitas useMemo, useCallback, React.memo manualmente
  • Menos errores: el compiler no olvida optimizar
  • Código más limpio: escribes lo que quieres, no cómo optimizarlo
  • Mejor rendimiento: optimización automática y consistente
  • Backward compatible: funciona con código existente

Desventajas actuales

  • Experimental: no está listo para producción
  • Complejidad: puede ser difícil de debuggear
  • Limitaciones: no puede optimizar todo el código
  • Overhead de compilación: aumenta el tiempo de build

Comparación: antes y después

// ANTES: optimización manual
import { memo, useMemo, useCallback } from 'react';

const List = memo(function List({ items, onItemClick }) {
  const sortedItems = useMemo(() => {
    return [...items].sort((a, b) => a.name.localeCompare(b.name));
  }, [items]);
  
  const handleClick = useCallback((id) => {
    onItemClick(id);
  }, [onItemClick]);
  
  return (
    <ul>
      {sortedItems.map(item => (
        <li key={item.id} onClick={() => handleClick(item.id)}>
          {item.name}
        </li>
      ))}
    </ul>
  );
});

// DESPUÉS: con React Compiler
function List({ items, onItemClick }) {
  const sortedItems = [...items].sort((a, b) => 
    a.name.localeCompare(b.name)
  );
  
  function handleClick(id) {
    onItemClick(id);
  }
  
  return (
    <ul>
      {sortedItems.map(item => (
        <li key={item.id} onClick={() => handleClick(item.id)}>
          {item.name}
        </li>
      ))}
    </ul>
  );
}

¿Deberías usarlo ahora?

No todavía. Pero prepárate para cuando esté listo:

  • Escribe código siguiendo las reglas de React
  • No dependas demasiado de optimizaciones manuales
  • Mantente actualizado sobre el progreso del compiler
  • Prueba en proyectos experimentales

El futuro de React

React Compiler representa un cambio de paradigma: de optimización manual a automática. Esto significa:

  • Menos tiempo pensando en optimización
  • Código más enfocado en la lógica de negocio
  • Mejor rendimiento por defecto
  • React más fácil de aprender para nuevos desarrolladores

Resumen

  • React Compiler automatiza la memorización de componentes y valores
  • Elimina la necesidad de useMemo, useCallback, React.memo manuales
  • Está en fase experimental, no listo para producción
  • Requiere seguir las reglas de React (pure functions, inmutabilidad)
  • Representa el futuro de la optimización en React
  • Prepárate escribiendo código limpio y siguiendo las mejores prácticas
