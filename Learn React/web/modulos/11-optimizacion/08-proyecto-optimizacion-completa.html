Proyecto: Optimización completa

Módulo 11 · Optimización

Introducción

En este proyecto vamos a optimizar una aplicación React completa aplicando todas las técnicas aprendidas en el módulo: React.memo, useMemo, useCallback, code splitting con lazy y Suspense.

Partiremos de una aplicación con problemas de rendimiento y la optimizaremos paso a paso, midiendo el impacto de cada optimización.

Aplicación inicial

La aplicación es un dashboard con:

  • Lista de productos (1000 items)
  • Filtros por categoría y precio
  • Búsqueda en tiempo real
  • Gráfico de ventas (componente pesado)
  • Múltiples páginas con React Router

Problemas:

  • La lista se re-renderiza completamente con cada cambio
  • Los filtros se recalculan en cada render
  • El gráfico se carga incluso cuando no es visible
  • El bundle inicial es muy grande

Paso 1: Diagnóstico

Antes de optimizar, medimos el rendimiento actual: 

1. Abre React DevTools Profiler
2. Graba una sesión mientras:
   - Escribes en el buscador
   - Cambias los filtros
   - Navegas entre páginas
3. Analiza los resultados:
   - ¿Qué componentes se re-renderizan innecesariamente?
   - ¿Cuánto tiempo tardan los renders?
   - ¿Cuál es el tamaño del bundle inicial?

Paso 2: Optimizar la lista de productos

// ANTES: sin optimización
function ProductList({ products, filters }) {
  // Se recalcula en cada render
  const filteredProducts = products
    .filter(p => p.category === filters.category)
    .filter(p => p.price <= filters.maxPrice)
    .filter(p => p.name.includes(filters.search));
  
  return (
    <ul>
      {filteredProducts.map(product => (
        <ProductItem key={product.id} product={product} />
      ))}
    </ul>
  );
}

// DESPUÉS: con useMemo
import { useMemo } from 'react';

function ProductList({ products, filters }) {
  const filteredProducts = useMemo(() => {
    return products
      .filter(p => p.category === filters.category)
      .filter(p => p.price <= filters.maxPrice)
      .filter(p => p.name.includes(filters.search));
  }, [products, filters]);
  
  return (
    <ul>
      {filteredProducts.map(product => (
        <ProductItem key={product.id} product={product} />
      ))}
    </ul>
  );
}

Paso 3: Memorizar ProductItem

// ANTES: sin memo
function ProductItem({ product }) {
  console.log('ProductItem render');
  return (
    <li>
      <h3>{product.name}</h3>
      <p>${product.price}</p>
    </li>
  );
}

// DESPUÉS: con React.memo
import { memo } from 'react';

const ProductItem = memo(function ProductItem({ product }) {
  console.log('ProductItem render');
  return (
    <li>
      <h3>{product.name}</h3>
      <p>${product.price}</p>
    </li>
  );
});

Paso 4: Estabilizar callbacks

// ANTES: función nueva en cada render
function ProductList({ products, onProductClick }) {
  return (
    <ul>
      {products.map(product => (
        <ProductItem 
          key={product.id} 
          product={product}
          onClick={() => onProductClick(product.id)}
        />
      ))}
    </ul>
  );
}

// DESPUÉS: con useCallback
import { useCallback } from 'react';

function ProductList({ products, onProductClick }) {
  const handleClick = useCallback((id) => {
    onProductClick(id);
  }, [onProductClick]);
  
  return (
    <ul>
      {products.map(product => (
        <ProductItem 
          key={product.id} 
          product={product}
          onClick={handleClick}
        />
      ))}
    </ul>
  );
}

Paso 5: Code splitting

// ANTES: todo en el bundle principal
import Dashboard from './pages/Dashboard';
import SalesChart from './components/SalesChart';
import Settings from './pages/Settings';

function App() {
  return (
    <Routes>
      <Route path="/" element={<Dashboard />} />
      <Route path="/settings" element={<Settings />} />
    </Routes>
  );
}

// DESPUÉS: con lazy y Suspense
import { lazy, Suspense } from 'react';

const Dashboard = lazy(() => import('./pages/Dashboard'));
const SalesChart = lazy(() => import('./components/SalesChart'));
const Settings = lazy(() => import('./pages/Settings'));

function App() {
  return (
    <Suspense fallback={<div>Cargando...</div>}>
      <Routes>
        <Route path="/" element={<Dashboard />} />
        <Route path="/settings" element={<Settings />} />
      </Routes>
    </Suspense>
  );
}

Paso 6: Carga condicional

import { lazy, Suspense, useState } from 'react';

const SalesChart = lazy(() => import('./components/SalesChart'));

function Dashboard() {
  const [showChart, setShowChart] = useState(false);
  
  return (
    <div>
      <button onClick={() => setShowChart(true)}>
        Mostrar gráfico
      </button>
      
      {showChart && (
        <Suspense fallback={<div>Cargando gráfico...</div>}>
          <SalesChart />
        </Suspense>
      )}
    </div>
  );
}

Paso 7: Medir el impacto

Después de aplicar todas las optimizaciones, medimos de nuevo: 

Métricas a comparar:
1. Tiempo de render (Profiler)
   - Antes: 200ms por render
   - Después: 50ms por render

2. Número de re-renders
   - Antes: ProductItem se renderiza 1000 veces con cada cambio
   - Después: solo se renderizan los items que cambian

3. Tamaño del bundle
   - Antes: 500KB
   - Después: 200KB (chunk principal) + chunks lazy

4. Tiempo de carga inicial
   - Antes: 2.5s
   - Después: 1.2s

Resultado final

La aplicación optimizada tiene:

  • 75% menos tiempo de render gracias a useMemo y React.memo
  • 60% menos bundle inicial gracias al code splitting
  • 50% menos tiempo de carga gracias a lazy loading
  • Mejor experiencia de usuario con feedback de carga

Lecciones aprendidas

  1. Mide antes de optimizar: no optimices por intuición
  2. Empieza por lo más impactante: listas grandes, cálculos costosos
  3. No sobre-optimices: solo optimiza lo que realmente es lento
  4. Mide después de optimizar: verifica que mejoró
  5. Balancea complejidad vs beneficio: no añadas optimización innecesaria
