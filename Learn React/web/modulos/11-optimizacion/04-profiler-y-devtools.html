Profiler y React DevTools

Módulo 11 · Optimización

Introducción

React DevTools es una extensión del navegador que te permite inspeccionar la jerarquía de componentes, ver props y estado, y analizar el rendimiento de tu aplicación.

El Profiler es la herramienta más poderosa para identificar problemas de rendimiento. Te permite grabar sesiones de interacción y ver exactamente qué componentes se re-renderizan y cuánto tiempo tardan.

Instalación

Instala React DevTools desde la tienda de extensiones de tu navegador:

  • Chrome
  • Firefox
  • Edge

Pestaña Components

La pestaña Components te muestra la jerarquía de componentes de tu aplicación.

Funcionalidades:

  • Ver la jerarquía de componentes
  • Inspeccionar props y estado de cada componente
  • Editar props y estado en tiempo real
  • Ver hooks y su valores
  • Navegar entre componentes
Ejercicio:
1. Abre tu aplicación en el navegador
2. Abre DevTools (F12)
3. Ve a la pestaña "Components"
4. Haz clic en diferentes componentes
5. Observa sus props y estado
6. Intenta editar un valor y observa cómo cambia la UI

Pestaña Profiler

El Profiler te permite grabar sesiones de interacción y analizar el rendimiento.

Cómo usar el Profiler:

  1. Ve a la pestaña "Profiler" en React DevTools
  2. Haz clic en el botón de grabación (círculo azul)
  3. Realiza la interacción que quieres analizar
  4. Haz clic en "Stop" para detener la grabación
  5. Analiza los resultados
Qué puedes ver en el Profiler:
- Cuánto tiempo tardó cada render
- Qué componentes se re-renderizaron
- Por qué se re-renderizaron (cambio de estado, props, etc.)
- Cuál fue el componente más costoso

Interpretando los resultados

El Profiler muestra una visualización de flamegraph de los renders.

Colores:

  • Amarillo: render lento (más de lo esperado)
  • Verde: render rápido
  • Gris: componente que no se re-renderizó

Métricas importantes:

  • Render time: cuánto tiempo tardó el render
  • Commit time: cuánto tiempo tardó React en aplicar los cambios al DOM
  • Interactions: interacciones del usuario que causaron renders

Highlight updates

Activa "Highlight updates when components render" para ver visualmente qué componentes se re-renderizan en tiempo real. 

Pasos:
1. Abre React DevTools
2. Ve a la pestaña "Settings" (engranaje)
3. Activa "Highlight updates when components render"
4. Interactúa con tu aplicación
5. Los componentes que se re-renderizan se iluminan

Esto te ayuda a identificar re-renders innecesarios rápidamente.

Ejemplo práctico

import { useState } from 'react';

function App() {
  const [count, setCount] = useState(0);
  const [text, setText] = useState('');
  
  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>
        Count: {count}
      </button>
      
      <input 
        value={text} 
        onChange={(e) => setText(e.target.value)} 
      />
      
      <ExpensiveList count={count} />
    </div>
  );
}

function ExpensiveList({ count }) {
  console.log('ExpensiveList render');
  
  const items = Array.from({ length: 100 }, (_, i) => ({
    id: i,
    name: `Item ${i}`
  }));
  
  return (
    <ul>
      {items.map(item => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  );
}

Análisis con Profiler:

  1. Graba una sesión mientras escribes en el input
  2. Observa que ExpensiveList se re-renderiza aunque no cambie count
  3. Identifica que el problema es que el padre se re-renderiza
  4. Aplica React.memo a ExpensiveList
  5. Graba de nuevo y verifica que ya no se re-renderiza

Settings útiles

Configuraciones recomendadas:

  • Highlight updates: activar para ver re-renders en tiempo real
  • Record why each component rendered: activar para ver causas de renders
  • Parse hook names: activar para ver nombres de hooks personalizados
  • Hide strings where...: activar para ocultar valores largos

Profiler en producción

Por defecto, el Profiler solo funciona en modo desarrollo. Para usarlo en producción, necesitas una build especial: 

# Build de producción con Profiler habilitado
# React
react-scripts build --profile

# Vite
vite build --mode profile

# O instala la extensión "React Developer Tools" en modo producción

Advertencia: La build con Profiler es más grande y lenta. Solo úsala para debugging, no para producción real.

Otras herramientas

Chrome DevTools Performance:

  • Mide el rendimiento general de la página
  • Identifica problemas de JavaScript, CSS, red
  • Muestra el timeline completo de la página

Lighthouse:

  • Auditoría de rendimiento, accesibilidad, SEO
  • Sugerencias de mejora
  • Puntuación general de la página

Ejercicio

  1. Abre una aplicación React en el navegador
  2. Activa "Highlight updates" en React DevTools
  3. Interactúa con la aplicación y observa qué se re-renderiza
  4. Graba una sesión con el Profiler
  5. Analiza los resultados: ¿qué componentes son lentos?
  6. Identifica re-renders innecesarios
  7. Aplica optimizaciones y mide de nuevo

Resumen

  • React DevTools es esencial para debuggear aplicaciones React
  • La pestaña Components te permite inspeccionar props y estado
  • El Profiler te permite analizar el rendimiento
  • "Highlight updates" muestra re-renders en tiempo real
  • Interpreta los resultados para identificar cuellos de botella
  • Combina con Chrome DevTools Performance para análisis completo
