Docker: PostgreSQL y Stack Completo

Módulo 14 · Backend .NET 8

Introducción

Docker permite levantar toda la aplicación (frontend, backend y base de datos) con un solo comando. Es ideal para compartir el entorno entre desarrolladores.

Dockerfile del backend

# proyecto-final/backend/Dockerfile
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY . .
RUN dotnet restore
RUN dotnet publish -c Release -o /app/publish

FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS runtime
WORKDIR /app
COPY --from=build /app/publish .
EXPOSE 8080
ENTRYPOINT ["dotnet", "TaskFlow.Api.dll"]

docker-compose.yml

# proyecto-final/docker-compose.yml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: taskflow
      POSTGRES_USER: taskflow
      POSTGRES_PASSWORD: taskflow
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  api:
    build:
      context: ./backend
      dockerfile: Dockerfile
    ports:
      - "8080:8080"
    environment:
      ASPNETCORE_ENVIRONMENT: Docker
      ConnectionStrings__Default: "Host=postgres;Port=5432;Database=taskflow;Username=taskflow;Password=taskflow"
      Jwt__Key: "una-clave-super-secreta-de-al-menos-32-caracteres!"
    depends_on:
      - postgres

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    ports:
      - "3000:80"
    depends_on:
      - api

volumes:
  postgres_data:

appsettings.Docker.json

{
  "ConnectionStrings": {
    "Default": "Host=postgres;Port=5432;Database=taskflow;Username=taskflow;Password=taskflow"
  }
}

Levantar el stack

docker-compose up --build

# Ejecutar migraciones dentro del contenedor
docker-compose exec api dotnet ef database update

Resumen

  • Docker estandariza el entorno de desarrollo
  • docker-compose orquesta backend, frontend y base de datos
  • Usa variables de entorno para configurar conexiones
  • Los volúmenes persistentes mantienen la BD entre reinicios
