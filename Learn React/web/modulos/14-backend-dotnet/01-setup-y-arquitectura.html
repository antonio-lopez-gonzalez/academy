Setup y Arquitectura Limpia

Módulo 14 · Backend .NET 8

Introducción

El backend de TaskFlow es una API REST construida con .NET 8. Separaremos responsabilidades en capas claras para que el proyecto sea fácil de probar, mantener y escalar.

Arquitectura

TaskFlow.Api/
├── Controllers/          # Endpoints HTTP
├── Hubs/                 # SignalR (WebSockets)
├── Middleware/           # Manejo de errores, JWT
├── Program.cs            # Configuración y pipeline
├── appsettings.json      # Configuración
├── appsettings.Docker.json
└── TaskFlow.Api.csproj

TaskFlow.Core/
├── Entities/             # Modelos de dominio
├── DTOs/                 # Objetos de transferencia
├── Interfaces/           # Contratos de repositorios
└── TaskFlow.Core.csproj

TaskFlow.Infrastructure/
├── Data/                 # DbContext y migraciones
├── Identity/             # JWT, password hashing
├── Repositories/         # Acceso a datos
└── TaskFlow.Infrastructure.csproj

docker-compose.yml        # PostgreSQL + API

Crear la solución

dotnet new sln -n TaskFlow

dotnet new webapi -n TaskFlow.Api -o TaskFlow.Api
dotnet new classlib -n TaskFlow.Core -o TaskFlow.Core
dotnet new classlib -n TaskFlow.Infrastructure -o TaskFlow.Infrastructure

dotnet sln add TaskFlow.Api/TaskFlow.Api.csproj
dotnet sln add TaskFlow.Core/TaskFlow.Core.csproj
dotnet sln add TaskFlow.Infrastructure/TaskFlow.Infrastructure.csproj

dotnet add TaskFlow.Api reference TaskFlow.Core TaskFlow.Infrastructure
dotnet add TaskFlow.Infrastructure reference TaskFlow.Core

Paquetes NuGet

# Infrastructure
dotnet add TaskFlow.Infrastructure package Npgsql.EntityFrameworkCore.PostgreSQL --version 8.0.11
dotnet add TaskFlow.Infrastructure package Microsoft.EntityFrameworkCore.Design --version 8.0.15
dotnet add TaskFlow.Infrastructure package Microsoft.AspNetCore.Identity.EntityFrameworkCore --version 8.0.15

# API
dotnet add TaskFlow.Api package Microsoft.AspNetCore.Authentication.JwtBearer --version 8.0.15
dotnet add TaskFlow.Api package Swashbuckle.AspNetCore --version 6.6.2

Program.cs inicial

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllers();
builder.Services.AddEndpointsApiExplorer();
builder.Services.AddSwaggerGen();

var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI();
}

app.UseHttpsRedirection();
app.UseAuthorization();
app.MapControllers();

app.Run();

Resumen

  • API, Core e Infrastructure: separación de responsabilidades
  • .NET 8 Web API + PostgreSQL + EF Core
  • JWT para autenticación
  • SignalR para notificaciones en tiempo real
  • Docker para ejecutar todo el stack
