SignalR: WebSockets en .NET

Módulo 14 · Backend .NET 8

Introducción

SignalR abstrae WebSockets para que podamos enviar mensajes desde el servidor a los clientes conectados. En TaskFlow, cada proyecto es un grupo al que se unen los usuarios.

Hub de tareas

// Api/Hubs/TasksHub.cs
using Microsoft.AspNetCore.SignalR;

namespace TaskFlow.Api.Hubs;

public class TasksHub : Hub
{
    public async Task JoinProject(string projectId)
    {
        await Groups.AddToGroupAsync(Context.ConnectionId, projectId);
    }

    public async Task LeaveProject(string projectId)
    {
        await Groups.RemoveFromGroupAsync(Context.ConnectionId, projectId);
    }

    public async Task NotifyTaskCreated(string projectId, object task)
    {
        await Clients.Group(projectId)
            .SendAsync("TaskCreated", task);
    }

    public async Task NotifyTaskMoved(string projectId, object task)
    {
        await Clients.Group(projectId)
            .SendAsync("TaskMoved", task);
    }

    public async Task NotifyTaskDeleted(string projectId, Guid taskId)
    {
        await Clients.Group(projectId)
            .SendAsync("TaskDeleted", taskId);
    }
}

Registrar SignalR

builder.Services.AddSignalR();

var app = builder.Build();

app.MapHub<TasksHub>("/hubs/tasks");

Notificar desde el controlador

public class TasksController : ControllerBase
{
    private readonly IHubContext<TasksHub> _hub;

    public TasksController(TaskFlowDbContext context, IHubContext<TasksHub> hub)
    {
        _context = context;
        _hub = hub;
    }

    [HttpPost]
    public async Task<IActionResult> Create(Guid projectId, CreateTaskDto dto)
    {
        // ... crear tarea
        await _hub.Clients.Group(projectId.ToString())
            .SendAsync("TaskCreated", task);
        return Ok(task);
    }
}

Resumen

  • SignalR maneja WebSockets, SSE y polling de forma transparente
  • Los clientes se unen a grupos por projectId
  • IHubContext permite enviar mensajes desde controladores
  • El frontend escucha eventos y actualiza el estado
