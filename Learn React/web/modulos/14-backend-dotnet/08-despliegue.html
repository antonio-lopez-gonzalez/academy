Despliegue del Backend

Módulo 14 · Backend .NET 8

Introducción

Desplegar una API .NET con PostgreSQL requiere pensar en la base de datos, variables de entorno y seguridad. Veremos opciones comunes.

Opciones de hosting

Plataforma Ventaja Ideal para
Azure App Service Integración .NET nativa Producción empresarial
Railway / Render Despliegue simple con Docker Proyectos personales
VPS + Docker Control total Equipos con DevOps

Variables de entorno en producción

# Nunca guardes secretos en appsettings.json
# Usa variables de entorno del proveedor

ConnectionStrings__Default=Host=db;Port=5432;Database=taskflow;Username=...;Password=...
Jwt__Key=clave-super-larga-y-secreta-de-32-caracteres-min
Jwt__Issuer=TaskFlow
Jwt__Audience=TaskFlow
ASPNETCORE_ENVIRONMENT=Production

Checklist de despliegue

  • La build compila en Release
  • Las migraciones se aplican antes de iniciar
  • La BD está accesible desde la API
  • JWT usa una clave fuerte y única
  • CORS permite el dominio del frontend
  • HTTPS está configurado

Resumen

  • Configura la API con variables de entorno
  • Elige el hosting según presupuesto y control
  • Aplica migraciones antes de publicar
  • Protege JWT y credenciales de la BD
  • Monitorea logs y errores en producción
