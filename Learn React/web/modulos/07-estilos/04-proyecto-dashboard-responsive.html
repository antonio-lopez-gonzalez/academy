🛠 Proyecto: dashboard responsive

Módulo 7 · Estilos ⏱ 60 minutos Proyecto

1 · Introducción

Construiremos un dashboard completo y responsive que integre todo lo aprendido: CSS Modules, variables CSS, temas claro/oscuro y diseño mobile first. El dashboard tendrá: sidebar colapsable, header con toggle de tema, grid de tarjetas con estadísticas, y una tabla responsive.

Decisiones de diseño

  • Mobile first: el sidebar se oculta en móvil y se muestra como drawer.
  • Grid responsive: las tarjetas pasan de 1 a 2 a 4 columnas.
  • Tabla responsive: en móvil, las tablas se convierten en tarjetas apiladas.
  • Tema persistente: se guarda en localStorage.

5 · Paso 3: App.jsx

src/App.jsx
import { useState, useEffect } from "react";
import Layout from "./components/Layout/Layout";
import Header from "./components/Header/Header";
import Sidebar from "./components/Sidebar/Sidebar";
import StatsGrid from "./components/StatsGrid";
import DataTable from "./components/DataTable/DataTable";

export default function App() {
  const [theme, setTheme] = useState(() => {
    return localStorage.getItem("theme") || "light";
  });
  const [sidebarOpen, setSidebarOpen] = useState(false);

  useEffect(() => {
    document.documentElement.dataset.theme = theme;
    localStorage.setItem("theme", theme);
  }, [theme]);

  function toggleTheme() {
    setTheme((t) => (t === "light" ? "dark" : "light"));
  }

  return (
    <Layout>
      <Header
        onMenuClick={() => setSidebarOpen(!sidebarOpen)}
        theme={theme}
        onToggleTheme={toggleTheme}
      />
      <Sidebar open={sidebarOpen} onClose={() => setSidebarOpen(false)} />
      <main className="main">
        <h1>Dashboard</h1>
        <StatsGrid />
        <DataTable />
      </main>
    </Layout>
  );
}

7 · Paso 5: instrucciones

  1. Crea el proyecto con Vite: pnpm create vite@latest m07-dashboard -- --template react.
  2. Crea src/styles/tokens.css con todas las variables.
  3. Importa los tokens en index.css.
  4. Crea los componentes: Layout, Header, Sidebar, StatsGrid, StatCard, DataTable.
  5. Cada componente con su CSS Module.
  6. Implementa el toggle de tema con persistencia en localStorage.
  7. Implementa el sidebar colapsable en móvil.
  8. Prueba en DevTools responsive: móvil, tablet, desktop.

10 · Preguntas frecuentes

¿Cómo manejo el sidebar en móvil?
En móvil, el sidebar es un drawer que se superpone al contenido. Usa position: fixed y un overlay. En desktop, es parte del grid layout.
¿Cómo hago la tabla responsive?
Dos opciones: scroll horizontal (overflow-x: auto) o transformar en tarjetas en móvil (ocultar table y mostrar divs con data-label).
¿Cómo pruebo el tema oscuro?
Cambia document.documentElement.dataset.theme y verifica que todas las variables se actualizan. Prueba todos los componentes.
¿Puedo usar CSS Grid para todo el layout?
Sí, CSS Grid es ideal para layouts 2D (filas y columnas). Flexbox es mejor para layouts 1D (una fila o una columna).
