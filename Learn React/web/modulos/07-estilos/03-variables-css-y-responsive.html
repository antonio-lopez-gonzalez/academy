Variables CSS y responsive

Módulo 7 · Estilos ⏱ 35 minutos

1 · Introducción

Las variables CSS (custom properties) son una de las características más potentes del CSS moderno. Te permiten definir valores reutilizables (--color-primary), cambiarlos dinámicamente desde JavaScript, y crear temas (claro/oscuro) sin librerías externas.

Combinadas con media queries, son la base del diseño responsive: una misma interfaz que se adapta a móviles, tablets y escritorio sin duplicar código.

2 · Teoría

Variables CSS: sintaxis

:root {
  --color-primary: #0066cc;
  --color-danger: #cc0000;
  --spacing-sm: 0.5rem;
  --spacing-md: 1rem;
  --spacing-lg: 2rem;
  --radius: 8px;
  --font-size-base: 1rem;
}

.button {
  background: var(--color-primary);
  padding: var(--spacing-sm) var(--spacing-md);
  border-radius: var(--radius);
}
  • Se definen con -- como prefijo.
  • :root las hace disponibles en toda la app.
  • Se usan con var(--nombre).
  • Pueden tener fallback: var(--color, red).

Temas con variables CSS

:root, [data-theme="light"] {
  --bg: #ffffff;
  --text: #333333;
  --surface: #f5f5f5;
}

[data-theme="dark"] {
  --bg: #1a1a1a;
  --text: #e0e0e0;
  --surface: #2a2a2a;
}

body {
  background: var(--bg);
  color: var(--text);
}
// Cambiar tema desde React:
document.documentElement.dataset.theme = "dark";
// o
document.documentElement.setAttribute("data-theme", "dark");

Media queries: responsive

/* Mobile first: estilos base para móvil */
.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: var(--spacing-md);
}

/* Tablet: 2 columnas */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop: 3 columnas */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

Variables CSS + media queries

:root {
  --spacing-page: 1rem;
}

@media (min-width: 768px) {
  :root {
    --spacing-page: 2rem;
  }
}

.container {
  padding: var(--spacing-page);   /* cambia según el viewport */
}

3 · Ejemplo mínimo

src/index.css
:root {
  --color-primary: #0066cc;
  --color-text: #333;
  --color-bg: #fff;
  --radius: 8px;
  --spacing: 1rem;
}

[data-theme="dark"] {
  --color-primary: #4dabf7;
  --color-text: #e0e0e0;
  --color-bg: #1a1a1a;
}

body {
  background: var(--color-bg);
  color: var(--color-text);
  font-family: system-ui, sans-serif;
}

.card {
  background: var(--color-bg);
  color: var(--color-text);
  padding: var(--spacing);
  border-radius: var(--radius);
  border: 1px solid color-mix(in srgb, var(--color-text) 20%, transparent);
}
src/App.jsx
import { useState } from "react";

export default function App() {
  const [theme, setTheme] = useState("light");

  function toggleTheme() {
    const next = theme === "light" ? "dark" : "light";
    setTheme(next);
    document.documentElement.dataset.theme = next;
  }

  return (
    <div>
      <button onClick={toggleTheme}>Cambiar tema</button>
      <div className="card">Contenido de la tarjeta</div>
    </div>
  );
}

4 · Ejemplo real

Sistema de diseño completo con variables y responsive:

src/styles/tokens.css
:root {
  /* Colores */
  --color-primary: #0066cc;
  --color-primary-hover: #0052a3;
  --color-success: #22c55e;
  --color-warning: #f59e0b;
  --color-danger: #ef4444;

  /* Espaciado */
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-3: 0.75rem;
  --space-4: 1rem;
  --space-6: 1.5rem;
  --space-8: 2rem;

  /* Tipografía */
  --font-size-sm: 0.875rem;
  --font-size-base: 1rem;
  --font-size-lg: 1.125rem;
  --font-size-xl: 1.5rem;
  --font-size-2xl: 2rem;

  /* Bordes */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;

  /* Sombras */
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.05);
  --shadow-md: 0 4px 6px rgba(0, 0, 0, 0.1);
  --shadow-lg: 0 10px 15px rgba(0, 0, 0, 0.1);
}

/* Tema oscuro */
[data-theme="dark"] {
  --color-primary: #4dabf7;
  --color-primary-hover: #339af0;
}

/* Responsive spacing */
@media (min-width: 768px) {
  :root {
    --space-4: 1.5rem;
    --space-8: 3rem;
  }
}

6 · Errores habituales

Error 1: no usar mobile first

/* ✘ Desktop first: luego hay que sobreescribir para móvil */
.grid { grid-template-columns: repeat(3, 1fr); }
@media (max-width: 768px) { .grid { grid-template-columns: 1fr; } }

/* ✔ Mobile first: progresión natural */
.grid { grid-template-columns: 1fr; }
@media (min-width: 768px) { .grid { grid-template-columns: repeat(2, 1fr); } }
@media (min-width: 1024px) { .grid { grid-template-columns: repeat(3, 1fr); } }

Error 2: valores fijos para tipografía

h1 { font-size: 32px; }   /* ✘ no escala con las preferencias del usuario */
h1 { font-size: 2rem; }   /* ✔ respeta el font-size del root */

Error 3: no probar en tamaños intermedios

Prueba en móvil (375px), tablet (768px), desktop (1024px) y desktop grande (1440px). Los bugs responsive suelen estar en los breakpoints.

7 · Ejercicio guiado

  1. Crea un archivo tokens.css con variables: colores, espaciado, tipografía, bordes.
  2. Define un tema claro (por defecto) y oscuro ([data-theme="dark"]).
  3. Importa tokens.css en index.css.
  4. Crea un componente ThemeToggle que cambie el atributo data-theme del html.
  5. Añade media queries para que el espaciado sea mayor en desktop.
  6. Guarda la preferencia de tema en localStorage y restáurala al cargar.

8 · Reto

🎯 Layout responsive completo

Crea un layout con: header fijo, sidebar que se oculta en móvil (menú hamburguesa), main con grid responsive (1/2/3 columnas), footer. Todo con variables CSS y mobile first.

9 · Resumen

  • Variables CSS: --nombre: valor, se usan con var(--nombre).
  • Temas: cambia variables según [data-theme].
  • Responsive: mobile first con min-width en media queries.
  • Breakpoints: móvil (base), tablet (768px), desktop (1024px).
  • Unidades relativas: rem para tipografía, % / fr para layouts.

10 · Preguntas frecuentes

¿Puedo cambiar variables CSS desde JavaScript?
Sí: document.documentElement.style.setProperty('--color-primary', 'red'). O cambia el atributo data-theme para cambiar un grupo entero de variables.
¿Las variables CSS funcionan en todos los navegadores?
Sí, en todos los navegadores modernos. IE11 no las soporta, pero ya no es relevante en 2024+.
¿Variables CSS o preprocesadores (Sass)?
Las variables CSS son nativas y dinámicas (cambian en runtime). Sass es estático (se compila a CSS). Para temas dinámicos, variables CSS. Para mixins y funciones, Sass.
¿Cómo pruebo el responsive sin un dispositivo real?
DevTools → modo responsive (Ctrl+Shift+M). Simula distintos viewports. Pero siempre prueba en dispositivos reales antes de publicar.
