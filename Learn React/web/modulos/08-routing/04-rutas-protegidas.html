Rutas protegidas

Módulo 8 · Routing ⏱ 35 minutos

1 · Introducción

Muchas aplicaciones tienen áreas restringidas: dashboards, perfiles de usuario, paneles de administración. Estas rutas solo deben ser accesibles para usuarios autenticados (o con ciertos permisos). React Router no tiene un concepto nativo de "rutas protegidas", pero podemos implementarlas fácilmente con componentes wrapper.

El patrón es simple: un componente que verifica si el usuario está autenticado. Si lo está, renderiza el contenido protegido. Si no, redirige al login.

2 · Teoría

Componente ProtectedRoute

import { Navigate, useLocation } from "react-router";

function ProtectedRoute({ children, isAuth }) {
  const location = useLocation();

  if (!isAuth) {
    // Redirige al login, guardando la URL original
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  return children;
}

Uso en las rutas

<Routes>
  <Route path="/login" element={<Login />} />
  <Route
    path="/dashboard"
    element={
      <ProtectedRoute isAuth={isAuth}>
        <Dashboard />
      </ProtectedRoute>
    }
  />
</Routes>

Volver a la URL original después del login

function Login() {
  const navigate = useNavigate();
  const location = useLocation();
  const from = location.state?.from?.pathname || "/";

  async function handleLogin() {
    await login();
    navigate(from, { replace: true });
  }

  return <button onClick={handleLogin}>Login</button>;
}

Protección basada en roles

function RoleRoute({ children, user, requiredRole }) {
  if (!user) {
    return <Navigate to="/login" replace />;
  }

  if (user.role !== requiredRole) {
    return <Navigate to="/unauthorized" replace />;
  }

  return children;
}

// Uso:
<Route
  path="/admin"
  element={
    <RoleRoute user={user} requiredRole="admin">
      <AdminPanel />
    </RoleRoute>
  }
/>

3 · Ejemplo mínimo

src/App.jsx
import { BrowserRouter, Routes, Route, Navigate, useLocation, useNavigate } from "react-router";
import { useState } from "react";

function ProtectedRoute({ children, isAuth }) {
  const location = useLocation();

  if (!isAuth) {
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  return children;
}

function Login({ setIsAuth }) {
  const navigate = useNavigate();
  const location = useLocation();
  const from = location.state?.from?.pathname || "/dashboard";

  function handleLogin() {
    setIsAuth(true);
    navigate(from, { replace: true });
  }

  return (
    <div>
      <h1>Login</h1>
      <button onClick={handleLogin}>Iniciar sesión</button>
    </div>
  );
}

function Dashboard() {
  return <h1>Dashboard protegido</h1>;
}

export default function App() {
  const [isAuth, setIsAuth] = useState(false);

  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<h1>Inicio</h1>} />
        <Route
          path="/login"
          element={<Login setIsAuth={setIsAuth} />}
        />
        <Route
          path="/dashboard"
          element={
            <ProtectedRoute isAuth={isAuth}>
              <Dashboard />
            </ProtectedRoute>
          }
        />
      </Routes>
    </BrowserRouter>
  );
}

4 · Ejemplo real

Sistema de autenticación completo con rutas protegidas y roles:

src/components/ProtectedRoute.jsx
import { Navigate, useLocation } from "react-router";

export default function ProtectedRoute({ children, isAuth, user, requiredRole }) {
  const location = useLocation();

  if (!isAuth) {
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  if (requiredRole && user?.role !== requiredRole) {
    return <Navigate to="/unauthorized" replace />;
  }

  return children;
}
src/App.jsx
import { BrowserRouter, Routes, Route, Link } from "react-router";
import { useState } from "react";
import ProtectedRoute from "./components/ProtectedRoute";

function Login({ setIsAuth, setUser }) {
  function handleLogin() {
    setIsAuth(true);
    setUser({ name: "Ana", role: "admin" });
  }

  return (
    <div>
      <h1>Login</h1>
      <button onClick={handleLogin}>Iniciar sesión como Admin</button>
    </div>
  );
}

function Dashboard() {
  return <h1>Dashboard</h1>;
}

function AdminPanel() {
  return <h1>Panel de Administración</h1>;
}

function Unauthorized() {
  return <h1>No tienes permisos para acceder a esta página</h1>;
}

export default function App() {
  const [isAuth, setIsAuth] = useState(false);
  const [user, setUser] = useState(null);

  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Inicio</Link> |{" "}
        <Link to="/dashboard">Dashboard</Link> |{" "}
        <Link to="/admin">Admin</Link>
      </nav>

      <Routes>
        <Route path="/" element={<h1>Inicio</h1>} />
        <Route
          path="/login"
          element={<Login setIsAuth={setIsAuth} setUser={setUser} />}
        />
        <Route
          path="/dashboard"
          element={
            <ProtectedRoute isAuth={isAuth}>
              <Dashboard />
            </ProtectedRoute>
          }
        />
        <Route
          path="/admin"
          element={
            <ProtectedRoute isAuth={isAuth} user={user} requiredRole="admin">
              <AdminPanel />
            </ProtectedRoute>
          }
        />
        <Route path="/unauthorized" element={<Unauthorized />} />
      </Routes>
    </BrowserRouter>
  );
}

6 · Errores habituales

Error 1: proteger solo el frontend

// ✘ El usuario puede saltarse la protección modificando la URL
// ✔ El backend también debe verificar autenticación y permisos

Error 2: no guardar la URL original

function Login() {
  navigate("/dashboard");   // ✘ siempre va al dashboard
  const from = location.state?.from?.pathname || "/dashboard";
  navigate(from);   // ✔ vuelve a donde intentaba ir
}

Error 3: mostrar contenido antes de verificar

function Dashboard() {
  // ✘ muestra contenido sensible antes de verificar
  return <div>Datos privados...</div>;
}

function Dashboard() {
  if (!isAuth) return null;   // ✔ no muestra nada si no está autenticado
  return <div>Datos privados...</div>;
}

7 · Ejercicio guiado

  1. Crea un componente ProtectedRoute que verifique isAuth.
  2. Si no está autenticado, redirige a /login con state={{ from: location }}.
  3. En Login, lee location.state.from y vuelve a esa URL después del login.
  4. Protege las rutas /dashboard y /profile.
  5. Prueba: intenta acceder a /dashboard sin login, inicia sesión, verifica que vuelves a /dashboard.

8 · Reto

🎯 Sistema de roles

Crea un sistema con tres roles: user, editor, admin. Protege rutas según el rol: /editor requiere editor o admin, /admin requiere admin. Muestra una página "no autorizado" si el usuario no tiene el rol requerido.

9 · Resumen

  • Rutas protegidas: componentes wrapper que verifican autenticación.
  • Guardar la URL original con state={{ from: location }}.
  • Volver a la URL original después del login.
  • Protección basada en roles: verificar permisos además de autenticación.
  • Siempre verificar también en el backend.

10 · Preguntas frecuentes

¿Puedo usar Context para la autenticación?
Sí, es lo habitual. Crea un AuthContext con isAuth y user, y úsalo en ProtectedRoute.
¿Cómo manejo tokens JWT?
Guarda el token en localStorage o cookies httpOnly. Envíalo en el header Authorization en cada petición al backend.
¿Puedo proteger rutas anidadas?
Sí, aplica ProtectedRoute al layout padre y todas las rutas hijas estarán protegidas.
¿Cómo hago logout?
Limpia el token y el estado de autenticación, luego redirige a /login con navigate("/login", { replace: true }).
