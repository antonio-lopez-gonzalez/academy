Filtros, Búsqueda y Paginación

Módulo 13 · Proyecto Final

Introducción

Cuando un proyecto crece, encontrar una tarea rápidamente se vuelve esencial. Aprenderemos a filtrar por estado, prioridad y etiquetas, buscar por texto y paginar resultados sin perder rendimiento.

Decisión: cliente vs servidor

Estrategia Ventaja Cuándo usarla
Cliente Respuesta inmediata, sin llamadas extra Pocos cientos de tareas
Servidor Escalable, menos datos transferidos Miles de tareas o datos sensibles

En TaskFlow usaremos ambas: filtros locales para el tablero actual y paginación en el servidor para vistas de listado grandes.

Estado de filtros

// src/hooks/useTaskFilters.js
import { useState, useMemo } from 'react'

export function useTaskFilters(tasks) {
  const [search, setSearch] = useState('')
  const [status, setStatus] = useState('all')
  const [priority, setPriority] = useState('all')
  const [label, setLabel] = useState('all')

  const filtered = useMemo(() => {
    const query = search.toLowerCase()

    return tasks.filter((task) => {
      const matchesSearch =
        task.title.toLowerCase().includes(query) ||
        task.description?.toLowerCase().includes(query)

      const matchesStatus = status === 'all' || task.status === status
      const matchesPriority = priority === 'all' || task.priority === priority
      const matchesLabel = label === 'all' || task.labels?.includes(label)

      return matchesSearch && matchesStatus && matchesPriority && matchesLabel
    })
  }, [tasks, search, status, priority, label])

  const availableLabels = useMemo(() => {
    const labels = new Set()
    tasks.forEach((t) => t.labels?.forEach((l) => labels.add(l)))
    return Array.from(labels)
  }, [tasks])

  return {
    filters: { search, status, priority, label },
    setSearch,
    setStatus,
    setPriority,
    setLabel,
    filtered,
    availableLabels
  }
}

Componente de filtros

// src/components/tasks/TaskFilters.jsx
import { TASK_STATUS, TASK_PRIORITY } from '../../types/task'
import styles from './TaskFilters.module.css'

export default function TaskFilters({
  filters,
  availableLabels,
  onSearchChange,
  onStatusChange,
  onPriorityChange,
  onLabelChange
}) {
  return (
    <div className={styles.filters}>
      <input
        type="search"
        placeholder="Buscar tareas..."
        value={filters.search}
        onChange={(e) => onSearchChange(e.target.value)}
      />

      <select value={filters.status} onChange={(e) => onStatusChange(e.target.value)}>
        <option value="all">Todos los estados</option>
        <option value={TASK_STATUS.TODO}>Por hacer</option>
        <option value={TASK_STATUS.IN_PROGRESS}>En progreso</option>
        <option value={TASK_STATUS.DONE}>Completadas</option>
      </select>

      <select value={filters.priority} onChange={(e) => onPriorityChange(e.target.value)}>
        <option value="all">Todas las prioridades</option>
        <option value={TASK_PRIORITY.LOW}>Baja</option>
        <option value={TASK_PRIORITY.MEDIUM}>Media</option>
        <option value={TASK_PRIORITY.HIGH}>Alta</option>
      </select>

      <select value={filters.label} onChange={(e) => onLabelChange(e.target.value)}>
        <option value="all">Todas las etiquetas</option>
        {availableLabels.map((label) => (
          <option key={label} value={label}>{label}</option>
        ))}
      </select>
    </div>
  )
}

Paginación del servidor

// src/hooks/usePaginatedTasks.js
import { useState, useEffect, useCallback } from 'react'
import { taskService } from '../services/taskService'

export function usePaginatedTasks(projectId, filters) {
  const [tasks, setTasks] = useState([])
  const [page, setPage] = useState(1)
  const [pageSize] = useState(10)
  const [total, setTotal] = useState(0)
  const [loading, setLoading] = useState(true)

  async function load() {
    try {
      setLoading(true)
      const data = await taskService.search(projectId, {
        ...filters,
        page,
        pageSize
      })
      setTasks(data.items)
      setTotal(data.total)
    } finally {
      setLoading(false)
    }
  }

  useEffect(() => {
    load()
  }, [projectId, filters, page, pageSize])

  const nextPage = useCallback(() => setPage((p) => p + 1), [])
  const prevPage = useCallback(() => setPage((p) => Math.max(1, p - 1)), [])
  const totalPages = Math.ceil(total / pageSize)

  return { tasks, loading, page, totalPages, nextPage, prevPage, reload: load }
}

Controles de paginación

// src/components/ui/Pagination.jsx
import styles from './Pagination.module.css'

export default function Pagination({ page, totalPages, onNext, onPrev }) {
  return (
    <div className={styles.pagination}>
      <button onClick={onPrev} disabled={page <= 1}>
        Anterior
      </button>
      <span>Página {page} de {totalPages}</span>
      <button onClick={onNext} disabled={page >= totalPages}>
        Siguiente
      </button>
    </div>
  )
}

Resumen

  • useTaskFilters combina búsqueda, estado, prioridad y etiquetas con useMemo
  • usePaginatedTasks delega la paginación al servidor
  • Elige filtrado en cliente para pocos datos y en servidor para muchos
  • Mantén los filtros cerca del componente que los consume
  • Resetea la página a 1 cuando cambian los filtros
