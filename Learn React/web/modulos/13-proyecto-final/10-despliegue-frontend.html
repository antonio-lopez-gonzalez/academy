Introducción

El último paso de cualquier proyecto es ponerlo disponible en Internet. Veremos cómo preparar una build optimizada, configurar variables de entorno y desplegar en Vercel o Netlify.

Variables de entorno

# .env.development
VITE_API_URL=http://localhost:8080/api
VITE_HUB_URL=http://localhost:8080/hubs/tasks

# .env.production
VITE_API_URL=https://api.taskflow.app/api
VITE_HUB_URL=https://api.taskflow.app/hubs/tasks

En Vite, solo las variables que empiezan por VITE_ llegan al cliente. Se acceden con import.meta.env.VITE_API_URL.

Script de build

// package.json
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "test": "vitest"
  }
}
# Compilar para producción
pnpm build

# Previsualizar localmente la build
pnpm preview

Reescritura de rutas

En SPA con React Router, el servidor debe devolver index.html para cualquier ruta desconocida. De lo contrario, al recargar /projects/123 obtendremos un 404. 

// vercel.json
{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}
# netlify.toml
[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

Despliegue en Vercel

# Instalar CLI (global o en el proyecto)
pnpm add -g vercel

# Login y despliegue
vercel login
vercel --prod

Despliegue con Docker

# Dockerfile
FROM node:22-alpine AS builder
WORKDIR /app
RUN corepack enable && corepack prepare pnpm@latest --activate
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile
COPY . .
RUN pnpm build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
# nginx.conf
server {
  listen 80;
  root /usr/share/nginx/html;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }
}

Checklist antes de desplegar

  • La build finaliza sin errores
  • Las variables de entorno de producción están configuradas
  • El backend permite CORS desde el dominio del frontend
  • Las rutas protegidas redirigen correctamente al login
  • Los tests pasan con pnpm test
  • La app funciona en móvil y en tema oscuro

Resumen

  • Usa variables VITE_ para configurar URLs por entorno
  • Configura reescrituras SPA para React Router
  • Vercel y Netlify son las opciones más rápidas
  • Docker + Nginx ofrece más control en producción
  • Revisa CORS, tests y responsive antes de publicar
