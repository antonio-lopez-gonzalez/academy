Vitest

Módulo 12 · Testing

Introducción

Vitest es un framework de testing ultrarrápido diseñado específicamente para proyectos Vite. Es compatible con la API de Jest, por lo que si ya conoces Jest, te sentirás como en casa.

¿Por qué Vitest y no Jest?

  • Integración nativa con Vite: usa la misma configuración y transformaciones
  • Ultrarrápido: aprovecha el bundling de Vite
  • TypeScript nativo: soporte out-of-the-box
  • API compatible con Jest: migración sencilla
  • Hot Module Replacement: los tests se actualizan en tiempo real

Instalación y configuración

# Instalar dependencias
pnpm add -D vitest @vitest/ui jsdom

Configuración en vite.config.js:

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  test: {
    environment: 'jsdom',
    globals: true,
    setupFiles: ['./src/test/setup.js']
  }
})

Scripts en package.json:

{
  "scripts": {
    "test": "vitest",
    "test:ui": "vitest --ui",
    "test:run": "vitest run",
    "test:coverage": "vitest run --coverage"
  }
}

Tu primer test

// src/utils/math.js
export function sum(a, b) {
  return a + b
}

export function multiply(a, b) {
  return a * b
}

// src/utils/__tests__/math.test.js
import { describe, it, expect } from 'vitest'
import { sum, multiply } from '../math'

describe('Math utilities', () => {
  describe('sum', () => {
    it('should sum two positive numbers', () => {
      expect(sum(2, 3)).toBe(5)
    })

    it('should handle negative numbers', () => {
      expect(sum(-1, 1)).toBe(0)
    })

    it('should handle zero', () => {
      expect(sum(0, 5)).toBe(5)
    })
  })

  describe('multiply', () => {
    it('should multiply two numbers', () => {
      expect(multiply(3, 4)).toBe(12)
    })

    it('should handle zero', () => {
      expect(multiply(5, 0)).toBe(0)
    })
  })
})

Matchers comunes

// Igualdad
expect(value).toBe(expected)           // ===
expect(value).toEqual(expected)        // Deep equality
expect(value).toStrictEqual(expected)  // Deep equality + tipos

// Truthiness
expect(value).toBeTruthy()
expect(value).toBeFalsy()
expect(value).toBeNull()
expect(value).toBeUndefined()
expect(value).toBeDefined()

// Números
expect(number).toBeGreaterThan(3)
expect(number).toBeGreaterThanOrEqual(3)
expect(number).toBeLessThan(5)
expect(number).toBeLessThanOrEqual(5)
expect(number).toBeCloseTo(0.3)  // Para floats

// Strings
expect(string).toMatch(/regex/)
expect(string).toContain('substring')

// Arrays
expect(array).toContain(item)
expect(array).toContainEqual(item)  // Deep equality
expect(array).toHaveLength(3)

// Objetos
expect(object).toHaveProperty('key')
expect(object).toHaveProperty('key', value)

// Errores
expect(fn).toThrow()
expect(fn).toThrow('error message')
expect(fn).toThrow(Error)

Setup y teardown

import { describe, it, expect, beforeAll, afterAll, beforeEach, afterEach } from 'vitest'

describe('Database tests', () => {
  let db

  beforeAll(async () => {
    // Se ejecuta una vez antes de todos los tests
    db = await connectToDatabase()
  })

  afterAll(async () => {
    // Se ejecuta una vez después de todos los tests
    await db.close()
  })

  beforeEach(() => {
    // Se ejecuta antes de cada test
    db.clear()
  })

  afterEach(() => {
    // Se ejecuta después de cada test
    jest.clearAllMocks()
  })

  it('should insert data', () => {
    db.insert({ name: 'test' })
    expect(db.getAll()).toHaveLength(1)
  })
})

Tests asíncronos

import { describe, it, expect } from 'vitest'

describe('Async tests', () => {
  it('should fetch data', async () => {
    const data = await fetchData()
    expect(data).toHaveProperty('id')
  })

  it('should handle promises', () => {
    return fetchData().then(data => {
      expect(data).toHaveProperty('id')
    })
  })

  it('should test async errors', async () => {
    await expect(fetchDataInvalid()).rejects.toThrow('Invalid ID')
  })

  it('should use fake timers', async () => {
    vi.useFakeTimers()
    
    const promise = fetchDataWithDelay()
    
    vi.advanceTimersByTime(1000)
    
    const result = await promise
    expect(result).toBeDefined()
    
    vi.useRealTimers()
  })
})

Parameterized tests

import { describe, it, expect } from 'vitest'
import { formatPrice } from '../utils'

describe('formatPrice', () => {
  it.each([
    [10, '$10.00'],
    [10.5, '$10.50'],
    [10.999, '$11.00'],
    [0, '$0.00'],
  ])('should format %s as %s', (input, expected) => {
    expect(formatPrice(input)).toBe(expected)
  })
})

Coverage

# Instalar plugin de coverage
pnpm add -D @vitest/coverage-v8

# Ejecutar con coverage
pnpm test:coverage

Configuración en vite.config.js:

export default defineConfig({
  test: {
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        'src/test/',
      ]
    }
  }
})

Watch mode

Vitest ejecuta tests en watch mode por defecto. Cada vez que guardas un archivo, los tests afectados se ejecutan automáticamente. 

# Modo watch (por defecto)
pnpm test

# Ejecutar una vez y salir
pnpm test:run

# UI interactiva
pnpm test:ui

Resumen

  • Vitest es el framework de testing nativo para Vite
  • API compatible con Jest, migración sencilla
  • Matchers potentes para todo tipo de aserciones
  • Soporte nativo para TypeScript y ESM
  • Watch mode y HMR para desarrollo rápido
  • Coverage integrado con @vitest/coverage-v8
