🛠 Proyecto: aplicación multipágina

Módulo 8 · Routing ⏱ 65 minutos Proyecto

1 · Introducción

Vamos a construir una aplicación multipágina completa que integre todo lo aprendido en el módulo: rutas estáticas y dinámicas, rutas anidadas, parámetros, navegación programática y rutas protegidas. La aplicación será un blog con:

  • Página de inicio con lista de posts
  • Página de detalle de post (/post/:slug)
  • Página de categorías (/category/:name)
  • Panel de administración protegido
  • Login con redirección

import { Link, Outlet } from "react-router";

  return (
    <div>

      </main>

src/App.jsx
import { BrowserRouter, Routes, Route } from "react-router";
import Layout from "./components/Layout";
import Home from "./pages/Home";
import PostDetail from "./pages/PostDetail";
import Category from "./pages/Category";
import Login from "./pages/Login";
import Admin from "./pages/Admin";
import NotFound from "./pages/NotFound";

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}>
          <Route index element={<Home />} />
          <Route path="post/:slug" element={<PostDetail />} />
          <Route path="category/:name" element={<Category />} />
          <Route path="login" element={<Login />} />
          <Route path="admin" element={<Admin />} />
          <Route path="*" element={<NotFound />} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}

4 · Paso 2: Páginas dinámicas

src/pages/PostDetail.jsx
import { useParams, Link } from "react-router";
import { posts } from "../data/posts";

export default function PostDetail() {
  const { slug } = useParams();
  const post = posts.find((p) => p.slug === slug);

  if (!post) {
    return <h1>Post no encontrado</h1>;
  }

  return (
    <article>
      <h1>{post.title}</h1>
      <p>Por {post.author} · {post.date}</p>
      <Link to={`/category/${post.category}`}>
        Categoría: {post.category}
      </Link>
      <div>{post.content}</div>
    </article>
  );
}
src/pages/Category.jsx
import { useParams, Link } from "react-router";
import { posts } from "../data/posts";

export default function Category() {
  const { name } = useParams();
  const categoryPosts = posts.filter((p) => p.category === name);

  return (
    <div>
      <h1>Categoría: {name}</h1>
      {categoryPosts.length === 0 ? (
        <p>No hay posts en esta categoría</p>
      ) : (
        <ul>
          {categoryPosts.map((post) => (
            <li key={post.id}>
              <Link to={`/post/${post.slug}`}>{post.title}</Link>
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}

5 · Paso 3: Rutas protegidas

src/components/ProtectedRoute.jsx
import { Navigate, useLocation } from "react-router";

export default function ProtectedRoute({ children, isAuth }) {
  const location = useLocation();

  if (!isAuth) {
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  return children;
}
src/pages/Login.jsx
import { useNavigate, useLocation } from "react-router";

export default function Login({ setIsAuth }) {
  const navigate = useNavigate();
  const location = useLocation();
  const from = location.state?.from?.pathname || "/";

  function handleLogin() {
    setIsAuth(true);
    navigate(from, { replace: true });
  }

  return (
    <div>
      <h1>Login</h1>
      <button onClick={handleLogin}>Iniciar sesión</button>
    </div>
  );
}

7 · Paso 5: Instrucciones

  1. Crea el proyecto: pnpm create vite@latest m08-blog -- --template react.
  2. Instala React Router: pnpm add react-router.
  3. Crea el archivo src/data/posts.js con datos de ejemplo.
  4. Crea los componentes: Layout, ProtectedRoute.
  5. Crea las páginas: Home, PostDetail, Category, Login, Admin, NotFound.
  6. Configura las rutas en App.jsx.
  7. Añade estilos en index.css.
  8. Prueba navegar entre páginas, acceder a posts, filtrar por categoría.
  9. Prueba la protección de rutas: intenta acceder a /admin sin login.

10 · Preguntas frecuentes

¿Puedo usar una API real en lugar de datos locales?
Sí, usa useEffect y fetch para cargar posts desde una API. Veremos esto en el Módulo 9.
¿Cómo manejo el SEO en una SPA?
Las SPAs tienen problemas de SEO. Considera Next.js o React Router con SSR para mejor SEO.
¿Puedo añadir animaciones entre páginas?
Sí, con librerías como Framer Motion o React Transition Group.
¿Cómo manejo el estado global (usuario autenticado)?
Usa Context API (Módulo 10) o una librería como Zustand o Redux.
