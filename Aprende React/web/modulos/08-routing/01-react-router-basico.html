React Router: primeras rutas

Módulo 8 · Routing ⏱ 40 minutos

1 · Introducción

Hasta ahora, todas nuestras aplicaciones han sido de una sola página: todo el código vive en App.jsx y cambiamos lo que se muestra con estado. Pero las aplicaciones reales tienen múltiples páginas: inicio, sobre nosotros, contacto, perfil de usuario…

En una web tradicional, cada página es un archivo HTML diferente y el navegador recarga la página completa al navegar. En una SPA (Single Page Application), queremos cambiar el contenido sin recargar. Ahí entra React Router: la librería estándar para manejar rutas en React.

React Router te permite definir rutas (/about, /contact) y asociar cada una con un componente. Cuando el usuario navega, React Router cambia el componente mostrado sin recargar la página.

2 · Teoría

Instalación

pnpm add react-router

Nota: en React Router v7+, el paquete principal es react-router (no react-router-dom).

Componentes básicos

  • BrowserRouter: envuelve toda tu app y habilita el enrutamiento.
  • Routes: contenedor de rutas.
  • Route: define una ruta (path) y el componente que muestra (element).
  • Link: enlace que navega sin recargar (reemplaza <a>).

Estructura básica

import { BrowserRouter, Routes, Route, Link } from "react-router";

function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Inicio</Link>
        <Link to="/about">Sobre nosotros</Link>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}

Cómo funciona

  1. BrowserRouter escucha los cambios en la URL.
  2. Cuando la URL cambia, Routes busca la Route que coincide.
  3. El componente de esa ruta se renderiza en el lugar de Routes.
  4. Link cambia la URL sin recargar (usa history.pushState internamente).

Ruta comodín (404)

<Route path="*" element={<NotFound />} />

La ruta * coincide con cualquier URL que no haya matcheado antes. Úsala al final para mostrar una página 404.

3 · Ejemplo mínimo

src/App.jsx
import { BrowserRouter, Routes, Route, Link } from "react-router";

function Home() {
  return <h1>Página de inicio</h1>;
}

function About() {
  return <h1>Sobre nosotros</h1>;
}

export default function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Inicio</Link> |{" "}
        <Link to="/about">Sobre nosotros</Link>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="*" element={<h1>404 - Página no encontrada</h1>} />
      </Routes>
    </BrowserRouter>
  );
}

4 · Ejemplo real

App con múltiples páginas y navegación activa:

src/App.jsx
import { BrowserRouter, Routes, Route, Link, useLocation } from "react-router";

function Home() {
  return (
    <div>
      <h1>Bienvenido</h1>
      <p>Esta es la página de inicio.</p>
    </div>
  );
}

function About() {
  return (
    <div>
      <h1>Sobre nosotros</h1>
      <p>Somos un equipo apasionado por React.</p>
    </div>
  );
}

function Contact() {
  return (
    <div>
      <h1>Contacto</h1>
      <p>Email: hola@ejemplo.com</p>
    </div>
  );
}

function NavLink({ to, children }) {
  const location = useLocation();
  const isActive = location.pathname === to;

  return (
    <Link
      to={to}
      style={{
        fontWeight: isActive ? "bold" : "normal",
        color: isActive ? "blue" : "black",
      }}
    >
      {children}
    </Link>
  );
}

export default function App() {
  return (
    <BrowserRouter>
      <nav>
        <NavLink to="/">Inicio</NavLink> |{" "}
        <NavLink to="/about">Sobre nosotros</NavLink> |{" "}
        <NavLink to="/contact">Contacto</NavLink>
      </nav>

      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="/contact" element={<Contact />} />
        <Route path="*" element={<h1>404 - Página no encontrada</h1>} />
      </Routes>
    </BrowserRouter>
  );
}

6 · Errores habituales

Error 1: usar <a> en lugar de Link

<a href="/about">Sobre nosotros</a>   // ✘ recarga la página
<Link to="/about">Sobre nosotros</Link>   // ✔ navegación sin recarga

Error 2: olvidar BrowserRouter

<Routes>   // ✘ error: "useLocation() may be used only in the context of a <Router>"
  <Route path="/" element={<Home />} />
</Routes>

Error 3: rutas duplicadas

<Routes>
  <Route path="/about" element={<About />} />
  <Route path="/about" element={<AboutUs />} />   // ✘ la segunda nunca se muestra
</Routes>

7 · Ejercicio guiado

  1. Instala React Router: pnpm add react-router.
  2. Crea tres componentes: Home, About, Contact.
  3. Envuelve App en BrowserRouter.
  4. Añade un nav con Link a cada página.
  5. Define las rutas en Routes.
  6. Añade una ruta 404 al final.
  7. Prueba navegar entre páginas.

8 · Reto

🎯 Navegación con estilo activo

Crea un componente NavLink que muestre el enlace activo en negrita y con un color diferente. Usa useLocation para detectar la ruta actual.

9 · Resumen

  • React Router permite crear SPAs con múltiples páginas.
  • Componentes clave: BrowserRouter, Routes, Route, Link.
  • Usa Link en lugar de <a> para evitar recargas.
  • La ruta * captura URLs no definidas (404).
  • useLocation te da acceso a la URL actual.

10 · Preguntas frecuentes

¿Puedo usar React Router sin BrowserRouter?
No. BrowserRouter (o HashRouter) es necesario para que el enrutamiento funcione.
¿Qué diferencia hay entre BrowserRouter y HashRouter?
BrowserRouter usa URLs limpias (/about). HashRouter usa hash (/#/about). El primero requiere configuración del servidor; el segundo no.
¿Puedo anidar Routes?
Sí, pero normalmente usas rutas anidadas con Outlet (próxima lección).
¿Cómo paso datos entre páginas?
Usa estado global (Context, Redux) o pasa datos por la URL (parámetros, query strings).
