Parámetros y rutas anidadas

Módulo 8 · Routing ⏱ 35 minutos

1 · Introducción

Las rutas estáticas (/about) son útiles, pero las aplicaciones reales necesitan rutas dinámicas: perfiles de usuario (/user/123), detalles de productos (/product/456), etc. React Router permite definir parámetros en las rutas y acceder a ellos desde los componentes.

Además, muchas aplicaciones tienen layouts compartidos: un dashboard con sidebar, una tienda con header y footer. Las rutas anidadas permiten definir rutas dentro de otras rutas, compartiendo el layout padre.

2 · Teoría

Parámetros de ruta

<Route path="/user/:id" element={<UserProfile />} />

// URL: /user/123
// useParams() devuelve { id: "123" }

Los parámetros se definen con :nombre en el path. Se acceden con el hook useParams().

Múltiples parámetros

<Route path="/product/:category/:id" element={<ProductDetail />} />

// URL: /product/electronics/789
// useParams() devuelve { category: "electronics", id: "789" }

Rutas anidadas

<Route path="/dashboard" element={<DashboardLayout />}>
  <Route index element={<DashboardHome />} />
  <Route path="settings" element={<Settings />} />
  <Route path="profile" element={<Profile />} />
</Route>

El componente padre (DashboardLayout) debe renderizar <Outlet /> donde quiere que aparezcan las rutas hijas.

Outlet

function DashboardLayout() {
  return (
    <div>
      <nav>Sidebar del dashboard</nav>
      <main>
        <Outlet />   {/* Aquí se renderizan las rutas hijas */}
      </main>
    </div>
  );
}

Ruta índice

La ruta index se renderiza cuando la URL coincide exactamente con la ruta padre. En el ejemplo anterior, /dashboard muestra DashboardHome.

3 · Ejemplo mínimo

src/App.jsx
import { BrowserRouter, Routes, Route, useParams } from "react-router";

function UserProfile() {
  const { id } = useParams();
  return <h1>Perfil del usuario {id}</h1>;
}

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<h1>Inicio</h1>} />
        <Route path="/user/:id" element={<UserProfile />} />
      </Routes>
    </BrowserRouter>
  );
}

4 · Ejemplo real

Dashboard con rutas anidadas:

src/App.jsx
import { BrowserRouter, Routes, Route, Link, Outlet, useParams } from "react-router";

function DashboardLayout() {
  return (
    <div>
      <nav>
        <Link to="/dashboard">Inicio</Link> |{" "}
        <Link to="/dashboard/settings">Configuración</Link> |{" "}
        <Link to="/dashboard/profile">Perfil</Link>
      </nav>
      <main>
        <Outlet />
      </main>
    </div>
  );
}

function DashboardHome() {
  return <h2>Bienvenido al dashboard</h2>;
}

function Settings() {
  return <h2>Configuración</h2>;
}

function Profile() {
  return <h2>Mi perfil</h2>;
}

function UserDetail() {
  const { userId } = useParams();
  return <h2>Detalles del usuario {userId}</h2>;
}

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<h1>Inicio</h1>} />
        <Route path="/dashboard" element={<DashboardLayout />}>
          <Route index element={<DashboardHome />} />
          <Route path="settings" element={<Settings />} />
          <Route path="profile" element={<Profile />} />
        </Route>
        <Route path="/user/:userId" element={<UserDetail />} />
      </Routes>
    </BrowserRouter>
  );
}

5 · Buenas prácticas

HazEvita

6 · Errores habituales

Error 1: olvidar Outlet en el layout padre

function DashboardLayout() {
  return (
    <div>
      <nav>Sidebar</nav>
      {/* ✘ falta <Outlet />: las rutas hijas no se renderizan */}
    </div>
  );
}

Error 2: no manejar parámetros faltantes

function UserProfile() {
  const { id } = useParams();
  // ✘ si id es undefined, la app puede romperse
  return <h1>Usuario {id}</h1>;
}

Error 3: rutas anidadas sin ruta índice

<Route path="/dashboard" element={<DashboardLayout />}>
  <Route path="settings" element={<Settings />} />
  {/* ✘ /dashboard no muestra nada (no hay ruta índice) */}
</Route>

9 · Resumen

  • Parámetros de ruta: :nombre en el path, se acceden con useParams().
  • Rutas anidadas: definen rutas dentro de otras rutas.
  • El layout padre debe renderizar <Outlet />.
  • Ruta índice: se muestra cuando la URL coincide exactamente con la ruta padre.
  • Valida siempre los parámetros antes de usarlos.

10 · Preguntas frecuentes

¿Puedo tener parámetros opcionales?
No directamente. Usa rutas separadas o valida en el componente si el parámetro existe.
¿Cómo paso query strings (?search=foo)?
Usa useSearchParams() para leer y modificar query params.
¿Puedo anidar rutas infinitamente?
Sí, pero evita anidar demasiado profundo. 2-3 niveles es lo habitual.
¿Cómo redirijo programáticamente?
Usa useNavigate() (próxima lección).
