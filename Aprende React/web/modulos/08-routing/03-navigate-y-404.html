Navigate, useNavigate y 404

Módulo 8 · Routing ⏱ 30 minutos

1 · Introducción

Hasta ahora hemos navegado con Link, que es perfecto para enlaces visibles. Pero a veces necesitas navegar programáticamente: después de un login exitoso, al enviar un formulario, o al detectar una condición (usuario no autenticado). React Router ofrece useNavigate para estos casos.

También veremos el componente Navigate para redirecciones condicionales en el render, y cómo manejar correctamente las rutas 404.

2 · Teoría

useNavigate

import { useNavigate } from "react-router";

function LoginForm() {
  const navigate = useNavigate();

  async function handleSubmit(e) {
    e.preventDefault();
    const success = await login();
    if (success) {
      navigate("/dashboard");   // redirige programáticamente
    }
  }

  return <form onSubmit={handleSubmit}>...</form>;
}

Opciones de navigate

navigate("/dashboard");                    // navegar a una ruta
navigate("/user/123", { replace: true });  // reemplaza el historial (no se puede ir atrás)
navigate(-1);                              // ir atrás (como el botón "atrás" del navegador)
navigate(1);                               // ir adelante

Componente Navigate

import { Navigate } from "react-router";

function PrivateRoute({ children, isAuth }) {
  if (!isAuth) {
    return <Navigate to="/login" replace />;
  }
  return children;
}

Navigate es un componente que redirige cuando se renderiza. Úsalo para redirecciones condicionales en el render (no en eventos).

Página 404

<Routes>
  <Route path="/" element={<Home />} />
  <Route path="*" element={<NotFound />} />   {/* captura cualquier URL no definida */}
</Routes>

3 · Ejemplo mínimo

src/App.jsx
import { BrowserRouter, Routes, Route, useNavigate } from "react-router";
import { useState } from "react";

function Home() {
  const navigate = useNavigate();

  return (
    <div>
      <h1>Inicio</h1>
      <button onClick={() => navigate("/about")}>Ir a About</button>
      <button onClick={() => navigate(-1)}>Atrás</button>
    </div>
  );
}

function About() {
  return <h1>Sobre nosotros</h1>;
}

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="*" element={<h1>404 - Página no encontrada</h1>} />
      </Routes>
    </BrowserRouter>
  );
}

4 · Ejemplo real

Login con redirección y ruta protegida:

src/App.jsx
import { BrowserRouter, Routes, Route, useNavigate, Navigate, Link } from "react-router";
import { useState } from "react";

function Login({ isAuth, setIsAuth }) {
  const navigate = useNavigate();

  function handleLogin() {
    setIsAuth(true);
    navigate("/dashboard", { replace: true });
  }

  return (
    <div>
      <h1>Login</h1>
      <button onClick={handleLogin}>Iniciar sesión</button>
    </div>
  );
}

function Dashboard({ isAuth }) {
  if (!isAuth) {
    return <Navigate to="/login" replace />;
  }
  return <h1>Dashboard privado</h1>;
}

export default function App() {
  const [isAuth, setIsAuth] = useState(false);

  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Inicio</Link> |{" "}
        <Link to="/dashboard">Dashboard</Link>
      </nav>

      <Routes>
        <Route path="/" element={<h1>Inicio</h1>} />
        <Route
          path="/login"
          element={<Login isAuth={isAuth} setIsAuth={setIsAuth} />}
        />
        <Route
          path="/dashboard"
          element={<Dashboard isAuth={isAuth} />}
        />
        <Route path="*" element={<h1>404 - Página no encontrada</h1>} />
      </Routes>
    </BrowserRouter>
  );
}

6 · Errores habituales

Error 1: usar useNavigate en el render

function MyComponent() {
  const navigate = useNavigate();
  navigate("/other");   // ✘ se ejecuta en cada render, causa loop
  return <div>...</div>;
}

Error 2: no usar replace después de login

navigate("/dashboard");   // ✘ el usuario puede volver al login con "atrás"
navigate("/dashboard", { replace: true });   // ✔ reemplaza el historial

Error 3: olvidar la ruta 404

<Routes>
  <Route path="/" element={<Home />} />
  {/* ✘ falta ruta 404: URLs inválidas muestran página en blanco */}
</Routes>

7 · Ejercicio guiado

  1. Crea un formulario de contacto que al enviarse redirija a /thank-you.
  2. Usa replace: true para que no se pueda volver al formulario.
  3. Crea una ruta protegida /admin que redirija a /login si no estás autenticado.
  4. Añade una página 404 con enlaces a las páginas principales.
  5. Prueba navegar atrás y adelante para verificar el comportamiento.

8 · Reto

🎯 Flujo de checkout

Crea un flujo de checkout con: /cart → /checkout → /success. Si el carrito está vacío en /checkout, redirige a /cart. Después del pago exitoso, redirige a /success con replace: true.

9 · Resumen

  • useNavigate() para navegación programática (en eventos).
  • Navigate para redirecciones condicionales (en el render).
  • replace: true reemplaza el historial (útil después de login).
  • Ruta * para capturar URLs no definidas (404).
  • Valida autenticación en rutas protegidas.

10 · Preguntas frecuentes

¿Puedo pasar datos al navegar?
Sí, con state: navigate("/page", { state: { data: "value" } }). Se accede con useLocation().state.
¿Cómo abro una URL externa?
Usa window.open() o <a target="_blank">. React Router es solo para navegación interna.
¿Puedo navegar fuera de React Router?
Sí, con window.location.href = "...", pero recargará la página.
