🛠 Proyecto: formulario de registro

Módulo 5 · Formularios ⏱ 60 minutos Proyecto

1 · Introducción

Llegó el momento de integrar todo lo aprendido en el Módulo 5. Vamos a construir un formulario de registro profesional con:

  • Inputs controlados (texto, email, password, checkbox, radio, select).
  • Validación en tiempo real con mensajes de error específicos.
  • Estado touched para mostrar errores solo después de interactuar.
  • Botón deshabilitado mientras haya errores.
  • Indicador de fortaleza de contraseña.
  • Resumen del formulario en vivo.

Este es el tipo de formulario que construirás en aplicaciones reales. Dominar este patrón te dará las bases para cualquier formulario que necesites en el futuro.

2 · Teoría

Arquitectura del proyecto

El proyecto se compone de:

  • App.jsx: componente principal que renderiza el formulario.
  • RegistrationForm.jsx: el formulario completo con todos los campos.
  • PasswordStrength.jsx: componente que muestra la fortaleza de la contraseña.
  • FormSummary.jsx: componente que muestra un resumen en vivo de los datos.

Campos del formulario

CampoTipoValidación
Nombre Texto Obligatorio, mínimo 3 caracteres
Email Email Obligatorio, formato válido (regex)
Contraseña Password Obligatoria, mínimo 8 caracteres, con letras y números
Confirmar contraseña Password Debe coincidir con la contraseña
Fecha de nacimiento Date Obligatoria, mayor de 18 años
País Select Obligatorio
Plan Radio Obligatorio (free, pro, enterprise)
Aceptar términos Checkbox Obligatorio

Estrategia de validación

  • Errores derivados: se calculan en cada render a partir de los valores.
  • touched: objeto con un booleano por campo. Se marca en onBlur.
  • Mensajes de error: solo se muestran si el campo ha sido tocado y hay error.
  • Botón deshabilitado: si hay algún error o algún campo obligatorio está vacío.

3 · Paso 1: estructura básica

Empieza con la estructura del formulario y los estados básicos:

src/components/RegistrationForm.jsx
import { useState } from "react";

const EMAIL_REGEX = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const PASSWORD_REGEX = /^(?=.*[A-Za-z])(?=.*\d).{8,}$/;

export default function RegistrationForm() {
  const [name, setName] = useState("");
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");
  const [confirmPassword, setConfirmPassword] = useState("");
  const [birthDate, setBirthDate] = useState("");
  const [country, setCountry] = useState("");
  const [plan, setPlan] = useState("");
  const [acceptTerms, setAcceptTerms] = useState(false);
  const [touched, setTouched] = useState({});

  // Errores derivados
  const errors = {
    name: name.trim().length < 3 ? "Mínimo 3 caracteres" : "",
    email: !EMAIL_REGEX.test(email) ? "Email inválido" : "",
    password: !PASSWORD_REGEX.test(password) ? "Mínimo 8 caracteres, con letras y números" : "",
    confirmPassword: password !== confirmPassword ? "No coincide" : "",
    birthDate: !isOver18(birthDate) ? "Debes ser mayor de 18 años" : "",
    country: country === "" ? "Selecciona un país" : "",
    plan: plan === "" ? "Selecciona un plan" : "",
    acceptTerms: !acceptTerms ? "Debes aceptar los términos" : "",
  };

  const hasErrors = Object.values(errors).some((err) => err !== "");

  function isOver18(dateStr) {
    if (!dateStr) return false;
    const birth = new Date(dateStr);
    const today = new Date();
    const age = today.getFullYear() - birth.getFullYear();
    return age > 18 || (age === 18 && today >= new Date(birth.setFullYear(birth.getFullYear() + 18)));
  }

  function handleSubmit(e) {
    e.preventDefault();
    // Marcamos todos como tocados
    setTouched({
      name: true, email: true, password: true, confirmPassword: true,
      birthDate: true, country: true, plan: true, acceptTerms: true,
    });
    if (!hasErrors) {
      alert(`Registro: ${name} (${email})`);
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      {/* Campos aquí */}
      <button type="submit" disabled={hasErrors}>Registrarse</button>
    </form>
  );
}

4 · Paso 2: campos del formulario

Añade todos los campos con sus handlers y mensajes de error:

src/components/RegistrationForm.jsx (continuación)
return (
  <form onSubmit={handleSubmit} className="registration-form">
    <div className="field">
      <label>Nombre</label>
      <input
        value={name}
        onChange={(e) => setName(e.target.value)}
        onBlur={() => setTouched((p) => ({ ...p, name: true }))}
        placeholder="Tu nombre"
      />
      {touched.name && errors.name && <span className="error">{errors.name}</span>}
    </div>

    <div className="field">
      <label>Email</label>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        onBlur={() => setTouched((p) => ({ ...p, email: true }))}
        placeholder="tu@email.com"
      />
      {touched.email && errors.email && <span className="error">{errors.email}</span>}
    </div>

    <div className="field">
      <label>Contraseña</label>
      <input
        type="password"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        onBlur={() => setTouched((p) => ({ ...p, password: true }))}
        placeholder="Mínimo 8 caracteres"
      />
      {touched.password && errors.password && <span className="error">{errors.password}</span>}
      <PasswordStrength password={password} />
    </div>

    <div className="field">
      <label>Confirmar contraseña</label>
      <input
        type="password"
        value={confirmPassword}
        onChange={(e) => setConfirmPassword(e.target.value)}
        onBlur={() => setTouched((p) => ({ ...p, confirmPassword: true }))}
        placeholder="Repite la contraseña"
      />
      {touched.confirmPassword && errors.confirmPassword && (
        <span className="error">{errors.confirmPassword}</span>
      )}
    </div>

    <div className="field">
      <label>Fecha de nacimiento</label>
      <input
        type="date"
        value={birthDate}
        onChange={(e) => setBirthDate(e.target.value)}
        onBlur={() => setTouched((p) => ({ ...p, birthDate: true }))}
      />
      {touched.birthDate && errors.birthDate && <span className="error">{errors.birthDate}</span>}
    </div>

    <div className="field">
      <label>País</label>
      <select
        value={country}
        onChange={(e) => setCountry(e.target.value)}
        onBlur={() => setTouched((p) => ({ ...p, country: true }))}
      >
        <option value="">Selecciona un país</option>
        <option value="es">España</option>
        <option value="mx">México</option>
        <option value="ar">Argentina</option>
        <option value="co">Colombia</option>
      </select>
      {touched.country && errors.country && <span className="error">{errors.country}</span>}
    </div>

    <fieldset className="field">
      <legend>Plan</legend>
      {["free", "pro", "enterprise"].map((p) => (
        <label key={p}>
          <input
            type="radio"
            name="plan"
            value={p}
            checked={plan === p}
            onChange={(e) => setPlan(e.target.value)}
          />
          {p}
        </label>
      ))}
      {touched.plan && errors.plan && <span className="error">{errors.plan}</span>}
    </fieldset>

    <div className="field">
      <label>
        <input
          type="checkbox"
          checked={acceptTerms}
          onChange={(e) => setAcceptTerms(e.target.checked)}
          onBlur={() => setTouched((p) => ({ ...p, acceptTerms: true }))}
        />
        Acepto los términos y condiciones
      </label>
      {touched.acceptTerms && errors.acceptTerms && (
        <span className="error">{errors.acceptTerms}</span>
      )}
    </div>

    <button type="submit" disabled={hasErrors}>Registrarse</button>
  </form>
);

5 · Paso 3: componentes auxiliares

PasswordStrength

Componente que muestra la fortaleza de la contraseña según su longitud y complejidad:

src/components/PasswordStrength.jsx
export default function PasswordStrength({ password }) {
  if (!password) return null;

  let strength = 0;
  if (password.length >= 8) strength++;
  if (/[A-Z]/.test(password)) strength++;
  if (/[0-9]/.test(password)) strength++;
  if (/[^A-Za-z0-9]/.test(password)) strength++;

  const labels = ["Muy débil", "Débil", "Media", "Fuerte", "Muy fuerte"];
  const colors = ["#ff4444", "#ff8800", "#ffcc00", "#88cc00", "#44bb44"];

  return (
    <div className="password-strength">
      <div className="strength-bar">
        <div
          className="strength-fill"
          style={{ width: `${(strength / 4) * 100}%`, backgroundColor: colors[strength] }}
        />
      </div>
      <span style={{ color: colors[strength] }}>{labels[strength]}</span>
    </div>
  );
}

FormSummary

Componente que muestra un resumen en vivo de los datos del formulario:

export default function FormSummary({ data }) {

        <li><strong>País:</strong> {data.country || "—"}</li>
        <li><strong>Plan:</strong> {data.plan || "—"}</li>
        <li><strong>Términos:</strong> {data.acceptTerms ? "Aceptados" : "Pendientes"}</li>
      </ul>
    </div>
  );
}

Nota: si quieres mostrar el resumen en vivo, necesitas elevar el estado a App.jsx y pasar los datos como props. O puedes integrar el resumen dentro de RegistrationForm. Ambas opciones son válidas; depende de si el resumen es parte del formulario o un componente independiente.

8 · Reto final

🎯 Mejoras adicionales

Una vez que el formulario básico funciona, añade estas mejoras:

  1. Validación asíncrona de email: simula una comprobación de si el email ya está registrado (con un timeout de 1 segundo). Muestra "Comprobando…" mientras tanto.
  2. Mostrar/ocultar contraseña: añade un botón junto al campo de contraseña para mostrar/ocultar el texto.
  3. Autocompletar país por IP: al cargar la página, simula una petición que detecta el país del usuario y lo selecciona automáticamente.
  4. Guardar borrador: guarda los datos en localStorage mientras el usuario escribe. Al recargar la página, recupera los datos.
  5. Animación de éxito: cuando el registro es exitoso, muestra una animación de checkmark y redirige a otra página (simulada con un mensaje).

10 · Preguntas frecuentes

¿Puedo usar una librería como React Hook Form?

Sí, y es recomendable en proyectos grandes. React Hook Form simplifica mucho la gestión de formularios complejos. Pero entender el patrón manual primero es esencial para saber qué hace la librería por ti.

¿Cómo manejo archivos (subida de imágenes)?

Usa <input type="file"> y lee el archivo con FileReader o URL.createObjectURL. Para subir al servidor, usa FormData y fetch con multipart/form-data. Lo veremos en el Módulo 9 (APIs).

¿Cómo envío el formulario al backend?

En handleSubmit, usa fetch con method: "POST" y body: JSON.stringify(data). Lo veremos en detalle en el Módulo 9. Por ahora, el alert es suficiente para probar.

¿Puedo reutilizar este formulario para editar un usuario?

Sí: pasa los datos iniciales como props y úsalos en los useState. Por ejemplo: const [name, setName] = useState(initialData.name || ""). El resto del formulario es idéntico.
