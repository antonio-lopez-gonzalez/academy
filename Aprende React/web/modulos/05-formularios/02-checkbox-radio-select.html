Checkbox, radio y select

Módulo 5 · Formularios ⏱ 30 minutos

1 · Introducción

En la lección anterior dominamos el input de texto controlado. Pero los formularios reales tienen más que texto: checkboxes, radios, selects, textareas… Cada uno tiene sus particularidades, pero todos siguen el mismo principio: el estado es la única fuente de verdad.

La diferencia clave: un input de texto guarda un string, pero un checkbox guarda un booleano, un radio group guarda un string (la opción seleccionada), un select puede guardar un string o un array (si es múltiple), y un textarea es idéntico al input de texto. En esta lección veremos cada uno y cómo controlarlos con React.

2 · Teoría

El patrón universal

Todos los inputs controlados siguen el mismo patrón:

  1. Un estado que refleja el valor del input.
  2. El atributo value (o checked) que lee del estado.
  3. Un handler onChange que actualiza el estado.

La única diferencia es el tipo de dato y el atributo HTML. Veámoslos uno por uno.

Checkbox: booleano

const [accepted, setAccepted] = useState(false);

<input
  type="checkbox"
  checked={accepted}                              // lee del estado (booleano)
  onChange={(e) => setAccepted(e.target.checked)}  // actualiza con el booleano
/>
  • checked en lugar de value: los checkboxes no tienen "valor" visible; tienen un estado de marcado/no marcado.
  • e.target.checked: es un booleano (true si está marcado, false si no).
  • El estado es un booleano: true = marcado, false = no marcado.

Radio buttons: un string entre varias opciones

const [size, setSize] = useState("medium");

<input type="radio" name="size" value="small"
  checked={size === "small"}
  onChange={(e) => setSize(e.target.value)} />
Small

<input type="radio" name="size" value="medium"
  checked={size === "medium"}
  onChange={(e) => setSize(e.target.value)} />
Medium

<input type="radio" name="size" value="large"
  checked={size === "large"}
  onChange={(e) => setSize(e.target.value)} />
Large
  • Un estado, varios radios: el estado guarda la opción seleccionada (un string).
  • checked={size === "small"}: cada radio compara su valor con el estado. Solo uno será true.
  • name="size": agrupa los radios visualmente (solo uno puede estar seleccionado a la vez).
  • e.target.value: el valor del radio que se acaba de seleccionar.

Select: un string (o array) entre opciones

const [country, setCountry] = useState("es");

<select value={country} onChange={(e) => setCountry(e.target.value)}>
  <option value="es">España</option>
  <option value="mx">México</option>
  <option value="ar">Argentina</option>
</select>
  • value en el <select>, no en los <option>: React controla el select entero, no cada opción.
  • e.target.value: el valor de la opción seleccionada (un string).
  • Select múltiple: añade multiple y el estado será un array. Veremos cómo manejarlo abajo.

Textarea: idéntico al input de texto

const [bio, setBio] = useState("");

<textarea
  value={bio}
  onChange={(e) => setBio(e.target.value)}
  placeholder="Cuéntanos sobre ti…"
/>
  • Se comporta exactamente igual que <input type="text">.
  • La única diferencia: en HTML, el texto de un textarea va entre las etiquetas (<textarea>texto</textarea>), pero en React usamos value como en los inputs.

Select múltiple: un array de valores

const [skills, setSkills] = useState([]);

<select
  multiple
  value={skills}
  onChange={(e) => {
    const selected = Array.from(e.target.selectedOptions, opt => opt.value);
    setSkills(selected);
  }}
>
  <option value="js">JavaScript</option>
  <option value="py">Python</option>
  <option value="rust">Rust</option>
</select>
  • multiple: permite seleccionar varias opciones (con Ctrl/Cmd).
  • e.target.selectedOptions: es una colección de las opciones seleccionadas. La convertimos a array con Array.from.
  • El estado es un array: ["js", "rust"] si el usuario seleccionó JavaScript y Rust.

3 · Ejemplo mínimo

src/components/Preferences.jsx
import { useState } from "react";

export default function Preferences() {
  const [newsletter, setNewsletter] = useState(false);   // checkbox: booleano
  const [theme, setTheme] = useState("dark");            // radio: string
  const [language, setLanguage] = useState("es");        // select: string

  return (
    <div>
      <label>
        <input
          type="checkbox"
          checked={newsletter}
          onChange={(e) => setNewsletter(e.target.checked)}
        />
        Suscribirme al newsletter
      </label>

      <fieldset>
        <legend>Tema</legend>
        {["light", "dark", "system"].map((t) => (
          <label key={t}>
            <input
              type="radio"
              name="theme"
              value={t}
              checked={theme === t}
              onChange={(e) => setTheme(e.target.value)}
            />
            {t}
          </label>
        ))}
      </fieldset>

      <select value={language} onChange={(e) => setLanguage(e.target.value)}>
        <option value="es">Español</option>
        <option value="en">English</option>
        <option value="fr">Français</option>
      </select>

      <pre>{JSON.stringify({ newsletter, theme, language }, null, 2)}</pre>
    </div>
  );
}

Línea por línea:

  1. Tres estados independientes: un booleano para el checkbox, dos strings para radio y select.
  2. El checkbox usa checked y e.target.checked (booleano).
  3. Los radios comparten name="theme" y cada uno compara su value con el estado.
  4. El select usa value en el <select> y e.target.value (string).
  5. El <pre> muestra el estado en vivo: ves cómo cambia al interactuar.

4 · Ejemplo real

Un filtro de productos: checkboxes para categorías, radio para ordenar, select para pageSize. Es el patrón real de una tienda online.

src/components/ProductFilter.jsx
import { useState } from "react";

const PRODUCTS = [
  { id: 1, name: "Camiseta", category: "ropa", price: 19 },
  { id: 2, name: "Pantalón", category: "ropa", price: 39 },
  { id: 3, name: "Zapatillas", category: "calzado", price: 59 },
  { id: 4, name: "Gorra", category: "accesorios", price: 15 },
];

export default function ProductFilter() {
  const [categories, setCategories] = useState([]);   // array de categorías seleccionadas
  const [sortBy, setSortBy] = useState("name");       // radio: "name" o "price"
  const [pageSize, setPageSize] = useState("10");     // select: "10", "25", "50"

  // Filtrar por categorías (si hay alguna seleccionada)
  let filtered = categories.length > 0
    ? PRODUCTS.filter((p) => categories.includes(p.category))
    : PRODUCTS;

  // Ordenar
  filtered = [...filtered].sort((a, b) =>
    sortBy === "price" ? a.price - b.price : a.name.localeCompare(b.name)
  );

  // Paginar (solo mostramos los primeros pageSize)
  filtered = filtered.slice(0, Number(pageSize));

  function toggleCategory(cat) {
    setCategories((prev) =>
      prev.includes(cat) ? prev.filter((c) => c !== cat) : [...prev, cat]
    );
  }

  return (
    <div>
      <fieldset>
        <legend>Categorías</legend>
        {["ropa", "calzado", "accesorios"].map((cat) => (
          <label key={cat}>
            <input
              type="checkbox"
              checked={categories.includes(cat)}
              onChange={() => toggleCategory(cat)}
            />
            {cat}
          </label>
        ))}
      </fieldset>

      <fieldset>
        <legend>Ordenar por</legend>
        <label>
          <input type="radio" name="sort" value="name"
            checked={sortBy === "name"} onChange={(e) => setSortBy(e.target.value)} />
          Nombre
        </label>
        <label>
          <input type="radio" name="sort" value="price"
            checked={sortBy === "price"} onChange={(e) => setSortBy(e.target.value)} />
          Precio
        </label>
      </fieldset>

      <select value={pageSize} onChange={(e) => setPageSize(e.target.value)}>
        <option value="10">10 por página</option>
        <option value="25">25 por página</option>
        <option value="50">50 por página</option>
      </select>

      <ul>
        {filtered.map((p) => (
          <li key={p.id}>{p.name} — {p.price}€</li>
        ))}
      </ul>
    </div>
  );
}

Decisiones explicadas:

  • Checkboxes con array: el estado es un array de categorías seleccionadas. toggleCategory añade o quita la categoría del array (patrón inmutable del Módulo 4).
  • Radios con string: el estado es la opción seleccionada. Cada radio compara su valor con el estado.
  • Select con string: el estado es el valor seleccionado. El select lo muestra.
  • Todo es derivado: filtered se calcula en cada render a partir de los tres estados. No es estado, es una función de los estados.
  • Paginación con slice: convertimos pageSize a número y cortamos el array. Simple y efectivo.

5 · Buenas prácticas

HazEvitaPor qué
Usar checked para checkboxes y radios Usar value para checkboxes Los checkboxes no tienen "valor" visible; tienen un estado de marcado. checked es el atributo correcto.
Agrupar radios con name Radios sin name (se pueden seleccionar varios) Sin name, los radios no se agrupan y pierdes el comportamiento de "solo uno seleccionado".
Poner value en el <select>, no en los <option> Poner selected en los <option> React controla el select entero. selected es el patrón HTML puro, no el de React.
Un estado por grupo de inputs relacionados Un estado por cada radio button Los radios de un grupo son mutuamente excluyentes: un solo estado refleja la opción elegida.
Usar arrays para selecciones múltiples Strings separados por comas Los arrays son más fáciles de manipular (includes, filter, map).

6 · Errores habituales

Error 1: usar value en un checkbox

✘ Incorrecto 
<input type="checkbox" value={accepted} onChange={…} />
// value no controla si está marcado; controla el valor que se envía en un formulario HTML puro.
// React ignora value en checkboxes y usa checked.
✔ Correcto 
<input type="checkbox" checked={accepted} onChange={(e) => setAccepted(e.target.checked)} />

Error 2: olvidar el name en radios

✘ Incorrecto 
<input type="radio" value="small" checked={size === "small"} onChange={…} />
<input type="radio" value="medium" checked={size === "medium"} onChange={…} />
// sin name, los radios NO se agrupan: el usuario puede seleccionar varios.
✔ Correcto 
<input type="radio" name="size" value="small" checked={size === "small"} onChange={…} />
<input type="radio" name="size" value="medium" checked={size === "medium"} onChange={…} />

Error 3: poner selected en los <option>

✘ Incorrecto 
<select>
  <option value="es" selected={country === "es"}>España</option>
  <option value="mx" selected={country === "mx"}>México</option>
</select>
// selected es el patrón HTML puro. React lo ignora y muestra una warning.
✔ Correcto 
<select value={country} onChange={(e) => setCountry(e.target.value)}>
  <option value="es">España</option>
  <option value="mx">México</option>
</select>

Error 4: mutar el array de selecciones múltiples

✘ Incorrecto 
function toggleCategory(cat) {
  if (categories.includes(cat)) {
    categories.splice(categories.indexOf(cat), 1);   // 💥 mutación directa
    setCategories(categories);                        // React no detecta el cambio
  } else {
    categories.push(cat);                             // 💥 mutación directa
    setCategories(categories);
  }
}
✔ Correcto 
function toggleCategory(cat) {
  setCategories((prev) =>
    prev.includes(cat)
      ? prev.filter((c) => c !== cat)   // nuevo array sin la categoría
      : [...prev, cat]                   // nuevo array con la categoría
  );
}

Formulario de preferencias de usuario:

  1. Crea tres estados: notifications (booleano), frequency (string: "daily", "weekly", "never"), categories (array).

  2. Añade un checkbox para "Recibir notificaciones" controlado por notifications.

  3. Añade tres radios para la frecuencia, agrupados con name="frequency". Solo se muestran si notifications es true (renderizado condicional del Módulo 2).

  4. Añade un select múltiple con 5 categorías de interés. El estado es un array. Usa el patrón toggleCategory de la lección.

9 · Resumen

  • Checkbox: estado booleano, atributo checked, handler lee e.target.checked.
  • Radio: estado string, atributo checked={estado === valor}, agrupa con name.
  • Select: estado string, atributo value en el <select>, handler lee e.target.value.
  • Textarea: idéntico al input de texto.
  • Select múltiple: estado array, usa e.target.selectedOptions y Array.from.
  • El patrón es universal: estado → atributo → handler → estado. Solo cambian el tipo de dato y el atributo HTML.

10 · Preguntas frecuentes

¿Puedo usar un array de objetos para las opciones de un select?

Sí: mapea el array para generar los <option>. Por ejemplo: options.map(opt => <option key={opt.id} value={opt.id}>{opt.name}</option>). El estado guarda el id (string), no el objeto entero.

¿Cómo manejo un checkbox "marcar todos"?

Crea un estado para el checkbox "todos" y otro para los items seleccionados. En el onChange del "todos", si se marca, selecciona todos los items; si se desmarca, vacía la selección. Y viceversa: si el usuario selecciona/deselecciona items individuales, actualiza el estado del "todos" según si todos están seleccionados.

¿Los radios pueden tener valores numéricos?

No directamente: el value de un input siempre es un string. Si necesitas un número, convierte en el handler: onChange={(e) => setAge(Number(e.target.value))}. O usa value={String(age)} en el radio.

¿Puedo deshabilitar un <option>?

Sí: <option value="x" disabled>No disponible</option>. El usuario no puede seleccionarlo, pero sigue visible en la lista.

¿Qué es un "input no controlado"?

Es aquel que tiene su propio estado interno y React solo lee el valor cuando necesita (con useRef). Se usa defaultValue en lugar de value. Es válido en formularios simples, pero pierdes el control total (no puedes resetear con un botón, no puedes validar en tiempo real…). El patrón controlado es el estándar.
