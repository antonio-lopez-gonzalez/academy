🛠 Proyecto: buscador de películas

Módulo 6 · Hooks en profundidad ⏱ 65 minutos Proyecto

1 · Introducción

Es hora de integrar todos los hooks del módulo en un proyecto real: un buscador de películas que consume la API de OMDb. Usaremos:

  • useState para el estado del formulario y los resultados.
  • useEffect para cargar datos de la API.
  • useRef para poner el foco en el input al cargar.
  • useMemo para memorizar el filtrado de resultados.
  • useCallback para las funciones que se pasan como props.
  • Custom hooks: useDebounce y useFetch.

3 · Paso 1: custom hooks

useDebounce

src/hooks/useDebounce.js
import { useState, useEffect } from "react";

export function useDebounce(value, delay = 500) {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debounced;
}

useFetch

src/hooks/useFetch.js
import { useState, useEffect } from "react";

export function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    if (!url) {
      setLoading(false);
      return;
    }

    let cancelled = false;
    setLoading(true);
    setError(null);

    fetch(url)
      .then((res) => {
        if (!res.ok) throw new Error(`Error ${res.status}`);
        return res.json();
      })
      .then((json) => {
        if (!cancelled) {
          setData(json);
          setLoading(false);
        }
      })
      .catch((err) => {
        if (!cancelled) {
          setError(err.message);
          setLoading(false);
        }
      });

    return () => { cancelled = true; };
  }, [url]);

  return { data, loading, error };
}

4 · Paso 2: componentes

SearchInput

src/components/SearchInput.jsx
import { useRef, useEffect } from "react";

export default function SearchInput({ value, onChange }) {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus();   // foco automático al montar
  }, []);

  return (
    <input
      ref={inputRef}
      type="search"
      value={value}
      onChange={(e) => onChange(e.target.value)}
      placeholder="Busca una película…"
      className="search-input"
    />
  );
}

import MovieCard from "./MovieCard";

export default function MovieList({ movies }) {
  if (!movies || movies.length === 0) {
    return <p className="no-results">No se encontraron películas</p>;
  }

  return (
    <div className="movie-grid">
      {movies.map((movie) => (

    </div>
  );
}

5 · Paso 3: App.jsx

src/App.jsx
import { useState, useMemo } from "react";
import { useDebounce } from "./hooks/useDebounce";
import { useFetch } from "./hooks/useFetch";
import SearchInput from "./components/SearchInput";
import MovieList from "./components/MovieList";

const API_KEY = "TU_API_KEY";   // sustituye por tu key real

export default function App() {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebounce(query, 500);

  const url = debouncedQuery
    ? `https://www.omdbapi.com/?s=${encodeURIComponent(debouncedQuery)}&apikey=${API_KEY}`
    : "";

  const { data, loading, error } = useFetch(url);

  // useMemo para evitar recalcular si data no cambia
  const movies = useMemo(() => {
    return data?.Search || [];
  }, [data]);

  return (
    <div className="app">
      <h1>Buscador de películas</h1>
      <SearchInput value={query} onChange={setQuery} />
      {loading && <p>Buscando…</p>}
      {error && <p className="error">Error: {error}</p>}
      {!loading && !error && <MovieList movies={movies} />}
    </div>
  );
}

7 · Paso 5: integración

  1. Crea el proyecto con pnpm create vite@latest m06-buscador-peliculas -- --template react.
  2. Crea la carpeta src/hooks/ y añade useDebounce.js y useFetch.js.
  3. Crea los componentes en src/components/.
  4. Obtén una API key gratuita de OMDb o usa una API alternativa.
  5. Integra todo en App.jsx.
  6. Prueba: escribe "matrix", espera 500ms, deberían aparecer los resultados.
  7. Abre React DevTools → Profiler y verifica que los MovieCard no se re-renderizan al escribir (gracias a memo y useMemo).

8 · Reto

🎯 Mejoras adicionales

  1. Historial de búsquedas: guarda las últimas 5 búsquedas en localStorage (usa un custom hook useLocalStorage).
  2. Detalles de película: al hacer clic en una tarjeta, abre un modal con más detalles (usa useFetch con &i=imdbID).
  3. Filtros: añade un select para filtrar por tipo (película, serie, episodio).
  4. Paginación: la API de OMDb devuelve 10 resultados por página. Añade botones "Anterior" / "Siguiente".
  5. Favoritos: permite marcar películas como favoritas (guardadas en localStorage).

9 · Resumen

  • Has construido un buscador de películas completo usando todos los hooks del módulo.
  • Custom hooks (useDebounce, useFetch) encapsulan la lógica reutilizable.
  • useRef para el foco automático, useMemo para memorizar resultados, useCallback para funciones estables.
  • React.memo en los componentes hijos evita re-renders innecesarios.
  • Este patrón es la base de cualquier aplicación que consuma APIs.

10 · Preguntas frecuentes

¿Puedo usar otra API sin key?
Sí: JSONPlaceholder, The Cat API, PokéAPI, Rick and Morty API… Todas gratuitas y sin key.
¿Cómo manejo la paginación?
Añade un estado page y pásalo a la URL: &page=${page}. Al cambiar de página, useFetch se re-ejecuta automáticamente.
¿Puedo cachear los resultados?
Sí: modifica useFetch para guardar resultados en un mapa (URL → datos). Antes de hacer fetch, comprueba si ya tienes los datos. O usa React Query (librería externa) que lo hace por ti.
¿Cómo cancelo la petición anterior si el usuario escribe rápido?
Usa AbortController en useFetch. Al limpiar el efecto, llama a controller.abort(). Lo veremos en detalle en el Módulo 9.
