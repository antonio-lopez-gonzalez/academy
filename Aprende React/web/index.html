De cero a avanzado, en español y con JavaScript (sin TypeScript). No aprenderás solo a escribir React: entenderás por qué funciona, cómo está diseñado y cuáles son las mejores prácticas profesionales. Termina con un proyecto full-stack tipo Trello con backend en .NET 8.

Cómo funciona este curso

📚 Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

🛠 Todo el código es ejecutable de verdad

Las carpetas ejemplos/ y proyectos/ del repositorio contienen proyectos Vite + React 19.2 reales. Instálalos una sola vez desde la raíz con pnpm install y arranca cualquiera con pnpm dev.

💡 Para quién es

Para desarrolladores que ya saben programar (.NET, JavaScript, Python…) pero que nunca han aprendido React correctamente. No necesitas saber React: sí necesitas soltura con JavaScript moderno (funciones, arrays, módulos).

🗺 Tu progreso se guarda en tu navegador

Marca cada lección como completada con el botón al final de la página. El progreso vive en localStorage: sin cuentas y sin servidores.
