Glosario de términos

Recursos

Este glosario recoge los términos que aparecen a lo largo del curso. No pretende sustituir a las lecciones, sino servir como referencia rápida cuando olvides el significado exacto de una palabra o quieras comparar conceptos.

Fundamentos de React

React
Biblioteca de JavaScript para construir interfaces de usuario. Su idea central es que la UI se define como una función del estado.
JSX
Extensión de sintaxis de JavaScript que permite escribir estructuras similares a HTML dentro del código JavaScript. El navegador no lo entiende directamente; Babel lo convierte en llamadas a React.createElement.
Componente
Pieza reutilizable de interfaz. Puede ser una función (componente funcional) o, en versiones antiguas, una clase. En React 19 usamos casi siempre funciones.
Props
Abreviatura de properties. Son los datos que un componente padre pasa a sus hijos. Las props son de solo lectura: un componente no debe modificar sus propias props.
Estado
Datos que pueden cambiar durante la vida de un componente y que provocan un nuevo renderizado cuando se actualizan. Se gestiona principalmente con useState.
Renderizado
Proceso por el cual React convierte el componente y su estado en una descripción de la interfaz (elementos de React) y luego sincroniza el DOM real.
Re-render
Nuevo renderizado de un componente que ya está montado. Ocurre cuando cambia el estado, las props o el contexto consumido. No siempre implica cambios en el DOM.
Virtual DOM
Representación ligera en memoria del DOM real. React la usa para comparar (diff) el árbol anterior con el nuevo y aplicar solo los cambios necesarios.
Reconciliación
Algoritmo de React que compara dos árboles de React (anterior y nuevo) para decidir qué nodos del DOM real deben crearse, actualizarse o eliminarse.
Key
Atributo especial que ayuda a React a identificar elementos en una lista. Debe ser estable y único entre hermanos. Usar el índice del array como key suele ser un error cuando la lista puede reordenarse.
Fragment
Contenedor invisible que permite devolver varios elementos sin añadir un nodo extra al DOM. Se escribe como <>...</> o <React.Fragment>.
Composición
Patrón de diseño que consiste en combinar componentes pequeños y especializados para construir interfaces más complejas. Es preferible a la herencia en React.

Hooks

Hook
Función especial de React que permite conectar estado y otros características de React a componentes funcionales. Siempre empiezan por use.
useState
Hook que añade estado a un componente funcional. Devuelve un valor y una función para actualizarlo.
useEffect
Hook para ejecutar efectos secundarios: suscripciones, peticiones, manipulación manual del DOM, etc. Recibe una función y un array de dependencias.
useRef
Hook que devuelve un objeto mutable persistente entre renders. Se usa para acceder a nodos del DOM o guardar valores que no deben provocar re-render.
useMemo
Hook que memoriza el resultado de un cálculo costoso para evitar recalcularlo en cada render mientras las dependencias no cambien.
useCallback
Hook que memoriza una función para que su referencia sea estable entre renders si las dependencias no cambian. Útil para optimizar hijos que dependen de la identidad de la función.
useReducer
Hook alternativo a useState para lógica de estado más compleja. Recibe una función reductora y un estado inicial, similar al patrón Redux.
useContext
Hook que permite consumir un contexto de React sin necesidad de usar el Consumer render prop.
Custom hook
Función que encapsula lógica reutilizable basada en hooks. Debe seguir las reglas de los hooks y puede llamar a otros hooks.
useTransition
Hook de React 19 que marca una actualización de estado como "no urgente" para que React pueda posponerla y mantener la UI fluida. Devuelve un booleano isPending y una función para iniciar la transición.
useDeferredValue
Hook de React 19 que retrasa un valor (a diferencia de useTransition, que retrasa una actualización). Ideal para búsquedas costosas: el input responde al instante y el filtrado se difiere. En React 19 acepta un initialValue.
useActionState
Hook de React 19 que conecta una action con su estado resultante. Devuelve [state, formAction, isPending]. Reemplaza al antiguo useFormState (nombre canary). Se usa con el atributo action de los formularios.
useOptimistic
Hook de React 19 que muestra un estado optimista (el resultado esperado) mientras una acción asíncrona se completa. Si la acción falla, React revierte automáticamente.
use()
API de React 19 para leer recursos en render: acepta una Promise (y se suspende hasta que resuelve) o un Context. A diferencia de otros hooks, puede llamarse de forma condicional.
useFormStatus
Hook de React 19 que lee el estado de envío del formulario padre desde un componente hijo. Devuelve pending, data, method y action.
useId
Hook que genera un identificador único y estable para un componente, útil para conectar <label> con inputs y para accesibilidad. Garantiza hidratación correcta entre servidor y cliente.
useEffectEvent
Hook de React 19.2 que crea "eventos de efecto": funciones que siempre ven los últimos props y estado pero que NO son dependencias del efecto. Resuelve el problema de los closures obsoletos en useEffect. Solo se llama desde dentro de efectos.
Reglas de los hooks
  1. Solo llamar hooks en el nivel superior de un componente o custom hook.
  2. Solo llamar hooks desde funciones de React (componentes o custom hooks).
  3. Llamar siempre los hooks en el mismo orden en cada render.

Estado global y gestión de datos

Context API
API de React para compartir datos entre componentes sin pasar props manualmente a cada nivel. Ideal para datos que cambian poco o para temas/idiomas.
Redux
Biblioteca de gestión de estado global predecible. Basada en un store inmutable, acciones y reducers. Redux Toolkit simplifica su configuración y uso.
Zustand
Biblioteca minimalista de gestión de estado global. Crea una store fuera del árbol de React y expone un hook para leerla y escribir en ella.
Prop drilling
Antipatrón que ocurre cuando las props se pasan a través de muchos niveles de componentes intermedios que no las usan. Soluciones: Context API, composición o estado global.
Inmutabilidad
Principio de no modificar directamente arrays, objetos o datos. En React, se crean nuevas estructuras con spread, map, filter, etc.
Lift state up
Técnica que consiste en subir el estado al ancestro común más cercano para compartirlo entre hermanos.

Routing y navegación

SPA
Single Page Application. Aplicación que carga una sola página HTML y actualiza el contenido dinámicamente sin recargar el navegador.
React Router
Biblioteca más popular para manejar rutas en aplicaciones React. Permite definir rutas, parámetros, redirecciones y rutas protegidas.
Ruta protegida
Ruta que solo permite el acceso si se cumple una condición, como estar autenticado. Si no se cumple, redirige al login o muestra un fallback.
Parámetro de ruta
Valor dinámico dentro de una URL, como /productos/:id. React Router lo expone mediante el hook useParams.

APIs y consumo de datos

Fetch API
API nativa del navegador para realizar peticiones HTTP. Devuelve una promesa y se usa con async/await.
Promesa
Objeto que representa un valor que puede estar disponible ahora, en el futuro o nunca. Estados: pending, fulfilled, rejected.
async/await
Sintaxis de JavaScript para escribir código asíncrono de forma más legible. Una función async devuelve una promesa y await pausa la ejecución hasta que se resuelve.
AbortController
API nativa para cancelar peticiones fetch. Se usa en el cleanup de useEffect para evitar actualizaciones en componentes desmontados.
Capa de servicios
Módulo que centraliza las llamadas a la API. Separa la lógica de red de los componentes y facilita el testing y el mantenimiento.
JSON
JavaScript Object Notation. Formato ligero de intercambio de datos. La mayoría de APIs REST envían y reciben JSON.
JWT
JSON Web Token. Estándar para transmitir información de forma compacta y segura. Se usa habitualmente para autenticación y autorización en APIs.

Optimización

React.memo
HOC que memoriza un componente funcional para evitar re-renders si sus props no cambian.
Lazy loading
Técnica que retrasa la carga de un componente hasta que se necesita. En React se combina React.lazy con Suspense.
Suspense
Componente de React que muestra un fallback mientras sus hijos se cargan. Se usa con lazy loading, data fetching y frameworks concurrentes.
Code splitting
Dividir el bundle en fragmentos más pequeños que se cargan bajo demanda. Reduce el tamaño inicial de la aplicación.
Profiler
Herramienta de React DevTools para medir el rendimiento de los renderizados y detectar cuellos de botella.
React Compiler
Compilador de React (estable en su versión 1.0, lanzada en octubre de 2025) que añade memorización automática a los componentes sin necesidad de escribir useMemo, useCallback o React.memo manualmente.
Document Metadata
Capacidad de React 19 de renderizar <title>, <meta>, <link> y <script> desde cualquier componente; React los "sube" (hoist) automáticamente al <head>. Sustituye a librerías como react-helmet.
Preloading
Conjunto de APIs de React 19 (preload, preinit, preconnect, prefetchDNS) para descargar y preparar recursos (fuentes, imágenes, scripts, CSS) antes de que se necesiten.
Activity
Componente de React 19.2 que oculta una parte de la UI preservando su estado. Tiene dos modos: visible y hidden. En hidden los efectos se desmontan y las actualizaciones se aplazan, pero el estado se conserva.
PPR (Partial Pre-rendering)
Técnica de renderizado en servidor que combina un shell de HTML estático (servido instantáneamente) con huecos dinámicos (Suspense) que se rellenan por streaming. React 19.2 añade las APIs resume y resumeToPipeableStream.
cacheSignal
API de React 19.2 para Server Components que informa cuándo una cache() ha dejado de ser válida, permitiendo descartar trabajo obsoleto.

Testing

Vitest
Framework de testing moderno para proyectos Vite. Compatible con la API de Jest y muy rápido gracias a Vite.
React Testing Library
Conjunto de utilidades para testear componentes React enfocándose en cómo los usa el usuario, no en la implementación interna.
Mock
Sustituto controlado de una función, módulo o API. Permite aislar el código bajo test y simular comportamientos.
Spy
Función que registra cómo fue llamada (argumentos, número de veces) sin modificar su comportamiento original.
Arrange, Act, Assert
Patrón de estructura de tests:
  1. Arrange: preparar el escenario.
  2. Act: ejecutar la acción a testear.
  3. Assert: verificar el resultado esperado.

Herramientas y entorno

Vite
Herramienta de construcción moderna que ofrece un entorno de desarrollo rápido con Hot Module Replacement y optimizaciones de producción.
pnpm
Gestor de paquetes eficiente que usa un store centralizado y enlaces duros para ahorrar espacio en disco. Es el gestor elegido en este curso.
Babel
Transpilador de JavaScript. Convierte JSX y código moderno en JavaScript compatible con navegadores antiguos. Vite lo usa internamente.
ESLint
Herramienta de análisis estático que detecta errores y estilos inconsistentes en el código JavaScript.
Prettier
Formateador de código que aplica un estilo consistente automáticamente.
npm scripts
Comandos definidos en package.json bajo la clave scripts. Son la forma habitual de ejecutar tareas como dev, build o test.
HMR
Hot Module Replacement. Actualiza módulos en caliente durante el desarrollo sin perder el estado de la aplicación.

Backend (.NET 8)

.NET 8
Plataforma de desarrollo de Microsoft para construir aplicaciones multiplataforma. En este curso se usa para crear la API REST del proyecto final.
ASP.NET Core
Framework de Microsoft para construir aplicaciones web, APIs y servicios en tiempo real con .NET.
Entity Framework Core
ORM oficial de .NET. Permite trabajar con bases de datos mediante objetos C# y consultas LINQ.
LINQ
Language Integrated Query. Conjunto de operadores de C# para consultar colecciones y bases de datos de forma declarativa.
PostgreSQL
Sistema de gestión de bases de datos relacional y open source. Es la base de datos elegida para el proyecto final.
Migración
En EF Core, archivo de código que describe los cambios en el esquema de la base de datos. Se aplica con dotnet ef database update.
Code-first
Enfoque de diseño de base de datos en el que primero se definen las entidades en C# y luego EF Core genera el esquema de la base de datos.
SignalR
Biblioteca de ASP.NET Core para comunicación en tiempo real mediante WebSockets. Ideal para notificaciones instantáneas y tableros colaborativos.
WebSocket
Protocolo de comunicación bidireccional y persistente entre cliente y servidor. Permite enviar datos en tiempo real sin polling.
Docker
Plataforma de contenedores que empaqueta aplicaciones con sus dependencias para ejecutarlas de forma consistente en cualquier entorno.
Docker Compose
Herramienta para definir y ejecutar aplicaciones multi-contenedor mediante un archivo docker-compose.yml.
Arquitectura limpia
Enfoque de organización de código que separa la aplicación en capas con dependencias dirigidas hacia el centro (dominio). Favorece el testeo y la mantenibilidad.

Conceptos generales

REST
Estilo arquitectónico para diseñar APIs basado en recursos, verbos HTTP y códigos de estado. Opera sobre el protocolo HTTP.
CRUD
Acrónimo de Create, Read, Update, Delete. Las cuatro operaciones básicas sobre datos. En una API REST suelen mapearse a POST, GET, PUT/PATCH y DELETE.
CORS
Cross-Origin Resource Sharing. Mecanismo de seguridad que controla qué dominios pueden hacer peticiones a una API desde el navegador.
Autenticación
Proceso de verificar la identidad de un usuario (¿quién eres?).
Autorización
Proceso de verificar qué puede hacer un usuario autenticado (¿qué permisos tienes?).
Hash de contraseña
Transformación unidireccional de una contraseña en un valor irreconocible. Se almacena en lugar de la contraseña en texto plano para mayor seguridad.
Declarativo
Paradigma en el que describes qué quieres que se vea, en lugar de indicar paso a paso cómo conseguirlo. React es declarativo.
Imperativo
Paradigma en el que describes los pasos exactos para modificar la interfaz. El DOM vanilla con document.getElementById es imperativo.
