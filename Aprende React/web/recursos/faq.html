FAQ general del curso

Recursos

Respuestas a preguntas recurrentes sobre el curso, su metodología, las herramientas elegidas y cómo sacarle el máximo partido.

¿Por qué JavaScript y no TypeScript?

El curso está pensado para desarrolladores que ya saben programar (por ejemplo en .NET, Java o Python) pero que nunca han aprendido React correctamente. Añadir TypeScript al principio introduce una capa extra de conceptos (tipos, interfaces, generics) que puede distraer del objetivo principal: entender React, su modelo mental y su ecosistema.

TypeScript es imprescindible en muchos equipos profesionales, pero se puede aprender una vez que ya se razona en componentes, hooks y estado. El curso se enfoca en JavaScript vanilla para mantener la barrera de entrada baja.

¿Por qué pnpm y no npm o yarn?

pnpm es más rápido, usa menos espacio en disco y evita problemas de phantom dependencies gracias a su node_modules estructurado. Además, el curso trabaja con workspaces y pnpm los gestiona de forma sencilla y eficiente.

Si en tu trabajo usas npm o yarn, los conceptos son casi idénticos; solo cambian los comandos. Aprender con pnpm no te limita: entenderás mejor por qué cada gestor toma las decisiones que toma.

¿Por qué Vite y no Create React App?

Create React App está en modo mantenimiento y ya no se recomienda para proyectos nuevos. Vite ofrece un servidor de desarrollo más rápido, builds más pequeñas y una configuración más simple. Es la herramienta estándar que se usa en la actualidad para proyectos React con JavaScript.

¿Necesito saber .NET para seguir el curso?

No. El curso de React funciona de forma independiente. El Módulo 14 (backend .NET 8) es opcional para quienes quieran convertirse en full-stack. Si prefieres otro backend (Node, Python, Java), los conceptos de API REST, JWT y WebSockets son transferibles.

¿Necesito instalar .NET 8 para seguir el backend?

Sí, si quieres ejecutar el backend localmente y probar el proyecto final completo. El Módulo 14 incluye los pasos de instalación. También puedes usar Docker para levantar el stack completo sin instalar .NET directamente en tu máquina.

¿El curso incluye despliegue?

Sí. El proyecto final incluye lecciones de despliegue del frontend y del backend. Se explican opciones gratuitas y de pago, y se incluye un docker-compose.yml para levantar todo el stack de forma local.

¿Por qué hay tantos proyectos y ejemplos?

React no se aprende leyendo; se aprende haciendo. Cada módulo incluye un proyecto práctico para aplicar lo visto en un contexto real. Repetir el proceso de crear, romper y arreglar código es lo que consolida el conocimiento.

¿Debo seguir el curso en orden?

Se recomienda seguir el orden de los módulos, especialmente al principio. Los conceptos se construyen uno sobre otro. Sin embargo, si ya conoces un tema, puedes repasar la lección rápida y pasar al proyecto. El índice te permite saltar donde prefieras.

¿Cómo uso el buscador del sidebar?

Escribe el nombre de una lección, un hook (por ejemplo useEffect) o un concepto en el campo de búsqueda de la barra superior. El sidebar filtrará automáticamente las lecciones y los recursos. Borra el texto para volver a ver el árbol completo.

¿El progreso se guarda?

Sí, en el almacenamiento local del navegador (localStorage). No se envía a ningún servidor. Si borras los datos del navegador o cambias de dispositivo, perderás el progreso. Puedes usar el botón "Marcar como completada" en cada lección para ir registrando tu avance.

¿Cómo funciona el tema oscuro?

El tema se guarda en localStorage bajo la clave rc19-theme. Un script en el <head> de cada página aplica el tema antes de que el navegador pinte el contenido, evitando parpadeos. Puedes alternar entre claro y oscuro con el botón de la barra superior.

¿Qué versión de React se usa?

React 19.2 (la versión estable más reciente). El curso cubre todas las novedades de React 19 — Form Actions, useActionState, useOptimistic, use(), Document Metadata y preloading — y el Módulo 15 añade lo que trajo React 19.2: <Activity>, useEffectEvent y PPR. Si en tu trabajo usas React 18, la mayoría de los conceptos son idénticos; las diferencias se señalan explícitamente.

¿Es obligatorio actualizar a React 19.2?

Si ya estás en React 19, conviene: la rama 19.2.x incluye parches de seguridad críticos (CVE-2025-55182) y las novedades de <Activity> y useEffectEvent. La actualización de 19 a 19.2 es menor y de bajo riesgo. Si aún estás en React 18, hazlo con calma: revisa la guía de actualización y los cambios de comportamiento que se señalan en las lecciones.

¿Por qué no se usa Tailwind en el curso?

Tailwind es muy popular, pero el objetivo de este curso es que entiendas CSS puro, las variables CSS, CSS Modules y cómo organizar estilos. Tailwind se menciona como opción al final, una vez que ya sabes qué problemas resuelve y cuáles crea.

¿Por qué Redux y Zustand si ya existe Context API?

Context API es perfecta para datos que cambian poco (tema, idioma, usuario). Para estado global que cambia frecuentemente o requiere lógica compleja, Redux Toolkit o Zustand ofrecen herramientas más robustas: middleware, devtools, persistencia y mejor rendimiento en actualizaciones frecuentes. El curso compara las tres opciones para que sepas cuándo usar cada una.

¿Qué hago si me atasco en un ejercicio?

Primero, lee el error detenidamente. La mayoría de los errores de React son mensajes claros. Segundo, revisa la sección de errores habituales de la lección. Tercero, compara tu código con el ejemplo mínimo. Si sigues atascado, descansa cinco minutos y vuelve; muchos bloqueos se resuelven con perspectiva.

¿Dónde están las soluciones de los ejercicios?

Cada lección incluye un ejercicio guiado resuelto paso a paso. Los retos adicionales no tienen solución inmediata: están pensados para que los intentes por tu cuenta antes de consultar recursos externos. El código de los proyectos se encuentra en las carpetas ejemplos/, proyectos/ y proyecto-final/.

¿Puedo usar este curso para enseñar a otros?

El material está creado para aprendizaje personal y docente. Si lo usas en un entorno educativo, menciona la fuente. No se permite vender el contenido tal cual ni reclamar su autoría.

¿Qué hago después de terminar el curso?

Sigue construyendo. La mejor forma de consolidar lo aprendido es crear un proyecto propio: una aplicación de gestión, un dashboard, una tienda online. Luego, aprende TypeScript, pruebas end-to-end, CI/CD y despliegue profesional. React es solo una parte del desarrollo frontend moderno.
