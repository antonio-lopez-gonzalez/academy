Glosario de Python

Referencia 📖 Términos clave

A

Argumento keyword-only
Parámetro que solo puede pasarse con su nombre, declarado después de un *: def f(*, clave). Obliga a la llamada a ser explícita.
Atributo de clase
Valor definido en el cuerpo de la class, compartido por todas las instancias. Cuidado con los mutables: una lista de clase es la misma para todos.
async/await
Sintaxis de asyncio: async def declara una corrutina y await suspende su ejecución hasta que la operación (I/O) termina, sin bloquear el hilo.

B

Bytecode / __pycache__
Representación intermedia que CPython compila y guarda en .pyc dentro de __pycache__. No lo edites: se regenera.

C

Closure
Función que recuerda las variables del ámbito donde se definió, aunque ese ámbito ya haya terminado. Base de los decoradores.
Comprehension
Forma concisa de construir listas, conjuntos o diccionarios con un bucle y un filtro opcional: [x*2 for x in xs if x > 0].
Context manager
Objeto que define __enter__/__exit__ y se usa con with para garantizar la limpieza (cerrar ficheros, liberar recursos).

D

Dataclass
Clase anotada con @dataclass que genera automáticamente __init__, __repr__ y __eq__. Ideal para modelar datos.
Dict comprehension
Comprehension que produce un diccionario: {k: v for k, v in pares}.
Duck typing
«Si camina como un pato y grazna como un pato…»: Python usa el comportamiento (métodos) más que el tipo declarado. Base de los protocolos.
Dunder
Método especial con doble guion bajo (__repr__, __eq__, __len__) que Python invoca en operaciones del lenguaje.

E

EAFP
«Es más fácil pedir perdón que permiso»: estilo pythonico de intentar la operación y capturar la excepción (try/except) en vez de comprobar antes (LBYL).
Entorno virtual
Directorio aislado con su propio intérprete y paquetes (.venv). Evita contaminar el Python del sistema.

G

Generador
Función con yield que produce valores de uno en uno, bajo demanda. Pereza y poca memoria.
GIL (Global Interpreter Lock)
Cerrojo de CPython que permite ejecutar bytecode en un solo hilo a la vez. Limita el paralelismo de CPU con threading; no afecta a I/O ni a multiprocessing.

H

Hashable
Objeto con valor de hash estable, usable como clave de dict o elemento de set. Los mutables (lista, dict) no lo son; las tuplas de inmutables sí.

I

Iterable / Iterador
Un iterable puede recorrerse (for); un iterador es el objeto que lleva la cuenta y devuelve el siguiente elemento con next() hasta StopIteration.

L

LEGB
Orden de resolución de nombres: Local → Enclosing → Global → Built-in. Explica qué variable «gana» cuando hay nombres repetidos.
LBYL
«Mira antes de saltar»: comprobar condiciones antes de actuar. A veces es lo claro; otras, EAFP es más pythonico.

M

Mutabilidad
Un objeto mutable (lista, dict, set) puede cambiar su contenido; uno inmutable (int, str, tuple) no. Relevante para defaults, claves de diccionario y copias.
MRO (Method Resolution Order)
Orden en que Python busca un método en una jerarquía de clases. Se consulta con Clase.__mro__ y guía a super().

P

PEP 8
Guía de estilo de Python: nombres snake_case, 4 espacios, imports al principio, líneas de hasta 79/88 caracteres.
pyproject.toml
Fichero estándar de configuración de un proyecto Python: metadatos, dependencias, build y herramientas (pytest, ruff, mypy).
Pythonic
Código que sigue las convenciones e ideas de Python (iterar directo, comprender, desempaquetar, usar with), resultando claro e idiomático.

R

REPL
Read-Eval-Print Loop: el intérprete interactivo (>>>). Perfecto para explorar y probar al vuelo.
ruff / black
Herramientas de calidad: ruff analiza (lint) y formatea; black es el formateador «sin discusión». Automatizan el estilo.

S

Slicing
Extraer una subsecuencia con inicio:fin:paso: xs[1:4], xs[::-1] (invertir).
snake_case
Convención de nombres en minúsculas con guion bajo, para funciones, variables y módulos.
stdlib (biblioteca estándar)
Conjunto de módulos que vienen con Python (json, pathlib, datetime, argparse…). El curso prioriza la stdlib frente a terceros.

T

Truthiness
Regla que decide si un valor se comporta como verdadero en un if: son falsy False, None, 0, 0.0, "" y las colecciones vacías.
Type hints
Anotaciones de tipo (def f(x: int) -> str) que documentan y permiten comprobar con mypy, pero no se aplican en tiempo de ejecución.

U

uv
Gestor de paquetes y entornos moderno y muy rápido, escrito en Rust. Sustituye a pip/venv con comandos como uv add y uv run y un lockfile reproducible.

V

venv
Módulo de la stdlib para crear entornos virtuales: python -m venv .venv.
