FAQ ❓ Dudas comunes

General

¿Necesito saber programar antes de empezar?

Sí, este curso lo asume. Está pensado para quien ya programa en otro lenguaje (JavaScript, C#, Java…) o para quien ya toca Python y quiere llenar los huecos. Va al grano y compara con otros lenguajes, así que si nunca has programado, te resultará exigente: empieza por un curso de introducción y vuelve después.

¿Qué versión de Python necesito?

Python 3.12 o superior. Usamos f-strings, match/case, tomllib y sintaxis moderna de tipos. Cualquier 3.12/3.13 sirve. No usamos Python 2 ni compatibilidad con versiones antiguas.

¿Hace falta instalar algo con pip antes de empezar?

No. Los módulos 0–6 funcionan solo con la biblioteca estándar. A partir del módulo 7 instalarás pytest, ruff y mypy (siempre dentro de un entorno virtual), y verás uv como alternativa moderna. Todo está explicado paso a paso.

¿Cuánto tiempo tengo que dedicar por lección?

Cada lección está pensada para 30–40 minutos más el reto. El ritmo recomendado es 3–4 lecciones por semana. Los ejercicios producen código real del proyecto Biblioteca, así que conviene hacerlos, no solo leerlos.

¿Qué pasa si me atasco en un reto?

Vuelve a la sección de teoría y al ejemplo mínimo: casi siempre la solución reutiliza lo explicado. Abre el REPL y experimenta con trozos pequeños (feedback instantáneo). Y recuerda que los retos son a propósito un poco más difíciles: intentarlo vale más que ver la solución.

El lenguaje

¿Por qué Python no tiene llaves y usa indentación?

Porque la legibilidad es una decisión de diseño central del lenguaje: los bloques se definen por sangría (4 espacios por convención), y así el código se ve igual para todo el mundo. La contrapartida es que mezclar tabuladores y espacios provoca IndentationError; por eso se configura el editor para insertar espacios.

¿Qué significa que "todo es un objeto"?

Que números, cadenas, funciones y clases son objetos con tipo, identidad y atributos. Por eso puedes pasar funciones como argumentos, guardar clases en variables y consultar type(x). Es la base de decoradores, comprehensions y duck typing.

¿Cuál es la diferencia entre is y ==?

== compara valores (dos listas con lo mismo son iguales); is compara identidad (si son el mismo objeto en memoria). Usa is solo con None y centinelas; para todo lo demás, ==.

¿Por qué hay que evitar una lista como valor por defecto?

Porque el valor por defecto se evalúa una sola vez al definir la función y se comparte entre llamadas: def f(x=[]) acumula elementos entre llamadas distintas. La solución es usar None y crear la lista dentro: def f(x=None): x = x or [].

Entorno y herramientas

¿venv/pip o uv? ¿Cuál uso?

Enseñamos los dos. venv+pip es el estándar que encontrarás en todas partes y conviene dominarlo. uv es la opción moderna: mucho más rápido, gestiona también versiones de Python y usa un lockfile reproducible. Regla práctica del curso: usa lo que pida el proyecto; si empiezas de cero, uv es cómodo, pero entiende qué hace venv+pip porque está en todas partes.

¿Puedo seguir el curso en Windows?

Sí, Python corre nativo en Windows. En los ejemplos verás el launcher py y la activación del entorno virtual con PowerShell (.venv\Scripts\Activate.ps1). Cada lección señala esa diferencia cuando aplica; no hace falta WSL.

¿Necesito un IDE concreto?

Recomendamos VSCode con la extensión de Python (Pylance), pero cualquier editor sirve. El REPL y la terminal son tus mejores herramientas mientras aprendes.

¿Vale la pena aprender Python en 2026?

Sí. Python domina la ciencia de datos, la automatización, el scripting y buena parte del backend y de la IA. Y aunque tu trabajo principal sea otro lenguaje, entender Python te da acceso a ese ecosistema. Además, es excelente para automatizar tareas del día a día.
