*args, **kwargs y desempaquetado

Módulo 2 · Control de flujo y funciones ⏱ 30 minutos

1 · Introducción

¿Y si no sabes de antemano cuántos argumentos te van a pasar? Hasta ahora cada parámetro tenía nombre y posición fijos. Python permite funciones variádicas: *args recoge todos los posicionales sobrantes y **kwargs todos los keyword sobrantes. Además, el mismo * sirve, en la llamada, para desempaquetar listas y diccionarios en argumentos.

Esta lección también cubre dos marcas modernas (3.8+) que dan control fino sobre cómo se llama una función: el * suelto que vuelve un parámetro keyword-only y la barra / que lo vuelve positional-only. Con esto cerrarás el diseño de firmas que empezaste en la lección anterior.

¿Por qué existe esta lección? Porque *args/**kwargs son la base de los wrappers y decoradores (Módulo 8), de las funciones que envuelven APIs y de los constructores flexibles. Entender hasta dónde llega su poder —y por qué no todo debe ser variádico— es lo que distingue una firma clara de una sopa de asteriscos.

2 · Teoría

*args: todos los posicionales, en una tupla

Un parámetro precedido de * recoge los argumentos posicionales que no encajaron en los nombres anteriores. Se llama args por convención, pero el nombre es libre: lo que importa es el asterisco. Dentro de la función, args es una tupla (inmutable).

def total(*prices):
    # 'prices' es una tupla con todos los argumentos posicionales.
    print(type(prices).__name__, prices)
    return sum(prices)

print(total(10, 20, 30))
print(total())

# Salida esperada:
# tuple (10, 20, 30)
# 60
# tuple ()
# 0

**kwargs: todos los keyword, en un diccionario

Un parámetro con doble asterisco recoge los argumentos pasados por nombre que no encajaron en otros parámetros. Dentro es un dict. El orden de inserción se conserva (desde 3.7), así que se puede recorrer con sentido.

def make_item(title, **extra):
    # 'extra' es un dict con los keyword sobrantes.
    item = {"title": title}
    item.update(extra)      # fusiona los extras en el ítem
    return item

print(make_item("1984", year=1949, borrowed=False))

# Salida esperada:
# {'title': '1984', 'year': 1949, 'borrowed': False}

El orden de la firma no es libre

En la definición, los parámetros deben ir en este orden. Saltárselo es SyntaxError:

def f(posicional,       # 1) normales (posicional o keyword)
      con_default=0,    # 2) con valor por defecto
      *args,            # 3) extra posicionales -> tupla
      keyword_only,     # 4) tras '*' o '*args': solo por nombre
      **kwargs):        # 5) extra keyword -> dict
    ...

Keyword-only: el * suelto

Si no necesitas *args pero quieres forzar que ciertos parámetros se pasen solo por nombre, pon un * a secas. Es perfecto para booleanos y opciones: save(data, overwrite=True) se lee; save(data, True) no.

def make_item(title, *, kind="book", year=None):
    return {"title": title, "kind": kind, "year": year}

print(make_item("Dune", kind="movie"))   # se pasan por nombre: OK
# make_item("Dune", "movie")            # ❌ TypeError: demasiados posicionales

# Salida esperada:
# {'title': 'Dune', 'kind': 'movie', 'year': None}

Positional-only: la barra /

La barra marca los parámetros que solo pueden pasarse por posición; a su derecha, los que pueden ser keyword. Sirve para funciones que quieren libertad de renombrar sus parámetros sin romper a quien las llama.

def greet(name, /, greeting="Hola"):
    # 'name' es positional-only; 'greeting' se puede nombrar.
    return f"{greeting}, {name}"

print(greet("Dune"))
print(greet("Dune", greeting="Hey"))
# greet(name="Dune")   # ❌ TypeError: name es positional-only

# Salida esperada:
# Hola, Dune
# Hey, Dune

Truco mental: * y / se leen como «a partir de aquí». A la derecha de *, keyword-only. A la izquierda de /, positional-only. En medio, flexible.

Desempaquetar al llamar: f(*seq) y f(**mapping)

El * también funciona en la llamada: convierte una secuencia en argumentos posicionales y un diccionario en keyword. Se pueden combinar y mezclar con argumentos explícitos.

def add(a, b, c):
    return a + b + c

values = [1, 2, 3]
print(add(*values))              # la lista se reparte en a, b, c -> 6

params = {"a": 10, "b": 20, "c": 30}
print(add(**params))             # el dict se reparte por nombre  -> 60

# Salida esperada:
# 6
# 60

Desempaquetar colecciones (asignación)

En una asignación, * recoge «el resto» en una lista. Es la forma elegante de separar cabecera y cola.

first, *rest = [1, 2, 3, 4]
print(first, rest)                 # 1 [2, 3, 4]

*init, last = [1, 2, 3, 4]
print(init, last)                  # [1, 2, 3] 4

first, *middle, last = [1, 2, 3, 4, 5]
print(first, middle, last)         # 1 [2, 3, 4] 5

# También sirve para fusionar diccionarios (sin mutar ninguno):
defaults = {"kind": "book", "borrowed": False}
override = {"year": 1949}
print({**defaults, **override})
# Salida esperada:
# {'kind': 'book', 'borrowed': False, 'year': 1949}

3 · Ejemplo mínimo

La función variádica más pequeña: sumar cualquier cantidad de números. Fíjate en el tipo que recibe.

def total(*numbers):
    """Suma cualquier cantidad de números (incluida ninguna)."""
    return sum(numbers)      # 'numbers' ya es una tupla lista para sum()

print(total(1, 2, 3))        # 6
print(total())               # 0
print(total(*[4, 5]))        # desempaqueta la lista -> 9

Línea por línea:

  1. def total(*numbers): captura todos los posicionales en la tupla numbers.
  2. sum(numbers) funciona porque numbers es iterable; con cero argumentos es la tupla vacía y sum(()) es 0.
  3. total(1, 2, 3) pasa tres valores sueltos.
  4. total(*[4, 5]) desempaqueta la lista: es equivalente a total(4, 5).

4 · Ejemplo real

En Biblioteca necesitamos una búsqueda con filtros flexibles: a veces por tipo, a veces por campos sueltos. *kinds y **filters modelan ambas cosas con una sola firma.

def search(catalog, *kinds, **filters):
    """Filtra el catálogo por tipo(s) y por campo=valor.

    Args:
        catalog: lista de ítems.
        *kinds: tipos aceptados ("book", "movie"...). Si no hay, cualquiera.
        **filters: pares campo=valor que deben coincidir exactamente.
    """
    results = []
    for item in catalog:
        # Si se pidieron tipos y el ítem no está entre ellos, fuera.
        if kinds and item["kind"] not in kinds:
            continue
        # Todos los filtros deben cumplirse (comprobación sin usar all()).
        matches = True
        for key, value in filters.items():
            if item.get(key) != value:
                matches = False
                break
        if matches:
            results.append(item["title"])
    return results

catalog = [
    {"title": "1984", "kind": "book", "year": 1949, "borrowed": False},
    {"title": "Dune", "kind": "book", "year": 1965, "borrowed": True},
    {"title": "Blade Runner", "kind": "movie", "year": 1982, "borrowed": False},
]

print(search(catalog))                             # sin filtros: todos
print(search(catalog, "book"))                     # solo libros
print(search(catalog, "book", "movie", borrowed=False))
print(search(catalog, year=1949))                  # por campo

# Salida esperada:
# ['1984', 'Dune', 'Blade Runner']
# ['1984', 'Dune']
# ['1984', 'Blade Runner']
# ['1984']

Decisiones de diseño:

  • *kinds documenta que se pueden pedir uno o varios tipos sin envolverlos en una lista: search(catalog, "book", "movie").
  • **filters permite filtrar por cualquier campo futuro sin cambiar la firma. Es la base de las APIs flexibles.
  • La comprobación con item.get(key) evita KeyError si un ítem no tiene ese campo; simplemente no coincide.
  • La función devuelve una lista nueva: no muta catalog.

6 · Errores habituales

Intentar mutar *args

# ❌ args es una TUPLA: no tiene append
def collect(*args):
    # args.append("x")      # AttributeError
    return list(args)        # ✅ si necesitas mutar, conviértelo

print(collect(1, 2))         # [1, 2]

Creer que *args captura también los keyword

# ❌ 'year=1949' no va a *args: va a **kwargs (o da TypeError si no existe)
def f(*args):
    return args

# f(1, 2, year=1949)   # TypeError: unexpected keyword argument 'year'

# ✅ Cada uno captura lo suyo
def g(*args, **kwargs):
    return args, kwargs

print(g(1, 2, year=1949))    # ((1, 2), {'year': 1949})

Abusar de **kwargs y ocultar errores de tecleo

# ❌ Un typo en el nombre no da error: se cuela en kwargs y se ignora
def create(**kwargs):
    return kwargs

print(create(titl="Dune"))    # {'titl': 'Dune'}  <- error silencioso

# ✅ Parámetros explícitos: el typo salta como TypeError
def create(title):
    return {"title": title}

# create(titl="Dune")   # TypeError: missing required argument 'title'

Objetivo: escribir una función de resumen que combine un título obligatorio, etiquetas variádicas y metadatos keyword-only, y ver el resultado exacto.

  1. Paso 1: define la firma con las tres zonas: obligatorio, *tags y **meta. 
    def summarize(title, *tags, kind="book", **meta):
    """Resume un ítem: título, tipo, etiquetas y metadatos extra."""
    parts = [f"{title} [{kind}]"]
    if tags:                                   # tupla no vacía
        parts.append("etiquetas: " + ", ".join(tags))
    if meta:                                   # dict no vacío
        extras = ", ".join(f"{key}={value}" for key, value in meta.items())
        parts.append(extras)
    return " | ".join(parts)
  2. Paso 2: llama en varios modos. 
    print(summarize("1984", "distopia", "clasico", year=1949, borrowed=False))
print(summarize("Dune", kind="movie"))
print(summarize("Blade Runner", "scifi"))
  3. Paso 3 (verificación): la salida esperada es: 
    # 1984 [book] | etiquetas: distopia, clasico | year=1949, borrowed=False
# Dune [movie]
# Blade Runner [book] | etiquetas: scifi

8 · Reto

🎯 Un wrapper que reenvía todo

Escribe una función trace(func) que devuelva una nueva función. Esa nueva función debe aceptar cualquier combinación de argumentos, imprimir cuáles llegaron y luego llamar a func reenviándoselos tal cual. Pruébala envolviendo summarize del ejercicio y comprueba que sigue funcionando igual.

Pista: la firma del wrapper es def wrapper(*args, **kwargs): y el reenvío es func(*args, **kwargs). Aquí * y ** hacen el papel de «recoger» y «repartir». Guarda el original como atributo con wrapper.func = func para no perderlo. Este es exactamente el esqueleto de un decorador (Módulo 8).

9 · Resumen

  • *args recoge los posicionales sobrantes en una tupla.
  • **kwargs recoge los keyword sobrantes en un dict.
  • El orden en la firma es: normales → con default → *args → keyword-only → **kwargs.
  • Un * suelto marca keyword-only; una / marca positional-only.
  • En la llamada, f(*seq) y f(**mapping) desempaquetan.
  • a, *resto = … recoge el resto de una colección en una lista.

10 · Preguntas frecuentes

¿Tengo que llamarlos args y kwargs?

No. Son solo convenciones muy extendidas. Puedes llamarlos *prices y **options. Lo que Python interpreta es el asterisco, no el nombre. Un nombre descriptivo mejora la legibilidad; cuando reenvías «todo lo que llegó» sin mirarlo, args/kwargs es lo habitual.

¿Puedo tener *args y **kwargs en la misma función?

Sí, y en ese orden: def f(a, *args, **kwargs):. Es el patrón de los wrappers que aceptan cualquier cosa y la reenvían. La regla es que *args va antes de **kwargs; el intérprete lo exige.

¿Para qué sirven de verdad / y * sueltos en una firma?

Para controlar la compatibilidad. Si un parámetro es positional-only, puedes renombrarlo en el futuro sin romper a quien lo llamaba por posición; si es keyword-only, fuerzas a que la llamada sea explícita y evitas errores con valores ambiguos. La biblioteca estándar los usa mucho en funciones muy extendidas.
