print, input, conversiones y None

Módulo 1 · Fundamentos del lenguaje ⏱ 30 minutos

1 · Introducción

Toda la lección anterior giró en torno a los datos. Ahora toca hablar con el exterior: mostrar resultados con print, leer lo que escribe el usuario con input, y convertir entre tipos, ese paso que siempre se olvida. Cierra el módulo un valor especial que causa más TypeError que ningún otro: None, la representación de «no hay valor».

Aquí también asomará por primera vez la truthiness: no todo valor es un booleano, pero casi todos pueden usarse en un if. Es un adelanto de condicionales (Módulo 2), pero conviene verlo junto a None porque van de la mano.

¿Por qué existe esta lección? Porque el error número uno de quien empieza es input() devolviendo un string: "20" + 1 falla, y "20" comparado con 20 no coincide. Entender la conversión explícita y el papel de None te ahorra horas de depuración y hace que el primer script interactivo de Biblioteca funcione.

2 · Teoría

print: no solo imprime

print es una función (en Python 3, no una sentencia) que admite varios argumentos y dos opciones muy útiles: sep (qué poner entre argumentos) y end (qué poner al final).

print("bk-01", "1984", 1949)             # bk-01 1984 1949  (sep por defecto: espacio)
print("a", "b", "c", sep="-")            # a-b-c            (sep personalizado)
print("sin salto", end="")               # no añade \n
print("…y sigo en la misma línea")       # se concatena con la anterior
print("uno", "dos", sep="\n")            # uno y dos en líneas distintas
# end también sirve para terminar con un espacio o tabulador
print("Procesando", end="… ")
print("listo")                           # Procesando… listo

Por defecto, cada print añade un salto de línea (end="\n") y separa los argumentos con un espacio (sep=" "). Controlarlos evita concatenaciones raras y barra de progreso mal maquetadas.

Cuando print recibe objetos que no son texto, llama a su str(). Por eso print(42) muestra 42 y no un objeto. Lo entenderás a fondo con los dunders en el Módulo 5.

input: SIEMPRE devuelve str

input(prompt) muestra un mensaje, espera a que el usuario escriba y pulse Enter, y devuelve el texto escrito como str. Da igual que hayas tecleado 20: lo recibes como "20".

# OJO: esto pide interacción por teclado; al ejecutarlo, escribe un valor.
name = input("¿Cómo te llamas? ")
print(f"Hola, {name}")           # str; p. ej. "Hola, Ana"
# Si necesitas un número, convierte explícitamente:
age_text = input("¿Tu edad? ")   # p. ej. el usuario escribe "30"
age = int(age_text)              # str -> int
print(f"El año que viene cumplirás {age + 1}")   # ...31

Nunca uses eval(input(...)). Evalúa lo que el usuario escriba como código Python: es un agujero de seguridad clásico. Convierte siempre con int(), float() o los que correspondan, y maneja el error con try/except (Módulo 6).

Conversiones explícitas

Convertir entre tipos es una operación habitual. Cada nombre de tipo actúa como función de conversión:

ConversiónEjemploResultado
int(str)int("42")42
float(str)float("3.5")3.5
str(x)str(42)"42"
list(iterable)list("abc")['a', 'b', 'c']
tuple(iterable)tuple([1, 2])(1, 2)
set(iterable)set("aab"){'a', 'b'}
bool(x)bool(0)False
 
print(int("42"))          # 42
print(float("3.5"))       # 3.5
print(str(42))            # 42  (ahora es texto: "42")
print(list("abc"))        # ['a', 'b', 'c']  -> separa en caracteres
print(list((1, 2)))       # [1, 2]           -> convierte tupla en lista
print(tuple([1, 2]))      # (1, 2)
print(set([1, 1, 2]))     # {1, 2}           -> elimina duplicados
print(bool(0), bool(1))   # False True
# Las conversiones pueden fallar si el texto no es válido:
# int("3.5")     -> ValueError: invalid literal for int() with base 10: '3.5'
# int("hola")    -> ValueError
print(int(float("3.5")))  # 3  -> primero a float, luego truncamos a int

int() no redondea, trunca. int("3.9") ni siquiera es válido (error), pero int(3.9) da 3, no 4. Si quieres redondear, usa round(). Y int("3.5") falla porque ese texto es un decimal: pasa primero por float.

None: el valor de «no hay valor»

None es un objeto único (un singleton) de tipo NoneType. Se usa para indicar ausencia: una función que no devuelve nada devuelve None, una clave opcional puede valer None, etc.

result = None
print(result)              # None
print(type(result))        # <class 'NoneType'>
# La forma CORRECTA de comprobarlo es 'is None' (identidad, no igualdad):
if result is None:
    print("todavía no hay resultado")   # todavía no hay resultado
# print devuelve None: eso confirma que es una función sin valor de retorno.
x = print("hola")          # hola
print(x)                   # None

¿Por qué is None y no == None? Porque None es un único objeto y is comprueba exactamente eso. Además, una clase podría redefinir == y responder True frente a None de forma inesperada. La convención PEP 8 es is None / is not None.

Truthiness: casi todo vale en un if

Cuando usas un valor donde se espera un booleano, Python lo evalúa como verdadero o falso llamando a bool(). Estos son los valores que se consideran falsy (falsos):

FalsyEjemplo
NoneNone
Cero, de cualquier tipo0, 0.0, 0j
Vacíos"", [], (), {}, set()
FalseFalse

Todo lo demás es truthy (verdadero). Esto permite escribir código idiomático, pero también es una trampa cuando un 0 legítimo se confunde con «ausente».

# ✅ Idiomático: comprobar si una lista tiene elementos
titles = ["1984", "Dune"]
if titles:
    print(f"Hay {len(titles)} títulos")   # Hay 2 títulos
empty = []
if not empty:
    print("Catálogo vacío")               # Catálogo vacío
# ⚠️ Cuidado: distinguir "no hay valor" de "el valor es 0/cadena vacía"
count = 0
if count:
    print("tengo elementos")
else:
    print("count es 0 o falsy")           # se imprime esto: ambiguo
# Si un 0 es válido, comprueba explícitamente:
if count is not None:
    print("count está definido")          # count está definido

3 · Ejemplo mínimo

Leer un año y decidir si es válido, sin olvidar la conversión.

# Al ejecutarlo, teclea por ejemplo: 1949
year_text = input("Año de publicación: ")   # -> siempre str
year = int(year_text)                        # str -> int (conversión explícita)
print(f"Año registrado: {year}")             # Año registrado: 1949
print(type(year))                            # <class 'int'>

Línea por línea:

  1. input(...): muestra el mensaje y devuelve "1949" (texto).
  2. int(year_text): convierte el texto en entero. Si el usuario escribe abc, lanzaría ValueError.
  3. f"…{year}…": interpola el entero sin necesidad de str().

Ejecutar el ejemplo: guárdalo como registro.py y lánzalo. En Linux/macOS: python3 registro.py. En Windows: py registro.py. El input() se quedará esperando tu teclado; eso es lo normal en un script interactivo.

4 · Ejemplo real

Primer contacto interactivo con Biblioteca: pedimos los datos de un libro, los convertimos y construimos el diccionario del ítem. Es un embrión de lo que el comando bib add hará en el Módulo 4.

# Pequeñas funciones de lectura con conversión y validación básica.
def ask_text(prompt: str) -> str:
    """Pide texto y quita espacios sobrantes de los extremos."""
    return input(prompt).strip()
def ask_int(prompt: str, default: int | None = None) -> int | None:
    """Pide un entero; si el usuario deja vacío, devuelve el default (None)."""
    raw = input(prompt).strip()
    return int(raw) if raw else default
# Recogemos los datos del nuevo ítem.
title = ask_text("Título: ")                 # p. ej. "Dune"
kind = ask_text("Tipo (book/movie): ")        # p. ej. "book"
year = ask_int("Año (opcional): ")            # p. ej. "1965" o vacío -> None
# Construimos el diccionario del ítem.
item = {
    "id": "bk-03",           # en el proyecto real se generará de forma única
    "title": title,
    "kind": kind,
    "year": year,            # puede ser None si no se indicó
    "borrowed": False,
}
print(f"\nAñadido: {item['title']} ({item['kind']})", end="")
# Mostramos el año solo si existe: is not None distingue 0 de "sin año".
print(f" · {item['year']}" if item["year"] is not None else " · año desconocido")
# Salida esperada (ejemplo de sesión):
# Título: Dune
# Tipo (book/movie): book
# Año (opcional): 1965
#
# Añadido: Dune (book) · 1965

Decisiones: separamos la lectura en funciones pequeñas para no repetir input(); strip() evita títulos con espacios accidentales; el año es opcional y por eso usamos None como valor por defecto, no 0 (que confundiría «año cero» con «sin año»). La comprobación is not None es la clave para mostrar 1965 sin ocultar un año legítimamente 0.

6 · Errores habituales

Olvidar convertir input()

# ❌ 'input' devuelve str: comparar con un número nunca coincide
year_text = "1949"                 # simulamos lo que devolvería input()
# if year_text > 1900:             # TypeError: '>' not supported between str and int
# ✅ Convierte antes de operar
year = int(year_text)
if year > 1900:
    print("año moderno")           # año moderno

Comparar con None usando ==

# ❌ Funciona, pero no es lo correcto ni lo idiomático
value = None
print(value == None)               # True  (pero evítalo)
# ✅ Identidad
print(value is None)               # True
print(value is not None)           # False

Usar 0 como «sin valor» y confundirlo con un cero real

# ❌ No se puede distinguir "sin año" de "año 0"
year = 0
if not year:
    print("sin año")               # se imprime aunque 0 podría ser un año
# ✅ Centinela explícito
year = None
if year is None:
    print("sin año")               # inequívoco

Confiar en la truthiness cuando un vacío es válido

# ❌ Una cadena vacía legítima se trata como ausencia
title = ""
if title:
    print("título válido")
else:
    print("sin título")            # se imprime; ¿querías permitir ""?
# ✅ Si "" es un valor válido, compara con None o valida aparte
title = ""
if title is not None:
    print("título definido")       # título definido

Usar eval(input(...))

# ❌ Ejecuta lo que teclee el usuario como código: peligroso
# value = eval(input("Número: "))   # "0" ok, pero "__import__('os')..." no
# ✅ Conversión explícita e intención clara
raw = input("Número: ")
value = int(raw)                   # falla con ValueError si no es un entero

7 · Ejercicio guiado

Objetivo: mini-CLI que pide dos años y calcula la antigüedad media, manejando None y conversiones. Paso a paso.

  1. Paso 1: pide dos años con input(), permitiendo que uno quede vacío.
  2. Paso 2: convierte cada respuesta de forma segura: si el texto está vacío, el año es None; si no, int().
  3. Paso 3: filtra los años que no son None y calcula su media. Si no queda ninguno, muestrа «sin datos».
  4. Paso 4: muestra el resultado formateado a un decimal.
  5. Paso 5 (verificación): ejecuta con 1965 y vacío → media 1965.0; con 1949 y 1965 → media 1957.0.

Solución de referencia:

def ask_year(prompt: str) -> int | None:
    """Devuelve un int, o None si el usuario deja el campo vacío."""
    raw = input(prompt).strip()
    return int(raw) if raw else None
first = ask_year("Primer año: ")          # p. ej. 1949
second = ask_year("Segundo año (opcional): ")  # p. ej. vacío -> None
# Filtramos los que sí tienen valor y calculamos la media.
years = [year for year in (first, second) if year is not None]
if years:
    average = sum(years) / len(years)
    print(f"Antigüedad media: {average:.1f}")   # con 1949 y vacío -> 1949.0
else:
    print("Sin datos")

Resultado esperado (sesión con 1949 y vacío):

Primer año: 1949
Segundo año (opcional): 
Antigüedad media: 1949.0

Cómo comprobarlo: con un solo año, sum(years) / len(years) es 1949 / 1 = 1949.0; con dos, la media de 1949 y 1965 es 1957.0. La comprensión de lista que filtra los None es el puente al Módulo 3; por ahora basta con leerla: «quédate con los que no son None».

8 · Reto

🎯 Formulario robusto que no se rompa

Escribe un pequeño formulario que pida título, tipo y año. Si el usuario teclea un año que no es un número, vuelve a pedirlo en lugar de que el programa reviente. Al final, imprime la ficha o «cancelado» si deja el título vacío.

Pista: envuelve int() en un try/except ValueError (Módulo 6) y repite dentro de un while hasta que la conversión funcione. Para el título vacío, comprueba if not title: —es un caso donde la truthiness sí encaja, porque «texto vacío» significa exactamente «sin título»—. Piensa en qué valor devuelves cuando el usuario cancela: probablemente None.

9 · Resumen

  • print admite varios argumentos y las opciones sep y end.
  • input(prompt) devuelve siempre un str: hay que convertir para operar con números.
  • Las conversiones son funciones: int(), float(), str(), list(), tuple(), set(), bool().
  • int("3.5") falla; int(3.9) trunca; para redondear usa round().
  • None representa «sin valor», es un singleton y se comprueba con is None.
  • Son falsy: None, False, ceros y colecciones vacías; todo lo demás es verdadero.
  • Nunca uses eval(input(...)): convierte explícitamente y maneja errores.

10 · Preguntas frecuentes

¿Por qué input no me devuelve un número si escribo un número?

Porque input solo sabe recibir texto: todo lo que el usuario teclea es una secuencia de caracteres. Convertir a número es una decisión que debes tomar tú con int() o float(), de modo que controlas qué hacer si el texto no es válido. Es una decisión de seguridad y claridad, no una limitación.

¿Cuál es la diferencia entre None, False y 0?

Son tres objetos distintos. None significa «ausencia de valor»; False es el booleano falso; 0 es el número cero. Los tres son falsy (se evalúan como falso en un if), por eso conviene distinguirlos con is None cuando la diferencia importa.

¿Qué hace exactamente end="" en print?

Reemplaza el salto de línea final por una cadena vacía, de modo que el siguiente print continúa en la misma línea. Es útil para escribir progreso o construir una línea por partes. Recuerda volver a añadir un salto al final para no dejar el prompt de la terminal «pegado».

¿Es mala idea usar la truthiness?

No, es idiomática cuando coincide con tu intención: if not items: («la lista está vacía») es más claro que if len(items) == 0:. El problema aparece cuando un valor falsy es legítimo y no significa ausencia (un precio de 0, un contador de 0). En esos casos, comprueba explícitamente con is None o == 0.

¿Cómo convierto una lista de números a texto y los uno con comas?

", ".join(str(n) for n in numbers). join solo acepta strings, por eso convertimos cada número primero. La expresión entre paréntesis es un generador (Módulo 3); una comprensión de lista equivalente sería ", ".join([str(n) for n in numbers]).
