Proyecto .NET que ejecutas con dotnet + Docker

En proyectos/redis-ws-hub/ encontrarás un servidor WebSocket + Minimal API en .NET 8 con un hub de conexiones distribuido sobre Redis, listo para levantar con docker compose up y dotnet run.

Para quién es

Para desarrolladores .NET que ya programan y quieren dominar Redis: entender las estructuras de datos, las decisiones de diseño (single-thread, TTL, pub/sub vs streams) y aplicarlas con StackExchange.Redis en un sistema real de tiempo real.
