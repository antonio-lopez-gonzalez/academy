IDatabase: strings, hashes y expiración

Módulo 6 · StackExchange.Redis en .NET ⏱ 40 minutos

1 · Introducción

IDatabase es la puerta de entrada a los comandos de Redis desde C#: strings, hashes, sets, sorted sets, streams, expiración, transacciones. Aquí traduces lo que viste en redis-cli (M1-M3) a su API async.

Verás la equivalencia exacta comando↔método y las trampas típicas: RedisValue, tipos, When.NotExists, y el TimeSpan en TTL.

RedisValue: bytes que puedes leer

Todos los comandos devuelven RedisValue: es un string binario. Pruébalo:

  • value.IsNull → ¿la key no existía? (nil)
  • value.ToString() → texto; (long)value para el número; value == "node-1".
  • Con RedisKey como clave tipada (evita typos).

TTL con TimeSpan

await db.KeyExpireAsync(key, TimeSpan.FromSeconds(30));      // EXPIRE
TimeSpan? ttl = await db.KeyTimeToLiveAsync(key);            // TTL (-1 => null? lo verás)
await db.KeyPersistAsync(key);                                // PERSIST

Ojo: KeyTimeToLiveAsync devuelve TimeSpan? (null = no TTL), que es distinto del «-1» de redis-cli.

When.NotExists / NotExists / Always

bool created = await db.StringSetAsync(lockKey, token,
    TimeSpan.FromSeconds(5), When.NotExists);   // SET NX PX → lock atómico
bool updated = await db.StringSetAsync(key, val,
    TimeSpan.FromSeconds(30), When.Exists);     // SET XX

3 · Ejemplo mínimo

using StackExchange.Redis;

IDatabase db = ConnectionMultiplexer.Connect("localhost:6379").GetDatabase();

// string con TTL
await db.StringSetAsync("g:hs", "hola", TimeSpan.FromSeconds(60));
var ok = await db.StringGetAsync("g:hs");            // RedisValue "hola"
if (ok.IsNull) { /* no existía */ }

// hash: campos
await db.HashSetAsync("hub:conn:1",
    [new HashEntry("node", "node-1"), new HashEntry("userId", "42")]);
string node = await db.HashGetAsync("hub:conn:1", "node");  // "node-1"
var all = await db.HashGetAllAsync("hub:conn:1");           // HashEntry[]

// contador atómico
long c = await db.StringIncrementAsync("stats:msgs");

4 · Ejemplo real

El registro del hub con hashes y TTL, la forma exacta en que lo harás:

public async Task RegisterAsync(IDatabase db, string nodeId, string conn, string userId)
{
    RedisKey key = $"hub:conn:{conn}";
    await db.HashSetAsync(key,
        [new HashEntry("node", nodeId), new HashEntry("userId", userId)]);
    await db.KeyExpireAsync(key, TimeSpan.FromSeconds(30));

    // heartbeat desde el worker del socket:
    //    _ = db.KeyExpireAsync(key, TimeSpan.FromSeconds(30));
}

public async Task<string?> FindNodeAsync(IDatabase db, string conn)
{
    RedisValue node = await db.HashGetAsync($"hub:conn:{conn}", "node");
    return node.IsNull ? null : node.ToString();
}

Patrón repetible: «hash para el objeto + TTL para la presencia».

6 · Errores habituales

Castear RedisValue a un tipo equivocado

// ❌ Error en runtime si el valor no es entero
int n = (int)await db.StringGetAsync("ct");

// ✅ Maneja IsNull y parsea con prudencia
var raw = await db.StringGetAsync("ct");
int n2 = raw.IsNull ? 0 : (int)raw;

Olvidar el namespace de la key en el código

Escribir hashsetAsync("conn:1", ...) sin el prefijo «hub:» rompe tu namespace y tus SCANs.

9 · Resumen

  • IDatabase traduce redis-cli → C# async (StringSet/Get, Hash*, Set*, SortedSet*, Stream*).
  • RedisValue: comprueba IsNull; RedisKey: tipos seguros.
  • When.NotExists/Exists para semánticas atómicas.
  • TTL con TimeSpan; KeyTimeToLiveAsync devuelve TimeSpan?.

10 · Preguntas frecuentes

¿Existe «db.SetString» etc. para todo en un solo paquete?

Sí: hay extensiones como StackExchange.Redis.Extensions.*, pero para el curso usamos la API cruda (IDatabase), que es la más pedagógica y la que te da control.

¿Puedo usar objetos directamente?

IDatabase trabaja con bytes/RedisValue. Tu capa de aplicación serializa (System.Text.Json) antes de SET y deserializa al GET. La abstracción IDistributedCache lo hace por ti (y lo ves en M6-04).
