Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Se diseña con método, números y diagramas

Todo diseño parte de requisitos + supuestos, pasa por una estimación de capacidad y termina en trade-offs explícitos. Los diagramas son ASCII y las decisiones se documentan en ADRs.

Para quién es

Para desarrolladores con experiencia (backend, bases de datos, despliegue) que quieren dar el salto a diseñar sistemas: elegir con criterio, estimar, justificar y comunicar arquitecturas. El hilo conductor es un cuaderno de arquitectura de casos.

Sin balas de plata

No hay una arquitectura "correcta": hay trade-offs. Aprenderás a elegir la solución más simple que cumple los requisitos y a justificarla con datos.
