1. Conceptos de Grid: contenedor, tracks y celdas

⏱ 30 minutos 📐 CSS Grid 🎓 Principiante

01 Introducción

Durante décadas, maquetar en CSS fue un arte de hacks. Usábamos float, inline-block, tablas y cualquier truco que funcionara. Luego llegó Flexbox y resolvió la distribución en una dimensión (filas o columnas). Pero seguía faltando algo: maquetar en dos dimensiones a la vez.

💡 ¿Por qué existe CSS Grid?

CSS Grid fue diseñado específicamente para layouts bidimensionales. Mientras Flexbox organiza elementos en una sola dirección (eje principal), Grid te permite controlar filas y columnas simultáneamente. Es como pasar de una lista a una hoja de cálculo: ahora tienes celdas con coordenadas (fila, columna).

Qué problema resuelve: layouts de página completos (header, sidebar, contenido, footer), galerías, dashboards, formularios complejos... cualquier diseño que necesite alinear elementos en dos ejes.

Cuándo usar Grid vs Flexbox:

  • Grid: cuando necesitas control sobre filas y columnas. La estructura es conocida de antemano (ej. layout de página).
  • Flexbox: cuando el contenido define el layout en una sola dirección (ej. barra de navegación, lista de tarjetas que se envuelven).
🧩 Analogía: Flexbox es un tren, Grid es una ciudad

Flexbox es como un tren: los vagones van uno detrás de otro en una dirección (o hacia abajo si cambias el eje), y puedes decidir cómo se distribuyen a lo largo de la vía. Grid es como el plano de una ciudad: defines manzanas (columnas) y calles (filas), y cada edificio ocupa exactamente la parcela que le asignas.

Errores típicos de principiantes:

  • Usar Grid para todo (una barra de navegación simple va mejor con Flexbox).
  • Olvidar que display: grid solo afecta a los hijos directos.
  • Confundir el número de tracks con el número de líneas (3 columnas = 4 líneas).
  • No entender la unidad fr y usar porcentajes donde fr es más limpio.

02 Teoría

El contenedor grid

Todo empieza con display: grid en el elemento padre (el grid container). A partir de ese momento, sus hijos directos se convierten en grid items y se colocan automáticamente en celdas.

.contenedor {
  display: grid;               /* Activa el contexto grid */
  grid-template-columns: 200px 1fr 200px; /* 3 columnas */
  grid-template-rows: 80px 1fr 60px;     /* 3 filas */
  gap: 16px;                   /* Espacio entre celdas */
}

Términos fundamentales que necesitas grabar

TérminoSignificadoAnalogía
Grid Container El elemento con display: grid El tablero de ajedrez
Grid Item Cada hijo directo del container Cada pieza sobre el tablero
Grid Track Una columna o fila completa Una columna o fila del tablero
Grid Cell La intersección de una fila y una columna Un casillero individual
Grid Line Línea divisoria entre tracks (numerada) Las líneas que separan los casilleros
Grid Area Rectángulo formado por una o más celdas Un grupo de casilleros contiguos
Gap Espacio entre filas y/o columnas El grosor de las líneas entre casilleros

grid-template-columns y grid-template-rows

Estas dos propiedades definen explícitamente cuántas columnas y filas tiene tu grid, y qué tamaño tiene cada una. Cada valor que pones crea un track.

/* 3 columnas: la del medio ocupa el doble que las laterales */
grid-template-columns: 1fr 2fr 1fr;

/* 2 filas: primera de 100px, segunda ocupa el resto */
grid-template-rows: 100px 1fr;

La unidad fr (fracción) — El corazón de Grid

fr significa fracción del espacio disponible. Es LA razón de ser de Grid y lo que lo diferencia de todo lo anterior.

💡 ¿Por qué fr es revolucionario?

Antes de Grid, si querías tres columnas que ocuparan todo el ancho, tenías que calcular porcentajes: 33.333% cada una. Pero si añadías padding, border o gap, los porcentajes se rompían porque no descuentan esos espacios automáticamente. Con 1fr 1fr 1fr, el navegador reparte el espacio que queda después de restar gaps, paddings y bordes. Es magia matemática que siempre cuadra.

/* Reparte el espacio en 3 partes iguales, DESPUÉS de descontar los gaps */
grid-template-columns: 1fr 1fr 1fr;
gap: 20px;
/* El navegador calcula: (ancho_total - 40px_de_gaps) / 3 = ancho de cada columna */

/* La central ocupa el doble que las laterales */
grid-template-columns: 1fr 2fr 1fr;
/* Espacio total disponible = 4 fracciones. Cada fracción = 25% del disponible */

Líneas numeradas

Grid numera automáticamente las líneas entre tracks, empezando en 1. Si tienes 3 columnas, existen 4 líneas verticales (la 1 al inicio, la 4 al final). Lo mismo para filas.

+-------+-------+-------+ | | | | | (1,1)| (1,2)| (1,3)| | | | | +-------+-------+-------+ | | | | | (2,1)| (2,2)| (2,3)| | | | | +-------+-------+-------+ | | | | | (3,1)| (3,2)| (3,3)| | | | | +-------+-------+-------+ LÍNEAS DE COLUMNA: 1 2 3 4 LÍNEAS DE FILA: 1 2 3 4 Cada celda se identifica por (línea-fila-inicio, línea-columna-inicio).

Gap: row-gap y column-gap

gap es el espacio entre tracks. Puedes usar la abreviatura gap: <row> <column> o especificar cada eje por separado.

gap: 20px;              /* Mismo gap en filas y columnas */
gap: 16px 24px;         /* 16px entre filas, 24px entre columnas */
row-gap: 16px;          /* Solo espacio vertical */
column-gap: 24px;       /* Solo espacio horizontal */
📝 Nota histórica

Antes de que gap se estandarizara para Grid (y luego para Flexbox), las propiedades se llamaban grid-row-gap y grid-column-gap. Esos prefijos ya no son necesarios, pero los verás en código antiguo.

03 Ejemplo mínimo

El grid más pequeño posible: 3 columnas, 3 filas, con gap. Abre este HTML en tu navegador para verlo.

ejemplo-minimo.html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <style>
    /* 1. Convertimos el contenedor en grid */
    .grid {
      display: grid;
      /* 2. Definimos 3 columnas: 1fr cada una = se reparten el ancho */
      grid-template-columns: 1fr 1fr 1fr;
      /* 3. Definimos 3 filas: cada una de 80px de alto */
      grid-template-rows: 80px 80px 80px;
      /* 4. Espacio entre celdas */
      gap: 12px;
      /* Estético: color de fondo para ver el grid */
      background: #333;
      padding: 12px;
      border-radius: 8px;
    }
    /* Cada hijo directo del grid es un grid item */
    .item {
      background: #58a6ff;
      color: white;
      display: flex;
      align-items: center;
      justify-content: center;
      border-radius: 6px;
      font-weight: bold;
      font-family: sans-serif;
    }
  </style>
</head>
<body>
  <!-- El contenedor con display: grid -->
  <div class="grid">
    <!-- 9 items = llenan exactamente 3x3 celdas -->
    <div class="item">1</div>
    <div class="item">2</div>
    <div class="item">3</div>
    <div class="item">4</div>
    <div class="item">5</div>
    <div class="item">6</div>
    <div class="item">7</div>
    <div class="item">8</div>
    <div class="item">9</div>
  </div>
</body>
</html>

Explicación línea por línea:

  1. display: grid — Activa el contexto grid en el contenedor. Sin esto, nada de lo demás funciona.
  2. grid-template-columns: 1fr 1fr 1fr — Crea 3 columnas. Cada 1fr es una fracción igual del espacio disponible.
  3. grid-template-rows: 80px 80px 80px — Crea 3 filas de 80px cada una. Podrían tener alturas distintas.
  4. gap: 12px — Separa cada celda 12px de sus vecinas.
  5. Los 9 items se colocan automáticamente: primero se llena la fila 1 (columnas 1→2→3), luego fila 2, luego fila 3.

El flujo por defecto es row (por filas): se llena una fila entera antes de pasar a la siguiente.

04 Ejemplo real

Vamos a construir un layout de 3 columnas tipo periódico: columna izquierda estrecha (navegación), columna central ancha (contenido principal), columna derecha estrecha (noticias relacionadas). Todo con CSS Grid puro.

05 Buenas prácticas

✅ Qué hacer

  • Usa fr para layouts fluidos. Las fracciones se adaptan automáticamente al viewport sin media queries. 1fr 2fr 1fr siempre mantiene la proporción 1:2:1.
  • Nombra tus grids. En proyectos reales, un display: grid sin nombre se vuelve difícil de depurar. Usa clases semánticas: .page-layout, .card-grid, .gallery.
  • Combina unidades. grid-template-columns: 250px 1fr es perfecto para un layout sidebar + contenido: la sidebar tiene ancho fijo, el contenido ocupa el resto.
  • Usa las DevTools del navegador. Inspecciona cualquier grid y verás una overlay con líneas numeradas, gaps resaltados y nombres de área. Es la herramienta más infravalorada.
🔧 DevTools: Inspecciona el grid

Abre las DevTools (F12), ve a la pestaña Elements/Layout. Al seleccionar un elemento con display: grid, haz clic en el icono grid junto al elemento en el panel Elements. Verás líneas numeradas, gaps sombreados y nombres de área. Activa "Show track sizes" para ver los tamaños calculados.

❌ Qué evitar

  • No definas más tracks de los necesarios. Si solo necesitas 3 columnas, no definas 12 "por si acaso". Grid crea tracks implícitos automáticamente si hay más items.
  • No uses fr y % mezclados sin entenderlo. grid-template-columns: 1fr 50% puede dar resultados confusos porque % se calcula sobre el contenedor, no sobre el espacio libre.
  • No uses Grid para layouts de una sola dimensión. Si tu diseño es una fila de elementos que se envuelven, Flexbox con flex-wrap: wrap es más simple y directo.

06 Errores habituales

Error 1: Creer que Grid reemplaza a Flexbox

Es el error conceptual más común. Grid y Flexbox son complementarios, no competidores.

❌ Incorrecto

<!-- Grid para un navbar simple: overkill -->
<nav style="display: grid; grid-template-columns: auto auto auto auto;">
  <a href="#">Inicio</a>
  <a href="#">Productos</a>
  <a href="#">Contacto</a>
  <a href="#">Blog</a>
</nav>

✅ Correcto

<!-- Flexbox para navbar: más natural y flexible -->
<nav style="display: flex; gap: 16px;">
  <a href="#">Inicio</a>
  <a href="#">Productos</a>
  <a href="#">Contacto</a>
  <a href="#">Blog</a>
</nav>

Error 2: Confundir líneas con tracks

3 columnas = 4 líneas verticales. Los principiantes suelen contar mal porque piensan en celdas, no en líneas.

❌ Incorrecto

/* El desarrollador piensa: "3 columnas, entonces 3 líneas" ❌ */
.item {
  grid-column: 1 / 3;  /* Esto ocupa SOLO 2 columnas (línea 1 a línea 3) */
}

✅ Correcto

/* Para ocupar las 3 columnas, necesitas llegar a la línea 4 ✓ */
.item {
  grid-column: 1 / 4;  /* Desde la línea 1 hasta la línea 4 = 3 columnas */
}

/* O usando span, que es más intuitivo: */
.item {
  grid-column: span 3;  /* Ocupa 3 columnas completas */
}

Error 3: No poner display: grid en el contenedor correcto

Grid solo afecta a los hijos directos. Los nietos no son grid items automáticamente.

❌ Incorrecto

<div class="grid"> <!-- Este es el grid container -->
  <div>                      <!-- Grid item ✓ -->
    <p>Este párrafo NO es grid item ❌</p>
    <p>Este tampoco ❌</p>
  </div>
</div>

✅ Correcto

<div class="grid">
  <div>Item 1</div>  <!-- Grid item ✓ -->
  <div>Item 2</div>  <!-- Grid item ✓ -->
  <div>Item 3</div>  <!-- Grid item ✓ -->
</div>

<!-- Si necesitas que los nietos también estén en grid,
     aplica display: grid también al div intermedio -->

07 Ejercicio guiado

Vamos a construir una cuadrícula de fotos 2x3 (2 filas, 3 columnas) con un banner que ocupa toda la primera fila. Lo haremos paso a paso.

  1. Crea el HTML base. Un div.galeria con 5 imágenes dentro (un banner + 4 fotos). 
    <div class="galeria">
  <img class="banner" src="banner.jpg" alt="Banner">
  <img src="foto1.jpg" alt="Foto 1">
  <img src="foto2.jpg" alt="Foto 2">
  <img src="foto3.jpg" alt="Foto 3">
  <img src="foto4.jpg" alt="Foto 4">
</div>
  2. Define el grid de 3 columnas. 
    .galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
}
    Ahora tienes un grid de 3 columnas. Los 5 items se colocan automáticamente: fila 1 (banner, foto1, foto2), fila 2 (foto3, foto4, y una celda vacía).
  3. Haz que el banner ocupe toda la primera fila. 
    .banner {
  grid-column: span 3;  /* Ocupa las 3 columnas */
}
  4. Define alturas de fila. La primera fila (banner) debe ser más alta: 
    .galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 300px 200px; /* Fila 1: 300px, Fila 2: 200px */
  gap: 12px;
}
  5. Ajusta las imágenes para que llenen sus celdas. 
    .galeria img {
  width: 100%;
  height: 100%;
  object-fit: cover;  /* Recorta la imagen para llenar sin deformarse */
  border-radius: 6px;
}

Resultado final completo:

.galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 300px 200px;
  gap: 12px;
  max-width: 900px;
  margin: 0 auto;
}

.galeria img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  border-radius: 6px;
}

.banner {
  grid-column: span 3;
}

08 Reto

🎯 Tu reto: Tablero de ajedrez

Crea un tablero de ajedrez 8x8 usando CSS Grid. Las reglas:

  • Usa display: grid con 8 columnas y 8 filas de 60px cada una.
  • Alterna colores: las celdas deben ser blancas y negras como un tablero real.
  • Prohibido poner clases a cada celda. Debes lograr el patrón solo con CSS.
  • Pista: investiga :nth-child() y cómo combinarlo para patrones de tablero de ajedrez.
  • Extra: añade números de fila (1-8) y letras de columna (a-h) en los bordes, usando ::before y ::after.

No mires la solución hasta que lo hayas intentado durante al menos 20 minutos. La frustración controlada es donde ocurre el aprendizaje real.

09 Resumen

📌 Conceptos clave de esta lección
  • CSS Grid es un sistema de layout bidimensional: controlas filas y columnas simultáneamente.
  • Todo empieza con display: grid en el contenedor padre.
  • grid-template-columns y grid-template-rows definen los tracks (columnas y filas) explícitos.
  • La unidad fr reparte el espacio disponible proporcionalmente, después de descontar gaps, paddings y bordes.
  • Las líneas se numeran automáticamente: N columnas = N+1 líneas.
  • gap controla el espacio entre celdas (vertical y horizontal).
  • Los grid items se colocan automáticamente por filas (row) de izquierda a derecha y de arriba a abajo.
  • Grid y Flexbox son complementarios: Grid para layouts bidimensionales, Flexbox para distribución en una dimensión.

10 FAQ — Preguntas frecuentes

¿Grid reemplaza a Flexbox?

No. Grid y Flexbox resuelven problemas distintos. Flexbox es para layouts unidimensionales (una fila O una columna). Grid es para layouts bidimensionales (filas Y columnas). En un proyecto real usarás ambos: Grid para la estructura de página y Flexbox para componentes como navbars, botones o cards.

¿Cuándo uso px, %, fr o auto en grid-template-columns?

px: tamaño fijo. La columna mide eso exactamente, sin importar el viewport. Útil para sidebars estrechas (250px).

%: porcentaje del ancho del contenedor. No descuenta gaps automáticamente.

fr: fracción del espacio disponible después de restar tracks fijos y gaps. Es la unidad recomendada para layouts fluidos.

auto: la columna mide lo que mide su contenido. Útil cuando no sabes el ancho de antemano.

¿Qué pasa si tengo más items que celdas definidas?

Grid crea automáticamente filas implícitas para acomodar los items sobrantes. La altura de estas filas se controla con grid-auto-rows (lo veremos en la lección 2 de este módulo). Si no defines grid-auto-rows, las filas implícitas tendrán altura auto (el alto de su contenido).

¿Puedo anidar grids?

Sí y es una práctica muy común. Un grid item puede ser a su vez un grid container (display: grid). Esto se llama subgrid cuando usas la keyword subgrid (nivel 2 de la especificación) para heredar las tracks del padre. Lo veremos en la lección 2.

¿Grid funciona en todos los navegadores?

Sí. CSS Grid Level 1 tiene soporte universal desde 2017. Incluso IE11 tiene soporte parcial (con prefijos y sintaxis antigua). A día de hoy, puedes usar Grid sin preocuparte por compatibilidad. Grid Level 2 (subgrid) tiene soporte en todos los navegadores modernos desde 2023.

¿Por qué mis columnas no ocupan todo el ancho aunque use 1fr?

Probablemente el contenedor grid no ocupa todo el ancho disponible. Revisa que el padre del grid no tenga un max-width restrictivo o que el grid container sea un elemento inline. Si usas display: grid (no inline-grid), el contenedor es block-level y ocupa todo el ancho por defecto.
