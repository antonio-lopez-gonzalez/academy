Flexibilidad: Crecer, Encogerse y Adaptarse

Módulo 2 · Flexbox ⏱ 30 minutos

1 · Introducción

Hasta ahora hemos controlado dónde se colocan los items. En esta lección vamos a controlar cuánto espacio ocupan. Las propiedades flex-grow, flex-shrink y flex-basis son el verdadero superpoder de Flexbox: permiten que los items se expandan, se contraigan y se adapten al espacio disponible de forma dinámica, sin necesidad de media queries.

También aprenderás sobre flex-wrap (el secreto del responsive sin breakpoints), order (cambiar el orden visual sin tocar el HTML) y el infame problema del min-width: 0 que ha frustrado a generaciones de desarrolladores.

2 · Teoría

flex-grow: repartir el espacio sobrante

flex-grow define cuánto crece un item en relación a los demás cuando hay espacio disponible en el eje principal. Es un factor de proporción, no un valor absoluto. El valor por defecto es 0 (no crece). 

flex-grow: 0 (todos) — por defecto
┌──────────────────────────────────────────────┐
│ [A ] [B ] [C ]            espacio sobrante   │
└──────────────────────────────────────────────┘

flex-grow: 1 (todos) — se reparten equitativamente
┌──────────────────────────────────────────────┐
│ [   A   ] [   B   ] [   C   ]               │
└──────────────────────────────────────────────┘

flex-grow: 1 en A y B, 2 en C — C recibe el doble
┌──────────────────────────────────────────────┐
│ [  A  ] [  B  ] [      C       ]            │
└──────────────────────────────────────────────┘

La fórmula: espacio_sobrante se divide en (suma de flex-grow) partes. Cada item recibe (su flex-grow) partes. Si A y B tienen flex-grow: 1 y C tiene flex-grow: 3, la suma es 5. A recibe 1/5, B recibe 1/5, C recibe 3/5 del espacio sobrante.

flex-grow solo reparte el espacio sobrante, no el espacio total. Si los items ya ocupan todo el contenedor, flex-grow no tiene efecto visible. Si los items tienen anchos fijos (por flex-basis o width), el espacio sobrante es la diferencia entre el ancho del contenedor y la suma de anchos.

flex-shrink: contraerse cuando falta espacio

flex-shrink define cuánto se encoge un item cuando el espacio total requerido supera el ancho del contenedor. El valor por defecto es 1 (se encoge proporcionalmente). Con 0, el item no se encoge nunca. 

flex-shrink: 1 (todos) — por defecto, se encogen juntos
┌────────────────────────────┐
│ [ A ][ B ][ C ] ← faltaba  │
│ se encogen                │
└────────────────────────────┘

flex-shrink: 0 en B — B mantiene su tamaño
┌────────────────────────────┐
│ [ A][   B   ][ C]  ← A y C│
│                   absorben │
│                   el déficit│
└────────────────────────────┘

El valor por defecto de flex-shrink es 1 (a diferencia de flex-grow que es 0). ¿Por qué? Porque Flexbox asume que es mejor que los items se encojan a que se desborden del contenedor. Es un comportamiento defensivo: si no cabe todo, mejor encoger que romper el layout.

flex-basis: el tamaño base antes de repartir

flex-basis define el tamaño inicial de un item en el eje principal antes de que flex-grow o flex-shrink actúen. Puede ser:

  • auto (por defecto): usa el width o height del item, o el tamaño de su contenido.
  • Un valor fijo: 200px, 10rem, 50%.
  • 0: el item empieza desde cero; ideal para distribuciones equitativas con flex-grow.
  • content: tamaño basado en el contenido (soporte limitado en navegadores).

La diferencia entre flex-basis: auto y flex-basis: 0 es sutil pero crucial. Con auto, el item parte de su tamaño de contenido antes de crecer. Con 0, el item parte de cero y TODO su tamaño viene de flex-grow. Esto significa que con flex: 1 (que equivale a flex-grow: 1; flex-basis: 0), los items se reparten el espacio equitativamente, ignorando su contenido.

El shorthand flex: grow shrink basis

En lugar de escribir las tres propiedades por separado, usa el shorthand flex:

ShorthandEquivalenteUso típico
flex: initial0 1 autoNo crece, se encoge si falta, tamaño del contenido
flex: auto1 1 autoCrece y se encoge, tamaño base del contenido
flex: none0 0 autoNi crece ni se encoge, tamaño fijo
flex: 11 1 0Crece y se encoge, reparto equitativo
flex: 22 1 0Recibe el doble que flex: 1
 
/* Todas estas son equivalentes */
.item { flex: 1 1 0%; }
.item { flex-grow: 1; flex-shrink: 1; flex-basis: 0%; }

/* Valor por defecto de los flex items */
.item { flex: 0 1 auto; }  /* = initial */

flex-wrap: el secreto del responsive sin media queries

flex-wrap controla si los items se mantienen en una sola línea o pueden saltar a la siguiente cuando no caben. Tres valores:

  • nowrap (por defecto): todos en una línea, se encogen si no caben.
  • wrap: saltan a la siguiente línea cuando no caben.
  • wrap-reverse: saltan a la línea anterior (se invierte el eje cruzado).
flex-wrap: nowrap (por defecto)
┌─────────────────────────────────────────────┐
│ [A] [B] [C] [D] [E] [F] ← se encogen      │
└─────────────────────────────────────────────┘

flex-wrap: wrap
┌─────────────────────────────────────────────┐
│ [ A ] [ B ] [ C ] [ D ]                    │
│ [ E ] [ F ]               ← saltan de línea│
└─────────────────────────────────────────────┘

flex-wrap: wrap-reverse
┌─────────────────────────────────────────────┐
│ [ E ] [ F ]               ← línea anterior │
│ [ A ] [ B ] [ C ] [ D ]                    │
└─────────────────────────────────────────────┘

Cuando combinas flex-wrap: wrap con flex: 1 1 250px en los items, obtienes una cuadrícula responsive que se ajusta automáticamente: los items ocupan al menos 250px y, si hay espacio, crecen equitativamente. Si no caben, saltan a la siguiente línea. Sin una sola media query.

order: cambiar el orden visual

order permite reordenar visualmente los flex items sin modificar el HTML. Por defecto, todos los items tienen order: 0. Los items se ordenan por valor ascendente. Un item con order: -1 aparecerá antes que uno con order: 0.

⚠️ Advertencia de accesibilidad: order solo cambia el orden visual, no el orden del DOM. Los lectores de pantalla y la navegación por teclado (Tab) siguen el orden del DOM. Si cambias visualmente el orden de forma que no coincida con el DOM, la experiencia para usuarios de teclado y lectores de pantalla será confusa y potencialmente inaccesible. Usa order con moderación.

min-width: 0 y el problema del overflow

Por defecto, los flex items tienen un min-width: auto implícito que impide que se encojan más allá del tamaño mínimo de su contenido. Esto causa que, en ciertas situaciones, los items se desborden del contenedor en lugar de encogerse. 

/* ❌ MAL: El contenido largo fuerza overflow */
.item {
  flex: 1;               /* flex-basis: 0, debería encogerse */
  /* min-width: auto implícito impide que baje de cierto tamaño */
}

/* ✅ BIEN: Permitir que el item se encoja completamente */
.item {
  flex: 1;
  min-width: 0;          /* Anula el min-width automático */
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

Este es uno de los bugs más frustrantes de Flexbox y aparece típicamente con texto largo dentro de un flex item que debería truncarse. La solución es siempre min-width: 0 (o min-height: 0 en dirección column).

3 · Ejemplo mínimo

Tres cajas que se reparten el espacio equitativamente con flex: 1: 

<div class="contenedor">
  <div class="caja">Caja 1</div>
  <div class="caja">Caja 2</div>
  <div class="caja">Caja 3</div>
</div>
.contenedor {
  display: flex;
  gap: 1rem;
}

.caja {
  flex: 1;                    /* = flex-grow: 1; flex-shrink: 1; flex-basis: 0% */
  background: #38bdf8;
  color: #0f172a;
  font-weight: bold;
  padding: 2rem;
  border-radius: 6px;
  text-align: center;
}

Tres cajas, mismo ancho, sin importar el tamaño del contenedor. Si añades una cuarta caja, automáticamente se reparten en 4 partes iguales. Si el contenedor se estrecha, las cajas se encogen proporcionalmente. Eso es flexibilidad real.

flex: 1 es probablemente la declaración más poderosa de Flexbox. Con solo 6 caracteres, le dices a un elemento: "crece para ocupar tu parte justa del espacio, encógete si hace falta, y empieza desde cero para que todos midan lo mismo".

4 · Ejemplo real

Galería de cards responsive sin media queries

Este es el patrón más útil que aprenderás hoy. Una galería que se adapta sola a cualquier ancho de pantalla combinando flex-wrap con flex: 

<div class="galeria">
  <article class="card">
    <img src="foto1.jpg" alt="">
    <h3>Título de la card</h3>
    <p>Descripción breve del contenido.</p>
  </article>
  <article class="card">...</article>
  <article class="card">...</article>
</div>
.galeria {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
  padding: 1rem;
}

.card {
  flex: 1 1 300px;   /* Crece, se encoge, base 300px */
  /*
    Equivale a:
    flex-grow: 1;      — toma el espacio sobrante
    flex-shrink: 1;    — se encoge si falta espacio
    flex-basis: 300px; — ancho base ideal
  */
  background: #1e293b;
  border: 1px solid #334155;
  border-radius: 12px;
  overflow: hidden;
  min-width: 0;        /* Previene overflow */
}

.card img {
  width: 100%;
  height: 200px;
  object-fit: cover;    /* La imagen cubre sin deformarse */
}

.card h3 {
  padding: 1rem 1rem 0;
  font-size: 1.1rem;
}

.card p {
  padding: 0.5rem 1rem 1rem;
  font-size: 0.9rem;
}

¿Qué hace esto?

  • Cada card tiene un ancho base ideal de 300px.
  • Si hay más espacio, las cards crecen equitativamente para llenarlo (flex-grow: 1).
  • Si el viewport es más estrecho que 300px, las cards se encogen (flex-shrink: 1).
  • Cuando ya no caben más cards en la fila, flex-wrap: wrap las manda a la siguiente línea.

Esta combinación (flex-wrap: wrap + flex: 1 1 <medida>) es tan poderosa que muchos frameworks CSS la llaman "auto-fit grid sin grid". Funciona sin media queries, sin cálculos de porcentajes y sin JavaScript.

Layout de dos columnas: sidebar + contenido

.layout {
  display: flex;
  gap: 1.5rem;
  min-height: 100vh;
}

.sidebar {
  flex: 0 0 250px;        /* No crece, no se encoge, base 250px */
  background: #1e293b;
  border-radius: 8px;
  padding: 1.5rem;
}

.contenido {
  flex: 1;                /* Ocupa TODO el espacio restante */
  min-width: 0;           /* Previene overflow de contenido largo */
  background: #1e293b;
  border-radius: 8px;
  padding: 1.5rem;
}

/* En pantallas pequeñas, sidebar arriba y contenido debajo */
@media (max-width: 640px) {
  .layout {
    flex-direction: column;
  }

  .sidebar {
    flex: 0 0 auto;
    width: 100%;
  }
}

En desktop, el sidebar mide fijo 250px y el contenido toma el resto. En móvil (≤640px), todo se apila verticalmente. Solo una media query para cambiar flex-direction. El resto es Flexbox trabajando solo.

6 · Errores habituales

Error 1: Pensar que flex-grow distribuye el ancho total

/* ❌ MAL: Esperar que con flex-grow: 1 midan 33% cada una */
.item { flex-grow: 1; }

/* Con flex-basis: auto, cada item tiene el ancho de su contenido.
   flex-grow solo reparte el espacio SOBRANTE. Si los contenidos
   son de distinto tamaño, los anchos NO serán iguales. */

/* ✅ BIEN: Para anchos iguales, usa flex: 1 (basis: 0) */
.item { flex: 1; }

Error 2: Olvidar min-width: 0 con texto largo

El síntoma clásico: tienes un flex item con flex: 1 pero el texto largo dentro de él fuerza al contenedor a desbordarse en lugar de truncarse. La causa: el min-width: auto implícito. La cura: min-width: 0.

Error 3: Usar order para todo

/* ❌ MAL: Reordenar drásticamente */
.header   { order: 1; }
.sidebar  { order: 3; }
.main     { order: 2; }
.footer   { order: 4; }

/* El DOM sigue siendo header, sidebar, main, footer.
   Un usuario con lector de pantalla "verá" ese orden,
   no el visual. Esto es una violación de WCAG. */

Error 4: Creer que flex-wrap genera una cuadrícula perfecta

flex-wrap NO alinea las columnas entre filas. Si tienes 5 items que hacen wrap en filas de 3 y 2, los items de la segunda fila NO se alinearán con las columnas de la primera. Para cuadrículas perfectas, usa CSS Grid.

Error 5: Confundir flex: 1 con flex: 1 1 auto

flex: 1 equivale a flex: 1 1 0% (parte de cero, reparto equitativo). flex: 1 1 auto parte del tamaño del contenido y luego reparte el sobrante. Con flex: 1, dos items con distinto contenido tendrán el mismo ancho. Con flex: 1 1 auto, tendrán anchos proporcionales a su contenido.

7 · Ejercicio guiado

Objetivo: Construir un sistema de columnas flexible con sidebar y contenido principal que se adapten sin media queries (excepto una para el cambio de orientación).

  1. Estructura HTML: Crea un contenedor .layout con dos hijos: <aside class="sidebar"> (con enlaces de navegación) y <main class="contenido"> (con título y párrafos).
  2. CSS base: .layout { display: flex; gap: 1.5rem; min-height: 100vh; }. Al sidebar dale flex: 0 0 250px (ancho fijo de 250px). Al contenido dale flex: 1; min-width: 0; (ocupa el resto, previene overflow).
  3. Media query para móvil: En ≤640px, cambia .layout a flex-direction: column y el sidebar a flex: 0 0 auto; width: 100% para que ocupe su altura natural.
  4. Prueba con contenido largo: Escribe un párrafo muy largo en el contenido principal. Sin min-width: 0, el layout se desbordará horizontalmente. Con él, el texto hará wrap correctamente. Esta es la prueba definitiva de que min-width: 0 funciona.

Este patrón (sidebar fijo + contenido flexible) es la base del 90% de los layouts de aplicación web. Lo verás en dashboards, paneles de administración, blogs con sidebar y documentación técnica. Dominarlo es esencial.

8 · Reto

🎯 Dashboard de analíticas con Flexbox puro

Nivel: Avanzado. Construye un dashboard con los siguientes requisitos:

  1. Fila superior: 4 tarjetas de métricas (KPI) que se repartan el ancho equitativamente con flex: 1. Cada tarjeta debe tener un número grande, una etiqueta pequeña y un icono.
  2. Fila inferior: Un gráfico grande (2/3 del ancho) y una lista de actividad reciente (1/3 del ancho). Usa flex: 2 y flex: 1 respectivamente.
  3. En móvil (≤768px), todo debe apilarse verticalmente.
  4. Las tarjetas KPI deben tener min-width: 150px para no colapsar en pantallas muy pequeñas, y hacer wrap si no caben 4 en una fila.
  5. El gráfico debe tener min-height: 300px incluso cuando el contenido es escaso.
  6. Todo el dashboard debe estar contenido en una sola columna flex con gap: 1.5rem.

9 · Resumen

  • flex-grow (default: 0) reparte el espacio sobrante. Es un factor de proporción, no un valor absoluto.
  • flex-shrink (default: 1) determina cuánto se encoge un item cuando falta espacio.
  • flex-basis (default: auto) define el tamaño base antes de repartir. 0 es clave para repartos equitativos.
  • El shorthand flex: <grow> <shrink> <basis> se recomienda sobre las propiedades individuales.
  • flex-wrap: wrap + flex: 1 1 <medida> es el patrón mágico para layouts responsive sin media queries.
  • order cambia el orden visual pero no el del DOM. Úsalo con moderación por accesibilidad.
  • min-width: 0 es la solución al problema de overflow en flex items con contenido largo.
  • flex: none es ideal para elementos de tamaño fijo como logos e iconos.
  • La diferencia entre flex: 1 y flex: 1 1 auto es que el primero reparte equitativamente y el segundo reparte proporcionalmente al contenido.

10 · Preguntas frecuentes

¿Cuál es la diferencia entre width y flex-basis?

En un contenedor flex con dirección row, flex-basis y width pueden parecer similares, pero flex-basis tiene prioridad. Si ambos están definidos, flex-basis gana. Además, flex-basis: auto mira el width del elemento, mientras que flex-basis: 0 lo ignora.

¿Por qué mis items no hacen wrap aunque tengo flex-wrap: wrap?

Probablemente los items no tienen un flex-basis o width definido, y están usando flex-basis: auto con flex-shrink: 1. Como resultado, se encogen todo lo posible antes de hacer wrap. Para forzar el wrap, asegúrate de que los items tengan un ancho mínimo: flex: 0 0 200px.

¿Puedo usar flex-grow con valores decimales?

Sí. flex-grow: 0.5 es perfectamente válido y hará que el item reciba la mitad de lo que recibiría un item con flex-grow: 1. La especificación no exige números enteros.

¿Cómo evito que las cards queden huérfanas en la última fila?

Este es un problema conocido de Flexbox con wrap: la última fila puede tener menos items y estos se estiran (con flex-grow: 1). Soluciones: (1) Usa CSS Grid con auto-fill si tu diseño lo permite. (2) Usa flex-grow: 0 y justify-content: flex-start para que la última fila se alinee a la izquierda sin estirarse.

¿El shorthand flex resetea los valores no especificados?

Sí. Cuando usas flex: 1, los valores omitidos se resetean a sus valores iniciales según la especificación: flex-grow: 1, flex-shrink: 1, flex-basis: 0%. Es mejor usar siempre flex en lugar de las propiedades individuales precisamente por esto: garantiza que los tres valores estén definidos explícitamente.
