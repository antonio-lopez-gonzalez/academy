# Curso de Tailwind CSS v4

> De cero a avanzado con repaso de CSS, Flexbox, Grid y uso en frameworks.

Un curso completo, didáctico y 100% práctico para dominar **Tailwind CSS v4** desde los fundamentos del CSS hasta proyectos reales con Vite. Está pensado para desarrolladores que ya saben programar pero quieren entender CSS moderno con la metodología **utility-first**.

## ✨ ¿Por qué este curso?

- **Enseña el "por qué", no solo el "cómo".** Entenderás qué problema resuelve Tailwind y por qué existe.
- **Base sólida de CSS.** Repasamos modelo de caja, Flexbox y Grid antes de entrar en Tailwind.
- **Metodología utility-first en profundidad**, comparada siempre con CSS puro, Bootstrap y BEM.
- **Práctica constante**: cada módulo termina con un proyecto real y ejecutable.
- **Tailwind CSS v4**: configuración *CSS-first* con `@theme`, sin `tailwind.config.js`.

## 🗂️ Estructura del repositorio

```text
├── web/          ← ★ El curso: web estática navegable (sin build)
├── ejemplos/     ← Mini-demos HTML + Tailwind CDN
└── proyectos/    ← Aplicaciones Vite + Tailwind ejecutables
```

## ▶️ Cómo empezar

```bash
# 1. Instala las dependencias del proyecto (opcional, para proyectos Vite)
pnpm install

# 2. Sirve la web del curso en local
pnpm serve
```

Para los proyectos de `proyectos/`, entra en cada carpeta e instala con `pnpm install` y arranca con `pnpm dev`.

## 🧭 Cómo se enseña

Cada lección sigue una estructura fija de 10 secciones:

1. **Introducción** — qué aprenderemos y qué problema resuelve

3. **Ejemplo mínimo** — el ejemplo más pequeño posible, línea por línea
4. **Ejemplo real** — aplicación cercana a un proyecto profesional
5. **Buenas prácticas** — qué hacer, qué evitar y por qué
6. **Errores habituales** — ejemplos incorrectos y su versión correcta
7. **Ejercicio guiado** — resuelto paso a paso

9. **Resumen** — conceptos clave
10. **Preguntas frecuentes** — dudas comunes
