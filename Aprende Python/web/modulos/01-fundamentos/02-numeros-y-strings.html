Números, strings y f-strings

Módulo 1 · Fundamentos del lenguaje ⏱ 35 minutos

1 · Introducción

Dos tipos de datos aparecen en casi todas las líneas de Python: números y texto. Saber cómo se representan por dentro (int de precisión arbitraria, float IEEE 754) y cómo se manipulan (//, %, **, slicing, métodos de str) evita una clase entera de errores silenciosos, como que 0.1 + 0.2 no dé exactamente 0.3.

El texto es el tipo que más vas a producir: mensajes, ids, informes, JSON… Por eso Python moderno tiene las f-strings, la forma más legible y rápida de interpolar valores y controlar su formato. Las dominarás aquí y las usarás en todo el curso.

¿Por qué existe esta lección? Porque muchos bugs no son de lógica sino de representación: comparar floats con ==, concatenar número y string, creer que un string se puede modificar. Entender el modelo de números y la inmutabilidad de str te da un vocabulario preciso para el resto del curso.

Que int no tenga límite es una decisión de diseño deliberada: Python maneja internamente tantos «dígitos» como haga falta. Puedes calcular 2 ** 200 sin miedo; en C o Java eso desbordaría.

big = 2 ** 100

print(type(big))           # <class 'int'>
# Un float tiene precisión finita y limitada:
print(1e308 * 10)          # inf
print(1e-324)              # 0.0 (por debajo del mínimo representable)

print(count)     # 16

Cuidado con // y negativos: -7 // 2 da -4, porque // redondea hacia abajo (floor). En C, -7 / 2 daría -3 (trunca hacia cero). No es un bug: es una decisión coherente con el módulo (-7 % 2 == 1).

La trampa clásica: precisión de float

Los float representan números en binario. Igual que 1/3 no tiene representación decimal exacta, 0.1 no tiene representación binaria exacta. El resultado es que ciertas sumas «no cuadran»:

print(0.1 + 0.2)            # 0.30000000000000004
print(0.1 + 0.2 == 0.3)     # False  -> ¡sorpresa!
print(round(0.1 + 0.2, 2))  # 0.3    -> redondeo para presentar

La conclusión es tajante: nunca compares floats con ==. Compara con una tolerancia (math.isclose) y no uses float para dinero. Para valores monetarios o cálculos exactos, la biblioteca estándar ofrece decimal.Decimal y fractions.Fraction (los verás en el Módulo 3).

import math
# ✅ Comparar floats con tolerancia
print(math.isclose(0.1 + 0.2, 0.3))   # True
# ✅ Dinero con Decimal (exacto en base 10)
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))  # 0.3  -> exacto

str: una secuencia inmutable de caracteres

Un string es una secuencia: puedes indexarlo y trocearlo igual que una lista, pero no modificarlo en sitio. No existe s[0] = "X"; cualquier «cambio» construye un string nuevo.

title = "Blade Runner"
print(title[0])        # B       -> primer carácter (índice 0)
print(title[-1])       # r       -> último (índices negativos desde el final)
print(title[0:5])      # Blade   -> slicing [inicio:fin) (fin excluido)
print(title[::-1])     # rennuR edalB -> con paso negativo, invertido
print(len(title))      # 12      -> longitud en caracteres
# ❌ Los strings son inmutables: esto lanza TypeError
# title[0] = "b"       # TypeError: 'str' object does not support item assignment
# ✅ Para "cambiar" hay que crear un string nuevo
fixed = "b" + title[1:]
print(fixed)           # blade Runner

Que str sea inmutable es lo que permite usarlo como clave de diccionario y compartirlo con seguridad entre partes del programa. Lo profundizaremos con slicing en la lección 3 y el Módulo 3.

f-strings: interpolar y formatear

Una f-string es un literal precedido de f donde {…} contiene una expresión que se evalúa y se inserta. Desde Python 3.6 es la forma recomendada; en 3.12 incluso puedes anidar comillas fácilmente.

title = "Dune"
year = 1965
rating = 4.567
# Interpolación básica
print(f"{title} se publicó en {year}")   # Dune se publicó en 1965
# Dentro de las llaves cabe cualquier expresión
print(f"El doble del año es {year * 2}")  # El doble del año es 3930
# Especificador de formato tras ':' -> {valor:formato}
print(f"Nota: {rating:.2f}")             # Nota: 4.57   (.2f = 2 decimales)
print(f"Título: {title:<12}|")           # Título: Dune        |  (< alinea a la izquierda)
print(f"Título: {title:>12}|")           # Título:         Dune|  (> a la derecha)
print(f"Título: {title:^12}|")           # Título:    Dune     |  (^ centra)
# El sufijo '=' imprime la expresión Y su valor (ideal para depurar)
print(f"{year = }")                       # year = 1965
print(f"{year * 2 = }")                   # year * 2 = 3930
# Formato numérico: miles, porcentaje, hexadecimal, binario
print(f"{1234567:,}")                     # 1,234,567
print(f"{0.256:.1%}")                     # 25.6%
print(f"{255:#x}")                        # 0xff
print(f"{10:08b}")                        # 00001010

Métodos de str más usados

raw = "  Blade Runner  "
print(raw.strip())            # Blade Runner   (quita espacios de los extremos)
print(raw.lower())            # '  blade runner  '
print("dune".capitalize())    # Dune
print("a,b,c".split(","))     # ['a', 'b', 'c']  -> divide en lista
print("-".join(["a", "b"]))   # a-b              -> une con separador
print("1984".isdigit())       # True             -> ¿solo dígitos?
print("Dune".startswith("Du"))  # True
print("hello".replace("l", "L"))  # heLLo
# f-string + métodos: normaliza y presenta
title = "  dune  "
print(f"[{title.strip().title()}]")   # [Dune]

3 · Ejemplo mínimo

Calcular el precio de un ítem con IVA y mostrarlo formateado. Tres líneas de lógica real.

price = 19.99                       # float: precio sin IVA
vat = 0.21                          # float: tipo de IVA (21%)
total = price * (1 + vat)           # operación aritmética
print(f"Total con IVA: {total:.2f} €")   # Total con IVA: 24.19 €

Línea por línea:

  1. price = 19.99: un float; recuerda que no es exacto, por eso no lo usaremos para dinero real.
  2. total = price * (1 + vat): 1 + 0.21 = 1.21; el producto da 24.1879.
  3. f"…{total:.2f}…": el especificador .2f redondea a dos decimales al presentar. El número no cambia; cambia el texto.

Multiplataforma: guarda el ejemplo como iva.py y ejecútalo con python3 iva.py en Linux/macOS o py iva.py en Windows. El script y su salida son exactamente los mismos: Python es nativo en los tres sistemas.

4 · Ejemplo real

Damos formato a las fichas del catálogo de Biblioteca. Generamos ids con ceros a la izquierda y una línea alineada por columnas, como haría el comando bib list.

# Datos de dos ítems del catálogo.
catalogs = [
    {"id": 1, "title": "1984", "kind": "book", "year": 1949},
    {"id": 2, "title": "Blade Runner", "kind": "movie", "year": 1982},
]
# Cabecera alineada: < izquierda, ^ centro, ancho fijo.
print(f"{'ID':<6}{'TÍTULO':<14}{'TIPO':<8}{'AÑO':>6}")
print("-" * 34)   # línea separadora de 34 guiones
for item in catalogs:
    # 02d -> entero con al menos 2 dígitos, rellenado con ceros (01, 02…)
    item_id = f"bk-{item['id']:02d}"
    print(f"{item_id:<6}{item['title']:<14}{item['kind']:<8}{item['year']:>6}")
# Salida esperada:
# ID    TÍTULO        TIPO       AÑO
# ----------------------------------
# bk-01 1984          book      1949
# bk-02 Blade Runner  movie     1982

Decisiones clave: {item['id']:02d} produce ids legibles y ordenables (bk-01, bk-02…); el ancho de columna hace que la salida se lea como una tabla sin librerías externas. Fíjate en que dentro de las llaves de una f-string usamos comillas simples para las claves del diccionario: Python 3.12 permite mezclarlas con las dobles del literal.

Truco para informes: f"{value:>8}" alinea números a la derecha (como haría una hoja de cálculo) y f"{text:<20}" alinea texto a la izquierda. Se combinan con . y precisión: f"{title:<20.10}" trunca a 10 caracteres.

Estilo PEP 8: deja un espacio alrededor de los operadores (x = a + b), pero sin espacios dentro de una f-string de formato (f"{x:.2f}"). El operador ** no lleva espacios alrededor cuando son operandos simples (2**10 puede ser 2 ** 10; sé consistente).

6 · Errores habituales

Concatenar número y texto

# ❌ 'str' + int -> TypeError
year = 1949
# print("Año: " + year)        # TypeError: can only concatenate str (not "int") to str
# ✅ Convierte explícitamente…
print("Año: " + str(year))     # Año: 1949
# ✅ …o, mejor, usa una f-string
print(f"Año: {year}")          # Año: 1949

Comparar floats por igualdad

# ❌ Esperar igualdad exacta tras operaciones con float
total = 0.1 + 0.2
print(total == 0.3)            # False
# ✅ Tolerancia explícita
import math
print(math.isclose(total, 0.3))  # True

Creer que un string se modifica en sitio

# ❌ Los strings son inmutables
title = "dune"
# title[0] = "D"               # TypeError
# ✅ Construye uno nuevo (y reasigna el nombre)
title = title.capitalize()
print(title)                   # Dune

Usar // esperando el comportamiento de C con negativos

# ❌ Asumir truncamiento hacia cero
print(-7 // 2)                 # -4  (no -3): // redondea hacia abajo
# ✅ Si quieres truncar hacia cero, usa int() sobre la división real
print(int(-7 / 2))             # -3

Usar % o .format() por costumbre

# ❌ Antiguo y más propenso a errores de orden/posición
name = "Dune"
print("Libro: %s" % name)      # funciona, pero es estilo heredado
print("Libro: {}".format(name))  # funciona, pero más verboso
# ✅ f-string: el valor va donde se lee
print(f"Libro: {name}")        # Libro: Dune

7 · Ejercicio guiado

Objetivo: construir una ficha de catálogo formateada y calculada. Paso a paso.

  1. Paso 1: define los datos base: 
    title = "  the matrix  "   # con espacios sobrantes a propósito
year = 1999
rating = 8.6666            # nota sobre 10
stock = 3                  # unidades disponibles
  2. Paso 2: normaliza el título con strip() y title() para dejarlo como The Matrix.
  3. Paso 3: calcula el año de la próxima década como year + (10 - year % 10). Con 1999 debe dar 2000.
  4. Paso 4: imprime una línea con la nota formateada a 1 decimal, porcentaje de stock y el título alineado a la izquierda en 16 caracteres. Usa una sola f-string.
  5. Paso 5 (verificación): comprueba que la salida es exactamente la esperada.

Solución de referencia:

clean = title.strip().title()          # "The Matrix"
next_decade = year + (10 - year % 10)  # 1999 -> 2000
print(f"{clean:<16}| nota {rating:.1f}/10 | próx. década {next_decade}")

Resultado esperado:

The Matrix      | nota 8.7/10 | próx. década 2000

Cómo comprobarlo: rating:.1f redondea 8.6666 a 8.7; year % 10 es 9, así que 10 - 9 = 1 y 1999 + 1 = 2000. El título ocupa 16 caracteres contando el relleno.

8 · Reto

🎯 Generador de identificadores «slug»

Escribe una función slugify(text) que convierta un título en un identificador seguro para URLs: minúsculas, sin acentos, espacios y símbolos reemplazados por guiones, sin guiones duplicados ni en los extremos. Por ejemplo, "¡Blade Runner (1982)!" debería producir blade-runner-1982.

Pista: empieza por .lower() y .strip(). Para los acentos puedes mapearlos con str.translate y una tabla, o normalizar con unicodedata.normalize("NFKD", …) y descartar los caracteres combinantes. Termina con re.sub(r"[^a-z0-9]+", "-", …) y .strip("-").

9 · Resumen

  • int es de precisión arbitraria; float es binario IEEE 754 y por eso 0.1 + 0.2 != 0.3.
  • / siempre devuelve float; // redondea hacia abajo; % da el resto; ** es potencia.
  • Nunca compares float con ==: usa math.isclose. Para dinero, Decimal o céntimos enteros.
  • str es una secuencia inmutable: se indexa y se trocea, pero no se modifica en sitio.
  • Las f-strings son la forma idiomática de interpolar y formatear (.2f, alineación, = para depurar).

10 · Preguntas frecuentes

¿Por qué 0.1 + 0.2 no da 0.3?

Porque float guarda números en base 2 y 0.1 no tiene una representación binaria finita exacta (igual que 1/3 en base 10 es 0.333…). Lo que ves con 0.30000000000000004 es el error de redondeo acumulado. No es un fallo de Python: es el estándar IEEE 754 que comparten casi todos los lenguajes.

¿Debo usar Decimal siempre que haya decimales?

No siempre. Usa float para medidas, gráficos o ciencias donde una tolerancia es aceptable. Reserva Decimal (o céntimos enteros) para dinero y cálculos contables, donde los céntimos deben cuadrar exactamente. Decimal es más lento, así que no lo uses «por si acaso».

¿Las f-strings son más rápidas que % o .format()?

Sí, además de más legibles. Al ser parte de la sintaxis, el intérprete las optimiza mejor que una llamada a .format() o al operador %. Pero la razón principal para usarlas es la claridad: el valor aparece donde lo lees, no al final de una lista de argumentos.

¿Qué diferencia hay entre str, bytes y bytearray?

str es texto Unicode (caracteres); bytes es una secuencia de bytes crudos (inmutable) y bytearray su versión mutable. Los necesitarás al leer ficheros binarios o redes (Módulo 6). Para texto normal usa siempre str; convertir entre ambos requiere especificar una codificación ("ñ".encode("utf-8")).

¿Por qué no puedo cambiar un carácter de un string?

Porque str es inmutable por diseño. Esto lo hace seguro como clave de diccionario, compartible entre hilos y predecible. Si necesitas editar caracteres con frecuencia, convierte a list, modifica, y vuelve a unir con "".join(...).
