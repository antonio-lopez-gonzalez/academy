Bucles: for, while, range y enumerate

Módulo 2 · Control de flujo y funciones ⏱ 30 minutos

1 · Introducción

Repetir trabajo es la esencia de un programa. Python tiene dos bucles: for, para recorrer algo que ya existe, y while, para repetir mientras una condición se mantenga. Aquí está la primera gran diferencia con otros lenguajes: el for de Python no cuenta índices, recorre elementos.

En JavaScript escribes for (let i = 0; i < arr.length; i++); en Python escribes for x in arr:. No es azúcar sintáctico: es que Python piensa en iterables, no en índices. Esta lección te enseña a recorrer bien, a limitar bucles con range, a obtener posición y valor con enumerate, a recorrer en paralelo con zip y a controlar el bucle con break/continue y el sorprendente else.

¿Por qué existe esta lección? Porque el for es el 90 % del código que escribirás. Dominar la iteración directa, enumerate y zip evita el anti-patrón range(len(x)) y hace que tu código sea a la vez más corto y más correcto.

2 · Teoría

El for itera sobre un iterable

Un iterable es cualquier objeto del que se puedan sacar elementos uno a uno: listas, tuplas, cadenas, diccionarios, conjuntos, range, ficheros… El for pide el siguiente elemento hasta que se agotan. Por debajo ocurre esto (lo estudiarás a fondo en el Módulo 3):

for elemento in iterable:        Python hace, por debajo:
    cuerpo                       iterator = iter(iterable)
                                 while True:
                                     try: elemento = next(iterator)
                                     except StopIteration: break
                                     cuerpo

La consecuencia práctica: no necesitas índices. Si solo quieres cada valor, recórrelo directamente. El índice es una preocupación de lenguajes que no tienen iterables de primera clase.

while: repetir mientras

while repite un bloque mientras una condición sea verdadera. Se usa cuando no sabes cuántas vueltas darás: leer hasta que llegue un centinela, consumir una cola, esperar un estado. Con while tú eres responsable de que la condición cambie; si no, el bucle es infinito.

remaining = 3
while remaining > 0:       # se evalúa ANTES de cada vuelta
    print(remaining)
    remaining -= 1         # imprescindible: acerca al final
print("¡Despegue!")

# Salida esperada:
# 3
# 2
# 1
# ¡Despegue!

Bucle infinito: si olvidas modificar la variable de control dentro del while, nunca termina. Se corta con Ctrl+C. En código real, casi todo while True: lleva un break que lo abandona.

range: generar números sin crearlos todos

range no es una lista: es un objeto perezoso que produce números bajo demanda, así que range(1_000_000) ocupa lo mismo que range(3). Sus tres formas:

FormaProduceEjemplo
range(n)0, 1, …, n-1range(3) → 0, 1, 2
range(start, stop)start … stop-1range(2, 5) → 2, 3, 4
range(start, stop, step)con saltorange(10, 0, -2) → 10, 8, 6, 4, 2

Fíjate en que el final es exclusivo. Es intencionado: range(len(x)) produce exactamente los índices válidos 0…len(x)-1, y range(a, b) tiene b - a elementos, lo que evita el clásico error «¿sumo uno o no?».

enumerate: posición y valor a la vez

Cuando de verdad necesitas el índice y el elemento, no cuentes a mano con range(len(x)): usa enumerate. Es más legible y no puede desincronizarse. Acepta start para numerar desde 1.

catalog = ["1984", "Dune", "Blade Runner"]
for index, title in enumerate(catalog, start=1):
    print(f"{index}. {title}")

# Salida esperada:
# 1. 1984
# 2. Dune
# 3. Blade Runner

zip: recorrer varios iterables en paralelo

zip empareja el elemento 0 de cada iterable, luego el 1, etc. Se detiene cuando el más corto se agota (no da error). Es ideal para combinar metadatos con datos.

titles = ["1984", "Dune"]
years = [1949, 1965]
for title, year in zip(titles, years):
    print(f"{title} ({year})")

# Salida esperada:
# 1984 (1949)
# Dune (1965)

break, continue y el else del bucle

  • break: abandona el bucle inmediatamente.
  • continue: salta a la siguiente vuelta, ignorando el resto del cuerpo.
  • else del bucle: se ejecuta solo si el bucle terminó sin break. Es «no encontré nada / no se rompió». Tanto for como while lo tienen.
def find(catalog, wanted):
    for item in catalog:
        if item["title"] == wanted:
            print(f"Encontrado: {item['title']}")
            break
    else:
        # Solo se ejecuta si el for terminó sin break: no había nada.
        print(f"No se encontró: {wanted}")

find(catalog=[{"title": "Dune"}], wanted="Dune")
find(catalog=[{"title": "Dune"}], wanted="1984")

# Salida esperada:
# Encontrado: Dune
# No se encontró: 1984

Este else desconcierta a todo el mundo. Léelo como «for… then…»: «recorre esto y, si nunca rompiste el bucle, haz lo siguiente». Evita tener que declarar una bandera found = False antes del bucle.

3 · Ejemplo mínimo

Recorrer una lista directamente, sin índices. La versión más pequeña de un for:

# items es un iterable (lista). El for toma cada elemento, no cada índice.
items = ["libro", "película"]

for item in items:
    print(item)          # 'item' es el propio elemento

# Salida esperada:
# libro
# película

Línea por línea:

  1. items = [...] es el iterable: la fuente de elementos.
  2. for item in items: en cada vuelta rebindea el nombre item al siguiente elemento.
  3. print(item) usa ese nombre dentro del cuerpo. El cuerpo es lo que está indentado.
  4. Cuando se agotan los elementos, el bucle termina solo. No hay condición ni índice que actualizar.

4 · Ejemplo real

En Biblioteca queremos listar el catálogo numerado y marcar los ítems prestados. Combinamos enumerate (posición), una expresión condicional (estado) y continue (saltar lo que no toca).

catalog = [
    {"title": "1984", "kind": "book", "borrowed": True},
    {"title": "Dune", "kind": "book", "borrowed": False},
    {"title": "Blade Runner", "kind": "movie", "borrowed": False},
]

# Listar solo los LIBROS, numerados desde 1.
position = 0
for item in catalog:
    if item["kind"] != "book":
        continue                    # no es libro: salta a la siguiente vuelta
    position += 1
    status = "prestado" if item["borrowed"] else "disponible"
    print(f"{position}. {item['title']} — {status}")

# Salida esperada:
# 1. 1984 — prestado
# 2. Dune — disponible

Decisiones de diseño:

  • continue deja el cuerpo principal limpio: el filtro «solo libros» se lee arriba y no anida todo el bloque bajo un if.
  • Contamos a mano con position += 1 porque enumerate contaría todas las vueltas, incluidas las de películas. Alternativa equivalente: filtrar primero la lista.
  • El ternario "prestado" if … else "disponible" evita un if/else de bloque para una simple etiqueta.

Y para buscar por título, for/else expresa «encontrado» o «no está» sin variables bandera:

def search(catalog, text):
    """Búsqueda insensible a mayúsculas; devuelve el primer match o None."""
    needle = text.lower()
    for item in catalog:
        if needle in item["title"].lower():
            return item              # encontró: devuelve y rompe el bucle
    return None                      # terminó sin match

print(search(catalog, "dune"))       # {'title': 'Dune', ...}
print(search(catalog, "matrix"))     # None

6 · Errores habituales

El vicio del índice: range(len(x))

titles = ["1984", "Dune"]

# ❌ Indexar para obtener lo que ya tienes iterando
for i in range(len(titles)):
    print(titles[i])          # funciona, pero es ruido innecesario

# ✅ Iterar directamente (y con enumerate si además quieres el índice)
for title in titles:
    print(title)
for i, title in enumerate(titles):
    print(i, title)

Modificar una lista mientras la recorres

# ❌ Borrar durante la iteración: el bucle reindexa y se salta elementos
numbers = [1, 2, 2, 3]
for n in numbers:
    if n == 2:
        numbers.remove(n)
print(numbers)   # [1, 2, 3]  -> ¡queda un 2 sin borrar!

# ✅ Filtra construyendo una lista nueva
numbers = [1, 2, 2, 3]
kept = [n for n in numbers if n != 2]   # comprehension (Módulo 3)
print(kept)      # [1, 3]

Confundir el else del bucle con el de un if

# ❌ Cree que se ejecuta "cuando no hay break"... pero dentro de un if
for n in [2, 4, 6]:
    if n % 2 == 0:
        print(n)
    # el else de aquí abajo NO pertenece al if: pertenece al for
else:
    print("bucle terminado")   # se imprime porque no hubo break

# ✅ Si quería el else del if, indenta al mismo nivel
for n in [2, 3, 4]:
    if n % 2 == 0:
        print("par")
    else:
        print("impar")

9 · Resumen

  • Un iterable entrega elementos; el for los recorre uno a uno sin índices.
  • while repite mientras una condición se mantenga: tú cambias la variable de control.
  • range genera números perezosamente; el límite final es exclusivo.
  • enumerate da índice y valor; zip recorre varios iterables en paralelo.
  • break sale del bucle; continue salta a la siguiente vuelta.
  • El else del bucle se ejecuta solo si no hubo break.

10 · Preguntas frecuentes

¿Por qué el for de Python no es como el de C/Java?

Porque Python se apoya en el protocolo de iteración: el for pide next() hasta agotar el iterable. No hay contador ni condición de parada visibles. Eso funciona igual con listas, cadenas, ficheros o generadores, sin que tú cambies nada.

¿Cuándo uso while y cuándo for?

Si tienes una colección o un rango conocido, for. Si repites «hasta que ocurra algo» (leer hasta un centinela, esperar un estado, consumir una cola), while. En la duda, for: es más difícil que se vuelva infinito.

¿range crea una lista de números en memoria?

No. En Python 3 range es un objeto perezoso: calcula cada número cuando se lo piden. Por eso range(1_000_000_000) se crea al instante y ocupa un tamaño fijo. Si de verdad quieres la lista, envuélvelo en list(range(...)).

¿Para qué sirve de verdad el else de un for?

Para el patrón «buscar y, si no encuentro, avisar». Sin él tendrías que declarar una bandera antes del bucle y comprobarla después. El else se ejecuta siempre que el bucle no se haya abandonado con break.
