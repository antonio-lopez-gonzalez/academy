Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Todo se ejecuta con la biblioteca estándar

Los ejemplos corren con Python 3.12+ y la stdlib; solo se añaden terceros cuando aportan (pytest, Ruff, mypy, uv). El proyecto final Biblioteca se instala y se usa de verdad.

Para quién es

Para desarrolladores que ya programan en otro lenguaje y quieren dominar Python en profundidad: entender por qué la indentación importa, por qué todo es un objeto, cómo funcionan los generadores y qué implica el GIL. El hilo conductor es Biblioteca, un catálogo de libros y películas.

Linux, macOS y Windows

Python corre nativo en los tres sistemas. Cada lección señala las diferencias cuando existen: el launcher py en Windows, la activación del entorno virtual en PowerShell, rutas y finales de línea.
