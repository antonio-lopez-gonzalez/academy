# Hola, Astro — ejemplo mínimo

El proyecto Astro más pequeño posible: una página que se genera en build time y
**no envía JavaScript** al navegador. Primer ejemplo del curso
[`Aprende Astro`](../../AGENTS.md).

```bash
cd "Aprende Astro/ejemplos/hola-astro"
pnpm install
pnpm dev      # http://localhost:4321
```
