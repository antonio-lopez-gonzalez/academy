Ejemplos que ejecutas al instante

La carpeta ejemplos/ contiene proyectos Astro que ejecutas con pnpm dev. Los proyectos grandes en proyectos/ son aplicaciones Astro completas listas para producción.

Para quién es

Para desarrolladores que ya saben JavaScript, React y Tailwind y quieren dominar la arquitectura MPA moderna. Aprenderás a construir sitios content-driven con hidratación selectiva, cero JavaScript innecesario y rendimiento excepcional por defecto.
