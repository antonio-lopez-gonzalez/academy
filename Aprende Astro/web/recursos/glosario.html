🚀 Glosario de Astro

Términos y conceptos clave para dominar el ecosistema Astro.

A

Astro: Framework web moderno para construir sitios content-driven con arquitectura MPA e islands. Por defecto envía cero JavaScript al cliente.

C

Content Collections: Sistema de Astro para gestionar contenido (Markdown, MDX, JSON) con validación de esquemas mediante Zod.

Componente .astro: Componente con extensión .astro que combina frontmatter (JS/TS) y template (HTML). Núcleo del framework.

F

Frontmatter: Bloque delimitado por --- al inicio de un componente .astro donde se escribe JavaScript/TypeScript que se ejecuta en build time.

G

getStaticPaths: Función exportada desde páginas dinámicas que define qué rutas se generan estáticamente durante el build.

H

Hidratación: Proceso por el cual un componente de framework UI (React, Vue, Svelte) se vuelve interactivo en el cliente cargando su JavaScript.

I

Island (isla): Componente interactivo de un framework UI (React, Vue, Svelte) que se incrusta en una página Astro. Se hidrata de forma aislada.

L

Layout: Componente .astro que envuelve páginas, proporcionando estructura común (header, footer, sidebar). Se anidan mediante slots.

M

MPA (Multi-Page Application): Arquitectura donde cada página es un documento HTML independiente, sin SPA router en cliente. Astro es MPA por defecto.

MDX: Extensión de Markdown que permite incluir componentes JSX dentro del contenido. Soportado en Astro vía integración.

P

Props: Propiedades que se pasan a un componente .astro desde su padre. Pueden tener tipos TypeScript y valores por defecto.

R

remark: Plugin del ecosistema Markdown que transforma el AST (árbol sintáctico) del Markdown. Ejemplo: añadir IDs a headings.

rehype: Plugin del ecosistema Markdown que transforma el HTML generado. Ejemplo: añadir clases CSS a elementos.

S

Slot: Punto de inserción en un componente donde se renderiza el contenido hijo. Pueden ser anónimos o nombrados.

SSG (Static Site Generation): Modo por defecto de Astro. Genera HTML estático en build time. Ideal para blogs, docs y landing pages.

SSR (Server-Side Rendering): Modo opcional de Astro. Renderiza HTML en cada petición en el servidor. Útil para contenido dinámico y auth.

V

View Transitions: API del navegador que Astro integra para animar transiciones entre páginas sin JavaScript adicional. Soportada en Astro 3+.

Z

Zod: Biblioteca de validación de esquemas en TypeScript. Usada en Content Collections para validar el frontmatter de los artículos.
