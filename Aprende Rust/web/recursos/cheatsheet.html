El mapa antes de los comandos

Todo en Rust gira alrededor de una pregunta: ¿quién es el dueño de este valor y quién lo está usando ahora? Cargo compila, el compilador demuestra, y el binario no lleva ninguna comprobación extra.

rustup   gestiona toolchains y componentes (clippy, rustfmt, rust-src)
cargo    gestiona el proyecto: build, run, test, doc, publish
rustc    el compilador (cargo lo invoca por ti)
clippy   linter: señala el código que compila pero no es idiomático
rustfmt  formateador: un único estilo para todo el equipo

propiedad  → un valor, un dueño, se libera al salir de ámbito
préstamo   → &T (muchos lectores) XOR &mut T (un escritor)
vida       → cuánto vive un préstamo cuando el compilador no lo deduce

Que no haya nullOption<T>La ausencia es un tipo, no un accidente.
Que un fallo no se ignoreResult<T, E> + ?El compilador obliga a tratarlo.
Polimorfismo sin herenciatrait + implEstático por defecto (monomorfización).
Concurrencia segurathread, Arc<Mutex<T>>Sin carreras: lo garantiza Send/Sync.
Muchas conexiones con poco costeasync + TokioUn futuro es una máquina de estados.

Ownership, préstamos y vidas

let a = String::from("hola");   // a es dueño del heap
let b = a;                      // MOVE: a deja de ser válido
let c = a.clone();              // COPIA explícita del heap (caro)

let x = 42;                     // i32 es Copy: se copia el valor
let y = x;                      // x sigue siendo válido

fn leer(s: &str) { }            // préstamo inmutable
fn escribir(s: &mut String) { } // préstamo mutable, exclusivo

let mut v = vec![1, 2, 3];
let primero = &v[0];            // &v inmutable
// v.push(4);                   // ✗ E0502: ya hay un préstamo inmutable vivo
println!("{primero}");

let r: &'static str = "literal"; // vive todo el programa
fn mayor<'a>(a: &'a str, b: &'a str) -> &'a str { if a.len() > b.len() { a } else { b } }
ReglaConsecuencia práctica
Un solo dueño por valorAsignar mueve; para duplicar hay que ser explícito (clone)
Muchos &T XOR un &mut TNo puedes mutar mientras iteras
El dueño libera al salir de ámbitoNo hay free: el Drop lo hace por ti
Los préstamos no pueden sobrevivir al dueñoDe ahí las vidas y los errores E0597/E0716

Errores y traits

use thiserror::Error;

#[derive(Debug, Error)]
pub enum Error {
    #[error("URL inválida: {0}")]
    InvalidUrl(String),
    #[error("no existe el código {0}")]
    NotFound(String),
    #[error(transparent)]
    Io(#[from] std::io::Error),
}

fn leer() -> Result<String, Error> {
    let texto = std::fs::read_to_string("datos.txt")?;  // ? convierte con From
    Ok(texto)
}

pub trait Store: Send + Sync {
    fn get(&self, code: &str) -> Result<Option<Link>, Error>;
    fn list(&self) -> Result<Vec<Link>, Error> {
        Ok(Vec::new())                 // método por defecto
    }
}

thiserror para librerías (error tipado), anyhow para aplicaciones (error con contexto, un solo tipo).

Concurrencia y async

// Hilos: cada uno con su propia copia del Arc
let contador = std::sync::Arc::new(std::sync::Mutex::new(0_u64));
for _ in 0..4 {
    let contador = std::sync::Arc::clone(&contador);
    std::thread::spawn(move || {
        *contador.lock().expect("lock") += 1;
    });
}

// Canales: productor/consumidor
let (tx, rx) = std::sync::mpsc::channel();
std::thread::spawn(move || tx.send("hola").unwrap());
println!("{}", rx.recv().unwrap());

// Tokio
#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let a = tokio::spawn(async { 1 + 1 });
    let (uno, dos) = tokio::join!(a, async { 2 });
    let _ = tokio::time::timeout(std::time::Duration::from_secs(1), async {
        tokio::time::sleep(std::time::Duration::from_millis(10)).await;
    })
    .await;
    Ok(())
}

Nunca bloquees el executor

std::thread::sleep dentro de un async fn para el hilo entero del runtime. Usa tokio::time::sleep y, para trabajo pesado de CPU, tokio::task::spawn_blocking.

Clap, Serde, Axum y reqwest

// Clap 4 (derive)
#[derive(clap::Parser)]
#[command(name = "urlshort", version, about = "Acorta URLs")]
struct Cli {
    #[arg(long, default_value = "data/links.json")]
    store: std::path::PathBuf,
    #[command(subcommand)]
    command: Command,
}

#[derive(clap::Subcommand)]
enum Command {
    Short { url: String },
    Serve { #[arg(long, default_value_t = 3000)] port: u16 },
}

// Serde
#[derive(serde::Serialize, serde::Deserialize)]
struct Link { code: String, url: String, #[serde(default)] hits: u64 }

// Axum 0.8: parámetros con llaves y estado clonable
fn router(service: Service) -> axum::Router {
    use axum::{routing::{get, post}, Router};
    Router::new()
        .route("/links", post(crear))
        .route("/links/{code}", get(resolver))
        .with_state(service)
}

// reqwest
async fn valida(url: &str) -> Result<(), Box<dyn std::error::Error>> {
    let cliente = reqwest::Client::builder()
        .timeout(std::time::Duration::from_secs(5))
        .build()?;
    let respuesta = cliente.head(url).send().await?.error_for_status()?;
    println!("{}", respuesta.status());
    Ok(())
}

Anti-patrones que este curso combate

Anti-patrónPor qué dueleAlternativa
clone() para calmar al compiladorCopia memoria y esconde un problema de diseñoPrestar o reordenar el código
unwrap() en todas partesUn panic! con mensaje inútil en producciónResult + ? + thiserror
Arc<Mutex<T>> por defectoSerializa todo y complica el códigoDatos inmutables, canales, RwLock, o estado por tarea
Bloquear dentro de asyncCongela el executor enterotokio::time, spawn_blocking
Abusar de Box<dyn Trait>Pierdes monomorfización y claridadGenéricos cuando el tipo se conoce en compilación
unsafe sin justificarRompe las garantías del lenguajeDemostrar con un comentario y tests; si no, no lo uses
