Glosario de Rust

Referencia 📚 40 términos · orden alfabético

De la A a la Z

Cada término con la definición que usaría alguien que viene de otro lenguaje, y el módulo del curso donde se desarrolla.

Borrow checker
La parte del compilador que verifica las reglas de préstamo: muchos &T o un &mut T, nunca ambos a la vez sobre el mismo dato. Módulo 1.
Box<T>
Puntero con dueño en el heap. Se usa para tipos recursivos, para dyn Trait y para devolver cosas grandes sin copiarlas. Módulo 2.
Canal (channel)
Mecanismo de paso de mensajes entre hilos o tareas. std::sync::mpsc en hilos, tokio::sync::mpsc en async. Módulo 5.
Clippy
Linter oficial. Señala código que compila pero no es idiomático: cargo clippy -- -D warnings. Módulo 4.
Closure
Función anónima que captura su entorno. Implementa Fn, FnMut o FnOnce según cómo capture. Módulo 2.
Copy
Trait de los tipos que se copian bit a bit al asignarse (i32, bool, char). Un tipo Copy no se mueve. Módulo 1.
Crate
Unidad de compilación y publicación. Un proyecto puede tener un crate librería (lib.rs) y uno binario (main.rs). Módulo 3.
Deref coercion
Conversión automática de &String a &str (o &Vec<T> a &[T]) al pasar argumentos. Módulo 1.
Drop
Trait que se ejecuta al salir de ámbito; ahí se libera la memoria y los recursos. Orden LIFO. Módulo 1.
DST (dynamically sized type)
Tipo cuyo tamaño no se conoce en compilación, como str o [T]. Siempre se usa detrás de una referencia o un Box. Módulo 1.
Dyn
Palabra clave para despacho dinámico: Box<dyn Store> guarda cualquier implementación del trait con una tabla virtual. Módulo 2.
Edición
Conjunto de cambios del lenguaje (2015, 2018, 2021, 2024) que conviven en el mismo binario. Se declara en Cargo.toml. Módulo 4.
Enum
Tipo suma: una de varias variantes, cada una con sus datos. Base de Option y Result. Módulo 2.
Feature
Conjunto de funcionalidad opcional de un crate, activable desde Cargo.toml. Afecta a la compilación, no a la ejecución. Módulo 4.
Future
Valor que representa un cálculo que puede no estar listo. Se avanza con poll y lo conduce un runtime. Módulo 5.
Generic
Parámetro de tipo (Vec<T>) resuelto en compilación mediante monomorfización: cero coste en ejecución. Módulo 2.
Guard (MutexGuard)
Testigo del bloqueo. Al soltarlo (Drop) se libera el mutex; por eso no se puede olvidar. Módulo 5.
Impl
Bloque que añade métodos y funciones asociadas a un tipo o implementa un trait para él. Módulo 2.
Lifetime
Etiqueta ('a) que dice cuánto vive un préstamo. El compilador casi siempre la deduce (elisión). Módulo 1.
Monomorfización
Generación de una versión del código por cada tipo concreto usado con un genérico. Explica el coste cero y el tamaño del binario. Módulo 2.
Move
Transferencia de la propiedad. El original deja de ser válido; no hay copia implícita del heap. Módulo 1.
MSRV
Minimum Supported Rust Version: la versión mínima con la que compila tu crate. Se declara con rust-version. Módulo 4.
Option<T>
Enum Some(T) / None: la ausencia de valor como tipo comprobado, en lugar de null. Módulo 2.
Orphan rule
Solo puedes implementar un trait para un tipo si el trait o el tipo son de tu crate. Evita implementaciones en conflicto. Módulo 2.
Ownership
Modelo de propiedad: cada valor tiene un único dueño que lo libera al salir de ámbito. Sustituye al recolector de basura. Módulo 1.
Panic
Error irrecuperable que desenrolla la pila (o aborta). Para bugs, no para entradas inválidas del usuario. Módulo 3.
Pattern matching
match, if let, let else, while let: desestructurar tipos y comprobar exhaustividad. Módulo 2.
Pin
Garantía de que un valor no se mueva en memoria; necesario para futuros auto-referenciales. Se usa, no se implementa a diario. Módulo 5.
Préstamo (borrow)
Referencia a un valor sin tomar la propiedad: &T (lectura) o &mut T (escritura exclusiva). Módulo 1.
Result<T, E>
Enum Ok(T) / Err(E): el fallo como valor que hay que tratar. Se compone con ?. Módulo 3.
Rustdoc
Documentación generada desde /// y //!. Sus doctests se ejecutan con cargo test. Módulo 4.
Send
Trait marcador: el tipo puede moverse a otro hilo. Rc<T> no es Send; Arc<T> sí. Módulo 5.
Shadowing
Redeclarar una variable con let, pudiendo cambiar incluso su tipo. No es mutación. Módulo 0.
Slice
Vista prestada sobre una secuencia: &[T] o &str. Lleva puntero y longitud. Módulo 1.
String / &str
String posee texto en el heap (crece, se modifica); &str es una vista prestada e inmutable. Módulo 1.
Struct
Tipo producto: campos con nombre, tupla o unitario. Con impl gana métodos. Módulo 2.
Sync
Trait marcador: &T puede compartirse entre hilos. Mutex<T> hace Sync a T. Módulo 5.
Trait
Contrato de métodos e implementaciones por defecto. Sustituye a las interfaces y a gran parte de la herencia. Módulo 2.
Trait bound
Restricción sobre un genérico: T: Display + Clone. Determina qué puedes hacer con la variable. Módulo 2.
Unsafe
Bloque donde el programador asume las garantías de memoria que el compilador no puede demostrar. Debe justificarse. Módulo 6.
Zero-cost abstraction
Abstracciones (iteradores, generics, traits) que no cuestan más en ejecución que el código equivalente escrito a mano. Módulo 2.

ComandoPara qué
