# Documentation First

When answering questions about programming languages, frameworks, libraries, APIs or SDKs:

1. Consult Context7 before answering.
2. Prefer official documentation over prior knowledge.
3. If multiple versions exist, use the latest stable version unless the user specifies another.
4. Mention breaking changes when relevant.
5. Generate code that follows the current official recommendations.
