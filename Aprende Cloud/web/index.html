Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Todo como código

La infraestructura se define con Terraform y se versiona. La consola del proveedor solo se usa para explorar. Nada de secretos en el repositorio: identidad gestionada y OIDC.

Para quién es

Para desarrolladores que ya programan (idealmente tras Aprende Docker y Aprende DevOps) y quieren dominar el despliegue en la nube: entender qué gestionas tú y qué no, asegurar el acceso y controlar el coste. El hilo conductor es Copiloto en la nube.

Azure y AWS, sin dogmas

El discurso es provider-neutral (Azure como principal, AWS en comparación) y el código es concreto. Aprenderás a moverte en cualquiera de las dos sin empezar de cero.
