Un curso completo en español de FastAPI: cómo funciona ASGI, rutas y Pydantic v2, dependencias e inyección, persistencia con SQLModel y Alembic, seguridad con OAuth2/JWT, testing con TestClient y despliegue. El hilo conductor es Copiloto API, el asistente del curso Aprende IA expuesto como API HTTP real.

Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Todo se ejecuta con uv

Los ejemplos corren con Python 3.12+ y uv. Levantas la API con uv run uvicorn y visitas /docs: la documentación interactiva (OpenAPI) es el contrato de tu API desde el primer endpoint.

Para quién es

Para desarrolladores que ya programan (Python, .NET, Node…) y quieren dominar FastAPI en profundidad: por qué la validación vive en los tipos, cómo funciona la inyección de dependencias, y cómo se modelan datos, errores y seguridad. El hilo conductor es Copiloto API.

Linux, macOS y Windows

Python, uv y uvicorn corren en los tres sistemas. Cada lección señala las diferencias cuando existen: activación de entornos, variables y rutas.
