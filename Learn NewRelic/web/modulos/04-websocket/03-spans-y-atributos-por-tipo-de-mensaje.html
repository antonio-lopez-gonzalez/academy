Spans y atributos por tipo de mensaje

Módulo 4 · Instrumentar WebSocket ⏱ 35 minutos

1 · Introducción

La transacción por mensaje te da el quién. Ahora le añadimos la mecánica interna: spans para las fases (parseo, validación, llamada externa, broadcast) y atributos de span para el detalle fino de cada fase.

Verás [Trace] para segmentos, CurrentSpan para atributos de span, y cómo nombrar spans para que el trace hable el idioma del negocio.

2 · Teoría

Elementos que puedes tocar

MecanismoQué produceCuándo
[Trace] en un métodoUn span (segmento) hijo de la transacciónFASES internas: ParsePayload, ValidateTrade, Broadcast
agent.CurrentSpan.AddCustomAttribute(...)Atributo en el span actualDetalle específico de la fase (símbolo, nº de clientes)
agent.CurrentSpan.SetName(...)Renombra el span visibleControlar nombres dinámicos del trace
transaction.AddCustomAttribute(...)Atributo en el evento TransactionContexto global del mensaje (type, userId)

Fases por tipo: «igual forma, distinto sentido»

[Transaction] OnMessage (msg.Type = trade)
 ├─ [Trace] ParsePayload        (atributo: symbol)
 ├─ [Trace] ValidateTrade      (atributo: isValid, reason)
 ├─ [Trace] CallPriceApi       (span automático http externo)
 └─ [Trace] BroadcastToClients (atributo: clients.count)

[Transaction] OnMessage (msg.Type = ping)
 └─ [Trace] HandlePing         (atributo: latencyMs)

Con nombres estables, preguntas como «p95 del broadcast» son triviales.

3 · Ejemplo mínimo

using NewRelic.Api.Agent;

public class TradeValidator
{
    [Trace]                                  // → span hijo de la transacción
    public bool Validate(TradeMessage trade)
    {
        IAgent agent = NewRelic.Api.Agent.NewRelic.GetAgent();
        agent.CurrentSpan
            .AddCustomAttribute("symbol", trade.Symbol)
            .AddCustomAttribute("currency", trade.Currency);

        // "isValid" al span para el postmortem
        var ok = trade.Amount > 0 && trade.Price > 0;
        agent.CurrentSpan.AddCustomAttribute("isValid", ok);
        return ok;
    }
}

En el trace verás el span Validate con symbol, currency e isValid.

4 · Ejemplo real

public class TradeProcessor
{
    [Trace]
    public async Task ProcessTrade(MessageEnvelope msg)
    {
        IAgent agent = NewRelic.Api.Agent.NewRelic.GetAgent();

        // Atributos del span del procesado
        agent.CurrentSpan.AddCustomAttribute("symbol", GetSymbol(msg.Payload));

        var price = await _priceApi.GetAsync(symbol);   // external automático
        agent.CurrentSpan.AddCustomAttribute("priceSource", price.Source);

        await Broadcast(msg, price);                     // [Trace] interno
    }

    [Trace]
    private async Task Broadcast(MessageEnvelope msg, Price price)
    {
        var count = _clients.Count;
        NewRelic.Api.Agent.NewRelic.GetAgent()
            .CurrentSpan.AddCustomAttribute("clients.count", count);

        await _hub.BroadcastAsync(price);               // se mide en el span
    }
}

El resultado: una traza con 3-4 niveles (ProcessTrade → CallPriceApi externo → Broadcast), cada uno con sus atributos y su duración. Exactamente lo que usamos para encontrar «dónde se perdieron los 9 segundos del trade #887».

6 · Errores habituales

Atributo de span en el momento equivocado

// ❌ Añadir en el momento que "CurrentSpan" es el de OTRA fase
public async Task ProcessTrade()
{
    await _priceApi.GetAsync(symbol);
    agent.CurrentSpan.AddCustomAttribute("latencyPrice", sw.ElapsedMilliseconds);
    // ○ aquí CurrentSpan ya es otro span, no el del get
}

// ✅ Captura el span de la fase mientras estás dentro de ella,
//    o usa el segmento [Trace] alrededor de la llamada.

No distinguir atributo de transacción vs span

Contexto global del mensaje → transacción; detalle de la fase → span. Mezclarlos ensucia ambas vistas.

8 · Reto

🎯 El trace que cuenta cuentos

Dibuja el trace ideal de un trade con las fases de tu dominio real (no del ejemplo): entrada, validación, reglas, persistencia, notificación. Para cada fase indica nombre de span y 2 atributos. Es tu borrador para el proyecto final.

9 · Resumen

  • [Trace] = span/fase; CurrentSpan para atributos y renombrado de span.
  • Atributos de transacción = contexto global; atributos de span = detalle de fase.
  • Nombres estables y cardinalidad baja en atributos.

10 · Preguntas frecuentes

¿Cuántos spans son demasiados?

El agente tiene límites por minuto (por defecto 2000 spans/min en el tracing estándar). Mucho más que eso, prioriza: traza las fases que cuestan o fallan, deja el resto.

¿Los spans existen aunque la transacción no se muestree?

Con head-based sampling, el muestreo decide qué trazas se conservan. Puedes generar trazas (spans) solo de la muestra; las métricas, sí, siempre se agregan.

¿SetName sobre el span cambia la métrica?

Sí: para spans de instrumentación custom, el nombre también altera la métrica reportada. Úsalo con cuidado y consistencia.
