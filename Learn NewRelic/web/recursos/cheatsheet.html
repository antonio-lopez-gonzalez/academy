Cheatsheet NRQL + agente .NET

Referencia rápida 📋 New Relic · .NET 8

Paquetes y arranque del agente .NET

# 1. Añade el agente completo (profiler + config)
dotnet add package NewRelic.Agent
# 2. Añade la API de instrumentación custom (IAgent, ITransaction, ISpan)
dotnet add package NewRelic.Agent.Api

# 3. Variables de entorno obligatorias (o en newrelic.config)
export NEW_RELIC_LICENSE_KEY=xxxxx
export NEW_RELIC_APP_NAME=NotificadorWebSocket

# 4. Con el paquete NewRelic.Agent en .NET Core/Windows, el profiler se
#    habilita con estas variables (las define el propio paquete al ejecutarse):
#    CORECLR_ENABLE_PROFILING=1
#    CORECLR_PROFILER={36032161-FFC0-4B61-B559-F6C5D41BAE5A}
#    CORECLR_PROFILER_PATH=<app>\newrelic\NewRelic.Profiler.dll
#    CORECLR_NEWRELIC_HOME=<app>\newrelic

dotnet run

newrelic.config mínimo

<?xml version="1.0" encoding="utf-8"?>
<configuration xmlns="urn:newrelic-config" agentEnabled="true">
  <service licenseKey="YOUR_LICENSE_KEY" />
  <application>
    <name>NotificadorWebSocket</name>
  </application>

  <!-- Distributed tracing (W3C traceparent/tracestate), por defecto en agentes ≥ 9.0 -->
  <distributedTracing enabled="true" excludeNewrelicHeader="false" />

  <!-- Logs en contexto: forwarding del agente + métricas -->
  <applicationLogging enabled="true">
    <metrics enabled="true" />
    <forwarding enabled="true" maxSamplesStored="10000" />
    <localDecorating enabled="false" />
  </applicationLogging>

  <errorCollector enabled="true" captureEvents="true" />
</configuration>

Precedencia de configuración: appsettings.json/web.config → variables de entorno → server-side → newrelic.config local → newrelic.config global.

API de instrumentación (NewRelic.Agent.Api)

using NewRelic.Api.Agent;

// IAgent: obtenerlo una vez y guardarlo (inyección lazy)
IAgent agent = NewRelic.Api.Agent.NewRelic.GetAgent();

// Atributo a la transacción actual (leer CurrentTransaction POR CADA USO)
agent.CurrentTransaction.AddCustomAttribute("messageType", "trade");

// Atributo al span actual
agent.CurrentSpan
     .AddCustomAttribute("topic", "orders")
     .SetName("ProcessOrderMessage");

// Métrica custom (nombre SIEMPRE con prefijo Custom/)
NewRelic.Api.Agent.NewRelic.RecordMetric("Custom/MessagesProcessed", 1);
NewRelic.Api.Agent.NewRelic.IncrementCounter("Custom/MessagesProcessed");

// Evento custom (facts de negocio; máx 64 atributos)
NewRelic.Api.Agent.NewRelic.RecordCustomEvent("OrderPlaced", new Dictionary<string, object> {
    { "orderId", 42 }, { "amount", 99.95 }, { "currency", "EUR" }
});

// Error
NewRelic.Api.Agent.NewRelic.NoticeError(ex);
NewRelic.Api.Agent.NewRelic.NoticeError("Fallo al procesar", null, isExpected: true);

Distributed tracing manual (WebSocket / colas)

IAgent agent = NewRelic.Api.Agent.NewRelic.GetAgent();
ITransaction txn = agent.CurrentTransaction;

// Emisor: inyectar headers en un contenedor clave/valor
Message msg = new() { Type = "event" };
txn.InsertDistributedTraceHeaders(msg, static (c, k, v) => c.TraceContext[k] = v);

// Receptor: aceptar el contexto W3C desde el mensaje
txn.AcceptDistributedTraceHeaders(
    msg.TraceContext,
    static (c, k) =>
    {
        _ = c.TryGetValue(k, out var v);
        return v is null ? [] : [v];
    },
    TransportType.Other);
// Nota: el enum no tiene "WebSocket"; valores reales:
//   Unknown, HTTP, HTTPS, Kafka, JMS, IronMQ, AMQP, Queue, Other
// Para WebSocket, usa Other.

Formato del header W3C traceparent:

traceparent: 00-<traceId de 32 hex>-<spanId/parentId de 16 hex>-<flags>
ejemplo    : 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01

NRQL en 30 segundos

-- Cláusulas: SELECT (obligatoria) FROM (obligatoria)
--            WHERE · FACET · SINCE · UNTIL · TIMESERIES
--            COMPARE WITH · LIMIT · AS · ORDER BY · EXTRAPOLATE

-- Transacciones por app (última hora)
SELECT count(*) FROM Transaction
WHERE appName = 'NotificadorWebSocket' SINCE 1 hour ago

-- Tipos de mensaje procesados por minuto
SELECT count(*), average(duration) FROM Transaction
FACET messageType TIMESERIES 1 minute

-- Percentiles de duración, comparando con la semana pasada
SELECT percentile(duration, 50, 90, 99) FROM Transaction
SINCE 1 week ago COMPARE WITH 1 week ago TIMESERIES AUTO

-- Eventos custom de negocio
SELECT count(*) FROM OrderPlaced
FACET currency SINCE 24 hours ago

-- Logs: errores por servicio
SELECT count(*) FROM Log WHERE level = 'ERROR'
FACET appName SINCE 6 hours ago

-- Agregadores: count(*) average(attr) sum(attr) min(attr) max(attr)
--   percentile(attr[,50,90,99]) median(attr) rate(fn[,interval])
--   percentage(fn, WHERE...) uniqueCount(attr) uniques(attr)
--   latest(attr) earliest(attr) stddev(attr) apdex(attr, t: 0.5)
--   filter(fn, WHERE cond) keyset()

-- Comillas: strings y etiquetas AS van entre COMILLAS SIMPLES
SELECT count(*) AS 'total' FROM Transaction
-- Atributos que son palabras reservadas: acentos graves ``
FACET `transactionName`

OpenTelemetry → New Relic (OTLP)

# Endpoint US (gRPC :4317 · HTTP :4318)
OTEL_EXPORTER_OTLP_ENDPOINT=https://otlp.nr-data.net:4318
OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
OTEL_EXPORTER_OTLP_HEADERS=api-key=<NEW_RELIC_LICENSE_KEY>
OTEL_EXPORTER_OTLP_COMPRESSION=gzip
OTEL_EXPORTER_OTLP_METRICS_TEMPORALITY_PREFERENCE=delta
using OpenTelemetry.Trace;
using OpenTelemetry.Metrics;
using OpenTelemetry.Logs;

builder.Services.AddOpenTelemetry()
    .WithTracing(t => t
        .AddAspNetCoreInstrumentation()
        .AddSource("NotificadorWs")
        .AddOtlpExporter())
    .WithMetrics(m => m.AddOtlpExporter());
