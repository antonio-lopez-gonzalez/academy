Glosario de observabilidad y New Relic

Referencia 📖 De la A a la Z
Apdex
Índice de satisfacción del usuario (0 a 1) basado en un umbral de satisfacción «T». Mide cuántas transacciones fueron satisfactorias, tolerables o frustrantes. Se calcula con apdex(attr, t: 0.5) en NRQL.
APM (Application Performance Monitoring)
El producto de New Relic que vigila el rendimiento de una aplicación: transacciones, métricas, errores, trazas y dependencias externas.
Agente
Librería/profiler que se adjunta a tu aplicación para capturar telemetría automáticamente. En .NET se distribuye con el paquete NuGet NewRelic.Agent.
Atributo
Par clave/valor que añade contexto a un evento, transacción, span o log. Ej.: messageType: "trade". Se guarda en NRDB y se usa en NRQL con WHERE y FACET.
Custom event
Evento propio de negocio enviado con RecordCustomEvent. Se consulta con FROM NombreEvento (máx. 64 atributos).
Custom metric
Métrica propia enviada con RecordMetric/IncrementCounter. Los nombres empiezan por Custom/.
Dashboard
Colección de gráficos (widgets) construidos sobre consultas NRQL, con variables y versiones para compartir y comparar.
Distributed tracing
Trazado de una petición a través de múltiples servicios. Une los spans por traceId para reconstruir el recorrido completo.
Entity
Unidad monitorizada por New Relic: una aplicación APM, un host, una base de datos, etc. Tiene un entity.guid único.
Errors inbox
La bandeja de New Relic que agrupa errores por similitud (error groups) y permite priorizarlos, asignarlos y cerrarlos.
Event
Registro atómico con marca de tiempo y atributos. Ej.: una transacción, un log, un evento custom. Aquí viven los «eventos» en NRDB.
Facet
Agrupación de resultados en NRQL por el valor de uno o varios atributos: FACET messageType.
Infinite Tracing
Servicio cloud de New Relic con muestreo tail-based: recibe el 100% de los spans y aplica samplers (por duración, error y aleatorio) para retener los traces más importantes.
Log forwarding
Envío de logs de tu aplicación al producto Logs de New Relic, con trace.id y span.id para correlacionarlos (logs in context).
Logs in context
Ver, en la misma pantalla de un trace o error, los logs relacionados de tu aplicación.
Métrica
Valor numérico agregable en el tiempo (count, average, percentile). Sirve para alertar y para consultas históricas ligeras.
NRDB
La base de datos de series temporales de New Relic donde viven todos los datos (eventos y métricas) consultables por NRQL.
NRQL
Los lenguajes de consulta de New Relic (New Relic Query Language): SELECT ... FROM ... WHERE ... FACET ... SINCE ....
OpenTelemetry (OTel)
Estándar abierto de telemetría (traces, métricas, logs) con un SDK en cada lenguaje. New Relic acepta datos OTLP vía otlp.nr-data.net.
OTLP
OpenTelemetry Protocol: formato de envío de telemetría. Puertos 4317 (gRPC) y 4318 (HTTP).
Sampling
Muestreo: decidir qué trazas se conservan. Head-based (el origen decide; por defecto en agentes, 10 traces/min en .NET) o tail-based (Infinite Tracing).
Span
Una unidad de trabajo dentro de un trace (una llamada HTTP, un segmento de método, el procesamiento de un mensaje). Tiene traceId y guid (parentId).
Trace
El recorrido completo de una operación a través de uno o varios servicios, formado por spans unidos por el mismo traceId.
traceId
Identificador único de un trace (32 caracteres hexadecimales). Se propaga con el header W3C traceparent y se añade a eventos, spans y logs.
Transaction
Evento que representa una petición atendida por tu app (una llamada a un endpoint HTTP o un segmento custom). Base del APM.
W3C Trace Context
Estándar de propagación de trazas con los headers traceparent y tracestate. New Relic lo soporta junto a su header propietario newrelic.
