Proyecto .NET que ejecutas con dotnet

En proyectos/newrelic-ws-demo/ encontrarás un servidor WebSocket + Minimal API en .NET 8, instrumentado con el agente de New Relic y configurable sin licencia: dotnet run y a probar.

Para quién es

Para desarrolladores .NET que ya programan y quieren dominar la observabilidad: entender cómo funciona el agente, cómo se propaga un traceId, qué es un evento vs. una métrica vs. un span, y cómo convertir eso en dashboards y alertas útiles.
