Local primero: funciona sin API key

El núcleo corre con un LLM local (Ollama) y embeddings locales, así que puedes seguirlo entero sin tarjeta ni claves. Cuando toca la nube (OpenAI/Anthropic), se muestra como alternativa explícita.

Para quién es

Para desarrolladores que ya programan (y quizá ya usan un agente de código) y quieren construir con IA de verdad: entender qué hace un LLM, medir coste y latencia, evaluar respuestas y montar un agente con herramientas. El hilo conductor es Copiloto, que crece contigo módulo a módulo.

Linux, macOS y Windows

Python y Ollama corren en los tres sistemas. Cada lección señala las diferencias cuando existen: activación de entornos, variables de entorno y rutas.
