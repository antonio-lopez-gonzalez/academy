Clases y objetos

Módulo 2 · POO en C# 40 minutos

1 · Introducción

En esta lección escribimos tu primera clase completa y creamos objetos reales. Verás los campos, los métodos y las propiedades, y entenderás cómo se relacionan los objetos entre sí.

Objetivo

Declarar clases, crear instancias con new, y usar campos, métodos y propiedades.

2 · Teoría

Declarar una clase

class Persona
{
    // Campo privado (estado interno)
    private string _nombre = "";

    // Propiedad (acceso controlado al estado)
    public string Nombre
    {
        get => _nombre;
        set => _nombre = value;
    }

    // Método (comportamiento)
    public void Saludar()
    {
        Console.WriteLine($"Hola, soy {_nombre}");
    }
}

Crear objetos con new

// new crea una instancia de la clase en memoria
var persona = new Persona();

persona.Nombre = "Antonio";   // usa el setter
persona.Saludar();            // usa el método
// Imprime: Hola, soy Antonio

new Persona() reserva memoria para el objeto y devuelve una referencia a él. La variable persona guarda esa referencia, no el objeto en sí.

Campos

Un campo es una variable que vive dentro del objeto. Por convención, los campos privados empiezan con guion bajo:

class Contador
{
    private int _valor = 0;   // campo privado
}

Propiedades

Una propiedad expone el estado de forma controlada. Tiene un get (leer) y un set (escribir):

class Persona
{
    public string Nombre { get; set; }   // propiedad automática

    // Equivale a:
    private string _nombre;
    public string Nombre2
    {
        get { return _nombre; }
        set { _nombre = value; }
    }
}

La propiedad automática { get; set; } es un atajo: el compilador genera el campo de respaldo (backing field) por ti.

Acceso a miembros

Para usar un miembro de un objeto, usas el punto .:

persona.Nombre = "Ana";     // escribir propiedad
string n = persona.Nombre;  // leer propiedad
persona.Saludar();          // llamar método

Estado y comportamiento

Recuerda: el estado son los campos/propiedades; el comportamiento son los métodos. Juntos, cada objeto mantiene su propio estado independiente:

var p1 = new Persona { Nombre = "Ana" };
var p2 = new Persona { Nombre = "Luis" };

p1.Saludar();   // Hola, soy Ana
p2.Saludar();   // Hola, soy Luis (estado independiente)

Referencias entre objetos

Un objeto puede guardar referencias a otros objetos. Esto permite modelar relaciones:

class Persona
{
    public string Nombre { get; set; } = "";
    public Mascota? Mascota { get; set; }   // referencia a otro objeto
}

class Mascota
{
    public string Nombre { get; set; } = "";
}

var ana = new Persona { Nombre = "Ana" };
ana.Mascota = new Mascota { Nombre = "Rex" };

Console.WriteLine($"{ana.Nombre} tiene una mascota llamada {ana.Mascota.Nombre}");

4 · Ejemplo real

Un pequeño sistema con dos clases que se relacionan: un pedido que contiene productos:

class Producto
{
    public string Nombre { get; set; } = "";
    public decimal Precio { get; set; }
}

class Pedido
{
    public int Numero { get; set; }
    public List<Producto> Productos { get; set; } = new();

    public decimal Total()
    {
        decimal suma = 0;
        foreach (var p in Productos)
            suma += p.Precio;
        return suma;
    }
}

var pedido = new Pedido { Numero = 42 };
pedido.Productos.Add(new Producto { Nombre = "Teclado", Precio = 29.99m });
pedido.Productos.Add(new Producto { Nombre = "Ratón", Precio = 15.50m });

Console.WriteLine($"Pedido {pedido.Numero}: {pedido.Total():C}");

6 · Errores habituales

Error 1: olvidar new

// Persona p;          // p es null (referencia sin objeto)
// p.Saludar();        // NullReferenceException

var p = new Persona();  // Correcto: creamos el objeto

Error 2: exponer campos públicos

// Incorrecto: estado expuesto sin control
// public string Nombre;   // campo público

// Correcto: propiedad con get/set
public string Nombre { get; set; }

Error 3: usar la clase en vez del objeto

// Persona.Saludar();   // error: Saludar es de instancia, no static
var p = new Persona();
p.Saludar();           // correcto

9 · Resumen

  • Una clase agrupa campos, propiedades y métodos.
  • new crea un objeto; la variable guarda su referencia.
  • Propiedades automáticas { get; set; } generan el campo de respaldo.
  • Los objetos pueden contener referencias a otros objetos.

10 · Preguntas frecuentes

¿Qué es un backing field?

El campo privado que respalda una propiedad. En las propiedades automáticas, el compilador lo crea por ti de forma oculta.

¿Por qué usar propiedades en vez de campos públicos?

Las propiedades permiten añadir validación o lógica al leer/escribir, y cambiar la implementación interna sin romper a los consumidores.

¿Qué es value en un setter?

Es la palabra reservada que representa el valor que se está asignando a la propiedad dentro de su set.
