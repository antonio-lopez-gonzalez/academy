Propiedades

Módulo 2 · POO en C# 35 minutos

1 · Introducción

Las propiedades son el mecanismo de C# para acceder al estado de un objeto de forma controlada. Van desde las más simples ({ get; set; }) hasta propiedades calculadas con lógica y validación.

Objetivo

Dominar los tipos de propiedades: automáticas, completas, calculadas, de solo lectura, init y expression-bodied.

2 · Teoría

Propiedades automáticas

class Persona
{
    public string Nombre { get; set; }     // lectura y escritura
    public int Edad { get; private set; }  // escritura privada
}

El compilador genera un backing field oculto. Es la forma más común.

Propiedades completas (con backing field)

Cuando necesitas lógica en el acceso, defines el campo de respaldo explícitamente:

class Persona
{
    private string _nombre = "";

    public string Nombre
    {
        get { return _nombre; }
        set
        {
            if (string.IsNullOrWhiteSpace(value))
                throw new ArgumentException("Nombre vacío");
            _nombre = value;
        }
    }
}

get, set e init

AccesorFunción
getLeer el valor
setAsignar el valor (puede ser privado)
initAsignar solo al crear el objeto (inmutable después)
 
class Persona
{
    public string Nombre { get; init; }   // solo en el inicializador o constructor

    public int Edad { get; set; }
}

var p = new Persona { Nombre = "Ana" };   // init: OK aquí
// p.Nombre = "Luis";                     // Error: init no permite reasignar

Propiedades calculadas

Una propiedad puede devolver un valor calculado, sin campo de respaldo:

class Rectangulo
{
    public double Ancho { get; set; }
    public double Alto { get; set; }

    public double Area => Ancho * Alto;   // calculada: sin campo
}

Propiedades de solo lectura

class Persona
{
    public string Nombre { get; }   // solo lectura (solo get)

    public Persona(string nombre) { Nombre = nombre; }
}

Expression-bodied properties

Para getters/setters de una línea, la sintaxis => es más compacta:

class Persona
{
    private string _nombre = "";

    public string Nombre
    {
        get => _nombre;
        set => _nombre = value ?? throw new ArgumentNullException(nameof(value));
    }

    public bool TieneNombre => !string.IsNullOrEmpty(_nombre);   // calculada
}

3 · Ejemplo mínimo

public string Nombre { get; private set; }

Lectura pública, escritura privada: la forma más habitual de encapsular un dato que solo cambia internamente.

4 · Ejemplo real

Una clase con validación, propiedad calculada y init:

class Producto
{
    private decimal _precio;

    public string Nombre { get; init; }   // inmutable tras crear

    public decimal Precio
    {
        get => _precio;
        set
        {
            if (value < 0) throw new ArgumentException("Precio negativo");
            _precio = value;
        }
    }

    public bool EsCaro => _precio > 100;   // calculada
}

var p = new Producto { Nombre = "Monitor", Precio = 199.99m };
Console.WriteLine($"{p.Nombre} es caro: {p.EsCaro}");

10 · Preguntas frecuentes

¿Propiedad o método?

Propiedad para exponer/leer estado (rápido, sin efectos). Método para operaciones con lógica o que modifican estado.

¿Qué diferencia hay entre init y set privado?

init permite asignar solo en la creación (inicializador o constructor). Un set privado permite reasignar desde dentro de la clase en cualquier momento.

¿Las propiedades calculadas ocupan memoria?

No almacenan nada; calculan en cada acceso. Por eso deben ser baratas de calcular.
