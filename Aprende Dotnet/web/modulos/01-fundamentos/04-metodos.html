Métodos

Módulo 1 · Fundamentos de C# 45 minutos

1 · Introducción

Un método es un bloque de código con nombre que recibe datos (parámetros), hace algo y opcionalmente devuelve un resultado. Son la unidad básica para reutilizar código y dividir un problema grande en trozos manejables.

Si vienes de otros lenguajes: un método en C# es lo que en JavaScript llamas "función" y en Python "función" también.

Objetivo

Declarar y usar métodos, dominar los parámetros (opcionales, con nombre, ref/out/in) y entender la sobrecarga.

2 · Teoría

Anatomía de un método

//  tipo de retorno  nombre    parámetros
static int Sumar(int a, int b)
{
    return a + b;   // devuelve el resultado
}
  • Tipo de retorno: qué tipo devuelve (int, string, etc.).
  • Nombre: PascalCase (Sumar, CalcularTotal).
  • Parámetros: datos de entrada, con su tipo.
  • static: en top-level statements los métodos suelen ser estáticos; más adelante veremos métodos de instancia.

void: sin retorno

static void Saludar(string nombre)
{
    Console.WriteLine($"Hola, {nombre}");
    // no hay return
}

Parámetros opcionales

Puedes dar un valor por defecto. El parámetro opcional se omite al llamar:

static string SaludarConTitulo(string nombre, string titulo = "Sr./Sra.")
{
    return $"{titulo} {nombre}";
}

SaludarConTitulo("Ana");            // "Sr./Sra. Ana"
SaludarConTitulo("Ana", "Dra.");    // "Dra. Ana"

Parámetros con nombre

Al llamar, puedes nombrar los argumentos para claridad o para cambiar el orden:

CrearUsuario(nombre: "Ana", edad: 30);
CrearUsuario(edad: 30, nombre: "Ana");   // mismo resultado

Sobrecarga (overload)

Puedes tener varios métodos con el mismo nombre si sus parámetros son distintos:

static int Sumar(int a, int b) => a + b;
static int Sumar(int a, int b, int c) => a + b + c;
static double Sumar(double a, double b) => a + b;

ref, out e in

Por defecto, los parámetros pasan el valor (se copia). Para pasar una referencia o devolver varios valores:

// ref: pasa una referencia (el método puede leer y modificar)
static void Incrementar(ref int valor) => valor++;

int n = 5;
Incrementar(ref n);   // n = 6

// out: el método DEBE asignar; se usa para devolver varios valores
static void Dividir(int a, int b, out int cociente, out int resto)
{
    cociente = a / b;
    resto = a % b;
}

Dividir(10, 3, out int c, out int r);   // c=3, r=1

// in: referencia de solo lectura (evita copiar estructuras grandes)
static void Mostrar(in int valor) => Console.WriteLine(valor);
No abuses

ref y out hacen el código menos legible. Úsalos solo cuando de verdad los necesites (devolver varios valores o rendimiento extremo).

Introducción a las lambdas

Una lambda es una función anónima y compacta. La verás a fondo en la lección de delegados, pero aquí tienes el sabor:

// En vez de un método completo, una expresión en línea
Func<int, int, int> sumar = (a, b) => a + b;
Console.WriteLine(sumar(2, 3));   // 5

3 · Ejemplo mínimo

static int Sumar(int a, int b)
{
    return a + b;
}

int resultado = Sumar(3, 4);
Console.WriteLine(resultado);   // 7

4 · Ejemplo real

Métodos que calculan el total de una factura con IVA y un descuento opcional:

const decimal Iva = 0.21m;

static decimal CalcularTotal(decimal precio, int cantidad, decimal descuento = 0m)
{
    decimal subtotal = precio * cantidad;
    decimal conIva = subtotal * (1 + Iva);
    return conIva - descuento;
}

decimal total = CalcularTotal(precio: 25.50m, cantidad: 3, descuento: 5m);
Console.WriteLine($"Total a pagar: {total:C}");

6 · Errores habituales

Error 1: no devolver en todos los caminos

// Incorrecto: si condicion es false, no hay return
static int Obtener(int x)
{
    if (x > 0) return x;
    // falta return
}

Error 2: olvidar el tipo del parámetro

// Incorrecto
// static int Sumar(a, b) => a + b;

// Correcto: cada parámetro lleva su tipo
static int Sumar(int a, int b) => a + b;

Error 3: confundir out con ref

// out: no requiere valor inicial (lo asigna el método)
// ref: sí requiere valor inicial (el método puede leerlo)

9 · Resumen

  • Un método: tipo de retorno + nombre + parámetros + cuerpo.
  • void para métodos sin retorno.
  • Parámetros opcionales (con valor por defecto) y con nombre.
  • Sobrecarga: mismo nombre, distinta firma.
  • ref (lee/modifica), out (asigna), in (solo lectura).

10 · Preguntas frecuentes

¿Por qué muchos métodos llevan static?

En top-level statements no hay un objeto contenedor, así que los métodos deben ser static. Cuando trabajes con clases (próximo curso), usarás métodos de instancia sin static.

¿Qué es la "firma" de un método?

Su nombre + el tipo y orden de sus parámetros. El tipo de retorno no cuenta para la firma; por eso la sobrecarga se basa en los parámetros.

¿Puedo devolver más de un valor?

Sí, con parámetros out, o devolviendo una tupla: (int, int) Dividir(...) => (a / b, a % b);.
