Archivos, directorios y JSON

Módulo 1 · Fundamentos de C# 45 minutos

1 · Introducción

Casi toda aplicación real lee o escribe archivos y, hoy en día, la mayoría intercambia datos en JSON. C# ofrece las clases File, Directory, Path y Stream para el sistema de archivos, y System.Text.Json para serializar y deserializar.

Objetivo

Leer/escribir archivos y directorios, y convertir objetos a JSON y viceversa.

2 · Teoría

Leer y escribir archivos con File

La clase File ofrece métodos estáticos sencillos para operaciones puntuales:

using System.IO;

// Escribir todo el contenido (sobrescribe)
File.WriteAllText("archivo.txt", "Hola, mundo");

// Añadir al final
File.AppendAllText("archivo.txt", " (añadido)");

// Leer todo el contenido
string contenido = File.ReadAllText("archivo.txt");

// Leer línea a línea
string[] lineas = File.ReadAllLines("archivo.txt");

// Comprobar existencia
if (File.Exists("archivo.txt")) { /* ... */ }

Copiar, mover y eliminar

File.Copy("origen.txt", "destino.txt", overwrite: true);
File.Move("viejo.txt", "nuevo.txt");   // mueve (o renombra)
File.Delete("archivo.txt");

FileInfo

Cuando trabajas con un archivo varias veces, FileInfo (objeto) es más cómodo:

var info = new FileInfo("archivo.txt");
long tamano = info.Length;
DateTime modificado = info.LastWriteTime;
bool existe = info.Exists;

Directorios

// Crear directorio (y sus padres)
Directory.CreateDirectory("datos/informes");

// Comprobar existencia
if (Directory.Exists("datos")) { /* ... */ }

// Listar archivos
string[] archivos = Directory.GetFiles("datos");

// Buscar con patrón (recursivo)
string[] txts = Directory.GetFiles("datos", "*.txt", SearchOption.AllDirectories);

Rutas con Path

string ruta = Path.Combine("datos", "informes", "mes.txt");  // une con el separador correcto
string nombreArchivo = Path.GetFileName(ruta);   // "mes.txt"
string extension = Path.GetExtension(ruta);      // ".txt"
string dir = Path.GetDirectoryName(ruta);        // "datos\informes"
Usa Path.Combine

No concatenes rutas con + "/" +: el separador varía entre sistemas operativos. Path.Combine lo resuelve.

Streams: StreamReader y StreamWriter

Para archivos grandes o lectura progresiva, los streams leen/escriben de forma incremental:

// Escribir con StreamWriter
using (var writer = new StreamWriter("archivo.txt"))
{
    writer.WriteLine("Línea 1");
    writer.WriteLine("Línea 2");
}

// Leer con StreamReader
using (var reader = new StreamReader("archivo.txt"))
{
    string? linea;
    while ((linea = reader.ReadLine()) != null)
    {
        Console.WriteLine(linea);
    }
}

El using garantiza que el stream se cierre (libere el archivo) al terminar.

JSON: serializar y deserializar

System.Text.Json convierte objetos a JSON (serializar) y JSON a objetos (deserializar):

using System.Text.Json;

var persona = new Persona("Ana", 30);

// Serializar: objeto → string JSON
string json = JsonSerializer.Serialize(persona);
// {"Nombre":"Ana","Edad":30}

// Deserializar: string JSON → objeto
Persona? recuperada = JsonSerializer.Deserialize<Persona>(json);

record Persona(string Nombre, int Edad);
System.Text.Json, no Newtonsoft

El curso usa System.Text.Json (integrado, más rápido y moderno). Newtonsoft.Json es la librería antigua de terceros que hoy se evita en proyectos nuevos.

JSON con opciones

var opciones = new JsonSerializerOptions
{
    WriteIndented = true,                 // formato legible (con saltos e indentación)
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase
};

string jsonBonito = JsonSerializer.Serialize(persona, opciones);
Console.WriteLine(jsonBonito);
// {
//   "nombre": "Ana",
//   "edad": 30
// }

3 · Ejemplo mínimo

using System.IO;
using System.Text.Json;

File.WriteAllText("datos.json", JsonSerializer.Serialize(new { Saludo = "Hola" }));
string contenido = File.ReadAllText("datos.json");
Console.WriteLine(contenido);   // {"Saludo":"Hola"}

4 · Ejemplo real

Guardar una lista de tareas en un archivo JSON y volver a leerla:

using System.IO;
using System.Text.Json;

var tareas = new List<Tarea>
{
    new("Estudiar C#", false),
    new("Hacer la compra", true),
};

// Guardar
string json = JsonSerializer.Serialize(tareas, new JsonSerializerOptions { WriteIndented = true });
File.WriteAllText("tareas.json", json);

// Leer
string leido = File.ReadAllText("tareas.json");
var cargadas = JsonSerializer.Deserialize<List<Tarea>>(leido);

foreach (var t in cargadas ?? new())
    Console.WriteLine($"[{(t.Completada ? "x" : " ")}] {t.Descripcion}");

record Tarea(string Descripcion, bool Completada);

6 · Errores habituales

Error 1: concatenar rutas a mano

// Incorrecto: "datos" + "/" + "archivo.txt" no es portable
// Correcto:
string ruta = Path.Combine("datos", "archivo.txt");

Error 2: no cerrar el stream

// Incorrecto: el archivo queda bloqueado
// var writer = new StreamWriter("x.txt"); writer.Write("...");

// Correcto: using lo cierra
using (var writer = new StreamWriter("x.txt")) { writer.Write("..."); }

Error 3: deserializar sin comprobar null

// Deserialize devuelve null si el JSON es inválido para el tipo.
// Comprueba el resultado o usa un tipo no anulable con opciones.

10 · Preguntas frecuentes

¿File.WriteAllText o StreamWriter?

File.WriteAllText para archivos pequeños y escritura de una vez. StreamWriter para archivos grandes o escritura progresiva.

¿Qué es serializar?

Convertir un objeto en un formato que se puede guardar o transmitir (como JSON). Deserializar es el proceso inverso.

¿JSON es sensible a mayúsculas en las propiedades?

Sí. Por defecto System.Text.Json respeta el nombre exacto. Puedes cambiarlo con PropertyNamingPolicy o atributos [JsonPropertyName].
