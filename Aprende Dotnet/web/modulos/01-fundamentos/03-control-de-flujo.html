Control de flujo

Módulo 1 · Fundamentos de C# 45 minutos

1 · Introducción

Un programa no ejecuta siempre las mismas líneas en el mismo orden: necesita decidir (condicionales) y repetir (bucles). Estas dos capacidades, junto con las variables, ya te permiten escribir casi cualquier programa.

Objetivo

Dominar if/else, switch y los cuatro bucles de C#, junto con break y continue.

2 · Teoría

Condicionales: if / else / else if

int nota = 7;

if (nota >= 9)
{
    Console.WriteLine("Sobresaliente");
}
else if (nota >= 7)
{
    Console.WriteLine("Notable");
}
else if (nota >= 5)
{
    Console.WriteLine("Aprobado");
}
else
{
    Console.WriteLine("Suspenso");
}

Las llaves { } delimitan el bloque. Para una sola instrucción puedes omitirlas, pero es mejor práctica ponerlas siempre.

switch clásico

string dia = "lunes";

switch (dia)
{
    case "lunes":
        Console.WriteLine("Inicio de semana");
        break;
    case "viernes":
        Console.WriteLine("¡Casi finde!");
        break;
    default:
        Console.WriteLine("Día normal");
        break;
}

El break evita que la ejecución "caiga" al siguiente caso (a diferencia de lenguajes como JavaScript antiguo). En C# es obligatorio salir de cada case.

Switch expressions (más moderno)

Cuando el switch solo devuelve un valor, la switch expression es mucho más limpia:

string dia = "viernes";

string tipo = dia switch
{
    "lunes" => "Inicio de semana",
    "viernes" => "¡Casi finde!",
    "sabado" or "domingo" => "Fin de semana",
    _ => "Día normal"
};
Console.WriteLine(tipo);

El patrón _ es el caso por defecto ("para todo lo demás"). or permite agrupar valores.

Bucles: for

// (inicialización; condición; incremento)
for (int i = 0; i < 5; i++)
{
    Console.WriteLine($"Iteración {i}");
}

Bucles: while y do while

// while: comprueba ANTES de cada vuelta (puede no ejecutarse nunca)
int contador = 0;
while (contador < 3)
{
    Console.WriteLine(contador);
    contador++;
}

// do while: se ejecuta AL MENOS una vez
int n = 0;
do
{
    Console.WriteLine(n);
    n++;
} while (n < 3);

Bucles: foreach

El bucle por excelencia para recorrer colecciones. No gestionas índices; recorres elemento a elemento:

string[] frutas = { "manzana", "pera", "uva" };

foreach (string fruta in frutas)
{
    Console.WriteLine(fruta);
}

break y continue

for (int i = 0; i < 10; i++)
{
    if (i == 3) continue;   // salta esta vuelta y pasa a la siguiente
    if (i == 7) break;      // sale del bucle por completo
    Console.WriteLine(i);   // imprime 0,1,2,4,5,6
}

3 · Ejemplo mínimo

// Imprimir solo los números pares del 1 al 10
for (int i = 1; i <= 10; i++)
{
    if (i % 2 != 0) continue;
    Console.WriteLine(i);
}

4 · Ejemplo real

Un menú interactivo con bucle y switch, patrón típico de apps de consola:

string? opcion;
do
{
    Console.WriteLine("1. Ver saldo");
    Console.WriteLine("2. Depositar");
    Console.WriteLine("3. Salir");
    Console.Write("Elige: ");
    opcion = Console.ReadLine();

    switch (opcion)
    {
        case "1":
            Console.WriteLine("Saldo: 150.00 €");
            break;
        case "2":
            Console.WriteLine("Depósito realizado");
            break;
        case "3":
            Console.WriteLine("Adiós");
            break;
        default:
            Console.WriteLine("Opción no válida");
            break;
    }
} while (opcion != "3");

6 · Errores habituales

Error 1: bucle infinito

// Incorrecto: olvidar incrementar el contador
int i = 0;
while (i < 5) { Console.WriteLine(i); }  // nunca termina

// Correcto
while (i < 5) { Console.WriteLine(i); i++; }

Error 2: olvidar break en switch

// Incorrecto: sin break no compila
switch (x) { case 1: Console.WriteLine("uno"); }  // error

// Correcto
switch (x) { case 1: Console.WriteLine("uno"); break; }

Error 3: confundir = y == en un if

// Incorrecto: asigna en vez de comparar
// if (edad = 18) { }  // error de compilación en C#

// Correcto
if (edad == 18) { }

9 · Resumen

  • if / else if / else para decisiones.
  • switch clásico (con break) y switch expression (con =>).
  • Bucles: for, while, do while, foreach.
  • break sale del bucle; continue salta a la siguiente iteración.

10 · Preguntas frecuentes

¿Cuándo uso while y cuándo for?

for cuando conoces de antemano cuántas veces iterar (recorrer un rango). while cuando no lo sabes (depende de una condición externa, como la entrada del usuario).

¿Qué es el patrón _ en switch?

Es el "descarte": representa cualquier valor no cubierto por los casos anteriores, es decir, el default de la switch expression.

¿Puedo recorrer un for al revés?

Sí: for (int i = 10; i >= 0; i--). Controlas tú la inicialización, la condición y el paso.
