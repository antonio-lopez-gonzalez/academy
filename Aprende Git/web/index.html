Git es un grafo, no una carpeta con copias

Un commit es una foto de un árbol, con un puntero al padre. Una rama es solo un puntero a un commit. Entender esto convierte "comandos que memorizar" en tres estados que mover: el directorio de trabajo, el índice y HEAD.

Para quién es

Para quien ya programa y usa Git de memoria, pero no entiende el modelo, duda al deshacer y le dan miedo las ramas, el rebase y la historia compartida. Aquí aprenderás el por qué y perderás el miedo a equivocarte.

Sin miedo a deshacer

Casi todo lo que Git "borra" es recuperable: el reflog guarda lo que ya no ves. Aprenderás a deshacer con la herramienta correcta y, sobre todo, a saber cuándo no está bien reescribir lo que ya compartiste.
