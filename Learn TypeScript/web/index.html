Como funciona este curso

Cada leccion sigue siempre la misma estructura

Introduccion → Teoria (con el por que) → Ejemplo minimo → Ejemplo real → Buenas practicas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabras donde estas y que esperar.

Ejemplos que ves al instante

La carpeta ejemplos/ contiene ejercicios de TypeScript que puedes compilar y ejecutar directamente. Sin instalar nada mas que Node.js. Los proyectos grandes en proyectos/ usan Vite + TypeScript.

Para quien es

Para desarrolladores que ya saben JavaScript y quieren dominar TypeScript profesionalmente. No necesitas saber TypeScript, pero si conocer bien JavaScript (funciones, objetos, arrays, modulos ES, async/await). El modulo 8 introduce TypeScript con React para quien quiera usarlo en el frontend.
