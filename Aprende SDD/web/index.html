spec.md — curso-spec-driven-development fuente de verdad

Un curso completo en español de Spec-Driven Development: anatomía de una spec, el ciclo specify → plan → implement → verify, specs para agentes de código, contratos, deltas y un proyecto final Lumen especificado e implementado de punta a punta. Escrito para desarrolladores que quieren intención versionada, no chats evaporados.

Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Todo vive en Markdown y Git

Specs, planes, ADRs y skills son ficheros versionados en tu repo: sin cuentas de pago, sin SaaS, sin nube. El CLI de ejemplo (Lumen) corre con node en Linux, macOS y Windows.

Para quién es

Para desarrolladores que ya programan y usan (o van a usar) un agente de código: de “pedir cosas en el chat” a trabajar con una spec que un humano o un agente puede implementar sin adivinar. El hilo conductor es Lumen, una bandeja de notas especificada de verdad.

Esta Academy ya es spec-driven

Cada curso de esta Academy nace de un spec.md con skills de apoyo. Este curso te enseña el método que lo hizo posible — y te señala dónde mirar cuando un ejemplo te resulte familiar.
