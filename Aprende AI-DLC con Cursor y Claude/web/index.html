ai-dlc — inventario gate pendiente

Un curso completo en español de AI-DLC (AI-Driven Development Life Cycle): fases, etapas, perfiles de workflow, gates de aprobación, agentes, sensores y audit trail. Ejecutado en los dos entornos que más se usan: Claude Code (CLI) y Cursor (IDE). Con un motor de workflows real en Node.js.

Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Misma metodología, dos harnesses

AI-DLC es un motor con varias «shells». El mismo plan, las mismas etapas y los mismos gates corren en Claude Code y en Cursor. Lo que cambia es dónde viven las reglas, cómo se invoca /aidlc y cómo se renderizan las aprobaciones. El curso te enseña ambos caminos sin tratar ninguno como el «correcto».

Para quién es

Para quien ya programa y quiere dejar de confiar en que el agente «se acuerde» del contexto. Si te preocupan las decisiones sin registro, los cambios que nadie aprobó o los equipos donde cada uno usa la IA a su manera, este es tu curso.

El humano conduce

AI-DLC no promete autonomía total: promete que el agente trabaja dentro de un ciclo verificable y que tú decides en cada gate. La auditoría, los sensores y las reglas existen para que el trabajo sea reconstruible, no para sustituir tu criterio.
