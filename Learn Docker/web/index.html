Todo se ejecuta en tu máquina

Docker, Compose, kind y Helm funcionan en Linux, macOS y Windows (con WSL2), sin cuentas de pago ni nubes. Los comandos y manifiestos del curso son reales y verificados.

Para quién es

Para desarrolladores que ya programan pero quieren dominar la contenerización y la orquestación en profundidad: de docker run a un clúster de Kubernetes con Helm. El hilo conductor es HarborTasks, un stack real (nginx + Node.js + PostgreSQL).

Windows / WSL2

En Windows el curso se trabaja dentro de WSL2 con Docker Desktop: el módulo 0 tiene una lección dedicada a montarlo correctamente. Cada lección señala las diferencias entre Linux, macOS y Windows cuando existen.
