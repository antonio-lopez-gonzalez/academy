Referencia rápida 🧭 por intención · MinIO Community + mc + minio-js

El mapa antes de los comandos

MinIO implementa la API S3: guardas objetos (datos + metadatos) bajo una clave dentro de un bucket. No hay carpetas reales: los prefijos son parte de la clave. Antes de crear nada, decide el modelo de claves y quién puede leerlas.

bucket: documentos
├── 2026/facturas/1042.pdf         ← la clave completa es "2026/facturas/1042.pdf"
├── 2026/facturas/1043.pdf
└── tmp/upload-8f3a.pdf            ← lifecycle lo expira a los 7 días

objeto = bytes + content-type + metadatos + ETag
prefijo ≠ carpeta: es un prefijo de la clave, no un directorio del sistema
Si buscas…Quién lo garantizaMecanismo
Que un objeto no se pierdaMinIOErasure coding + réplica / modo distribuido
Que nadie lea un bucket privadoPolíticasBucket policy + usuario de mínimo privilegio
Subir sin dar credencialesFirmaPresigned URL con expiración
Recuperar un borradoVersionadoVersiones + delete marker
No acumular basuraLifecycleReglas de expiración y transición

La regla del curso: root solo para arrancar. La aplicación usa un usuario con una política acotada y, cuando puede, una presigned URL. Ver Usuarios y políticas.

Levantar el servidor y mirarlo

# Servidor local (API S3 en 9000, consola en 9001)
docker run -p 9000:9000 -p 9001:9001 \
  --name minio \
  -v ~/minio/data:/data \
  -e "MINIO_ROOT_USER=minioadmin" \
  -e "MINIO_ROOT_PASSWORD=cambia-esto-123" \
  quay.io/minio/minio server /data --console-address ":9001"

# Con Compose (recomendado en el curso)
docker compose up -d
docker compose logs -f minio

# Consola: http://localhost:9001
# Health de la API S3
curl -I http://localhost:9000/minio/health/live

Compose es para un solo nodo. MinIO no soporta Docker Compose para clústeres distribuidos; para eso usa Kubernetes Operator o baremetal. No presentes un Compose multi-nodo como arquitectura de producción.

mc: buckets y objetos

# Alias del servidor
mc alias set local http://127.0.0.1:9000 minioadmin cambia-esto-123
mc admin info local

# Buckets
mc mb local/documentos
mc ls local
mc stat local/documentos

# Objetos
mc cp informe.pdf local/documentos/2026/facturas/1042.pdf
mc ls local/documentos/2026/facturas/
mc stat local/documentos/2026/facturas/1042.pdf
mc cat local/documentos/2026/facturas/1042.pdf > copia.pdf
mc rm local/documentos/2026/facturas/1042.pdf

# Espejo (copia incremental) y borrado recursivo
mc mirror ./documentos local/documentos
mc rm --recursive --force local/documentos/tmp/

# Presigned URL temporal
mc share download --expire 1h local/documentos/2026/facturas/1042.pdf

SDK de Node.js

import * as Minio from "minio";

const client = new Minio.Client({
  endPoint: process.env.MINIO_ENDPOINT ?? "127.0.0.1",
  port: Number(process.env.MINIO_PORT ?? 9000),
  useSSL: process.env.MINIO_USE_SSL === "true",
  accessKey: process.env.MINIO_ACCESS_KEY,
  secretKey: process.env.MINIO_SECRET_KEY,
});

const bucket = "documentos";
if (!(await client.bucketExists(bucket))) {
  await client.makeBucket(bucket, "us-east-1");
}

// Subida desde Buffer o stream
await client.putObject(bucket, "2026/facturas/1042.pdf", buffer, buffer.length, {
  "Content-Type": "application/pdf",
  "x-amz-meta-tenant": "acme",
});

// URL firmada para que el navegador suba/descargue sin credenciales
const putUrl = await client.presignedPutObject(bucket, "tmp/8f3a.pdf", 15 * 60);
const getUrl = await client.presignedGetObject(bucket, "2026/facturas/1042.pdf", 60 * 60);

// Listado por prefijo
const stream = client.listObjectsV2(bucket, "2026/", true);
stream.on("data", (obj) => console.log(obj.name, obj.size));
stream.on("error", console.error);

DescargargetObject(bucket, key) (stream)
Firmar subidapresignedPutObject(bucket, key, expiry)
Firmar descargapresignedGetObject(bucket, key, expiry)

Usuarios, políticas y presigned URLs

# Usuario de aplicación (no root)
mc admin user add local app 'secreto-largo-y-aleatorio'
mc admin policy attach local readwrite --user app

# Política propia de mínimo privilegio
cat > documentos-rw.json <<'JSON'
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
    "Resource": ["arn:aws:s3:::documentos/*"]
  }]
}
JSON
mc admin policy create local documentos-rw documentos-rw.json
mc admin policy attach local documentos-rw --user app

# Presigned: corta, acotada y con HTTPS en producción
mc share download --expire 15m local/documentos/2026/facturas/1042.pdf
RiesgoMitigación
Root en la appUsuario con política acotada
Bucket público «temporal»Presigned URL en su lugar
URL que no caducaExpiración corta y mínima acción
HTTP en tránsitoTLS en el servidor y en el cliente
Datos en reposo sin cifrarSSE-S3 / SSE-KMS según el caso

Una presigned URL es una credencial temporal. No la registres en logs, no la publiques y no la generes con root. Si se filtra, cualquiera puede usarla hasta que expire.

Lifecycle, réplica y eventos

# Versionado (imprescindible para borrados recuperables)
mc version enable local/documentos

# Lifecycle: expirar temporales a los 7 días
mc ilm rule add local/documentos --expire-days 7 --prefix "tmp/"

# Réplica de bucket a otro sitio
mc replicate add local/documentos \
  --remote-bucket https://otro-minio/documentos \
  --replicate "delete,delete-marker"

# Notificaciones a webhook
mc event add local/documentos arn:minio:sqs::1:webhook \
  --event put --suffix ".pdf"
mc event list local/documentos

Prueba la restauración, no solo el backup. Un backup que nunca se ha restaurado es una hipótesis. El curso incluye una lección específica de backups y retención.

Anti-patrones que este curso evita

Anti-patrónPor qué dueleAlternativa
Root en la aplicaciónUn fallo compromete todo el servidorUsuario y política acotados
Bucket públicoFiltración silenciosaPrivado + presigned
Guardar archivos en disco localNo escala ni sobrevive al contenedorObjetos con claves estables
Contar con carpetasRenombrar un «directorio» copia cada objetoDiseñar la clave desde el inicio
Sin versionadoUn borrado es definitivoVersionado + lifecycle
Compose multi-nodoNo está soportadoKubernetes Operator o baremetal

Vuelve al modelo de objetos cuando dudes: casi todos los errores vienen de tratar un bucket como un sistema de ficheros.
