Un prefijo no es una carpeta

S3 no tiene directorios: tiene objetos con una clave como 2026/facturas/1042.pdf. La consola dibuja carpetas para que te sientas cómodo, pero la clave es plana. Entenderlo cambia cómo listas, cómo renombras y cuánto pagas.

Para quién es

Para quien ya programa y ha guardado archivos en disco o en base de datos, pero quiere hacerlo bien: subidas directas, permisos, versiones, caducidad y recuperación. Si algún día has dicho «luego lo paso a S3», este es tu curso.

El almacenamiento también se opera

Tener discos no es tener durabilidad. Erasure coding, réplica, lifecycle y backups se diseñan y se prueban. Aquí no solo subimos objetos: aprendemos a no perderlos.
