Glosario de JavaScript

Referencia 📖 Términos clave

A

AbortController
API que permite cancelar peticiones asíncronas (fetch, etc.) pasando una signal. Esencial para timeouts y cancelación al cambiar de vista.
Array
Estructura de datos ordenada y de tamaño dinámico que almacena múltiples valores (de cualquier tipo). Es un objeto con métodos de iteración.
Array.fromAsync (ES2025)
Variante asíncrona de Array.from(): crea un array desde un async iterable (o un iterable de promesas) esperando cada valor de forma secuencial. Se usa con await.
Arrow function
Función definida con =>. No tiene su propio this, arguments ni puede ser constructora; hereda el contexto del ámbito donde se define.
async/await
Sintaxis que simplifica el trabajo con promesas: async marca una función que devuelve una promesa, y await pausa su ejecución hasta que la promesa se resuelva.

B

BOM (Browser Object Model)
Conjunto de APIs del navegador accesibles desde JS: window, location, history, navigator. Complementa al DOM.
Breakpoint (punto de interrupción)
Marca en el depurador que pausa la ejecución en una línea concreta para inspeccionar el estado, la pila de llamadas y las variables.
Bundler
Herramienta (Vite, esbuild, Rollup) que combina los módulos de una aplicación en archivos optimizados para producción. Vite usa esbuild/Rollup.
Burbuja (event bubbling)
Fase de propagación de eventos en la que un evento disparado en un nodo sube hacia sus ancestros hasta el documento.

C

Call stack (pila de llamadas)
Estructura LIFO que registra las funciones en ejecución. Al terminar una función, se desapila y se reanuda la llamadora.
Callback
Función que se pasa como argumento a otra función para que se ejecute cuando termine (o ante un evento). Base histórica de la asincronía.
Closure
Función que "recuerda" las variables del ámbito donde fue creada, incluso después de que ese ámbito haya terminado.
Coerción de tipos
Conversión automática e implícita que hace JavaScript entre tipos (ej. "5" + 2 → "52"). Origen de muchos bugs; se controla con === y comparaciones explícitas.
CRUD
Acrónimo de Create, Read, Update, Delete: las cuatro operaciones básicas de cualquier sistema de datos.

D

DOM (Document Object Model)
Representación en memoria del HTML de una página como un árbol de nodos que JavaScript puede consultar y modificar.
Debounce
Técnica que retrasa la ejecución de una función hasta que pasa un tiempo sin que se vuelva a llamar. Ideal para búsquedas mientras escribes.
Destructuring (desestructuración)
Sintaxis para extraer valores de objetos o arrays en variables individuales: const { a, b } = obj o const [x, y] = arr.
Dynamic import
import() en tiempo de ejecución que carga un módulo bajo demanda y devuelve una promesa. Permite code splitting.

E

Event loop
Mecanismo del motor que procesa tareas: las tareas síncronas primero, luego las microtareas (promesas) y después las macrotareas (setTimeout, I/O). Es la base del modelo asíncrono.
ESM (ES Modules)
Sistema de módulos nativo de JavaScript (import/export), estático y asíncrono. Estándar desde ES2015.
Event delegation
Patrón que coloca un único listener en un ancestro y usa e.target.closest() para manejar eventos de muchos hijos. Mejora rendimiento y memoria.
Expression vs Statement
Una expresión produce un valor (a + b); una sentencia ejecuta una acción (if, return). Las arrow functions de una línea devuelven expresiones.

F

Falsy / Truthy
Valores que se evalúan como false o true en contextos booleanos. Falsy: false, 0, "", null, undefined, NaN. Todo lo demás es truthy.
Fetch API
API estándar para hacer peticiones HTTP desde el navegador y Node. Basada en promesas. Recuerda: no lanza error en respuestas 404/500.
Función pura
Función que, dados los mismos argumentos, devuelve siempre el mismo resultado y no produce efectos secundarios. Facilita el testing y el razonamiento.
Framework
Biblioteca (React, Vue, Angular) que impone una estructura y reglas propias para construir interfaces. Este curso enseña a hacer lo mismo con JavaScript vanilla.

I

Iterator helpers (ES2025)
Métodos de Iterator.prototype (map, filter, take, drop, reduce, toArray...) que portan la API funcional de los arrays a cualquier iterador, con evaluación perezosa: no crean arrays temporales hasta que se consume el iterador.
Inmutabilidad
Principio de no modificar los datos existentes; se crean nuevas versiones con [...spread], toSorted, structuredClone... Facilita predecibilidad, testing y debugging.

P

Promise.try (ES2025)
Método estático que ejecuta una función (síncrona o asíncrona) y envuelve su resultado o su error en una promesa. Evita el try/catch manual para uniformar el manejo asíncrono.

R

RegExp.escape (ES2025)
Método estático que devuelve una cadena con los caracteres especiales de regex escapados, para usarla de forma segura dentro de un patrón con new RegExp().
