El DOM: estructura, nodos y selección

Módulo 5 · DOM y Eventos ⏱ 30 minutos

1 · Introducción

El DOM (Document Object Model) es la representación en memoria de un documento HTML. El navegador parsea el HTML y construye un árbol de nodos donde cada etiqueta, texto y comentario se convierte en un objeto que JavaScript puede leer y modificar. El DOM es el puente entre tu HTML estático y la interactividad dinámica de JavaScript.

Analogía — El plano de una casa: El HTML es el plano (el documento). El DOM es la maqueta 3D que el arquitecto construye a partir del plano: puedes tocarla, mover paredes, añadir muebles. JavaScript es la mano que manipula esa maqueta. Cuando modificas el DOM, el navegador repinta automáticamente lo que el usuario ve.

2 · Teoría

El árbol del DOM

Dado este HTML:

<!DOCTYPE html>
<html>
  <head><title>Mi página</title></head>
  <body>
    <h1>Bienvenido</h1>
    <p>Esto es un <strong>ejemplo</strong></p>
  </body>
</html>

El navegador construye este árbol:

                          document
                              │
                         ┌────▼────┐
                         │  <html>  │  (Element Node)
                         └────┬────┘
                    ┌─────────┴─────────┐
               ┌────▼────┐         ┌───▼───┐
               │ <head>  │         │<body> │  (Element Nodes)
               └────┬────┘         └───┬───┘
               ┌────▼────┐       ┌─────┴──────┐
               │ <title> │    ┌──▼──┐     ┌──▼──┐
               └────┬────┘    │ <h1> │     │ <p> │
               ┌────▼────┐    └──┬───┘     └──┬──┘
               │"Mi pág."│   ┌───▼────┐  ┌────▼────┐
               │(Text)   │   │"Bienv."│  │ <strong> │
               └─────────┘   │(Text)  │  └────┬────┘
                             └────────┘  ┌────▼────┐
                                         │"ejemplo"│
                                         │ (Text)  │
                                         └─────────┘

El objeto document

Es el punto de entrada al DOM. document es un objeto global en el navegador que representa todo el documento cargado:

console.log(document.nodeType);      // 9 (Document node)
console.log(document.documentElement); // <html> (el elemento raíz)
console.log(document.head);            // <head>
console.log(document.body);            // <body>

Selección de elementos

getElementById — la forma más rápida (un solo elemento)

// Devuelve el elemento con id="principal" o null si no existe
const main = document.getElementById('principal');
console.log(main); // <main id="principal">...</main>

querySelector — selector CSS, devuelve la primera coincidencia

// Acepta cualquier selector CSS válido
const primerParrafo = document.querySelector('p');
const activo = document.querySelector('.clase.activa');
const input = document.querySelector('#formulario input[name="email"]');
const li = document.querySelector('ul > li:first-child');

// Devuelve null si no encuentra nada (no lanza error)

querySelectorAll — selector CSS, devuelve TODAS las coincidencias

// Devuelve una NodeList ESTÁTICA
const todosLosParrafos = document.querySelectorAll('p');
console.log(todosLosParrafos.length); // número de <p>

// Se puede iterar con forEach directamente
todosLosParrafos.forEach(p => console.log(p.textContent));

// También se puede convertir a array para usar map, filter, etc.
const parrafosArray = [...todosLosParrafos];
const textos = parrafosArray.map(p => p.textContent);

getElementsByClassName y getElementsByTagName

// Devuelven HTMLCollection VIVA — se actualiza si el DOM cambia
const items = document.getElementsByClassName('item');
const divs = document.getElementsByTagName('div');

console.log(divs.length); // X divs ahora mismo
// Si añado un div nuevo, divs.length cambia automáticamente

Navegación por el DOM

const elemento = document.querySelector('.contenedor');

// Hijos
elemento.children;        // HTMLCollection de elementos hijos (solo tags)
elemento.childNodes;      // NodeList de TODOS los nodos hijos (incluye texto y comentarios)
elemento.firstChild;      // Primer nodo hijo (puede ser texto)
elemento.lastChild;       // Último nodo hijo
elemento.firstElementChild; // Primer ELEMENTO hijo (ignora texto/comentario)
elemento.lastElementChild;  // Último ELEMENTO hijo

// Hermanos
elemento.nextSibling;        // Siguiente nodo hermano (puede ser texto)
elemento.previousSibling;    // Nodo hermano anterior
elemento.nextElementSibling;  // Siguiente ELEMENTO hermano
elemento.previousElementSibling; // ELEMENTO hermano anterior

// Padre
elemento.parentNode;      // Nodo padre (siempre existe; para un elemento suelto es document)
elemento.parentElement;   // Elemento padre (null si el padre no es un elemento)

3 · Ejemplo mínimo

// Dado este HTML hipotético:
// <ul id="lista">
//   <li>Manzana</li>
//   <li>Pera</li>
//   <li>Uva</li>
// </ul>

// 1. Seleccionar la lista por ID
const lista = document.getElementById('lista');
console.log(lista.tagName);  // 'UL'

// 2. Seleccionar todos los <li> dentro de la lista
const items = lista.querySelectorAll('li');
console.log(items.length);   // 3

// 3. Acceder por posición
console.log(items[0].textContent);  // 'Manzana'
console.log(items[1].textContent);  // 'Pera'

// 4. Navegar: del hijo al padre
const primerLi = items[0];
console.log(primerLi.parentElement === lista); // true
console.log(primerLi.nextElementSibling.textContent); // 'Pera'

4 · Ejemplo real

Encontrar y resaltar todos los enlaces externos de una página:

// 1. Seleccionar todos los enlaces de la página
const enlaces = document.querySelectorAll('a[href]');

// 2. Filtrar los que son externos (no apuntan a este dominio)
const dominioActual = window.location.hostname;

const enlacesExternos = [...enlaces].filter(enlace => {
  try {
    const url = new URL(enlace.href);
    return url.hostname !== dominioActual;
  } catch {
    return false; // enlaces inválidos se ignoran
  }
});

// 3. Añadir una marca visual e indicador a cada enlace externo
enlacesExternos.forEach(enlace => {
  // Modificar estilo directamente
  enlace.style.borderBottom = '2px dashed #ff9800';

  // Añadir un icono después del texto
  const icono = document.createElement('span');
  icono.textContent = ' ↗';
  icono.style.fontSize = '0.8em';
  icono.style.color = '#ff9800';
  enlace.appendChild(icono);
});

console.log(`Encontrados ${enlacesExternos.length} enlaces externos`);

// 4. Demostrar HTMLCollection viva
const todosLosDivs = document.getElementsByTagName('div');
console.log(`Antes: ${todosLosDivs.length} divs`);

// Añadir un div dinámicamente
const nuevoDiv = document.createElement('div');
nuevoDiv.textContent = 'Div añadido después';
document.body.appendChild(nuevoDiv);

console.log(`Después: ${todosLosDivs.length} divs`);
// La colección VIVA refleja el nuevo div automáticamente

6 · Errores habituales

Error 1: Intentar manipular un elemento que no existe (todavía)

// ❌ MAL: El script se ejecuta antes de que el DOM esté listo
const boton = document.querySelector('#btn-enviar');
boton.addEventListener('click', () => {}); // TypeError: boton is null

// ✅ CORRECTO: Esperar a que el DOM esté listo
document.addEventListener('DOMContentLoaded', () => {
  const boton = document.querySelector('#btn-enviar');
  boton.addEventListener('click', () => {});
});

// ✅ Alternativa: script con defer en el HTML
// <script src="app.js" defer></script>

Error 2: Modificar el DOM mientras se itera una HTMLCollection viva

// ❌ MAL: Se salta elementos porque la colección cambia mientras iteramos
const items = document.getElementsByClassName('item');
for (let i = 0; i < items.length; i++) {
  items[i].remove(); // La longitud cambia, algunos items se quedan sin eliminar
}

// ✅ CORRECTO: Crear una copia estática primero
const itemsStatic = [...document.getElementsByClassName('item')];
itemsStatic.forEach(item => item.remove());

// ✅ O mejor: querySelectorAll ya devuelve una NodeList estática
document.querySelectorAll('.item').forEach(item => item.remove());

Error 3: No verificar si querySelector encontró el elemento

// ❌ MAL: Usar el resultado sin comprobar null
const precio = document.querySelector('.precio').textContent; // Error si no existe .precio

// ✅ CORRECTO: Siempre verificar o usar optional chaining
const precio = document.querySelector('.precio')?.textContent ?? 'No disponible';

7 · Ejercicio guiado

Objetivo: Implementar una tabla de contenidos automática a partir de los encabezados de la página.

  1. Paso 1: Seleccionar todos los encabezados

    // Selecciona h2 y h3 (los niveles típicos de contenido)
const encabezados = document.querySelectorAll('h2, h3');
console.log(`Encontrados ${encabezados.length} encabezados`);

  2. Paso 2: Construir la estructura de la tabla de contenidos

    const contenedorTOC = document.getElementById('tabla-contenidos');
if (!contenedorTOC) {
  console.warn('No se encontró #tabla-contenidos');
} else {
  const ol = document.createElement('ol');
  ol.classList.add('toc-list');

  encabezados.forEach((heading, index) => {
    const li = document.createElement('li');

    // Crear un enlace que apunte al encabezado
    const a = document.createElement('a');
    a.textContent = heading.textContent;

    // Si el encabezado no tiene id, le asignamos uno
    if (!heading.id) {
      heading.id = `seccion-${index}`;
    }
    a.href = `#${heading.id}`;

    // Si es h3, indentamos (es un sub-nivel)
    if (heading.tagName === 'H3') {
      li.style.paddingLeft = '1.5em';
    }

    li.appendChild(a);
    ol.appendChild(li);
  });

  contenedorTOC.appendChild(ol);
}

  3. Paso 3: Verificar la navegación entre hermanos

    // Encontrar la sección que sigue a cada h2
encabezados.forEach(heading => {
  if (heading.tagName === 'H2') {
    const siguiente = heading.nextElementSibling;
    if (siguiente) {
      console.log(`"${heading.textContent}" → siguiente: <${siguiente.tagName}>`);
    }
  }
});

8 · Reto

🎯 Navegador de breadcrumbs

Crea una función que, dado un elemento del DOM, construya la ruta de breadcrumbs (miga de pan) desde el elemento hasta el <body>:

  • Usa parentElement para subir por el árbol.
  • Para cada ancestro, muestra su tagName y, si tiene id, muéstralo (DIV#contenido).
  • Si tiene classList, muestra la primera clase (SECTION.intro).
  • El resultado debe ser un array de strings desde el elemento más profundo hasta BODY.
  • Bonus: si el ancestro es un <nav> o <header>, márcalo con un asterisco.

9 · Resumen

  • El DOM es un árbol de nodos que representa el HTML. document es la raíz.
  • Tipos de nodos: Element (1), Text (3), Comment (8), Document (9).
  • getElementById es el más rápido. querySelector/All acepta selectores CSS completos.
  • NodeList (estática) de querySelectorAll vs HTMLCollection (viva) de getElementsBy*.
  • Navegación: parentElement, children, nextElementSibling, previousElementSibling.
  • Espera a DOMContentLoaded o usa defer para manipular el DOM de forma segura.

10 · Preguntas frecuentes

¿Cuándo usar HTMLCollection viva en lugar de NodeList estática?

Cuando necesites reflejar automáticamente los cambios del DOM sin volver a seleccionar. Por ejemplo, un sistema de pestañas donde se añaden/eliminan paneles dinámicamente. Pero es muy raro: en la práctica, NodeList estática es más predecible y menos propensa a bugs. Si usas HTMLCollection viva, congélala en un array antes de iterar si vas a modificar el DOM.

¿Por qué childNodes incluye nodos de texto en blanco?

El DOM preserva fielmente el HTML original. Los saltos de línea y la indentación entre etiquetas se convierten en nodos de texto con whitespace. Por eso es mejor usar children (solo elementos) o firstElementChild. Si necesitas procesar TODOS los nodos incluyendo texto, usa childNodes y filtra por nodeType.

¿querySelector funciona en fragmentos de HTML sueltos o solo en el documento?

Funciona en cualquier elemento, no solo en document. Puedes hacer miDiv.querySelector('span.activo') para buscar dentro de un subárbol. Esto es muy útil para acotar la búsqueda y mejorar el rendimiento.
