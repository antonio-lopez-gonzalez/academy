Arrays: creación, acceso, métodos básicos

Módulo 1 · Fundamentos ⏱ 30 minutos

1 · Introducción

Los arrays son la estructura de datos más utilizada en JavaScript. Representan listas ordenadas de elementos y son el caballo de batalla de casi cualquier aplicación: listas de productos, resultados de búsqueda, filas de una tabla, colas de mensajes, coordenadas, configuraciones... todo son arrays.

En esta lección aprenderás a crear arrays de varias formas, acceder a sus elementos (incluyendo índices negativos con at()), y dominar los métodos básicos de mutación (push, pop, shift, unshift, splice) y de acceso (slice, concat, join, indexOf, includes, find).

¿Por qué existe esta lección? Porque elegir el método de array equivocado (especialmente splice cuando quieres slice) es una fuente constante de bugs. Y porque entender que los arrays son objetos con superpoderes numéricos es clave para apreciar el diseño de JavaScript.

2 · Teoría

¿Qué es un array?

Un array en JavaScript es un objeto especial cuyas claves son índices numéricos (0, 1, 2...) y que tiene una propiedad length que se actualiza automáticamente. A diferencia de otros lenguajes, los arrays de JS:

  • Pueden contener elementos de distintos tipos en el mismo array ([1, 'hola', true, null]).
  • Son dinámicos: crecen y se encogen automáticamente.
  • Son objetos: typeof [] devuelve 'object'. Usa Array.isArray([]) para verificar.

Analogía: Un array es como un tren. Cada vagón tiene un número (índice) empezando por 0. Puedes añadir vagones al final (push), quitarlos del final (pop), añadirlos al principio (unshift), quitarlos del principio (shift), o reemplazar vagones en cualquier posición (splice). El maquinista siempre sabe cuántos vagones hay (length).

Creación de arrays

// Literal de array (la forma preferida)
const frutas = ['manzana', 'pera', 'uva'];

// Constructor (evítalo, tiene comportamiento confuso con un solo número)
const vacio1 = new Array();        // []
const vacio2 = new Array(3);       // [vacío × 3]  ← ¡no es [3]!
const lleno = new Array(1, 2, 3);  // [1, 2, 3]   ← solo con múltiples argumentos

// Array.from(): crea array a partir de iterables o array-likes
const desdeString = Array.from('Hola'); // ['H', 'o', 'l', 'a']
const conMap = Array.from([1, 2, 3], x => x * 2); // [2, 4, 6]

// Array.fromAsync() (ES2025): igual que Array.from, pero para fuentes
// ASÍNCRONAS (async iterables, generadores async, promesas). Espera
// secuencialmente cada valor en lugar de lanzar todo en paralelo.
// (Se usa con `await` y se detalla en el módulo de asincronía.)
// const datos = await Array.fromAsync(apiDatosAsync());

// Array.of(): crea array con los argumentos (sin la ambigüedad de new Array)
const unElemento = Array.of(7);     // [7] ← correcto
const varios = Array.of(1, 2, 3);   // [1, 2, 3]

Acceso a elementos

const arr = ['a', 'b', 'c', 'd', 'e'];

arr[0];           // 'a' (primer elemento)
arr[2];           // 'c' (tercer elemento)
arr[arr.length - 1]; // 'e' (último elemento — clásico)

// at() con índices negativos (ES2022) — ¡la forma moderna!
arr.at(0);        // 'a'
arr.at(-1);       // 'e' (último elemento)
arr.at(-2);       // 'd' (penúltimo)

// Fuera de rango
arr[10];          // undefined (no lanza error)
arr.at(10);       // undefined

La propiedad length

const nums = [10, 20, 30];
console.log(nums.length); // 3

// Length es escribible (peculiaridad de JS)
nums.length = 5;  // Amplía el array
console.log(nums); // [10, 20, 30, vacío × 2]

nums.length = 1;  // Trunca el array (¡elimina elementos!)
console.log(nums); // [10]

// Limpiar un array de un golpe
nums.length = 0;  // [] — forma eficiente de vaciar un array

splice: el bisturí quirúrgico

const arr = ['a', 'b', 'c', 'd', 'e'];

// Eliminar: splice(inicio, cuantosAEliminar)
arr.splice(2, 2);  // Devuelve ['c', 'd']; arr queda ['a', 'b', 'e']

// Insertar: splice(inicio, 0, ...elementos)
arr.splice(1, 0, 'x', 'y'); // Inserta en posición 1; arr: ['a', 'x', 'y', 'b', 'e']

// Reemplazar: splice(inicio, cuantosAEliminar, ...elementos)
arr.splice(0, 2, 'z'); // Reemplaza 'a' y 'x' por 'z'; arr: ['z', 'y', 'b', 'e']

const original = [1, 2, 3, 4, 5];

// slice: extrae sin mutar (como slice de strings)
original.slice(1, 3);   // [2, 3] (copias)
original.slice(-2);     // [4, 5] (índices negativos)
original.slice();       // [1, 2, 3, 4, 5] (copia completa, útil para clonar)

// concat: une arrays
const a = [1, 2];
const b = [3, 4];
a.concat(b);         // [1, 2, 3, 4]
a.concat(b, [5, 6]); // [1, 2, 3, 4, 5, 6] (múltiples argumentos)

// join: array → string (inverso de split)
['a', 'b', 'c'].join(', '); // 'a, b, c'
['H', 'o', 'l', 'a'].join(''); // 'Hola'

Búsqueda en arrays

const items = ['manzana', 'pera', 'uva', 'pera'];

items.indexOf('pera');       // 1 (primera ocurrencia)
items.lastIndexOf('pera');   // 3 (última ocurrencia)
items.indexOf('sandía');     // -1 (no encontrado)
items.includes('uva');       // true

// find y findIndex con función de prueba
const nums = [5, 12, 8, 130, 44];
nums.find(n => n > 10);      // 12 (primer elemento que cumple)
nums.findIndex(n => n > 10); // 1 (índice del primer elemento que cumple)
nums.find(n => n > 200);     // undefined (ninguno cumple)

for...of con arrays

const colores = ['rojo', 'verde', 'azul'];

// for...of: itera sobre los VALORES (lo que quieres el 95% del tiempo)
for (const color of colores) {
  console.log(color); // 'rojo', 'verde', 'azul'
}

// También tienes acceso al índice si lo necesitas:
for (const [i, color] of colores.entries()) {
  console.log(`${i}: ${color}`); // '0: rojo', '1: verde', '2: azul'
}

Arrays multidimensionales

// Matriz 3x3 (array de arrays)
const matriz = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

matriz[0][0];   // 1 (fila 0, columna 0)
matriz[2][1];   // 8 (fila 2, columna 1)
matriz[0];      // [1, 2, 3] (la primera fila entera)

3 · Ejemplo mínimo

Operaciones CRUD (Create, Read, Update, Delete) con arrays:

// CREATE: añadir elementos
const tasks = [];                    // Array vacío
tasks.push('Aprender HTML');         // ['Aprender HTML']
tasks.push('Aprender CSS');          // ['Aprender HTML', 'Aprender CSS']
tasks.unshift('Aprender Git');       // ['Aprender Git', 'Aprender HTML', 'Aprender CSS']

// READ: acceder y buscar
console.log(tasks[0]);               // 'Aprender Git'
console.log(tasks.at(-1));           // 'Aprender CSS' (último)
console.log(tasks.includes('Aprender HTML')); // true
console.log(`Tienes ${tasks.length} tareas`); // 'Tienes 3 tareas'

// UPDATE: modificar
const index = tasks.indexOf('Aprender CSS');
if (index !== -1) tasks[index] = 'Aprender CSS Avanzado';

// DELETE: eliminar
const last = tasks.pop();            // Elimina y devuelve 'Aprender CSS Avanzado'
const first = tasks.shift();         // Elimina y devuelve 'Aprender Git'
tasks.splice(0, 1);                  // Elimina 'Aprender HTML' por índice

console.log(tasks);                  // []

4 · Ejemplo real

Sistema de historial de navegación con límite de entradas:

// Historial de páginas visitadas (como el history del navegador)
const MAX_HISTORY = 50;
const history = [];

function visitPage(url) {
  // Si es la misma página que la última visitada, no duplicar
  if (history.at(-1) === url) return;

  // Añadir al final
  history.push(url);

  // Si excede el límite, eliminar las más antiguas
  if (history.length > MAX_HISTORY) {
    const overflow = history.length - MAX_HISTORY;
    history.splice(0, overflow); // Elimina desde el principio
  }
}

function goBack() {
  if (history.length <= 1) {
    console.log('No hay páginas anteriores');
    return null;
  }
  history.pop();                  // Eliminar página actual
  return history.at(-1);         // Devolver la anterior
}

function getRecentPages(count = 5) {
  // slice con índice negativo: últimas 'count' páginas
  return history.slice(-count).reverse();
}

// Simulación
visitPage('/home');
visitPage('/products');
visitPage('/products/laptop');
visitPage('/cart');
visitPage('/checkout');

console.log('Últimas páginas:', getRecentPages(3));
// ['/checkout', '/cart', '/products/laptop']

const previous = goBack();
console.log('Volviendo a:', previous); // '/cart'
console.log('Historial actual:', history);
// ['/home', '/products', '/products/laptop', '/cart']

6 · Errores habituales

Confundir slice con splice

const original = [1, 2, 3, 4, 5];

// ❌ Creer que slice modifica el array
const sub = original.slice(1, 3);
console.log(original); // [1, 2, 3, 4, 5] ← no muta
console.log(sub);      // [2, 3]

// ❌ Usar splice cuando querías slice
const arr = [1, 2, 3, 4, 5];
const mal = arr.splice(1, 3); // ¡MUTA arr!
console.log(arr); // [1, 5] ← destruiste el original sin querer
console.log(mal); // [2, 3, 4]

// ✅ Si no quieres mutar, usa slice
const arr2 = [1, 2, 3, 4, 5];
const bien = arr2.slice(1, 4); // [2, 3, 4], arr2 intacto

Usar new Array() con un solo número

// ❌ new Array(5) NO crea [5], crea un array con 5 huecos vacíos
const mal = new Array(5);
console.log(mal);      // [vacío × 5]
console.log(mal[0]);   // undefined

// ✅ Usa Array.of() para crear [5]
const bien = Array.of(5);
console.log(bien);     // [5]

// ✅ O directamente el literal
const mejor = [5];

Usar delete en arrays

// ❌ delete deja un hueco (no reindexa, length no cambia)
const arr = ['a', 'b', 'c'];
delete arr[1];
console.log(arr);        // ['a', vacío, 'c']
console.log(arr.length); // 3 (¡sigue siendo 3!)
console.log(arr[1]);     // undefined

// ✅ Usa splice para eliminar limpiamente
const arr2 = ['a', 'b', 'c'];
arr2.splice(1, 1);
console.log(arr2);        // ['a', 'c']
console.log(arr2.length); // 2 (correcto)

Asumir que sort() ordena números correctamente

// ❌ sort() sin función de comparación ordena alfabéticamente (como strings)
const nums = [2, 10, 5, 1, 25];
nums.sort();
console.log(nums); // [1, 10, 2, 25, 5] ← ¡no es orden numérico!

// ✅ Pasa siempre una función de comparación para números
const nums2 = [2, 10, 5, 1, 25];
nums2.sort((a, b) => a - b); // Orden ascendente
console.log(nums2); // [1, 2, 5, 10, 25]

9 · Resumen

  • Creación: [] (preferido), Array.from(), Array.of(). Evita new Array(n).
  • Acceso: arr[i], arr.at(i) (soporta índices negativos desde ES2022).
  • Mutación (modifican el array): push/pop (final, O(1)), unshift/shift (inicio, O(n)), splice (cualquier posición).
  • No mutación: slice (copia porción), concat (unir), join (a string).
  • Búsqueda: indexOf, includes, find, findIndex.
  • Iteración: for...of sobre valores; for...of entries() para índice + valor.
  • slice vs splice: una letra de diferencia, comportamientos opuestos. slice no muta.
  • Arrays son objetos: verifica con Array.isArray(), no con typeof.

10 · Preguntas frecuentes

¿Por qué typeof [] devuelve 'object' y no 'array'?

Porque en JavaScript, los arrays son objetos. La especificación define typeof para devolver 'object' para cualquier cosa que no sea uno de los tipos primitivos. Es una limitación histórica. Para comprobar si algo es un array, usa Array.isArray(valor), que es fiable en todos los contextos.

¿Cuál es la diferencia entre for...of y forEach?

for...of es una construcción del lenguaje que funciona con cualquier iterable (arrays, strings, Maps, Sets). Puedes usar break y continue dentro de él. forEach es un método de array que recibe un callback; no puedes usar break ni continue. Además, for...of funciona perfectamente con await dentro de funciones async, mientras que forEach no espera promesas. En código moderno, for...of es generalmente preferible.

¿Cómo clono un array correctamente?

Para una copia superficial (elementos primitivos o referencias compartidas): const copia = original.slice(), [...original] (spread), o Array.from(original). Para una copia profunda (objetos anidados independientes): const copia = structuredClone(original) (método moderno, disponible en navegadores y Node 17+). Evita JSON.parse(JSON.stringify(obj)): pierde funciones, undefined, símbolos y fechas.

¿Por qué [1, 2] + [3, 4] devuelve '1,23,4'?

Porque el operador + convierte los arrays a strings antes de concatenarlos. [1, 2].toString() es '1,2', y [3, 4].toString() es '3,4'. La concatenación produce '1,23,4'. Para unir arrays correctamente, usa concat() o el operador spread: [...[1, 2], ...[3, 4]] → [1, 2, 3, 4].

¿Es mejor push() o asignación por índice para añadir al final?

Siempre push(). arr[arr.length] = valor funciona pero es menos legible. push() expresa tu intención claramente y además acepta múltiples argumentos: arr.push(a, b, c). En cuanto a rendimiento, son equivalentes. Usa la forma que comunique mejor tu intención, y esa es push().
