Cómo funciona este curso

Cada lección sigue siempre la misma estructura

Introducción → Teoría (con el por qué) → Ejemplo mínimo → Ejemplo real → Buenas prácticas → Errores habituales → Ejercicio guiado → Reto → Resumen → FAQ. Siempre sabrás dónde estás y qué esperar.

Ejemplos que ves al instante

La carpeta ejemplos/ contiene archivos HTML que se abren directamente en el navegador: sin instalar nada, sin builds. Los proyectos grandes en proyectos/ sí usan Vite + JS real.

Para quién es

Para desarrolladores que ya programan pero quieren dominar JavaScript en profundidad. El curso cubre desde los fundamentos del lenguaje hasta Web APIs, testing y arquitectura de aplicaciones sin frameworks. Todo con JavaScript vanilla moderno (ES2026+).

Tu progreso se guarda en tu navegador

Marca cada lección como completada con el botón al final de la página. El progreso vive en localStorage: sin cuentas y sin servidores.
