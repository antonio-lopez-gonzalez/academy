Manipulación del DOM: crear, modificar y eliminar

Módulo 5 · DOM y Eventos ⏱ 35 minutos

1 · Introducción

Seleccionar elementos es solo el primer paso. La verdadera interactividad ocurre cuando creas, modificas y eliminas nodos del DOM en respuesta a las acciones del usuario. JavaScript ofrece un abanico de métodos para manipular el árbol, desde los más básicos (appendChild) hasta atajos modernos como insertAdjacentHTML. Conocer todos te permite elegir la herramienta adecuada para cada situación.

2 · Teoría

Crear elementos

// Crear un elemento (no se inserta automáticamente en el DOM)
const parrafo = document.createElement('p');

// Configurar propiedades antes de insertar (más eficiente)
parrafo.textContent = 'Hola mundo';
parrafo.id = 'saludo';
parrafo.classList.add('mensaje', 'destacado');

// cloneNode: copiar un elemento existente
const original = document.querySelector('.plantilla');
const copiaSuperficial = original.cloneNode();       // false = no clona hijos
const copiaProfunda = original.cloneNode(true);       // true = clona hijos y todo el subárbol

    Modificar contenido: textContent, innerHTML, innerText

    const elemento = document.querySelector('.contenedor');

// textContent: solo texto, ignora HTML. RÁPIDO y SEGURO
elemento.textContent = '<strong>Hola</strong>';
// Resultado: muestra literalmente "<strong>Hola</strong>"

// innerHTML: interpreta HTML. POTENTE pero PELIGROSO (XSS)
elemento.innerHTML = '<strong>Hola</strong>';
// Resultado: muestra "Hola" en negrita

// ⚠️ NUNCA uses innerHTML con datos de usuario sin sanitizar
// ❌ PELIGRO: datosUsuario puede contener <script>malicioso</script>
// elemento.innerHTML = datosUsuario;

// innerText: como textContent pero respeta CSS (visibility, display)
// Es más lento porque fuerza un reflow para calcular estilos
elemento.innerText = 'Texto visible';

    Regla de oro para innerHTML: Solo úsalo con HTML que tú mismo has generado (plantillas, fragmentos estáticos). Si el contenido viene del usuario, de una API externa o de la URL, usa textContent o sanitízalo antes con una librería como DOMPurify.

    Modificar atributos

    const imagen = document.querySelector('img');

// setAttribute / getAttribute / removeAttribute
imagen.setAttribute('src', 'foto.jpg');
imagen.setAttribute('alt', 'Una foto');
console.log(imagen.getAttribute('alt')); // 'Una foto'
imagen.removeAttribute('alt');

// Atajos para atributos comunes (más rápido y legible)
imagen.src = 'foto.jpg';
imagen.alt = 'Una foto';

// data-* attributes: dataset API
imagen.dataset.id = '123';
imagen.dataset.precioOriginal = '99.99';
console.log(imagen.dataset.id);          // '123'
// En HTML: <img data-id="123" data-precio-original="99.99">

    classList — La forma correcta de manejar clases

    const caja = document.querySelector('.caja');

caja.classList.add('visible', 'animado');    // Añade una o varias clases
caja.classList.remove('oculto');             // Elimina una clase
caja.classList.toggle('activo');             // Alterna: añade si no está, quita si está
caja.classList.toggle('tema-oscuro', true);  // Fuerza añadir (true) o quitar (false)
caja.classList.contains('visible');          // ¿Tiene la clase? → true/false
caja.classList.replace('visible', 'oculto'); // Cambia una clase por otra

    Estilos inline

    const caja = document.querySelector('.caja');

// Propiedades individuales (camelCase)
caja.style.backgroundColor = '#333';
caja.style.color = 'white';
caja.style.padding = '1rem';
caja.style.display = 'none';

// Múltiples estilos a la vez (sobrescribe todo el inline style)
caja.style.cssText = 'color: white; background: #333; padding: 1rem;';

// Leer estilos computados (incluye CSS de hojas de estilo)
const estilos = getComputedStyle(caja);
console.log(estilos.fontSize);    // '16px' (lo que realmente se está aplicando)
console.log(estilos.display);     // 'block'

    Eliminar y reemplazar

    const elemento = document.querySelector('.obsoleto');

// remove() — método moderno, elimina el elemento directamente
elemento.remove();

// removeChild — método clásico, requiere el padre
elemento.parentNode.removeChild(elemento);

// replaceWith — reemplaza un elemento por otro(s)
const nuevo = document.createElement('p');
nuevo.textContent = 'Reemplazo';
elemento.replaceWith(nuevo);
// También acepta múltiples argumentos o texto:
// elemento.replaceWith('Texto', document.createElement('br'), 'Más texto');

// replaceChild — versión clásica desde el padre
elemento.parentNode.replaceChild(nuevo, elemento);

    DocumentFragment — Inserciones por lotes eficientes

    Cuando necesitas insertar muchos elementos, hacerlo uno a uno provoca múltiples reflows (repintados del navegador). DocumentFragment es un contenedor invisible que te permite construir el subárbol en memoria y luego insertarlo todo de una vez:

    const lista = document.querySelector('#lista');

// ❌ MAL: 1000 inserciones = 1000 reflows
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  lista.appendChild(li); // Cada appendChild dispara un reflow
}

// ✅ CORRECTO: 1 inserción = 1 reflow con DocumentFragment
const fragmento = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  fragmento.appendChild(li); // No causa reflow (está fuera del DOM)
}
lista.appendChild(fragmento); // Único reflow — ¡mucho más rápido!

    3 · Ejemplo mínimo

    // 1. Crear un elemento
const tarjeta = document.createElement('article');
tarjeta.classList.add('tarjeta');

// 2. Crear y configurar hijos
const titulo = document.createElement('h2');
titulo.textContent = 'Mi tarjeta';

const cuerpo = document.createElement('p');
cuerpo.textContent = 'Contenido de ejemplo';

// 3. Ensamblar el árbol en memoria
tarjeta.append(titulo, cuerpo);

// 4. Insertar en el DOM (único reflow)
document.querySelector('#contenedor').append(tarjeta);

// 5. Modificar después de insertada
tarjeta.style.border = '1px solid #ccc';
tarjeta.classList.toggle('seleccionada', true);

    4 · Ejemplo real

    Un constructor de tablas dinámicas a partir de datos:

    function crearTabla(datos, opciones = {}) {
  const { columnas, clases = [] } = opciones;

  // 1. Crear la tabla
  const tabla = document.createElement('table');
  tabla.classList.add('tabla-datos', ...clases);

  // 2. Crear cabecera (thead)
  if (columnas && columnas.length > 0) {
    const thead = document.createElement('thead');
    const tr = document.createElement('tr');

    columnas.forEach(col => {
      const th = document.createElement('th');
      th.textContent = typeof col === 'string' ? col : col.titulo;
      th.scope = 'col';
      tr.appendChild(th);
    });

    thead.appendChild(tr);
    tabla.appendChild(thead);
  }

  // 3. Crear cuerpo (tbody) con DocumentFragment
  const tbody = document.createElement('tbody');
  const fragmento = document.createDocumentFragment();

  datos.forEach((fila, indice) => {
    const tr = document.createElement('tr');
    tr.dataset.indice = indice; // data-index para referencia posterior

    fila.forEach((celda, i) => {
      const td = document.createElement('td');
      td.textContent = celda;
      tr.appendChild(td);
    });

    fragmento.appendChild(tr);
  });

  tbody.appendChild(fragmento);
  tabla.appendChild(tbody);

  return tabla;
}

// Uso
const datos = [
  ['Ana',   28, 'Madrid'],
  ['Luis',  34, 'Barcelona'],
  ['María', 25, 'Valencia']
];

const columnas = ['Nombre', 'Edad', 'Ciudad'];
const tabla = crearTabla(datos, {
  columnas,
  clases: ['stripe', 'hover']
});

document.querySelector('#resultados').appendChild(tabla);

    6 · Errores habituales

    Error 1: XSS con innerHTML y datos de usuario

    // ❌ PELIGROSO: Si el usuario escribe <img src=x onerror="alert('hackeado')">
const comentarioUsuario = '<img src=x onerror="alert(\'hackeado\')">';
document.querySelector('#comentarios').innerHTML += comentarioUsuario;
// El script se ejecuta — ¡vulnerabilidad de seguridad!

// ✅ CORRECTO: textContent neutraliza el HTML
const div = document.createElement('div');
div.textContent = comentarioUsuario;
document.querySelector('#comentarios').appendChild(div);

// ✅ Alternativa con sanitización: DOMPurify (librería externa)
// div.innerHTML = DOMPurify.sanitize(comentarioUsuario);

    Error 2: appendChild mueve el nodo, no lo copia

    const parrafo = document.querySelector('p');
const contenedorA = document.querySelector('#a');
const contenedorB = document.querySelector('#b');

contenedorA.appendChild(parrafo);
contenedorB.appendChild(parrafo);
// El párrafo ahora está en contenedorB. Se MOVIÓ, no se copió.

// ✅ Para duplicar, usa cloneNode
contenedorA.appendChild(parrafo.cloneNode(true));
contenedorB.appendChild(parrafo.cloneNode(true));

    Error 3: Modificar style uno a uno en bucles

    // ❌ MAL: Cada asignación de style puede disparar un reflow
const items = document.querySelectorAll('.item');
items.forEach(item => {
  item.style.color = 'red';
  item.style.fontSize = '1.2em';
  item.style.margin = '10px';
});

// ✅ CORRECTO: Usa clases CSS o cssText para cambios en lote
items.forEach(item => {
  item.classList.add('item-destacado'); // La clase aplica todos los estilos de golpe
});

// O si necesitas estilos dinámicos inline:
items.forEach(item => {
  item.style.cssText = 'color: red; font-size: 1.2em; margin: 10px;';
});

    Objetivo: Construir un generador de tarjetas de producto a partir de un array de objetos.

    1. Paso 1: Datos de los productos

      const productos = [
  { nombre: 'Auriculares BT', precio: 59.99, stock: true },
  { nombre: 'Teclado mecánico', precio: 89.99, stock: false },
  { nombre: 'Monitor 27"',   precio: 299.99, stock: true },
  { nombre: 'Ratón wireless', precio: 39.99, stock: true }
];

    2. Paso 2: Función para crear una tarjeta

      function crearTarjetaProducto(producto) {
  const tarjeta = document.createElement('article');
  tarjeta.classList.add('producto-tarjeta');

  const nombre = document.createElement('h3');
  nombre.textContent = producto.nombre;
  nombre.classList.add('producto-nombre');

  const precio = document.createElement('span');
  precio.textContent = `$${producto.precio.toFixed(2)}`;
  precio.classList.add('producto-precio');

  const stock = document.createElement('span');
  stock.textContent = producto.stock ? '✅ En stock' : '❌ Agotado';
  stock.classList.add('producto-stock');
  stock.style.color = producto.stock ? 'green' : 'red';

  tarjeta.append(nombre, precio, stock);

  // data-* para referencia futura
  tarjeta.dataset.nombre = producto.nombre;
  tarjeta.dataset.precio = producto.precio;

  return tarjeta;
}

    3. Paso 3: Renderizar todas las tarjetas con DocumentFragment

      function renderizarProductos(productos, contenedorSelector) {
  const contenedor = document.querySelector(contenedorSelector);
  if (!contenedor) {
    console.error(`No se encontró el contenedor: ${contenedorSelector}`);
    return;
  }

  // Limpiar contenido existente
  contenedor.textContent = '';

  const fragmento = document.createDocumentFragment();
  productos.forEach(producto => {
    fragmento.appendChild(crearTarjetaProducto(producto));
  });

  contenedor.appendChild(fragmento);
}

renderizarProductos(productos, '#lista-productos');

    4. Paso 4: Filtrar y re-renderizar

      function filtrarEnStock() {
  const enStock = productos.filter(p => p.stock);
  renderizarProductos(enStock, '#lista-productos');
}

    9 · Resumen

    • createElement + configuración de propiedades → append/prepend/insertAdjacentHTML para insertar.
    • textContent para texto (seguro, rápido). innerHTML solo con HTML de confianza (riesgo XSS).
    • classList (add, remove, toggle, contains, replace) es la forma moderna de manejar clases CSS.
    • style para estilos inline dinámicos; pero prefiere classList con clases CSS predefinidas.
    • remove() / replaceWith() son los métodos modernos para eliminar y reemplazar.
    • DocumentFragment evita reflows múltiples al insertar muchos elementos: construye en memoria, inserta una vez.
    • cloneNode(true) duplica un subárbol; appendChild mueve el nodo, no lo copia.

    10 · Preguntas frecuentes

    ¿Qué diferencia hay entre append y appendChild?

    append (moderno): acepta varios argumentos, incluyendo strings (los inserta como texto). No devuelve nada. appendChild (clásico): solo acepta un nodo, devuelve el nodo insertado. Si necesitas compatibilidad con navegadores muy antiguos, usa appendChild. En cualquier proyecto moderno, append es más cómodo.

    ¿Es innerHTML += '...' realmente tan malo?

    Sí, por dos razones: (1) destruye y recrea todo el contenido interno del elemento, perdiendo event listeners y estado (value de inputs), y (2) si concatenas datos de usuario, abre la puerta a XSS. Usa insertAdjacentHTML o append(createElement(...)) como alternativas seguras.

    ¿Cuándo usar style inline vs clases CSS?

    Usa clases CSS para estilos predefinidos (temas, variantes, estados). Usa style solo cuando el valor se calcula dinámicamente y no puede conocerse de antemano (ej. style.left = x + 'px' para una animación, o style.display = 'none' para ocultar). Las clases tienen mejor rendimiento y mantienen la separación de responsabilidades.
