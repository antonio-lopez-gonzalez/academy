Clases (ES6): constructor, métodos, getters/setters

Módulo 4 · Objetos y Clases ⏱ 35 minutos

1 · Introducción

La palabra class llegó a JavaScript en ES6 (2015). No introdujo un nuevo modelo de herencia; es azúcar sintáctico sobre el sistema de prototipos que ya existía. La sintaxis class hace que el código sea más legible y familiar para desarrolladores que vienen de lenguajes como Java, C# o Python, pero por debajo todo sigue siendo prototipos.

Dato clave: typeof MiClase === "function". Una clase en JavaScript es, literalmente, una función. Solo cambia la sintaxis con la que la declaras.

2 · Teoría

Declaración de clase

class Coche {
  // El constructor se ejecuta automáticamente al hacer new Coche(...)
  constructor(marca, modelo) {
    // Las propiedades de instancia se definen con this dentro del constructor
    this.marca = marca;
    this.modelo = modelo;
    this.kilometros = 0;
  }

  // Método de instancia: vive en Coche.prototype
  conducir(km) {
    this.kilometros += km;
    return `Has conducido ${km} km. Total: ${this.kilometros} km`;
  }

  // Getter: se accede como propiedad, no como método
  get descripcion() {
    return `${this.marca} ${this.modelo} (${this.kilometros} km)`;
  }

  // Setter: se activa al asignar un valor
  set nombreCorto(valor) {
    if (valor.length > 20) {
      throw new Error('El nombre corto no puede superar 20 caracteres');
    }
    this._nombreCorto = valor;
  }

  get nombreCorto() {
    return this._nombreCorto || `${this.marca} ${this.modelo}`;
  }

  // Método estático: vive en la función Coche, NO en Coche.prototype
  static fabricar(marca, modelo) {
    return new Coche(marca, modelo);
  }

  // Otro estático útil: comparar dos coches
  static comparar(cocheA, cocheB) {
    return cocheA.kilometros - cocheB.kilometros;
  }
}

Uso de la clase

const miCoche = new Coche('Toyota', 'Corolla');

console.log(miCoche.conducir(50));  // 'Has conducido 50 km. Total: 50 km'
console.log(miCoche.descripcion);   // 'Toyota Corolla (50 km)' — getter, sin ()

miCoche.nombreCorto = 'Toyoco';     // setter
console.log(miCoche.nombreCorto);   // 'Toyoco' — getter

// Método estático: se llama en la clase, no en la instancia
const otroCoche = Coche.fabricar('Honda', 'Civic');
console.log(otroCoche.descripcion); // 'Honda Civic (0 km)'

console.log(Coche.comparar(miCoche, otroCoche)); // 50 (positivo: miCoche tiene más km)

La clase por dentro

Esto es lo que realmente ocurre:

class Demo {
  constructor(x) { this.x = x; }
  metodo() { return this.x; }
  static estatico() { return 'estático'; }
}

console.log(typeof Demo);                  // "function" — ¡una clase es una función!
console.log(Demo.prototype.metodo);        // [Function: metodo] — los métodos viven en prototype
console.log(Demo.estatico);                // [Function: estatico] — los estáticos viven en la función

const d = new Demo(42);
console.log(d.metodo());                   // 42
console.log(Object.getPrototypeOf(d) === Demo.prototype); // true — herencia prototípica pura

Propiedades de instancia: dos formas de declararlas

// Forma 1: Dentro del constructor (clásica, compatible con todo)
class UsuarioA {
  constructor(nombre) {
    this.nombre = nombre;
    this.rol = 'usuario';
  }
}

// Forma 2: Declaración de campos (ES2022, más moderna)
class UsuarioB {
  rol = 'usuario';         // propiedad de instancia con valor por defecto
  #intentos = 0;           // propiedad privada (la veremos en la siguiente lección)
  nombre;

  constructor(nombre) {
    this.nombre = nombre;  // asignación final
  }
}

// Ambas producen el mismo resultado
const ua = new UsuarioA('Ana');
const ub = new UsuarioB('Ana');
console.log(ua.nombre, ua.rol); // Ana usuario
console.log(ub.nombre, ub.rol); // Ana usuario

new.target — Detectar si se llamó con new

class Figura {
  constructor() {
    // new.target es la función/clase que se invocó con new
    console.log('Instanciando:', new.target.name);
  }
}

class Circulo extends Figura {
  constructor(radio) {
    super(); // new.target aquí es Circulo, no Figura
    this.radio = radio;
  }
}

const c = new Circulo(5); // Imprime: "Instanciando: Circulo"

instanceof

Comprueba si un objeto tiene en su cadena de prototipos la propiedad prototype de una función constructora o clase:

const fecha = new Date();
const arr = [1, 2, 3];

console.log(fecha instanceof Date);    // true
console.log(fecha instanceof Object);  // true (Date.prototype hereda de Object.prototype)
console.log(arr instanceof Array);     // true
console.log(arr instanceof Object);    // true

// ⚠️ Cuidado: instanceof no es infalible
console.log([] instanceof Object);     // true — todo hereda de Object
console.log(null instanceof Object);   // false — null es primitivo, no objeto

Expresiones de clase

Puedes asignar una clase a una variable, igual que haces con funciones:

const Rectangulo = class {
  constructor(ancho, alto) {
    this.ancho = ancho;
    this.alto = alto;
  }
  area() { return this.ancho * this.alto; }
};

const r = new Rectangulo(10, 5);
console.log(r.area()); // 50

Recordatorio importante: Las clases NO tienen hoisting como las funciones declaradas. No puedes usar una clase antes de declararla. Esto es intencionado: evita errores sutiles de orden de inicialización.

3 · Ejemplo mínimo

// La clase más pequeña posible con un getter
class Contador {
  constructor(inicial = 0) {
    this._valor = inicial;
  }

  // Getter: permite leer this._valor sin exponerlo directamente
  get valor() {
    return this._valor;
  }

  // Método normal
  incrementar() {
    this._valor++;
    return this._valor;
  }

  resetear() {
    this._valor = 0;
  }
}

const c = new Contador(5);
console.log(c.valor);       // 5 — se accede como propiedad
console.log(c.incrementar());// 6
console.log(c.incrementar());// 7
console.log(c.valor);       // 7
c.resetear();
console.log(c.valor);       // 0

4 · Ejemplo real

Un carrito de compras con getters calculados y métodos estáticos:

class Carrito {
  constructor() {
    this.items = [];
  }

  agregar(producto, cantidad = 1) {
    const existente = this.items.find(item => item.nombre === producto.nombre);
    if (existente) {
      existente.cantidad += cantidad;
    } else {
      this.items.push({ ...producto, cantidad });
    }
  }

  eliminar(nombreProducto) {
    this.items = this.items.filter(item => item.nombre !== nombreProducto);
  }

  // Getter calculado: su valor se deriva del estado interno
  get total() {
    return this.items.reduce((sum, item) => sum + item.precio * item.cantidad, 0);
  }

  get totalArticulos() {
    return this.items.reduce((sum, item) => sum + item.cantidad, 0);
  }

  get resumen() {
    if (this.items.length === 0) return 'Carrito vacío';
    return `${this.totalArticulos} artículos — Total: $${this.total.toFixed(2)}`;
  }

  // Método estático: crear un carrito desde localStorage
  static desdeJSON(json) {
    const datos = JSON.parse(json);
    const carrito = new Carrito();
    carrito.items = datos.items;
    return carrito;
  }

  toJSON() {
    return JSON.stringify({ items: this.items });
  }
}

const carrito = new Carrito();
carrito.agregar({ nombre: 'Camiseta', precio: 29.99 }, 2);
carrito.agregar({ nombre: 'Pantalón', precio: 49.99 });

console.log(carrito.resumen); // '3 artículos — Total: $109.97'

// Guardar y recuperar
const guardado = carrito.toJSON();
const recuperado = Carrito.desdeJSON(guardado);
console.log(recuperado.resumen); // '3 artículos — Total: $109.97'

6 · Errores habituales

Error 1: Olvidar new al instanciar

class Tarea {
  constructor(titulo) {
    this.titulo = titulo;
  }
}

// ❌ MAL: Sin new, this es undefined (en strict mode) y falla
try {
  const t = Tarea('Comprar pan'); // TypeError: Cannot set properties of undefined
} catch (e) {
  console.error(e.message);
}

// ✅ CORRECTO: Siempre con new
const t = new Tarea('Comprar pan');
console.log(t.titulo); // 'Comprar pan'

Error 2: Usar getters como si fueran métodos

class Rectangulo {
  constructor(ancho, alto) { this.ancho = ancho; this.alto = alto; }
  get area() { return this.ancho * this.alto; }
}

const r = new Rectangulo(10, 5);

// ❌ MAL: Invocar el getter como método
// console.log(r.area()); // TypeError: r.area is not a function

// ✅ CORRECTO: Acceder como propiedad
console.log(r.area); // 50

Error 3: this perdido en callbacks

class Reloj {
  constructor() { this.segundos = 0; }
  iniciar() {
    // ❌ MAL: this dentro de setInterval es window/global, no la instancia
    this.intervalo = setInterval(function() {
      this.segundos++; // undefined + 1 = NaN
    }, 1000);
  }
}

// ✅ CORRECTO: Arrow function hereda el this del contexto
class RelojCorregido {
  constructor() { this.segundos = 0; }
  iniciar() {
    this.intervalo = setInterval(() => {
      this.segundos++; // ✅ this es la instancia de Reloj
    }, 1000);
  }
}

7 · Ejercicio guiado

Objetivo: Implementar una clase Termostato con getter/setter para la temperatura.

  1. Paso 1: Estructura base

    class Termostato {
  constructor(tempInicial = 20) {
    this._temperatura = tempInicial;
    this._unidad = 'C'; // Celsius por defecto
  }

  // Getter: devuelve la temperatura con su unidad
  get temperatura() {
    return `${this._temperatura}°${this._unidad}`;
  }

  // Setter: valida que la temperatura esté en un rango seguro
  set temperatura(valor) {
    if (valor < -50 || valor > 150) {
      throw new Error(`Temperatura ${valor}° fuera de rango (-50 a 150)`);
    }
    this._temperatura = valor;
  }
}

  2. Paso 2: Añadir métodos y más getters

    class Termostato {
  constructor(tempInicial = 20) {
    this._temperatura = tempInicial;
    this._unidad = 'C';
    this._historial = [tempInicial];
  }

  get temperatura() {
    return `${this._temperatura}°${this._unidad}`;
  }

  set temperatura(valor) {
    if (valor < -50 || valor > 150) {
      throw new Error(`Temperatura ${valor}° fuera de rango (-50 a 150)`);
    }
    this._temperatura = valor;
    this._historial.push(valor);
  }

  // Getter para el promedio de temperaturas
  get promedio() {
    const sum = this._historial.reduce((a, b) => a + b, 0);
    return (sum / this._historial.length).toFixed(1);
  }

  // Método para cambiar unidad (y convertir)
  cambiarACelsius() {
    if (this._unidad === 'F') {
      this._temperatura = ((this._temperatura - 32) * 5) / 9;
      this._unidad = 'C';
    }
  }

  cambiarAFahrenheit() {
    if (this._unidad === 'C') {
      this._temperatura = (this._temperatura * 9) / 5 + 32;
      this._unidad = 'F';
    }
  }

  static desdeFahrenheit(tempF) {
    const t = new Termostato();
    t._temperatura = tempF;
    t._unidad = 'F';
    return t;
  }
}

  3. Paso 3: Probar

    const t = new Termostato();
console.log(t.temperatura); // '20°C'

t.temperatura = 23;
t.temperatura = 25;
t.temperatura = 22;

console.log(t.temperatura); // '22°C'
console.log(t.promedio);    // '22.5' — media de [20, 23, 25, 22]

// Usar el factory estático
const tUSA = Termostato.desdeFahrenheit(68);
console.log(tUSA.temperatura); // '68°F'
tUSA.cambiarACelsius();
console.log(tUSA.temperatura); // '20°C'

9 · Resumen

  • La sintaxis class es azúcar sobre prototipos. typeof MiClase === "function".
  • El constructor se ejecuta al hacer new. Aquí defines las propiedades de instancia con this.
  • Los métodos viven en Clase.prototype. Los métodos estáticos viven en la propia función Clase.
  • Los getters (get) se acceden como propiedades, sin paréntesis. Los setters (set) interceptan asignaciones.
  • instanceof recorre la cadena de prototipos del objeto buscando la referencia prototype de la clase.
  • new.target permite saber qué clase se invocó exactamente con new (útil en herencia avanzada).
  • Las clases no tienen hoisting: debes declararlas antes de usarlas.

10 · Preguntas frecuentes

¿Cuándo usar getters/setters en lugar de métodos normales?

Usa getters cuando el valor se deriva de otras propiedades (area, nombreCompleto) y no necesita parámetros. Usa setters cuando quieras validar o transformar automáticamente al asignar un valor. Si la operación produce efectos secundarios (ej. guardar en base de datos), mejor usa un método normal para que la intención sea explícita.

¿Por qué typeof dice que una clase es "function"?

Porque lo es. La sintaxis class no introduce un nuevo tipo en JavaScript. Internamente, class Foo {} se traduce aproximadamente a function Foo() {} con Foo.prototype configurado. Es puro azúcar sintáctico sobre el modelo de prototipos preexistente.

¿Las clases de JavaScript son iguales a las de Java?

No. En Java, una clase es una entidad estática que define el tipo y la estructura. En JavaScript, una clase es un objeto (función) en tiempo de ejecución. Puedes modificarla después de declararla. Los métodos se buscan por delegación prototípica, no por despacho estático. La sintaxis se parece, pero el mecanismo interno es radicalmente distinto.
