this en profundidad: bind, call, apply, arrow functions

Módulo 4 · Objetos y Clases ⏱ 35 minutos

1 · Introducción

this es probablemente la palabra clave más incomprendida de JavaScript. No es el objeto que "contiene" la función, ni una referencia a la propia función. this es un valor que se determina en tiempo de ejecución, dependiendo de cómo se invoca la función, no de dónde se declaró. Dominar this es esencial para trabajar con clases, objetos, eventos del DOM y callbacks.

Analogía — El pronombre "yo": La palabra "yo" significa cosas distintas según quién la diga. Si Ana dice "yo tengo hambre", "yo" = Ana. Si Juan lo dice, "yo" = Juan. this funciona igual: su valor depende de quien llama a la función en ese momento.

2 · Teoría

Diagrama de flujo: ¿qué es this?

¿Cómo se invoca la función?

1. ¿Se llamó con new?
   └─ SÍ → this = la nueva instancia creada

2. ¿Se usó bind / call / apply?
   └─ SÍ → this = el valor explícito que pasaste

3. ¿Se llamó como método de un objeto? (obj.metodo())
   └─ SÍ → this = el objeto a la izquierda del punto (obj)

4. ¿Es una arrow function?
   └─ SÍ → this = el this del ámbito donde se definió (léxico)

5. ¿Es modo estricto ('use strict')?
   └─ SÍ → this = undefined
   └─ NO  → this = objeto global (window / globalThis)

Regla 1 — Global / window

// Sin 'use strict': this es el objeto global (window en navegador)
function mostrarThis() {
  console.log(this);
}
mostrarThis(); // window (en navegador) o global (en Node)

// Con 'use strict': this es undefined
function mostrarThisStrict() {
  'use strict';
  console.log(this);
}
mostrarThisStrict(); // undefined

Regla 2 — Método de objeto

const persona = {
  nombre: 'Carlos',
  saludar() {
    console.log(`Hola, soy ${this.nombre}`);
  }
};

persona.saludar(); // 'Hola, soy Carlos' — this = persona

// ¡Cuidado! Si extraes el método, pierde el this
const saludarSuelto = persona.saludar;
saludarSuelto(); // 'Hola, soy undefined' — this = window/undefined (regla 1)

Regla 3 — new (función constructora o clase)

function Persona(nombre) {
  // Con new, this apunta a la nueva instancia que se está creando
  this.nombre = nombre;
}

const p = new Persona('Diana');
console.log(p.nombre); // 'Diana'

// Sin new, this es window/global (o undefined en strict)
const p2 = Persona('Error'); // contaminando el scope global
console.log(window.nombre);  // 'Error' — ¡hemos creado window.nombre!

Regla 4 — bind, call, apply (explícito)

Estos tres métodos permiten especificar exactamente qué valor debe tomar this:

call — invoca la función inmediatamente

function saludar(saludo, signo) {
  console.log(`${saludo}, soy ${this.nombre}${signo}`);
}

const usuario = { nombre: 'Elena' };

// call(thisArg, arg1, arg2, ...)
saludar.call(usuario, 'Hola', '!'); // 'Hola, soy Elena!'

apply — igual que call pero argumentos en array

// apply(thisArg, [arg1, arg2, ...])
saludar.apply(usuario, ['Buenos días', '!!']); // 'Buenos días, soy Elena!!'

// Útil con Math.max en arrays
const numeros = [5, 12, 3, 8, 20];
console.log(Math.max.apply(null, numeros)); // 20
// (Hoy usarías Math.max(...numeros), pero ayuda a entender apply)

bind — crea una nueva función con this fijado permanentemente

const saludarElena = saludar.bind(usuario, 'Hey');
// bind NO ejecuta la función, devuelve una nueva

saludarElena('?');  // 'Hey, soy Elena?'
saludarElena('!!!'); // 'Hey, soy Elena!!!'

// Una vez bindeado, this no cambia nunca más
saludarElena.call({ nombre: 'Otro' }, 'Intento'); // 'Hey, soy ElenaIntento' — el bind gana

Arrow functions y this léxico

Las arrow functions no tienen su propio this. Heredan el this del ámbito donde fueron definidas. Esto las hace ideales para callbacks donde necesitas conservar el contexto:

const equipo = {
  nombre: 'Águilas',
  jugadores: ['Ana', 'Luis', 'Pedro'],

  // ❌ MAL: function normal pierde el this en forEach
  presentacionMala() {
    this.jugadores.forEach(function(jugador) {
      console.log(`${jugador} juega en ${this.nombre}`);
      // this.nombre = undefined (this es window/undefined en forEach)
    });
  },

  // ✅ CORRECTO: arrow function hereda el this del método
  presentacionBuena() {
    this.jugadores.forEach(jugador => {
      console.log(`${jugador} juega en ${this.nombre}`); // this = equipo
    });
  }
};

equipo.presentacionBuena();
// Ana juega en Águilas
// Luis juega en Águilas
// Pedro juega en Águilas

El problema clásico: perder this en callbacks y event listeners

class Boton {
  constructor(texto) {
    this.texto = texto;
    this.clicks = 0;
  }

  // ❌ MAL: this se pierde en el callback del evento
  montarMalo() {
    document.querySelector('#btn').addEventListener('click', function() {
      this.clicks++; // this = el elemento #btn, NO la instancia de Boton
    });
  }

  // ✅ Solución 1: Arrow function
  montarArrow() {
    document.querySelector('#btn').addEventListener('click', () => {
      this.clicks++; // this = instancia de Boton (léxico)
    });
  }

  // ✅ Solución 2: .bind()
  montarBind() {
    document.querySelector('#btn').addEventListener('click', function() {
      this.clicks++;
    }.bind(this)); // forzamos this a ser la instancia
  }

  // ✅ Solución 3: Variable self/that (patrón clásico pre-ES6)
  montarSelf() {
    const self = this;
    document.querySelector('#btn').addEventListener('click', function() {
      self.clicks++;
    });
  }
}

En la práctica actual: Usa arrow functions para callbacks (solución más limpia) o .bind() cuando necesites una función nombrada. El patrón self/that es histórico; hoy solo lo verás en código legacy.

3 · Ejemplo mínimo

// Muestra las 4 formas de establecer this en una misma función
function quienSoy() {
  console.log('this es:', this?.nombre ?? this);
}

const ana = { nombre: 'Ana', quienSoy };

// Regla 3 — método de objeto
ana.quienSoy(); // this es: Ana

// Regla 4 — llamada simple (modo no estricto: window)
const fn = ana.quienSoy;
fn(); // this es: window (o undefined en strict mode)

// Regla 2 — call explícito
fn.call({ nombre: 'Explícito' }); // this es: Explícito

// Regla 1 — new
new fn(); // this es: {} (objeto vacío, la nueva instancia)

// Arrow: this léxico
const arrow = () => console.log('arrow this:', this?.nombre ?? this);
const obj = { nombre: 'Objeto', arrow };
obj.arrow(); // arrow this: window — la arrow ignora el obj, hereda el this global

4 · Ejemplo real

Un contador de eventos con binding correcto en diferentes escenarios:

class ContadorEventos {
  constructor() {
    this.eventos = { click: 0, keydown: 0, scroll: 0 };
    this._iniciado = false;

    // bind temprano: garantiza que este método siempre tenga el this correcto
    this.manejarClick = this.manejarClick.bind(this);
    this.manejarTecla = this.manejarTecla.bind(this);
  }

  manejarClick(evento) {
    this.eventos.click++;
    console.log(`Clicks: ${this.eventos.click} — elemento: ${evento.target.tagName}`);
  }

  manejarTecla(evento) {
    this.eventos.keydown++;
    console.log(`Teclas: ${this.eventos.keydown} — tecla: ${evento.key}`);
  }

  // scroll usa arrow function (alternativa a bind)
  manejarScroll = () => {
    this.eventos.scroll++;
    console.log(`Scrolls: ${this.eventos.scroll}`);
  };

  iniciar() {
    if (this._iniciado) return;
    document.addEventListener('click', this.manejarClick);
    document.addEventListener('keydown', this.manejarTecla);
    window.addEventListener('scroll', this.manejarScroll);
    this._iniciado = true;
  }

  detener() {
    document.removeEventListener('click', this.manejarClick);
    document.removeEventListener('keydown', this.manejarTecla);
    window.removeEventListener('scroll', this.manejarScroll);
    this._iniciado = false;
  }

  get resumen() {
    return Object.entries(this.eventos)
      .map(([tipo, count]) => `${tipo}: ${count}`)
      .join(' | ');
  }
}

// ⚠️ Importante: al usar .bind() guardamos la referencia para poder hacer removeEventListener
const tracker = new ContadorEventos();
tracker.iniciar();
// Después de usar la app...
console.log(tracker.resumen); // click: 5 | keydown: 12 | scroll: 3
tracker.detener();

6 · Errores habituales

Error 1: this en setTimeout con método de objeto

// ❌ MAL
const reloj = {
  hora: 0,
  iniciar() {
    setTimeout(function() {
      this.hora++; // this = window (o undefined en strict)
    }, 1000);
  }
};

// ✅ CORRECTO — arrow function
const relojCorrecto = {
  hora: 0,
  iniciar() {
    setTimeout(() => {
      this.hora++; // this = reloj (porque arrow hereda el this de iniciar())
    }, 1000);
  }
};

Error 2: Pasar un método de clase como callback directamente

class Logger {
  constructor(prefix) { this.prefix = prefix; }
  log(msg) { console.log(`[${this.prefix}] ${msg}`); }
}

const logger = new Logger('APP');

// ❌ MAL: this se pierde al pasar log como callback
setTimeout(logger.log, 1000, 'Hola'); // [undefined] Hola
// Esto es equivalente a: const fn = logger.log; fn('Hola');

// ✅ CORRECTO: bind o arrow
setTimeout(() => logger.log('Hola'), 1000); // [APP] Hola
setTimeout(logger.log.bind(logger), 1000, 'Hola'); // [APP] Hola

Error 3: Arrow function como método de objeto esperando this dinámico

// ❌ MAL: arrow function como método (this no será el objeto)
const obj = {
  nombre: 'Test',
  saludar: () => `Hola, ${this.nombre}`
};
console.log(obj.saludar()); // 'Hola, undefined'

// ✅ CORRECTO: usa sintaxis de método abreviada
const objCorrecto = {
  nombre: 'Test',
  saludar() { return `Hola, ${this.nombre}`; }
};
console.log(objCorrecto.saludar()); // 'Hola, Test'

7 · Ejercicio guiado

Objetivo: Implementar un Temporizador que use correctamente this.

  1. Paso 1: Estructura con arrow function en setInterval

    class Temporizador {
  constructor(segundos) {
    this.segundosRestantes = segundos;
    this.segundosIniciales = segundos;
    this.intervaloId = null;
    this.terminado = false;
  }

  iniciar() {
    if (this.intervaloId) return; // ya está corriendo

    this.intervaloId = setInterval(() => {
      if (this.segundosRestantes > 0) {
        this.segundosRestantes--;
        this.mostrar();
      } else {
        this.terminado = true;
        this.detener();
        this.alTerminar();
      }
    }, 1000);
  }

  2. Paso 2: Métodos con bind en el constructor

    class Temporizador {
  constructor(segundos) {
    this.segundosRestantes = segundos;
    this.segundosIniciales = segundos;
    this.intervaloId = null;
    this.terminado = false;

    // Bind para callbacks que necesitan ser extraídos
    this.iniciar = this.iniciar.bind(this);
    this.detener = this.detener.bind(this);
    this.reiniciar = this.reiniciar.bind(this);
  }

  iniciar() {
    if (this.intervaloId) return;
    this.intervaloId = setInterval(() => {
      if (this.segundosRestantes > 0) {
        this.segundosRestantes--;
        this.mostrar();
      } else {
        this.terminado = true;
        this.detener();
        this.alTerminar();
      }
    }, 1000);
  }

  detener() {
    if (this.intervaloId) {
      clearInterval(this.intervaloId);
      this.intervaloId = null;
    }
  }

  reiniciar() {
    this.detener();
    this.segundosRestantes = this.segundosIniciales;
    this.terminado = false;
    this.iniciar();
  }

  mostrar() {
    const mins = Math.floor(this.segundosRestantes / 60);
    const secs = this.segundosRestantes % 60;
    console.log(`${String(mins).padStart(2, '0')}:${String(secs).padStart(2, '0')}`);
  }

  alTerminar() {
    console.log('⏰ ¡Tiempo cumplido!');
  }

  get progreso() {
    return ((this.segundosIniciales - this.segundosRestantes) / this.segundosIniciales) * 100;
  }
}

  3. Paso 3: Demostrar que los métodos bindeados funcionan como callbacks

    const timer = new Temporizador(5);

// Podemos pasar los métodos como callbacks sin preocuparnos por this
document.querySelector('#btnIniciar').addEventListener('click', timer.iniciar);
document.querySelector('#btnDetener').addEventListener('click', timer.detener);
document.querySelector('#btnReiniciar').addEventListener('click', timer.reiniciar);
// ✅ this siempre apunta a timer, gracias al bind en el constructor

9 · Resumen

  • this se determina en tiempo de llamada, no en tiempo de definición.
  • Las 4 reglas en orden de prioridad: new → bind/call/apply → método de objeto → llamada simple.
  • call(contexto, arg1, arg2) invoca inmediatamente. apply(contexto, [args]) igual pero con array. bind(contexto) devuelve una nueva función.
  • Las arrow functions no tienen this propio: heredan el del ámbito donde fueron definidas.
  • En clases: usa arrow functions como campos de clase o haz .bind(this) en el constructor para métodos que se usarán como callbacks.
  • En event listeners: si necesitas quitar el listener luego, usa .bind() y guarda la referencia. Si no, arrow function.

10 · Preguntas frecuentes

¿Por qué this no funciona como en otros lenguajes?

En lenguajes como Java o C#, this es una referencia fija a la instancia actual de la clase donde se escribe el código. En JavaScript, las funciones son objetos de primera clase que pueden desvincularse de sus objetos. Esto da mucha flexibilidad (puedes "prestar" métodos de un objeto a otro), pero obliga a entender las reglas de binding. Es un trade-off entre flexibilidad y predictibilidad.

¿Cuándo usar bind vs arrow function?

Arrow function: cuando escribes el callback inline y no necesitas quitarlo después. Es más corto y el this es léxico. bind: cuando necesitas una referencia estable a la función bindeada (ej. para removeEventListener) o cuando defines un método de clase que siempre debe tener el this correcto. También cuando trabajas con funciones predefinidas que no controlas.

¿this en el scope global de un módulo ES es window?

No. En un módulo ES (<script type="module">), el código se ejecuta en modo estricto automáticamente, y this en el nivel superior es undefined, no window. Esto evita contaminar el scope global por accidente.
