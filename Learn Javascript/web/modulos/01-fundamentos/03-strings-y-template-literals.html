Strings, template literals y métodos

Módulo 1 · Fundamentos ⏱ 25 minutos

1 · Introducción

Los strings (cadenas de texto) son, junto con los números, el tipo de dato con el que más vas a trabajar. Ya sea para mostrar mensajes, procesar datos de un formulario, parsear JSON, construir URLs o renderizar HTML. JavaScript ofrece tres formas de crear strings y más de 30 métodos para manipularlos.

En esta lección dominarás la creación de strings (comillas simples, dobles, backticks), las secuencias de escape y Unicode, los métodos de búsqueda, extracción, transformación y formateo, y las capacidades avanzadas de los template literals incluyendo tagged templates.

¿Por qué existe esta lección? Porque procesar texto mal es la causa de bugs muy frustrantes: espacios invisibles que rompen comparaciones, mayúsculas/minúsculas inconsistentes, y concatenaciones que se vuelven ilegibles. Un profesional conoce el arsenal completo de métodos de string.

2 · Teoría

Creación de strings

JavaScript ofrece tres delimitadores intercambiables:

const simple = 'Hola mundo';        // Comillas simples (preferido por la comunidad)
const doble = "Hola mundo";         // Comillas dobles
const backtick = `Hola mundo`;      // Backticks (template literals)

// Elige uno y sé consistente. La mayoría de guías de estilo prefieren simples.
// La ventaja de las simples: no necesitas escapar comillas dobles para HTML.
const html = '<div class="container">'; // Más limpio que con dobles

Secuencias de escape y caracteres especiales

console.log('Línea 1\nLínea 2');        // \n = nueva línea
console.log('Tabulado:\tcon tab');      // \t = tabulador
console.log('Comillas: \'simples\'');   // \' = comilla simple escapada
console.log('Barra: \\');               // \\ = backslash literal
console.log('Unicode: \u{1F600}');      // \u{} = carácter Unicode (ES6+)
console.log('Hex: \x41');               // \x = carácter hexadecimal (A)

Backticks y multilínea: Solo los template literals (backticks) permiten strings multilínea sin escapes. Las comillas simples y dobles necesitan \n para saltos de línea.

Métodos de búsqueda

const frase = 'JavaScript es increíble';

frase.length;                  // 25 (número de caracteres)
frase[0];                      // 'J' (acceso por índice)
frase.charAt(0);               // 'J' (alternativa clásica)
frase.indexOf('Script');       // 4 (posición de la primera ocurrencia, -1 si no existe)
frase.lastIndexOf('a');        // 3 (última ocurrencia)
frase.includes('increíble');   // true (¿contiene este substring?)
frase.startsWith('Java');      // true (¿empieza por...?)
frase.endsWith('ble');         // true (¿termina por...?)

Métodos de extracción

const texto = '0123456789';

texto.slice(2, 5);         // '234' (desde índice 2 hasta 5, sin incluir 5)
texto.slice(4);            // '456789' (desde 4 hasta el final)
texto.slice(-3);           // '789' (índices negativos = desde el final)
texto.slice(-5, -2);       // '567' (desde -5 hasta -2)

texto.substring(2, 5);     // '234' (similar a slice, pero no acepta negativos)
// ⚠ substr está DEPRECATED: texto.substr(2, 3) → NO USAR

Métodos de transformación

const nombre = '  Antonio García  ';

nombre.trim();                  // 'Antonio García' (quita espacios inicio y fin)
nombre.trimStart();             // 'Antonio García  ' (solo inicio)
nombre.trimEnd();               // '  Antonio García' (solo final)
nombre.toUpperCase();           // '  ANTONIO GARCÍA  '
nombre.toLowerCase();           // '  antonio garcía  '
nombre.replace('Antonio', 'A.'); // '  A. García  ' (primera ocurrencia)
nombre.replaceAll('a', '@');    // '  Antonio G@rcí@  ' (todas las ocurrencias)

replace vs replaceAll: replace('a', 'b') solo reemplaza la primera ocurrencia (a menos que uses regex con flag /g). replaceAll('a', 'b') (ES2021) reemplaza todas sin necesidad de regex.

split y join: de string a array y viceversa

const csv = 'Ana,Carlos,María,Juan';
const array = csv.split(',');           // ['Ana', 'Carlos', 'María', 'Juan']
const deVuelta = array.join(' | ');     // 'Ana | Carlos | María | Juan'

const palabras = 'Una frase cualquiera'.split(' '); // ['Una', 'frase', 'cualquiera']
const letras = 'Hola'.split('');         // ['H', 'o', 'l', 'a']
const limitado = 'a-b-c-d'.split('-', 2); // ['a', 'b'] (límite de 2 elementos)

Métodos de relleno

'7'.padStart(3, '0');            // '007' (rellena al inicio hasta length 3)
'42'.padStart(5);                // '   42' (rellena con espacios por defecto)
'Hola'.padEnd(10, '.');          // 'Hola......' (rellena al final)

Template literals avanzados

// Interpolación de cualquier expresión (no solo variables)
const a = 5, b = 10;
console.log(`Suma: ${a + b}, ¿es mayor? ${a > b}`);

// Anidamiento de template literals
const condicion = true;
console.log(`Estado: ${condicion ? `✅ Activo` : `❌ Inactivo`}`);

// Tagged templates: funciones que procesan template literals
function highlight(strings, ...values) {
  let result = '';
  strings.forEach((str, i) => {
    result += str;
    if (i < values.length) {
      result += `**${values[i]}**`;
    }
  });
  return result;
}

const user = 'Ana', action = 'compró';
console.log(highlight`${user} ${action} un libro`);
// **Ana** **compró** un libro

Comparación de strings

'a' < 'b';            // true (orden lexicográfico)
'Antonio' > 'Ana';    // true ('t' > 'a')
'2' > '10';           // true — ¡cuidado! Comparación lexicográfica: '2' > '1'
2 > 10;               // false — Comparación numérica

// Comparación insensible a mayúsculas y acentos
'Antonio'.localeCompare('antonio', 'es', { sensitivity: 'base' }); // 0 (igual)

3 · Ejemplo mínimo

Todas las operaciones esenciales con strings en un solo vistazo:

const raw = '  Bienvenido a JavaScript ES2025!  ';

// 1. Limpiar
const clean = raw.trim();                // 'Bienvenido a JavaScript ES2025!'

// 2. Verificar
console.log(clean.startsWith('Bien'));   // true
console.log(clean.includes('JavaScript')); // true
console.log(clean.endsWith('!'));       // true

// 3. Transformar
console.log(clean.toUpperCase());        // 'BIENVENIDO A JAVASCRIPT ES2025!'

// 4. Extraer
console.log(clean.slice(0, 10));         // 'Bienvenido'

// 5. Reemplazar
console.log(clean.replace('ES2025', 'ES2026'));

// 6. Dividir y reconstruir
const partes = clean.split(' ');
console.log(partes.join('-')); // 'Bienvenido-a-JavaScript-ES2025!'

4 · Ejemplo real

Sanitizador de nombres de archivo y generador de slugs para URLs:

// Utilidad para convertir títulos en slugs de URL y nombres de archivo seguros
function createSlug(title) {
  return title
    .toLowerCase()                        // Todo a minúsculas
    .trim()                               // Quitar espacios de los extremos
    .replaceAll(' ', '-')                 // Espacios → guiones
    .replaceAll(/[^a-z0-9-]/g, '')        // Eliminar caracteres no válidos (regex)
    .replaceAll(/--+/g, '-')              // Múltiples guiones → uno solo
    .replace(/^-|-$/g, '');              // Quitar guiones al inicio y final
}

function formatFileSize(bytes) {
  if (bytes === 0) return '0 Bytes';
  const units = ['Bytes', 'KB', 'MB', 'GB'];
  const i = Math.floor(Math.log(bytes) / Math.log(1024));
  const size = (bytes / Math.pow(1024, i)).toFixed(1);
  return `${size} ${units[i]}`;           // Template literal para formatear
}

function truncateText(text, maxLength = 50) {
  return text.length <= maxLength
    ? text
    : text.slice(0, maxLength - 3).trimEnd() + '...';
}

// Uso
const titulo = '¡10 Consejos para Aprender JavaScript en 2026!';
console.log(createSlug(titulo));     // '10-consejos-para-aprender-javascript-en-2026'
console.log(formatFileSize(1536000)); // '1.5 MB'
console.log(truncateText('Un texto muy largo que necesita ser recortado para caber en la UI', 40));
// 'Un texto muy largo que necesita ser rec...'

6 · Errores habituales

Comparar strings sin normalizar

// ❌ Comparación ingenua: sensible a mayúsculas y espacios
const input = ' Admin ';
console.log(input === 'admin'); // false (mayúsculas + espacios)

// ✅ Normalizar antes de comparar
console.log(input.trim().toLowerCase() === 'admin'); // true

Olvidar que replace() solo reemplaza la primera ocurrencia

// ❌ Bug: solo se reemplaza el primer guión
const slug = 'mi-titulo-con-varios-guiones'.replace('-', '_');
console.log(slug); // 'mi_titulo-con-varios-guiones' (solo el primero)

// ✅ replaceAll reemplaza todas las ocurrencias
console.log('mi-titulo-con-varios-guiones'.replaceAll('-', '_'));
// 'mi_titulo_con_varios_guiones'

Usar comparación lexicográfica para números en strings

// ❌ Comparar strings que contienen números
console.log('10' > '2');   // false ('1' < '2' en orden lexicográfico)
console.log('10' < '2');   // true (INCORRECTO para comparación numérica)

// ✅ Convierte a número antes de comparar
console.log(Number('10') > Number('2')); // true (CORRECTO)

No escapar correctamente en strings con comillas anidadas

// ❌ Mezclar tipos de comillas sin escapar
// const html = '<div class='container'>'; // SyntaxError

// ✅ Usar el otro tipo de comilla o escapar
const html = '<div class="container">';    // Comillas dobles dentro de simples
const html2 = "<div class='container'>";   // Comillas simples dentro de dobles
const html3 = '<div class=\'container\'>'; // Escapando

// ✅ Template literal: la opción más limpia
const html4 = `<div class="container">`;

7 · Ejercicio guiado

Objetivo: Construir un formateador de nombres de persona.

  1. Paso 1 — Entrada sin procesar: 
    const rawName = '  maría  josé  garcía-lópez  ';
  2. Paso 2 — Limpiar espacios múltiples: 
    const clean = rawName.trim().replaceAll(/\s+/g, ' ');
// 'maría josé garcía-lópez'
  3. Paso 3 — Capitalizar cada palabra: 
    function capitalizeWords(str) {
  return str
    .split(' ')
    .map(word => word.charAt(0).toUpperCase() + word.slice(1).toLowerCase())
    .join(' ');
}

const formatted = capitalizeWords(clean);
// 'María José García-lópez'
  4. Paso 4 — Corregir apellidos compuestos: 
    function fixCompoundSurnames(str) {
  return str
    .replaceAll('-', '###')   // Temporalmente marcamos los guiones
    .split(' ')
    .map(part => part.includes('###')
      ? part.split('###').map(p =>
          p.charAt(0).toUpperCase() + p.slice(1).toLowerCase()
        ).join('-')
      : part
    )
    .join(' ');
}

console.log(fixCompoundSurnames(formatted)); // 'María José García-López'
  5. Paso 5 — Versión final unificada: Combina todo en una función formatName(rawName) y pruébala con diferentes entradas: ' JUAN PABLO ' , 'álvaro de la torre'.

8 · Reto

🎯 Generador de contraseñas legibles

Crea una función generatePassword(words, numbers, symbols) que genere contraseñas basadas en parámetros:

  1. words: array de palabras en minúsculas (ej: ['casa', 'perro', 'azul']).
  2. Elige 2 o 3 palabras aleatorias del array.
  3. Capitaliza la primera letra de cada palabra.
  4. Une las palabras con un símbolo aleatorio (-, _, ., !).
  5. Añade al final numbers dígitos aleatorios (ej: 2 dígitos → '42').
  6. Añade al final symbols caracteres especiales aleatorios.
  7. Usa solo métodos de string vistos en esta lección. Nada de arrays (excepto los necesarios para elegir palabras).

Ejemplo: generatePassword(['casa', 'perro', 'azul', 'montaña', 'rio'], 2, 1) podría generar 'Rio!Casa42#'.

9 · Resumen

  • Creación: comillas simples ('), dobles (") o backticks (`). La comunidad prefiere simples.
  • Template literals (``) permiten interpolación con ${}, strings multilínea y tagged templates.
  • Búsqueda: indexOf, includes, startsWith, endsWith, length.
  • Extracción: slice(inicio, fin) — soporta índices negativos. Evita substr() (deprecated).
  • Transformación: trim, toUpperCase, toLowerCase, replace, replaceAll, padStart, padEnd.
  • split/join: convierten entre strings y arrays. split('') descompone en caracteres.
  • Comparación: normaliza con .trim().toLowerCase() antes de comparar. Cuidado con comparaciones lexicográficas de números.

10 · Preguntas frecuentes

¿Comillas simples o dobles? ¿Cuál es el estándar?

No hay un estándar absoluto. Prettier por defecto usa dobles. Airbnb Style Guide prefiere simples. La mayoría de la comunidad JS moderna usa simples por dos razones: (1) el HTML usa dobles, así que evitas escapar; (2) requieren menos tecleo (no necesitas Shift). Elige una y sé consistente en todo tu proyecto. Usa Prettier para no tener que pensar en esto.

¿Cuál es la diferencia entre slice y substring?

slice() acepta índices negativos (cuenta desde el final). substring() trata los índices negativos como 0. Además, si el índice de inicio es mayor que el final, substring() los intercambia, mientras que slice() devuelve string vacío. En código moderno, usa siempre slice().

¿Puedo modificar un carácter de un string directamente?

No. Los strings en JavaScript son inmutables. str[0] = 'X' no hace nada (no lanza error, pero no modifica el string). Para «cambiar» un carácter, debes crear un nuevo string: str.slice(0, 3) + 'X' + str.slice(4).

¿Qué son los tagged templates y para qué sirven?

Un tagged template es una función que se coloca delante de un template literal. La función recibe las partes estáticas del string y los valores interpolados por separado, permitiendo procesarlos. Se usan en librerías como styled-components (CSS-in-JS), GraphQL (consultas), y para sanitización automática (evitar XSS escapando HTML). Es una característica avanzada pero poderosa.

¿Cómo manejo caracteres Unicode y emojis correctamente?

Algunos caracteres Unicode (como ciertos emojis) ocupan dos posiciones en el índice del string (son «surrogate pairs»). '👨‍👩‍👧‍👦'.length es 11, no 1. Para iterar correctamente sobre caracteres Unicode, usa for...of: for (const char of 'Hola 👋') itera carácter por carácter, no por code unit. O usa Array.from(str) para obtener un array de caracteres reales.
