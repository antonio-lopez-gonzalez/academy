Qué es JavaScript

Módulo 0 · Preparación ⏱ 30 minutos

1 · Introducción

JavaScript es el lenguaje de programación que hizo posible la web interactiva que conoces hoy. Sin él, cada página web sería un documento estático: sin botones que respondan, sin animaciones, sin formularios que validen datos al vuelo, sin aplicaciones completas ejecutándose dentro del navegador.

En esta lección conocerás de dónde viene JavaScript, por qué se llama así, cómo ha evolucionado desde un «juguete» de 10 días hasta convertirse en el lenguaje más ubicuo del planeta, y por qué aprenderlo en 2026 es una de las mejores decisiones profesionales que puedes tomar.

¿Por qué existe esta lección? Porque entender el origen y la filosofía de un lenguaje te da perspectiva. No es lo mismo memorizar sintaxis que comprender por qué las cosas son como son. Cuando sepas la historia detrás de var, de la asincronía o de los módulos, cada concepto técnico encajará de forma natural.

2 · Teoría

El nacimiento de JavaScript (1995)

Corre el año 1995. La web es joven — apenas 4 años desde que Tim Berners-Lee creó el primer sitio. El navegador dominante es Netscape Navigator, y las páginas web son completamente estáticas. Netscape quiere añadir interactividad y contrata a Brendan Eich para crear un lenguaje de scripting para el navegador.

Eich lo hace en 10 días. El lenguaje se llama primero Mocha, luego LiveScript, y finalmente JavaScript — un nombre de marketing para aprovechar el tirón de Java, que estaba de moda. Pero JavaScript no tiene nada que ver con Java: son lenguajes completamente distintos.

Analogía: Java y JavaScript se parecen como «car» y «carpet» en inglés. Comparten letras, pero uno es un vehículo y el otro una alfombra. La similitud del nombre fue una decisión de marketing, no técnica.

ECMAScript: el estándar

En 1996, Microsoft crea su propio dialecto (JScript) para Internet Explorer. Para evitar una guerra de navegadores fragmentada, Netscape entrega JavaScript a Ecma International para estandarizarlo. Nace ECMAScript (ES).

El nombre oficial del lenguaje es ECMAScript. JavaScript es la implementación comercial. En la práctica, ambos términos se usan indistintamente.

Dónde se ejecuta JavaScript

JavaScript nació para el navegador, pero hoy está en todas partes:

  • Navegadores: Chrome (motor V8), Firefox (SpiderMonkey), Safari (JavaScriptCore). Cada pestaña es un entorno JS independiente.
  • Servidores: Node.js (2009) usa el motor V8 de Chrome para ejecutar JS fuera del navegador. Permite crear APIs, servicios, herramientas CLI.
  • Aplicaciones de escritorio: Electron (VS Code, Slack, Discord, Figma) empaqueta Chromium + Node.js.
  • Aplicaciones móviles: React Native, NativeScript, Ionic.
  • Dispositivos IoT: Johnny-Five, Espruino.
  • Bases de datos: MongoDB usa JS como lenguaje de consulta.

Dato clave: JavaScript es el único lenguaje que puede ejecutarse de forma nativa en todos los navegadores del mundo sin plugins. Esta ubicuidad es su superpoder.

Qué NO es JavaScript

  • No es Java. Distinto lenguaje, distinta filosofía, distinto ecosistema.
  • No es solo para la web. Con Node.js haces backend, scripts, herramientas.
  • No es un lenguaje «de juguete». Netflix, PayPal, LinkedIn, Uber y WhatsApp usan Node.js en producción.
  • No es TypeScript. TypeScript es un superset que añade tipos estáticos. Compila a JavaScript.

¿Por qué aprender JavaScript en 2026?

  1. Stack completo. Con un solo lenguaje haces frontend y backend.
  2. Ecosistema gigante. pnpm/npm tiene más de 2 millones de paquetes. Hay librerías para absolutamente todo.
  3. Demanda laboral. Es el lenguaje más demandado año tras año en encuestas como Stack Overflow.
  4. Comunidad enorme. Nunca estarás solo: hay tutoriales, foros, conferencias y meetups en cada ciudad.
  5. Está en todas partes. Una vez que sabes JS, puedes hacer webs, apps, servidores, bots, extensiones, scripts, automatizaciones...

3 · Ejemplo mínimo

Abre las DevTools de tu navegador (F12), ve a la pestaña Console y escribe esto:

// Este es tu primer programa JavaScript
console.log('Hola, JavaScript!');

// JavaScript puede hacer operaciones matemáticas directamente
console.log(2 + 2); // 4

// Y manipular texto
console.log('JavaScript'.toUpperCase()); // "JAVASCRIPT"

En solo 3 líneas has saludado al mundo, sumado números y transformado texto. JavaScript se ejecuta línea por línea (es un lenguaje interpretado), lo que significa que ves el resultado inmediatamente. Esta inmediatez es una de las razones por las que aprender JS es tan gratificante: feedback instantáneo.

4 · Ejemplo real

Imagina que trabajas en una plataforma de cursos online. Necesitas un script que calcule el progreso de un estudiante. Esto es JavaScript real:

// Datos del estudiante (simulados, en producción vendrían de una API)
const estudiante = {
  nombre: 'María',
  cursos: [
    { titulo: 'JavaScript Básico', completado: true, lecciones: 10 },
    { titulo: 'JavaScript Avanzado', completado: false, lecciones: 15 },
    { titulo: 'React', completado: false, lecciones: 20 }
  ]
};

// Calcular progreso total
function calcularProgreso(estudiante) {
  const cursosCompletados = estudiante.cursos.filter(c => c.completado).length;
  const totalCursos = estudiante.cursos.length;
  const totalLecciones = estudiante.cursos.reduce((sum, c) => sum + c.lecciones, 0);

  console.log(`Estudiante: ${estudiante.nombre}`);
  console.log(`Cursos completados: ${cursosCompletados} de ${totalCursos}`);
  console.log(`Total de lecciones: ${totalLecciones}`);
}

calcularProgreso(estudiante);

Al ejecutarlo en la consola verás el resumen del progreso. Este patrón — tomar datos, procesarlos y mostrar resultados — es el corazón del 90% de las aplicaciones JavaScript que escriben los profesionales cada día.

6 · Errores habituales

Creer que JavaScript y Java son lo mismo

// ❌ Pensar que la sintaxis de Java funciona en JavaScript
// No puedes declarar tipos así en JS:
// String nombre = "Ana";  ← Esto NO es JavaScript
// int edad = 25;          ← Esto NO es JavaScript

// ✅ JavaScript tiene tipado dinámico
const nombre = 'Ana';
let edad = 25;

Confundir JavaScript del navegador con Node.js

// ❌ Intentar usar APIs del navegador en Node.js
// Si ejecutas esto en Node.js fallará porque 'window' no existe
// window.alert('Hola'); // ReferenceError: window is not defined

// ✅ En Node.js usa console.log
console.log('Hola desde Node.js');

Asumir que JavaScript es un lenguaje completo como Java o C#

JavaScript es un lenguaje multiparadigma (soporta programación orientada a objetos, funcional e imperativa). Tiene un sistema de tipos dinámico muy flexible. No intentes escribir JavaScript como si fuera Java: abraza su naturaleza dinámica y aprende sus patrones propios.

// ❌ Patrón Java en JavaScript (over-engineering)
class Calculadora {
  sumar(a, b) {
    return a + b;
  }
}
const calc = new Calculadora();
calc.sumar(2, 3);

// ✅ Patrón JavaScript natural (simple y directo)
const sumar = (a, b) => a + b;
sumar(2, 3);

9 · Resumen

  • JavaScript fue creado por Brendan Eich en 1995 en 10 días para Netscape.
  • El nombre «JavaScript» fue marketing; no tiene relación con Java.
  • ECMAScript es el estándar oficial; JavaScript es la implementación.
  • Desde ES6 (2015) se publica una nueva versión cada año.
  • JavaScript se ejecuta en navegadores, servidores (Node.js), apps de escritorio (Electron) y móviles.
  • Es el único lenguaje nativo de los navegadores y el más demandado del mundo.
  • Aprender JavaScript te permite ser full-stack con un solo lenguaje.

10 · Preguntas frecuentes

¿Necesito saber programar antes de aprender JavaScript?

No es obligatorio, pero ayuda. Este curso asume que sabes programar (variables, bucles, funciones) y se centra en las particularidades de JavaScript. Si no has programado nunca, te recomiendo primero un curso de introducción a la programación.

¿Por qué se llama ECMAScript y no simplemente JavaScript?

JavaScript es una marca registrada de Oracle (que compró Sun Microsystems). El estándar no puede usar ese nombre por razones legales, así que se llama ECMAScript. En la práctica, todos decimos JavaScript.

¿Debería aprender TypeScript en vez de JavaScript?

TypeScript es JavaScript con tipos. Para entender TypeScript necesitas entender JavaScript primero. Este curso te da las bases sólidas de JS; después, añadir TypeScript será mucho más fácil.

¿Vale la pena aprender JavaScript en 2026 con tantos frameworks nuevos?

Sí, absolutamente. Los frameworks (React, Vue, Svelte, Astro, Next.js) están construidos sobre JavaScript. Si entiendes bien JS vanilla, puedes aprender cualquier framework en días. Si solo sabes un framework sin entender JS, eres dependiente de él.

¿Cuánto tiempo se tarda en dominar JavaScript?

Depende de tu dedicación y experiencia previa. Un desarrollador con bases de programación puede ser productivo en 1-2 meses y dominar los conceptos avanzados en 6-12 meses. La clave es la constancia diaria y construir proyectos reales, no solo leer teoría.
